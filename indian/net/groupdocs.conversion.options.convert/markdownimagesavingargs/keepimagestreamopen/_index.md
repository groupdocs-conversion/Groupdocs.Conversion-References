## MarkdownImageSavingArgs.KeepImageStreamOpen property

जब false (डिफ़ॉल्ट) हो, रूपांतरणकर्ता [`ImageStream`](../imagestream) को लिखने के बाद बंद कर देता है — यह FileStream प्रतिस्थापनों के लिए सामान्य है जिन्हें डिस्क पर फ्लश किया जाना चाहिए। true सेट करने पर रूपांतरण पूर्ण होने के बाद स्ट्रीम खुला रहता है (आमतौर पर MemoryStream के लिए जिसे आप स्वयं पढ़ना चाहते हैं); कॉलर तब निपटान का जिम्मेदार होता है।

```csharp
public bool KeepImageStreamOpen { get; set; }
```
