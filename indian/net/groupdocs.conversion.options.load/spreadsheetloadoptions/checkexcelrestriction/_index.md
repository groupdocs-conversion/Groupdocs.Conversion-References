## SpreadsheetLoadOptions.CheckExcelRestriction property

जब उपयोगकर्ता कोशिकाओं से संबंधित वस्तुओं को संशोधित करता है तो एक्सेल फ़ाइल की प्रतिबंधों की जाँच करें या नहीं। उदाहरण के लिए, एक्सेल 32K से अधिक लंबा स्ट्रिंग मान इनपुट करने की अनुमति नहीं देता। यदि आप 32K से अधिक मान इनपुट करते हैं और यह प्रॉपर्टी true है, तो आपको एक Exception मिलेगा। यदि यह प्रॉपर्टी false है, तो हम आपके इनपुट स्ट्रिंग मान को सेल के मान के रूप में स्वीकार करेंगे ताकि बाद में आप CSV जैसे अन्य फ़ाइल फ़ॉर्मेट के लिए पूर्ण स्ट्रिंग मान आउटपुट कर सकें। हालांकि, यदि आपने ऐसा मान सेट किया है जो एक्सेल फ़ाइल फ़ॉर्मेट के लिए अमान्य है, तो आपको बाद में वर्कबुक को एक्सेल फ़ाइल फ़ॉर्मेट में सहेजना नहीं चाहिए। अन्यथा उत्पन्न एक्सेल फ़ाइल में अप्रत्याशित त्रुटि हो सकती है।

public bool CheckExcelRestriction { get; set; }
