## TxtLoadOptions.DetectNumberingWithWhitespaces property

प्लेन टेक्स्ट दस्तावेज़ के रूपांतरण के समय क्रमांकित सूची आइटम कैसे पहचाने जाते हैं, इसे निर्दिष्ट करने की अनुमति देता है। डिफ़ॉल्ट मान true है।

```csharp
public bool DetectNumberingWithWhitespaces { get; set; }
```

### टिप्पणियाँ

यदि यह विकल्प false पर सेट किया जाता है, तो सूची पहचान एल्गोरिद्म सूची पैराग्राफ़ का पता लगाता है, जब सूची संख्याएँ डॉट, राइट ब्रैकेट या बुलेट प्रतीकों (जैसे "•", "*", "-" या "o") में समाप्त होती हैं।

यदि यह विकल्प true पर सेट किया जाता है, तो व्हाइटस्पेस को भी सूची संख्या विभाजक के रूप में उपयोग किया जाता है: अरबी शैली की क्रमांकन (1., 1.1.2.) के लिए सूची पहचान एल्गोरिद्म व्हाइटस्पेस और डॉट (".") दोनों प्रतीकों का उपयोग करता है।
