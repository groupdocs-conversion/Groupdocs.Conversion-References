### Svg {#Svg}
```
public static final PageDescriptionLanguageFileType Svg
```


एक SVG फ़ाइल एक Scalar Vector Graphics फ़ाइल है जो छवि की उपस्थिति का वर्णन करने के लिए XML‑आधारित टेक्स्ट फ़ॉर्मेट का उपयोग करती है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://wiki.fileformat.com/page-description-language/svg) देखें।


### Eps {#Eps}
```
public static final PageDescriptionLanguageFileType Eps
```


EPS एक्सटेंशन वाली फ़ाइलें मूलतः एक Encapsulated PostScript भाषा प्रोग्राम को वर्णित करती हैं जो एक पृष्ठ की उपस्थिति का विवरण देती है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://wiki.fileformat.com/page-description-language/eps) देखें।


### Cgm {#Cgm}
```
public static final PageDescriptionLanguageFileType Cgm
```


Computer Graphics Metafile (CGM) एक मुफ्त, प्लेटफ़ॉर्म‑स्वतंत्र, अंतर्राष्ट्रीय मानक मेटाफाइल फ़ॉर्मेट है जो वेक्टर ग्राफ़िक्स (2D), रास्टर ग्राफ़िक्स और टेक्स्ट को संग्रहित और आदान‑प्रदान करने के लिए उपयोग होता है। CGM ऑब्जेक्ट‑ओरिएंटेड दृष्टिकोण और छवि उत्पादन के लिए कई फ़ंक्शन प्रावधानों का उपयोग करता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://wiki.fileformat.com/page-description-language/cgm) देखें।


### Xps {#Xps}
```
public static final PageDescriptionLanguageFileType Xps
```


एक XPS फ़ाइल पृष्ठ लेआउट फ़ाइलों को दर्शाती है जो Microsoft द्वारा निर्मित XML Paper Specifications पर आधारित हैं। यह फ़ॉर्मेट Microsoft द्वारा EMF फ़ाइल फ़ॉर्मेट के विकल्प के रूप में विकसित किया गया था और PDF फ़ाइल फ़ॉर्मेट के समान है, लेकिन दस्तावेज़ के लेआउट, उपस्थिति और प्रिंटिंग जानकारी में XML का उपयोग करता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://wiki.fileformat.com/page-description-language/xps) देखें।


### Tex {#Tex}
```
public static final PageDescriptionLanguageFileType Tex
```


TeX एक भाषा है जो प्रोग्रामिंग और मार्क‑अप सुविधाओं दोनों को सम्मिलित करती है, जिसका उपयोग दस्तावेज़ों को टाइपसेट करने के लिए किया जाता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://wiki.fileformat.com/page-description-language/tex) देखें।


### Ps {#Ps}
```
public static final PageDescriptionLanguageFileType Ps
```


PostScript (PS) एक सामान्य‑उद्देश्य पेज विवरण भाषा है जो डेस्कटॉप और इलेक्ट्रॉनिक प्रकाशन के व्यवसाय में उपयोग की जाती है। PostScript (PS) का मुख्य लक्ष्य द्वि‑आयामी ग्राफ़िक डिज़ाइन को सुगम बनाना है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://wiki.fileformat.com/page-description-language/ps) देखें।


### Pcl {#Pcl}
```
public static final PageDescriptionLanguageFileType Pcl
```


PCL का अर्थ Printer Command Language है, जो Hewlett Packard (HP) द्वारा प्रस्तुत एक पेज विवरण भाषा है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://wiki.fileformat.com/page-description-language/pcl) देखें।


### Oxps {#Oxps}
```
public static final PageDescriptionLanguageFileType Oxps
```


फ़ाइल फ़ॉर्मेट OXPS को Open XML Paper Specification के रूप में जाना जाता है। यह एक पेज विवरण भाषा और दस्तावेज़ फ़ॉर्मेट है। Microsoft इस फ़ॉर्मेट का डेवलपर है। OXPS फ़ाइल फ़ॉर्मेट PDF फ़ाइलों से बहुत समान है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://docs.fileformat.com/page-description-language/oxps) देखें।
