### Ppt {#Ppt}
```
public static final PresentationFileType Ppt
```


PPT एक्सटेंशन वाली फ़ाइल PowerPoint फ़ाइल को दर्शाती है जिसमें स्लाइडशो के रूप में प्रदर्शित करने के लिए स्लाइड्स का संग्रह होता है। यह Microsoft PowerPoint 97-2003 द्वारा उपयोग किए जाने वाले बाइनरी फ़ाइल फ़ॉर्मेट को निर्दिष्ट करती है।
इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें [यहाँ](../https://wiki.fileformat.com/presentation/ppt).


### Pps {#Pps}
```

```


PPS, PowerPoint स्लाइड शो, फ़ाइलें Microsoft PowerPoint का उपयोग करके स्लाइड शो के उद्देश्य से बनाई जाती हैं। PPS फ़ाइल पढ़ना और बनाना Microsoft PowerPoint 97-2003 द्वारा समर्थित है।
इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें [यहाँ](../https://wiki.fileformat.com/presentation/pps).

PPTX एक्सटेंशन वाली फ़ाइलें लोकप्रिय Microsoft PowerPoint एप्लिकेशन से बनाई गई प्रेजेंटेशन फ़ाइलें हैं। पहले के प्रेजेंटेशन फ़ाइल फ़ॉर्मेट PPT, जो बाइनरी था, के विपरीत, PPTX फ़ॉर्मेट Microsoft PowerPoint ओपन XML प्रेजेंटेशन फ़ाइल फ़ॉर्मेट पर आधारित है।
इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें [यहाँ](../https://wiki.fileformat.com/presentation/pptx).
