### Mp4 {#Mp4}
```
public static final VideoFileType Mp4
```


MP4 (MPEG-4 पार्ट 14 का संक्षिप्त रूप) एक फ़ाइल फ़ॉर्मेट है जो ISO/IEC 14496-12:2004 पर आधारित है और QuickTime फ़ाइल फ़ॉर्मेट पर निर्मित है, लेकिन औपचारिक रूप से Initial Object Descriptors (IOD) और अन्य MPEG विशेषताओं के समर्थन को निर्दिष्ट करता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें [यहाँ](../https://docs.fileformat.com/video/mp4/).


### Avi {#Avi}
```
public static final VideoFileType Avi
```


AVI फ़ाइल फ़ॉर्मेट एक ऑडियो-वीडियो मल्टीमीडिया कंटेनर फ़ाइल फ़ॉर्मेट है जिसे Microsoft ने प्रस्तुत किया था। यह कई कोडेक (कोडर/डिकोडर) जैसे XVid और DivX का उपयोग करके निर्मित और संकुचित ऑडियो और वीडियो डेटा को रखता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें [यहाँ](../https://docs.fileformat.com/video/avi/).


### Flv {#Flv}
```
public static final VideoFileType Flv
```


FLV (Flash Video) एक कंटेनर फ़ाइल फ़ॉर्मेट है जिसमें .flv एक्सटेंशन है। FLV का उपयोग इंटरनेट पर ऑडियो/वीडियो सामग्री प्रदान करने के लिए Adobe Flash Player या Adobe Air द्वारा किया जाता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://docs.fileformat.com/video/flv/)।


### Mkv {#Mkv}
```
public static final VideoFileType Mkv
```


MKV (Matroska Video) एक मल्टीमीडिया कंटेनर है जो MOV और AVI फ़ॉर्मेट के समान है, लेकिन यह एक ही फ़ाइल में एक से अधिक ऑडियो और सबटाइटल ट्रैक का समर्थन करता है। एक MKV फ़ाइल वीडियो के लिए उपयोग किया जाने वाला Matroska मल्टीमीडिया कंटेनर फ़ॉर्मेट है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://docs.fileformat.com/video/mkv/)।


### Mov {#Mov}
```
public static final VideoFileType Mov
```


MOV या QuickTime फ़ाइल फ़ॉर्मेट एक मल्टीमीडिया कंटेनर है जिसे Apple ने विकसित किया है: इसमें एक या अधिक ट्रैक होते हैं, प्रत्येक ट्रैक एक विशिष्ट प्रकार का डेटा रखता है जैसे कि वीडियो, ऑडियो, टेक्स्ट, आदि। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://docs.fileformat.com/video/mov/)।


### Webm {#Webm}
```
public static final VideoFileType Webm
```


.webm एक्सटेंशन वाली फ़ाइल एक वीडियो फ़ाइल है जो ओपन, रॉयल्टी-फ़्री WebM फ़ाइल फ़ॉर्मेट पर आधारित है। इसे वेब पर वीडियो साझा करने के लिए डिज़ाइन किया गया है और यह वीडियो और ऑडियो फ़ॉर्मेट सहित फ़ाइल कंटेनर संरचना को परिभाषित करता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://docs.fileformat.com/video/webm//)।


### Wmv {#Wmv}
```
public static final VideoFileType Wmv
```


Windows Media Video माइक्रोसॉफ्ट द्वारा विकसित संकुचित वीडियो फ़ॉर्मेट है। मोशन पिक्चर एंड टेलीविज़न इंजीनियर्स सोसाइटी (SMPTE) द्वारा मानकीकरण के बाद, WMV अब एक ओपन स्टैंडर्ड फ़ॉर्मेट माना जाता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए [यहाँ](../https://docs.fileformat.com/video/wmv/)।
