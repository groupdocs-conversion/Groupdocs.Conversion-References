निर्दिष्ट मार्जिन हटाकर वर्तमान rectangle का क्रॉप किया हुआ संस्करण बनाता है।

```python
def crop(self, crop_left, crop_top, crop_right, crop_bottom):
    ...
```

| पैरामीटर | प्रकार | विवरण |
| :- | :- | :- |
| crop_left | `int` | बाएँ पक्ष से हटाने के लिए पिक्सेल की संख्या। |
| crop_top | `int` | ऊपर पक्ष से हटाने के लिए पिक्सेल की संख्या। |
| crop_right | `int` | दाएँ पक्ष से हटाने के लिए पिक्सेल की संख्या। |
| crop_bottom | `int` | नीचे पक्ष से हटाने के लिए पिक्सेल की संख्या। |
