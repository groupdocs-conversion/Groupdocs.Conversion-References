## Metered class

मीटरड (प्रति-उपयोग भुगतान) लाइसेंसिंग का प्रबंधन करता है।

Metered लाइसेंस वास्तविक उपभोग (आमतौर पर पृष्ठों या
दस्तावेज़ प्रोसेस किए गए)। सार्वजनिक/निजी कुंजी जोड़ी को एक बार सेट करें
एप्लिकेशन स्टार्टअप पर; रैपर उपयोग को GroupDocs को वापस रिपोर्ट करता है
पृष्ठभूमि में लाइसेंस सर्वर।

Metered प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:

### विधियाँ
| विधि | विवरण |
| :- | :- |
| [get_consumption_credit](/conversion/python-net/groupdocs.conversion/metered/get_consumption_credit/) | वर्तमान कुंजी के लिए शेष मीटरेड क्रेडिट लौटाएँ। |
| [get_consumption_quantity](/conversion/python-net/groupdocs.conversion/metered/get_consumption_quantity/) | अब तक उपभोग की गई कुल मीटरेड मात्रा लौटाएँ। |
| [set_metered_key](/conversion/python-net/groupdocs.conversion/metered/set_metered_key/#public_key-private_key) | दिए गए सार्वजनिक/निजी कुंजी जोड़ी के साथ मीटरेड बिलिंग सक्रिय करें। |
