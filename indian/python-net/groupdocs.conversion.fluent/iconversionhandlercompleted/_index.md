## IConversionHandlerCompleted class

`OnConversionFailed` सेट होने के बाद सहज इंटरफ़ेस को दर्शाता है, जिससे `OnConversionCompleted` सेट करने या `Convert`/`Compress` पर आगे बढ़ने की अनुमति मिलती है।

IConversionHandlerCompleted प्रकार निम्नलिखित सदस्य उजागर करता है:

### विधियाँ
| विधि | विवरण |
| :- | :- |
| [compress](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/compress/#options) | परिवर्तन परिणामों को संपीड़ित करता है और एक निरंतरता लौटाता है जो `Convert` की ओर आगे बढ़ती है। |
| [compress_compression_convert_options](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/compress_compression_convert_options/) |  |
| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/convert/) | परिवर्तन श्रृंखला को निष्पादित करें। |
| [on_conversion_completed](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/on_conversion_completed/#on_completed) | जब दस्तावेज़ रूपांतरण सफलतापूर्वक पूर्ण हो जाए तो कॉलबैक को पंजीकृत करता है। |
| [on_conversion_completed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/on_conversion_completed_action/) |  |
| [on_conversion_failed](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/on_conversion_failed/#on_failed) | जब दस्तावेज़ परिवर्तन विफल हो तो बुलाए जाने वाले कॉलबैक को पंजीकृत करता है। पुनः‑बुलाने से पहले सेट किए गए हैंडलर को बदल दिया जाता है। |
