## IConversionCompressResultCompletedOrConvert class

`Compress(...)` के बाद निरंतरता। सीधे `Convert` के साथ आगे बढ़ें; विरासत में मिला [`IConversionCompressResultCompleted.OnCompressionCompleted`](/conversion/python-net/groupdocs.conversion.fluent/iconversioncompressresultcompleted/on_compression_completed/) अब अप्रचलित है — इसके बजाय प्रवेश चरण में [`IConversionSettings.WithEvents`](/conversion/python-net/groupdocs.conversion.fluent/iconversionsettings/with_events/) के माध्यम से हैंडलर पंजीकृत करें।

IConversionCompressResultCompletedOrConvert प्रकार निम्नलिखित सदस्य उजागर करता है:

### विधियाँ
| विधि | विवरण |
| :- | :- |
| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversioncompressresultcompletedorconvert/convert/) | परिवर्तन श्रृंखला को निष्पादित करें। |
| [on_compression_completed](/conversion/python-net/groupdocs.conversion.fluent/iconversioncompressresultcompletedorconvert/on_compression_completed/#compressed_document_stream) | संपीड़ित दस्तावेज़ स्ट्रीम प्राप्त करता है। केवल तभी सक्रिय होगा जब `Compress(CompressionConvertOptions)` सेट किया गया हो। |
| [on_compression_completed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversioncompressresultcompletedorconvert/on_compression_completed_action/) |  |
