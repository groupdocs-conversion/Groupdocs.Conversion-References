## IConversionHandlerOnly class

केवल रूपांतरण हैंडलर्स सेट करने के लिए एक सहज इंटरफ़ेस प्रदान करता है।

`Convert`/`Compress` के लिए [`IConversionHandlersStage`](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlersstage/) को विरासत में लेता है; चरणबद्ध `OnConversion*` ओवरलोड को `new` कीवर्ड के माध्यम से रखा जाता है ताकि मौजूदा रिटर्न टाइप्स और बैक कॉम्पैटिबिलिटी बनी रहे।

IConversionHandlerOnly प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### विधियाँ
| विधि | विवरण |
| :- | :- |
| [compress](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandleronly/compress/#options) | रूपांतरण के परिणामों को संपीड़ित करता है। |
| [compress_compression_convert_options](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandleronly/compress_compression_convert_options/) |  |
| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandleronly/convert/) | परिवर्तन श्रृंखला को निष्पादित करें। |
| [on_conversion_completed](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandleronly/on_conversion_completed/#on_completed) | जब दस्तावेज़ रूपांतरण सफलतापूर्वक पूर्ण हो जाए तो कॉलबैक को पंजीकृत करता है। |
| [on_conversion_completed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandleronly/on_conversion_completed_action/) |  |
| [on_conversion_failed](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandleronly/on_conversion_failed/#on_failed) | जब दस्तावेज़ रूपांतरण विफल हो जाए तो कॉलबैक को पंजीकृत करता है। |
| [on_conversion_failed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandleronly/on_conversion_failed_action/) |  |
