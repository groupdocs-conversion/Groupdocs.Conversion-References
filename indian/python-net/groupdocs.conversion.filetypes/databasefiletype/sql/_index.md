## SQL field

.sql एक्सटेंशन Structured Query Language (SQL) फ़ाइल है जिसमें रिलेशनल डेटाबेस के साथ काम करने के लिए कोड होता है। इसका उपयोग डेटाबेस पर CRUD (Create, Read, Update, and Delete) ऑपरेशन्स के लिए SQL स्टेटमेंट लिखने में किया जाता है। इस फ़ाइल फ़ॉर्मेट के बारे में यहाँ अधिक जानें।
