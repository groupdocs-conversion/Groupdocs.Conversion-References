## WordProcessingFileType class

WordProcessingFileType क्लास Word Processing फ़ाइल फ़ॉर्मेट को परिभाषित करती है, जिसमें साधारण टेक्स्ट और रिच टेक्स्ट वैरिएंट शामिल हैं।

सादा टेक्स्ट फ़ाइलें बिना किसी फ़ॉन्ट या पेज सेटिंग के अनफ़ॉर्मेटेड टेक्स्ट रखती हैं। रिच टेक्स्ट फ़ाइलें फ़ॉर्मेटिंग विकल्पों जैसे फ़ॉन्ट प्रकार, शैलियाँ (बोल्ड, इटैलिक, अंडरलाइन), पेज मार्जिन, हेडिंग्स, बुलेट्स, नंबर और अन्य सुविधाओं का समर्थन करती हैं।

### उदाहरण

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # इनपुट दस्तावेज़ के साथ Converter को इंस्टैंशिएट करें
    with Converter("./business-plan.docx") as converter:
        # कनवर्ट विकल्प निर्धारित करें; डिफ़ॉल्ट आउटपुट फ़ॉर्मेट DOCX है
        word_convert_options = WordProcessingConvertOptions()
        # फ़ॉर्मेट परिवार के भीतर आउटपुट फ़ॉर्मेट को DOCX से TXT में बदलें
        word_convert_options.format = WordProcessingFileType.Txt

        # इनपुट दस्तावेज़ को TXT में कनवर्ट करें
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
