फ़ाइल प्रकार स्थिरांक और फ़ॉर्मेट पहचानकर्ता।

### क्लासेस
| क्लास | विवरण |
| :- | :- |

| [`DatabaseFileType`](/conversion/python-net/groupdocs.conversion.filetypes/databasefiletype/) | डेटाबेस दस्तावेज़ों को परिभाषित करता है। निम्नलिखित फ़ाइल प्रकार शामिल हैं। |

| [`EmailFileType`](/conversion/python-net/groupdocs.conversion.filetypes/emailfiletype/) | ईमेल एप्लिकेशन द्वारा संदेश, अटैचमेंट, फ़ोल्डर, एड्रेस बुक और अन्य डेटा को संग्रहीत करने के लिए उपयोग किए जाने वाले ईमेल फ़ाइल फ़ॉर्मेट्स को परिभाषित करता है। |

| [`FinanceFileType`](/conversion/python-net/groupdocs.conversion.filetypes/financefiletype/) | वित्तीय दस्तावेज़ प्रकारों को परिभाषित करता है। |
| [`FontFileType`](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/) | फ़ॉन्ट दस्तावेज़ प्रकारों को दर्शाता है। |

| [`ImageFileType`](/conversion/python-net/groupdocs.conversion.filetypes/imagefiletype/) | इमेज दस्तावेज़ फ़ाइल प्रकारों को दर्शाता है। |

| [`PageDescriptionLanguageFileType`](/conversion/python-net/groupdocs.conversion.filetypes/pagedescriptionlanguagefiletype/) | पृष्ठ विवरण दस्तावेज़ फ़ाइल प्रकारों को परिभाषित करता है। |
| [`PdfFileType`](/conversion/python-net/groupdocs.conversion.filetypes/pdffiletype/) | PDF दस्तावेज़ों का प्रतिनिधित्व करता है। |

| [`PublisherFileType`](/conversion/python-net/groupdocs.conversion.filetypes/publisherfiletype/) | पब्लिशर दस्तावेज़ों को परिभाषित करता है। |
| [`SpreadsheetFileType`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/) | स्प्रेडशीट दस्तावेज़ों को परिभाषित करता है। |
| [`ThreeDFileType`](/conversion/python-net/groupdocs.conversion.filetypes/threedfiletype/) | 3D दस्तावेज़ों को परिभाषित करता है। |
| [`VideoFileType`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/) | वीडियो दस्तावेज़ प्रकारों का प्रतिनिधित्व करता है। |
| [`WebFileType`](/conversion/python-net/groupdocs.conversion.filetypes/webfiletype/) | वेब दस्तावेज़ फ़ाइल प्रकारों को परिभाषित करता है, जिसमें [`WebFileType.xml`](/conversion/python-net/groupdocs.conversion.filetypes/webfiletype/xml/), [`WebFileType.json`](/conversion/python-net/groupdocs.conversion.filetypes/webfiletype/json/), [`WebFileType.html`](/conversion/python-net/groupdocs.conversion.filetypes/webfiletype/html/), [`WebFileType.htm`](/conversion/python-net/groupdocs.conversion.filetypes/webfiletype/htm/), [`WebFileType.mht`](/conversion/python-net/groupdocs.conversion.filetypes/webfiletype/mht/), [`WebFileType.mhtml`](/conversion/python-net/groupdocs.conversion.filetypes/webfiletype/mhtml/), और [`WebFileType.chm`](/conversion/python-net/groupdocs.conversion.filetypes/webfiletype/chm/) को शामिल करता है। |
| [`WordProcessingFileType`](/conversion/python-net/groupdocs.conversion.filetypes/wordprocessingfiletype/) | WordProcessingFileType क्लास Word Processing फ़ाइल फ़ॉर्मेट को परिभाषित करती है, जिसमें साधारण टेक्स्ट और रिच टेक्स्ट वैरिएंट शामिल हैं। |
