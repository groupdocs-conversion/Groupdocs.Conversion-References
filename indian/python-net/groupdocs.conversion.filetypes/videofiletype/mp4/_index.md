## MP4 field

MP4 (MPEG-4 Part 14 का संक्षिप्त रूप) एक फ़ाइल फ़ॉर्मेट है जो ISO/IEC 14496-12:2004 पर आधारित है और QuickTime File Format पर आधारित है, लेकिन औपचारिक रूप से Initial Object Descriptors (IOD) और अन्य MPEG सुविधाओं के समर्थन को निर्दिष्ट करता है। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानने के लिए यहाँ देखें।
