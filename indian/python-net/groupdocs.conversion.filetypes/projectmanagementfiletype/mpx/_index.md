## MPX field

Microsoft Exchange फ़ाइल फ़ॉर्मेट एक ASCII फ़ाइल फ़ॉर्मेट है जो Microsoft Project (MSP) और अन्य अनुप्रयोगों के बीच प्रोजेक्ट जानकारी के स्थानांतरण के लिए उपयोग होता है, जो MPX फ़ाइल फ़ॉर्मेट का समर्थन करते हैं जैसे Primavera Project Planner, Sciforma और Timerline Precision Estimating। इस फ़ाइल फ़ॉर्मेट के बारे में अधिक जानें यहाँ।
