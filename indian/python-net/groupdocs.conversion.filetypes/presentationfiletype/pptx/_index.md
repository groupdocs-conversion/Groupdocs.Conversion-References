## PPTX field

PPTX एक्सटेंशन वाली फ़ाइलें लोकप्रिय Microsoft PowerPoint एप्लिकेशन से बनाई गई प्रस्तुति फ़ाइलें हैं। पहले संस्करण PPT जो बाइनरी था, उसके विपरीत, PPTX स्वरूप Microsoft PowerPoint ओपन XML प्रस्तुति फ़ाइल स्वरूप पर आधारित है। इस फ़ाइल स्वरूप के बारे में यहाँ अधिक जानें।
