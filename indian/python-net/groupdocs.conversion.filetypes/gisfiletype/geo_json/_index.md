## GEO_JSON field

GeoJSON एक JSON-आधारित फ़ॉर्मेट है जिसे भौगोलिक विशेषताओं को उनके गैर-स्थानिक गुणों के साथ दर्शाने के लिए डिज़ाइन किया गया है। यह फ़ॉर्मेट विभिन्न JSON (JavaScript Object Notation) ऑब्जेक्ट्स और उनके संयोजन को परिभाषित करता है। JSON फ़ॉर्मेट भौगोलिक विशेषताओं, उनके स्थानिक विस्तार और गुणों के बारे में सामूहिक जानकारी प्रस्तुत करता है। इस फ़ाइल फ़ॉर्मेट के बारे में यहाँ अधिक जानें।
