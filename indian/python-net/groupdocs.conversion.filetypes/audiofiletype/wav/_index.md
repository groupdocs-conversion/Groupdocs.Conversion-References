## WAV field

WAV, जिसे WAVE (Waveform Audio File Format) के नाम से जाना जाता है, Microsoft के Resource Interchange File Format (RIFF) विनिर्देश का एक उपसमुच्चय है जो डिजिटल ऑडियो फ़ाइलों को संग्रहीत करने के लिए उपयोग होता है। इस फ़ाइल फ़ॉर्मेट के बारे में यहाँ अधिक जानें।
