## IResourceLoadingOptions class

IResourceLoadingOptions प्रकार निम्नलिखित सदस्यों को उजागर करता है:

### गुणधर्म
| गुण | विवरण |
| :- | :- |
| [skip_external_resources](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/skip_external_resources/) | यह प्रॉपर्टी दर्शाती है कि बाहरी संसाधन लोड किए गए हैं या नहीं। |
| [whitelisted_resources](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/) | वे बाहरी संसाधन जो हमेशा लोड किए जाएंगे। |
