## IConverterListener class

कनवर्टर लिसनिंग करने के लिए उपयोग की जाने वाली विधियों को परिभाषित करता है।

और अधिक जानें।

- More about monitoring conversion progress: https://docs.groupdocs.com/display/conversionnet/Listening

IConverterListener प्रकार निम्नलिखित सदस्यों को प्रदर्शित करता है:

### विधियाँ
| विधि | विवरण |
| :- | :- |
| [completed](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/completed/) | परिवर्तन पूर्ण होने पर बुलाया जाता है। |
| [progress](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress/#current) | परिवर्तन प्रगति बदलने पर प्रत्येक बार बुलाया जाता है। |
| [progress_byte](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress_byte/) |  |
| [started](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/started/) | वास्तविक परिवर्तन शुरू होते ही बुलाया जाता है। |
