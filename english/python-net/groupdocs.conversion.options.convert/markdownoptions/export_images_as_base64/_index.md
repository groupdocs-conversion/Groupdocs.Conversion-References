## export_images_as_base64 property

The export_images_as_base64 option determines whether images are exported as base64.

Default is True. Ignored when [`MarkdownOptions.image_saving_callback`](/conversion/python-net/groupdocs.conversion.options.convert/markdownoptions/image_saving_callback/) is set.
