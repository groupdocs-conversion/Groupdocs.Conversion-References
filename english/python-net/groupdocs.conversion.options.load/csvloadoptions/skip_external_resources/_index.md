## skip_external_resources property

The property indicates whether external resources are loaded. If True, all external resources will not be loaded except those in [`IResourceLoadingOptions.whitelisted_resources`](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/) list. Default: True.
