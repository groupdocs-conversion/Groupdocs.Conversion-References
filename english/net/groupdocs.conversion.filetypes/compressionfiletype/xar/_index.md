## CompressionFileType.Xar field

A file with .xar extension is an eXtensible ARchive, a format built around a table of contents stored as compressed XML. It is used to distribute macOS installer packages and keeps each entry compressed on its own. Learn more about this file format [here](https://docs.fileformat.com/compression/xar/).
