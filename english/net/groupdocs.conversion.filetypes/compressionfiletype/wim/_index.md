## CompressionFileType.Wim field

A file with .wim extension is a Windows Imaging Format archive, a file-based disk image that Microsoft uses to deploy Windows. A single archive holds one or more images and stores each file once, no matter how many images reference it. Learn more about this file format [here](https://docs.fileformat.com/disc-and-media/wim/).
