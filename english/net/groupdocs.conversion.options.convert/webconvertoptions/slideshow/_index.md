## WebConvertOptions.SlideShow property

Applies only to converting a presentation to [`Html`](../../../groupdocs.conversion.filetypes/webfiletype/html) or [`Htm`](../../../groupdocs.conversion.filetypes/webfiletype/htm), and is ignored for every other conversion. Specifies whether the presentation becomes an interactive HTML slideshow with slide transitions and shape animations, instead of the default static HTML page. Default is false.

```csharp
public bool SlideShow { get; set; }
```

### Remarks

The result is a single HTML file with styles, scripts, images, fonts and media inlined. The two JavaScript libraries driving the slideshow are loaded from a CDN, so the page needs an internet connection to animate and navigate.
