## FinanceLoadOptions.ExternalResourceHandler property

Gets or sets the handler called for each resource the document asks an engine to load. Default: `null`.

```csharp
public IExternalResourceHandler ExternalResourceHandler { get; set; }
```

### Remarks

For XBRL and inline XBRL documents the handler is called for each taxonomy reference the document's chain holds while [`SkipExternalResources`](../skipexternalresources) is `true`, except references inside the document. It can skip a reference, which makes the load fail as a denied reference does, but it cannot allow a reference that is denied, and [`Data`](../../externalresourceloadingargs/data) has no effect. While [`SkipExternalResources`](../skipexternalresources) is `false` it is not called. See [`IExternalResourceHandler`](../../iexternalresourcehandler) for the rules.

The handler is copied with the options and kept for every document the operation loads from them. It is not serialized with the options.
