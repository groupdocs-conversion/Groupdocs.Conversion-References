## ThreeDLoadOptions.ExternalResourceHandler property

Gets or sets the handler called for each dependency the 3D document loads, also while it is saved. Default: `null`.

```csharp
public IExternalResourceHandler ExternalResourceHandler { get; set; }
```

### Remarks

The handler sees the decision of [`SkipExternalResources`](../skipexternalresources) and [`WhitelistedResources`](../whitelistedresources) for each dependency and can allow it, skip it or supply its content. Dependencies are read as local files only, so allowing a remote dependency does not load it; supply its content through [`Data`](../../externalresourceloadingargs/data) instead. See [`IExternalResourceHandler`](../../iexternalresourcehandler) for the rules.

The handler is copied with the options and kept for every document the operation loads from them. It is not serialized with the options.
