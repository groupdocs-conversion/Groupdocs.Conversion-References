## SvgLoadOptions.ExecuteScripts property

Gets or sets whether the document's scripts run while it loads and converts. Default: `false`.

```csharp
public bool ExecuteScripts { get; set; }
```

### Remarks

When `false`, no script runs, inline or external, and no external script file is requested, whatever [`SkipExternalResources`](../skipexternalresources) is set to. Content a script would generate is absent from the output.

When `true`, inline scripts run, and an external script file is a resource like any other: it loads only as [`SkipExternalResources`](../skipexternalresources) and [`WhitelistedResources`](../whitelistedresources) allow. Turn it on only for documents you trust.
