Gets the location of the resource as the engine is about to load it.

```csharp
public string Uri { get; }
```

### Remarks

For word processing, presentation, HTML and SVG documents it is usually already resolved against the document's base, so it is the URL that would be requested. For other formats it is the reference as the document carries it, so it can be relative.
