## ExternalResourceLoadingArgs.Data property

Gets or sets the content to use instead of loading the resource. An empty array supplies empty content.

```csharp
public byte[] Data { get; set; }
```

### Remarks

When set and [`Skipped`](../skipped) is `false`, the engine receives exactly these bytes and nothing is requested. For some formats, such as XSL-FO, XBRL, SVG converted to XPS or a spreadsheet, and images in an e-mail converted to a spreadsheet, the handler can only allow or skip a resource and this value has no effect.
