## PresentationLoadOptions.ExternalResourceHandler property

Gets or sets the handler called for each resource the document asks an engine to load. Default: `null`.

```csharp
public IExternalResourceHandler ExternalResourceHandler { get; set; }
```

### Remarks

The handler sees the decision of [`SkipExternalResources`](../skipexternalresources) and [`WhitelistedResources`](../whitelistedresources) for each resource and can allow it, skip it or supply its content. See [`IExternalResourceHandler`](../../iexternalresourcehandler) for the rules.

The handler is copied with the options and kept for every document the operation loads from them, including intermediate documents and reloads. It is not serialized with the options.
