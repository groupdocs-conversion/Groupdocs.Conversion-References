### Remarks

When a document fails to load because it needs a password, or the password was wrong, the load options delegate is asked once more. [`FailedLoadOptions`](../../groupdocs.conversion/loadcontext/failedloadoptions) then holds a copy of the options that failed; when it implements this interface, set [`Password`](./password) on it and return it to load the document again with that password.

For an archive entry that could not be extracted, the password returned this way applies to that entry only.
