## Metered class

Ölçülen (kullandıkça öde) lisanslamayı yönetir.

Metered lisanslar gerçek tüketim üzerinden faturalandırılır (genellikle sayfalar veya
işlenen belgeler). public/private anahtar çiftini bir kez şu konumda ayarlayın
uygulama başlangıcında; sarmalayıcı kullanımı GroupDocs'e geri bildirir
lisans sunucusuna arka planda.

Metered türü aşağıdaki üyeleri sunar:

### Yöntemler
| Yöntem | Açıklama |
| :- | :- |
| [get_consumption_credit](/conversion/python-net/groupdocs.conversion/metered/get_consumption_credit/) | Mevcut anahtar için kalan ölçülen krediyi döndürür. |
| [get_consumption_quantity](/conversion/python-net/groupdocs.conversion/metered/get_consumption_quantity/) | Şu ana kadar tüketilen toplam ölçülen miktarı döndürür. |
| [set_metered_key](/conversion/python-net/groupdocs.conversion/metered/set_metered_key/#public_key-private_key) | Verilen public/private anahtar çiftiyle ölçülen faturalandırmayı etkinleştir. |
