## load_schemas_from_internet property

Bu özellik, dönüştürmenin Internet'ten XML şemalarını yüklemesine izin verilip verilmediğini belirler.

False olarak ayarlanırsa, 'file://' ile başlamayan mutlak URI'lere sahip şemalar yüklenmez. Varsayılan değer False'tur.
