## schema_location property

schema_location, boşlukla ayrılmış URI çiftleri listesidir; her çiftteki ilk URI ad alanı URI'sı, ikinci URI ise o ad alanının XML şemasının yoludur.

None olarak ayarlanırsa, Conversion belge kök öğesinden schemaLocation özniteliğini okumaya çalışır. Varsayılan değer None'dur.
