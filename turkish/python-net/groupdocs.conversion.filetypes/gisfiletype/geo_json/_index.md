## GEO_JSON field

GeoJSON, coğrafi özellikleri ve bunların mekansal olmayan niteliklerini temsil etmek için tasarlanmış JSON tabanlı bir formattır. Bu format, farklı JSON (JavaScript Object Notation) nesnelerini ve bunların birleştirilme şeklini tanımlar. JSON formatı, coğrafi özellikler, bunların mekansal kapsamları ve özellikleri hakkında toplu bilgi sunar. Bu dosya formatı hakkında daha fazla bilgi için buraya bakın.
