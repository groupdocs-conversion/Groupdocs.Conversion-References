## PPTX field

PPTX uzantılı dosyalar, popüler Microsoft PowerPoint uygulamasıyla oluşturulan sunum dosyalarıdır. Önceki PPT sunum dosyası formatının ikili olmasının aksine, PPTX formatı Microsoft PowerPoint açık XML sunum dosyası formatına dayanır. Bu dosya formatı hakkında daha fazla bilgi için buraya bakın.
