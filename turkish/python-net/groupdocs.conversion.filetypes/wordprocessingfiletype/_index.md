## WordProcessingFileType class

WordProcessingFileType sınıfı, düz metin ve zengin metin varyantlarını kapsayan Kelime İşleme dosya formatlarını tanımlar.

Düz metin dosyaları, herhangi bir yazı tipi veya sayfa ayarı uygulanmamış biçimlendirilmemiş metin içerir. Zengin metin dosyaları, yazı tipi türleri, stiller (kalın, italik, altı çizili), sayfa kenar boşlukları, başlıklar, madde işaretleri, numaralar ve diğer özellikler gibi biçimlendirme seçeneklerini destekler.

### Örnek

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # Dönüştürücüyü giriş belgesiyle örnekleyin
    with Converter("./business-plan.docx") as converter:
        # Dönüştürme seçeneklerini tanımlayın; varsayılan çıktı formatı DOCX'tir
        word_convert_options = WordProcessingConvertOptions()
        # Format ailesi içinde çıktı formatını DOCX'ten TXT'ye değiştirin
        word_convert_options.format = WordProcessingFileType.Txt

        # Giriş belgesini TXT'ye dönüştürün
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
