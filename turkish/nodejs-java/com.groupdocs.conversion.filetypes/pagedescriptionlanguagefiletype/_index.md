### Cgm {#Cgm}
```
public static final PageDescriptionLanguageFileType Cgm
```


Computer Graphics Metafile (CGM), vektör grafikler (2D), raster grafikler ve metinlerin depolanması ve değişimi için ücretsiz, platform bağımsız, uluslararası bir standart metafile formatıdır. CGM, nesne yönelimli yaklaşım ve görüntü üretimi için birçok işlev sağlar. Bu dosya formatı hakkında daha fazla bilgi edinin [here][].


[here]: https://wiki.fileformat.com/page-description-language/cgm

### Xps {#Xps}
```
public static final PageDescriptionLanguageFileType Xps
```


XPS dosyası, Microsoft tarafından oluşturulan XML Paper Specifications temelli sayfa düzeni dosyalarını temsil eder. Bu format, EMF dosya formatının yerine Microsoft tarafından geliştirilmiş olup PDF dosya formatına benzer, ancak bir belgenin düzen, görünüm ve baskı bilgileri için XML kullanır. Bu dosya formatı hakkında daha fazla bilgi edinin [here][].


[here]: https://wiki.fileformat.com/page-description-language/xps

### Ps {#Ps}
```
public static final PageDescriptionLanguageFileType Ps

[here]: https://wiki.fileformat.com/page-description-language/ps

### Oxps {#Oxps}
```
public static final PageDescriptionLanguageFileType Oxps

OXPS dosya formatı, Open XML Paper Specification olarak bilinir. Bu, bir sayfa tanım dili ve belge formatıdır. Microsoft bu formatın geliştiricisidir. OXPS dosya formatı, PDF dosyalarına oldukça benzer. Bu dosya formatı hakkında daha fazla bilgi edinin [here][].


[here]: https://docs.fileformat.com/page-description-language/oxps
