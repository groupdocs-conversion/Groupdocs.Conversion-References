## WordProcessingLoadOptions.FontSubstitutes property

WordsProcessing belgesi dönüştürülürken belirli yazı tiplerini değiştirir.

```csharp
public IList<FontSubstitute> FontSubstitutes { get; set; }
```

### Açıklamalar

**Note:** The order of substitution is as follows:

1) Eksik yazı tiplerini otomatik olarak yazı tipi adına göre değiştir (etkinleştirildiyse).

2) Eksik yazı tiplerini otomatik olarak FontConfig'e göre değiştir (etkinleştirildiyse).

3) Eksik yazı tiplerini FontSubstitutes'a göre değiştir (ayarlandıysa).

4) Eksik yazı tiplerini otomatik olarak FontInfo'ya göre değiştir (etkinleştirildiyse).

5) Eksik yazı tiplerini DefaultFont'a göre değiştir (ayarlandıysa).
