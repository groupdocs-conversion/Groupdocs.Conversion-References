### Tiff {#Tiff}
```
public static final ImageFileType Tiff
```


TIFF, Tagged Image File Format, bu dosya formatı standardına uyan çeşitli cihazlarda kullanılmak üzere tasarlanmış raster görüntüleri temsil eder. Birkaç renk uzayında iki seviyeli, gri tonlamalı, palet renkli ve tam renkli görüntü verilerini tanımlayabilir.
Bu dosya formatı hakkında daha fazla bilgi edinin [burada](../https://wiki.fileformat.com/image/tiff).

Bu dosya formatı hakkında daha fazla bilgi edinin [burada](../https://wiki.fileformat.com/image/gif).
