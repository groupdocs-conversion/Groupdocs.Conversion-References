### Ac3 {#Ac3}
```
public static final AudioFileType Ac3
```


.ac3 uzantılı bir dosya, Dolby Laboratories tarafından tanıtılan Audio Codec 3 dosyasıdır. Altı kanala kadar ses çıkışı içerebilen bir ses formatıdır. Bu dosya formatı hakkında daha fazla bilgi edinin [burada](../https://docs.fileformat.com/audio/ac3/).


### Ogg {#Ogg}
```
public static final AudioFileType Ogg
```


OGG, .ogg uzantısıyla kaydedilen bir Ogg Vorbis Sıkıştırılmış Ses Dosyasıdır. OGG dosyaları ses verilerini depolamak için kullanılır ve sanatçı, parça bilgileri ve meta verileri de içerebilir. Bu dosya formatı hakkında daha fazla bilgi edinin [burada](../https://docs.fileformat.com/audio/ogg/).
