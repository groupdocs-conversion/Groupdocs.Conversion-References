### Svg {#Svg}

```
public static final PageDescriptionLanguageFileType Svg
```


Bir SVG dosyası, bir görüntünün görünümünü tanımlamak için XML tabanlı metin formatı kullanan Scalar Vector Graphics dosyasıdır. Bu dosya formatı hakkında daha fazla bilgi edinin [here](../https://wiki.fileformat.com/page-description-language/svg).


### Eps {#Eps}
```
public static final PageDescriptionLanguageFileType Eps
```


EPS uzantılı dosyalar, tek bir sayfanın görünümünü tanımlayan bir Encapsulated PostScript dil programını esasen tanımlar. Bu dosya formatı hakkında daha fazla bilgi edinin [here](../https://wiki.fileformat.com/page-description-language/eps).


### Cgm {#Cgm}
```
public static final PageDescriptionLanguageFileType Cgm
```


Computer Graphics Metafile (CGM), vektör grafikler (2D), raster grafikler ve metinlerin depolanması ve değiş tokuşu için ücretsiz, platform bağımsız, uluslararası standart bir metafile formatıdır. CGM, nesne yönelimli yaklaşım ve görüntü üretimi için birçok fonksiyon sağlar. Bu dosya formatı hakkında daha fazla bilgi edinin [here](../https://wiki.fileformat.com/page-description-language/cgm).


### Xps {#Xps}
```
public static final PageDescriptionLanguageFileType Xps
```


Bir XPS dosyası, Microsoft tarafından oluşturulan XML Paper Specifications tabanlı sayfa düzeni dosyalarını temsil eder. Bu format, Microsoft tarafından EMF dosya formatının yerine geliştirilmiş olup PDF dosya formatına benzer, ancak bir belgenin düzen, görünüm ve baskı bilgileri için XML kullanır. Bu dosya formatı hakkında daha fazla bilgi edinin [here](../https://wiki.fileformat.com/page-description-language/xps).


### Tex {#Tex}
```
public static final PageDescriptionLanguageFileType Tex
```


TeX, programlama ve işaretleme özelliklerini içeren, belgeleri biçimlendirmek için kullanılan bir dildir. Bu dosya formatı hakkında daha fazla bilgi edinin [here](../https://wiki.fileformat.com/page-description-language/tex).


### Ps {#Ps}
```
public static final PageDescriptionLanguageFileType Ps
```


PostScript (PS), masaüstü ve elektronik yayıncılık işinde kullanılan genel amaçlı bir sayfa tanımlama dilidir. PostScript (PS)’nin ana odak noktası iki boyutlu grafik tasarımını kolaylaştırmaktır. Bu dosya formatı hakkında daha fazla bilgi edinin [here](../https://wiki.fileformat.com/page-description-language/ps).


### Pcl {#Pcl}
```
public static final PageDescriptionLanguageFileType Pcl
```


PCL, Hewlett Packard (HP) tarafından tanıtılan bir Sayfa Tanımlama Dili olan Printer Command Language anlamına gelir. Bu dosya formatı hakkında daha fazla bilgi edinin [here](../https://wiki.fileformat.com/page-description-language/pcl).


### Oxps {#Oxps}
```
public static final PageDescriptionLanguageFileType Oxps
```


OXPS dosya formatı, Open XML Paper Specification olarak bilinir. It\\u2019s bir sayfa tanımlama dili ve belge formatıdır. Microsoft bu formatın geliştiricisidir. OXPS dosya formatı, bu PDF dosyalarına çok benzer. Bu dosya formatı hakkında daha fazla bilgi edinin [here](../https://docs.fileformat.com/page-description-language/oxps).
