## ImageFileType.Png field

PNG, Portable Network Graphics, si riferisce a un tipo di formato file immagine raster che utilizza la compressione senza perdita. Questo formato file è stato creato come sostituto del Graphics Interchange Format (GIF) e non ha limitazioni di copyright.
