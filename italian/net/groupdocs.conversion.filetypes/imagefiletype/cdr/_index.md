## ImageFileType.Cdr field

Un file CDR è un file immagine di disegno vettoriale creato nativamente con CorelDRAW per memorizzare immagini digitali codificate e compresse. Un tale file di disegno contiene testo, linee, forme, immagini, colori ed effetti per la rappresentazione vettoriale del contenuto dell'immagine. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/image/cdr).
