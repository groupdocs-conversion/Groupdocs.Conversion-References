## ImageFileType.Psb field

Adobe Photoshop salva i file in due formati. I file con dimensioni di 30.000 per 30.000 pixel vengono salvati con estensione PSD e i file più grandi di PSD fino a 300.000 per 300.000 pixel vengono salvati con estensione PSB, noto come "Photoshop Big". Scopri di più su questo formato di file [qui](https://docs.fileformat.com/image/psb).
