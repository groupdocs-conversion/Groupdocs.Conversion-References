## ImageFileType.Bmp field

BMP rappresenta file Bitmap Image utilizzati per memorizzare immagini digitali bitmap. Queste immagini sono indipendenti dall'adattatore grafico e sono anche chiamate formato di file device independent bitmap (DIB). Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/image/bmp).
