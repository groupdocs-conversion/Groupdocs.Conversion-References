## ImageFileType.Emz field

Un file EMZ è in realtà una versione compressa di un file EMF di Microsoft. Questo consente una distribuzione più semplice del file online. Quando un file EMF viene compresso utilizzando l'algoritmo di compressione .GZIP, gli viene quindi assegnata l'estensione .emz.
