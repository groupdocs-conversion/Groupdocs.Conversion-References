## ImageFileType.Avif field

AVIF (AV1 Image File Format) è un formato di file immagine che memorizza immagini compresse con AV1 nel formato di file HEIF. I file AVIF sono salvati con l'estensione .avif. La versione 1 di AVIF è stata finalizzata a febbraio 2019. Offre funzionalità come High Dynamic Range (HDR), supporto per profondità di colore 8, 10 e 12 bit, supporto per qualsiasi spazio colore (ISO/IEC CICP e profili ICC, ampia gamma di colori), ecc. Scopri di più su questo formato di file [qui](https://docs.fileformat.com/image/avif/).
