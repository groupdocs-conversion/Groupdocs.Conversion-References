## CadFileType.Dwg field

I file con estensione DWG rappresentano file binari proprietari utilizzati per contenere dati di progettazione 2D e 3D. Come i DXF, che sono file ASCII, i DWG rappresentano il formato file binario per i disegni CAD (Computer Aided Design). Scopri di più su questo formato file [qui](https://wiki.fileformat.com/cad/dwg).
