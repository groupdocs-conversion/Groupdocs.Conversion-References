## FontFileType.Cff field

Un file con estensione .cff è un Compact Font Format ed è anche noto come PostScript Type 1, o CIDFont. CFF funge da contenitore per archiviare più font insieme in un'unica unità nota come FontSet. Scopri di più su questo formato di file [qui](https://docs.fileformat.com/font/cff/).
