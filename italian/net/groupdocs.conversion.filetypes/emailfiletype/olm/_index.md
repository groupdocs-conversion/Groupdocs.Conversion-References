## EmailFileType.Olm field

Un file con estensione .olm è un file Microsoft Outlook per il sistema operativo Mac. Un file OLM memorizza messaggi email, diari, dati di calendario e altri tipi di dati dell'applicazione. Questi sono simili ai file PST utilizzati da Outlook su Windows. Tuttavia, i file OLM creati da Outlook per Mac non possono essere aperti in Outlook per Windows. Per saperne di più su questo formato di file [qui](https://wiki.fileformat.com/email/olm).
