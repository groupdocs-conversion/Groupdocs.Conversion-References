## ThreeDFileType.Ply field

PLY, Polygon File Format, rappresenta un formato file 3D che memorizza oggetti grafici descritti come una collezione di poligoni. Lo scopo di questo formato file era di stabilire un tipo di file semplice e facile, sufficientemente generico da essere utile per un'ampia gamma di modelli.
