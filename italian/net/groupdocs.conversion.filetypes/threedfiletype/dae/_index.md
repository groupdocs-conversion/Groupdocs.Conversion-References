## ThreeDFileType.Dae field

Un file DAE è un formato di file Digital Asset Exchange che viene utilizzato per lo scambio di dati tra applicazioni 3D interattive. Questo formato di file si basa sullo schema XML COLLADA (COLLAborative Design Activity) che è uno schema XML standard aperto per lo scambio di risorse digitali tra applicazioni software grafiche. Maggiori informazioni su questo formato di file [qui](https://docs.fileformat.com/3d/dae).
