## ThreeDFileType.ThreeDS field

Un file con estensione .3ds rappresenta il formato file mesh 3D Sudio (DOS) utilizzato da Autodesk 3D Studio. Autodesk 3D Studio è presente nel mercato dei formati file 3D dagli anni ’90 e si è evoluto in 3D Studio MAX per la modellazione, l'animazione e il rendering 3D.
