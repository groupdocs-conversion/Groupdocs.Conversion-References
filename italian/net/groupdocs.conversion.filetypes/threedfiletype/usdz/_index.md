## ThreeDFileType.Usdz field

Un file con estensione .usdz è un archivio ZIP non compresso e non crittografato per il formato file USD (Universal Scene Description) che contiene e funge da proxy per file di altri formati (come texture e animazioni) incorporati nell'archivio e li esegue direttamente con il runtime USD senza necessità di estrazione. Scopri di più su questo formato file [qui](https://docs.fileformat.com/3d/usdz).
