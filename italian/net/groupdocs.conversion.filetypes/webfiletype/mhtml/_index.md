## WebFileType.Mhtml field

I file con estensione MHTML rappresentano un formato di archivio di pagine web che può essere creato da diverse applicazioni. Il formato è noto come formato di archivio perché salva il codice HTML web e le risorse associate in un unico file. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/web/mhtml).
