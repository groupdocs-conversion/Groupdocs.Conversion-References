## PresentationFileType.Potm field

I file con estensione POTM sono file modello di Microsoft PowerPoint con supporto per macro. I file POTM sono creati con PowerPoint 2007 o versioni successive e contengono impostazioni predefinite che possono essere usate per creare ulteriori file di presentazione. Per saperne di più su questo formato di file [qui](https://wiki.fileformat.com/presentation/potm).
