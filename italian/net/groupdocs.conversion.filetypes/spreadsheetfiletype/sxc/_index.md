## SpreadsheetFileType.Sxc field

Il formato file SXC (Sun XML Calc) appartiene a una suite office chiamata OpenOffice.org. Questo formato gestisce generalmente le esigenze di fogli di calcolo degli utenti poiché è un formato di file spreadsheet basato su XML. Il formato SXC supporta formule, funzioni, macro e grafici insieme a DataPilot. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/spreadsheet/sxc).
