## SpreadsheetFileType.Xltm field

L'estensione di file XLTM rappresenta i file generati da Microsoft Excel come file modello abilitati alle macro. I file XLTM sono simili a XLTX nella struttura, tranne per il fatto che quest'ultimo non supporta la creazione di file modello con macro.
