## DiagramFileType.Vsx field

I file con estensione .VSX si riferiscono a stencil che consistono in disegni e forme utilizzati per creare diagrammi in Microsoft Visio. I file VSX sono salvati in formato XML e sono stati supportati fino a Visio 2013. Scopri di più su questo formato di file [qui](https://wiki.fileformat.com/image/vsx).
