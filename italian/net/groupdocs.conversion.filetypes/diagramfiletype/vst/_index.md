## DiagramFileType.Vst field

I file con estensione VST sono file immagine vettoriali creati con Microsoft Visio e fungono da modello per creare altri file. Questi file modello sono in formato binario e contengono il layout e le impostazioni predefinite utilizzate per la creazione di nuovi disegni Visio.
