## FinanceFileType.IXbrl field

Nell'iXBRL, i contenuti di XBRL sono avvolti nel formato di file xHTML che utilizza tag XML. Come XBRL, è l'elemento radice dei file iXBRL. Il formato XHTML rappresenta i suoi contenuti come una collezione di diversi tipi di documenti e moduli. Tutti i file in XHTML si basano sul formato di file XML e sono conformi agli standard dei documenti XML.
