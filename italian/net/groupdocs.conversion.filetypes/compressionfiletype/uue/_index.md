## CompressionFileType.Uue field

Un archivio uuencoded è un file o una raccolta di file che sono stati codificati usando lo schema di codifica Unix-to-Unix (uuencode). Questo metodo di codifica converte i dati binari in un formato di testo, facilitando l'invio dei file su canali che supportano solo testo, come la posta elettronica.
