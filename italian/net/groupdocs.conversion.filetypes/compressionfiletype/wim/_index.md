## CompressionFileType.Wim field

Un file con estensione .wim è un archivio Windows Imaging Format, un'immagine disco basata su file che Microsoft utilizza per distribuire Windows. Un singolo archivio contiene una o più immagini e memorizza ogni file una sola volta, indipendentemente da quante immagini lo facciano riferimento. Scopri di più su questo formato file [qui](https://docs.fileformat.com/disc-and-media/wim/).
