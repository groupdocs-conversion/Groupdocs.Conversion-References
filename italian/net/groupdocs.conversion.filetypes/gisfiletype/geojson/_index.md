## GisFileType.GeoJson field

GeoJSON è un formato basato su JSON progettato per rappresentare le caratteristiche geografiche con i loro attributi non spaziali. Questo formato definisce diversi oggetti JSON (JavaScript Object Notation) e il loro modo di collegamento. Il formato JSON rappresenta informazioni collettive sulle caratteristiche geografiche, le loro estensioni spaziali e le proprietà.
