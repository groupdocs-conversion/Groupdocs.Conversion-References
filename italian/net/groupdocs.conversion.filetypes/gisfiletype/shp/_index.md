## GisFileType.Shp field

SHP è l'estensione di file per uno dei principali tipi di file utilizzati per la rappresentazione di ESRI Shapefile. Rappresenta informazioni geospaziali sotto forma di dati vettoriali da utilizzare nelle applicazioni Geographic Information Systems (GIS).
