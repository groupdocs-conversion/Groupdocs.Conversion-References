## GisFileType.Osm field

Il formato di file OSM è un formato di dati strutturato utilizzato per memorizzare dati geografici nel progetto OpenStreetMap. I file OSM sono tipicamente in formato XML e contengono informazioni come la posizione di strade, edifici, punti di interesse e altre caratteristiche sulla mappa.
