## EBookFileType.Azw3 field

AZW3, noto anche come Kindle Format 8 (KF8), è la versione modificata del formato di file digitale ebook AZW sviluppato per i dispositivi Amazon Kindle. Il formato è un miglioramento rispetto ai vecchi file AZW ed è utilizzato sui dispositivi Kindle Fire solo con compatibilità retroattiva per il formato di file originale, cioè MOBI e AZW. Scopri di più su questo formato di file [qui](https://docs.fileformat.com/ebook/azw3/).
