## GmlLoadOptions.RestoreSchema property

Determina se la Conversione è autorizzata a analizzare gli attributi in un file Gml in cui lo schema XML è mancante o non può essere caricato. Se impostato su true, il lettore della Conversione non richiede la presenza di uno schema XML. Il valore predefinito è false.
