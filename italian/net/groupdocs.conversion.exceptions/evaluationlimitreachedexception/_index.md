## EvaluationLimitReachedException class

Eccezione GroupDocs generata quando il limite di conversione di valutazione per il processo corrente è stato esaurito.

```csharp
public sealed class EvaluationLimitReachedException : GroupDocsConversionException
```

### Osservazioni

Generata solo senza licenza. L'applicazione di una licenza elimina il limite, quindi un processo con licenza non incontra mai questa eccezione, indipendentemente dal numero di documenti convertiti.
