## PdfConvertOptions.EmbedFullFonts property

Quando impostato su true, l'intero file del font viene incorporato nel PDF invece di un sottoinsieme. Questo aumenta la dimensione del file di output ma garantisce una migliore compatibilità durante la modifica del PDF risultante. Si applica solo durante la conversione da documenti WordProcessing.
