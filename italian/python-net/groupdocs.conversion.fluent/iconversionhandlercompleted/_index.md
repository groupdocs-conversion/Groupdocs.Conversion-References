## IConversionHandlerCompleted class

Rappresenta l'interfaccia fluida dopo che `OnConversionFailed` è impostato, consentendo di impostare `OnConversionCompleted` o procedere a `Convert`/`Compress`.

Il tipo IConversionHandlerCompleted espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [compress](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/compress/#options) | Comprimi i risultati della conversione e restituisce una continuazione che procede a `Convert`. |
| [compress_compression_convert_options](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/compress_compression_convert_options/) |  |
| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/convert/) | Esegui la catena di conversione. |
| [on_conversion_completed](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/on_conversion_completed/#on_completed) | Registra una callback da invocare quando una conversione di documento termina con successo. |
| [on_conversion_completed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/on_conversion_completed_action/) |  |
| [on_conversion_failed](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/on_conversion_failed/#on_failed) | Registra una callback da invocare quando la conversione di un documento fallisce. La reinvocazione sostituisce qualsiasi gestore precedentemente impostato. |
| [on_conversion_failed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/on_conversion_failed_action/) |  |
