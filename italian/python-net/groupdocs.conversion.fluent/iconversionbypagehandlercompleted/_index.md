## IConversionByPageHandlerCompleted class

Fornisce un'interfaccia fluida dopo che `OnConversionFailed` è impostato per la conversione della pagina. Consente di impostare `OnConversionCompleted` o di procedere a `Convert`/`Compress`.

Il tipo IConversionByPageHandlerCompleted espone i seguenti membri:

| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlercompleted/convert/) | Esegui la catena di conversione. |

| [on_conversion_completed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlercompleted/on_conversion_completed_action/) |  |
