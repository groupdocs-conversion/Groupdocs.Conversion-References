## IConverterListener class

Definisce i metodi utilizzati per eseguire l'ascolto del convertitore.

Per saperne di più.

- More about monitoring conversion progress: https://docs.groupdocs.com/display/conversionnet/Listening

Il tipo IConverterListener espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [completed](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/completed/) | Invocato quando la conversione è completata. |
| [progress](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress/#current) | Chiamato ogni volta che lo stato di avanzamento della conversione cambia. |
| [progress_byte](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress_byte/) |  |
| [started](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/started/) | Invocato non appena inizia la conversione reale. |
