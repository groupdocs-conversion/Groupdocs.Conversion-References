## OXPS field

Il formato di file OXPS è noto come Open XML Paper Specification. È un linguaggio di descrizione di pagina e un formato di documento. Microsoft è lo sviluppatore di questo formato. Il formato di file OXPS è molto simile a questi file PDF. Scopri di più su questo formato di file qui.
