## XPS field

Un file XPS rappresenta file di layout di pagina basati su XML Paper Specifications creati da Microsoft. Questo formato è stato sviluppato da Microsoft come sostituto del formato di file EMF ed è simile al formato PDF, ma utilizza XML per il layout, l'aspetto e le informazioni di stampa di un documento. Scopri di più su questo formato di file qui.
