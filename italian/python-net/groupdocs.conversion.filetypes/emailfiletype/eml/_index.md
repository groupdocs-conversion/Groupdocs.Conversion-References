## EML field

Il formato file EML rappresenta i messaggi email salvati usando Outlook e altre applicazioni pertinenti. Quasi tutti i client di posta elettronica supportano questo formato di file per la sua conformità allo Standard RFC-822 Internet Message Format. Scopri di più su questo formato di file qui.
