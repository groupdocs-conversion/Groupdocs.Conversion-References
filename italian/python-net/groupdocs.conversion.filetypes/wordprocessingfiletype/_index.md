## WordProcessingFileType class

La classe WordProcessingFileType definisce i formati di file di elaborazione testi, coprendo varianti di testo semplice e testo formattato.

I file di testo semplice contengono testo non formattato senza impostazioni di carattere o pagina applicate. I file di testo ricco supportano opzioni di formattazione come tipi di carattere, stili (grassetto, corsivo, sottolineato), margini di pagina, intestazioni, elenchi puntati, numeri e altre funzionalità.

### Esempio

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # Istanzia Converter con il documento di input
    with Converter("./business-plan.docx") as converter:
        # Definisci le opzioni di conversione; il formato di output predefinito è DOCX
        word_convert_options = WordProcessingConvertOptions()
        # Cambia il formato di output all'interno della famiglia di formati da DOCX a TXT
        word_convert_options.format = WordProcessingFileType.Txt

        # Converti il documento di input in TXT
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
