## DIF field

DIF sta per Data Interchange Format ed è usato per importare/esportare dati di fogli di calcolo tra diverse applicazioni. Queste includono Microsoft Excel, OpenOffice Calc, StarCalc e molte altre. Scopri di più su questo formato di file qui.
