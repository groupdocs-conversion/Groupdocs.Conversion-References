## SXC field

Il formato di file SXC (Sun XML Calc) appartiene a una suite office chiamata OpenOffice.org. Questo formato soddisfa generalmente le esigenze di foglio di calcolo degli utenti poiché è un formato di file di foglio di calcolo basato su XML. Il formato SXC supporta formule, funzioni, macro e grafici insieme a DataPilot. Scopri di più su questo formato di file qui.
