## XLTM field

L'estensione di file XLTM rappresenta file generati da Microsoft Excel come modelli abilitati alle macro. I file XLTM sono simili a XLTX nella struttura, tranne per il fatto che quest'ultimo non supporta la creazione di modelli con macro. Scopri di più su questo formato di file qui.
