## PUB field

Un file PUB è un formato di documento Microsoft Publisher. Viene utilizzato per creare diversi tipi di documenti di layout di design come newsletter, volantini, brochure, cartoline, ecc. I file PUB possono contenere testo, immagini raster e vettoriali. Scopri di più su questo formato di file qui.
