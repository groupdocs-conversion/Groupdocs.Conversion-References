## CHM field

Il formato di file CHM rappresenta il file di aiuto HTML di Microsoft, costituito da una raccolta di pagine HTML. Fornisce un indice per accedere rapidamente agli argomenti e una navigazione verso le diverse parti del documento di aiuto. Scopri di più su questo formato di file qui.
