## VSTX field

I file con estensione VSTX sono file modello di disegno creati con Microsoft Visio 2013 e versioni successive. Questi file VSTX forniscono un punto di partenza per creare disegni Visio, salvati come file .VSDX, con layout e impostazioni predefinite. Scopri di più su questo formato di file qui.
