## VST field

I file con estensione VST sono file immagine vettoriale creati con Microsoft Visio e fungono da modello per creare ulteriori file. Questi file modello sono in formato file binario e contengono il layout predefinito e le impostazioni utilizzate per la creazione di nuovi disegni Visio. Scopri di più su questo formato di file qui.
