## VTX field

Un file con estensione VTX è un modello di disegno Microsoft Visio che viene salvato su disco in formato XML. Il modello è destinato a fornire un file con impostazioni di base che può essere utilizzato per creare più file Visio con le stesse impostazioni. Scopri di più su questo formato di file qui.
