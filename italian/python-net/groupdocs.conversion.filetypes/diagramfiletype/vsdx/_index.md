## VSDX field

I file con estensione .VSDX rappresentano il formato file Microsoft Visio introdotto a partire da Microsoft Office 2013. È stato sviluppato per sostituire il formato file binario .VSD, supportato dalle versioni precedenti di Microsoft Visio. Scopri di più su questo formato di file qui.
