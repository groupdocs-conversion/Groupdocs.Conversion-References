| [VST](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vst/) | I file con estensione VST sono file immagine vettoriale creati con Microsoft Visio e fungono da modello per creare ulteriori file. Scopri di più su questo formato di file qui. |
| [VSX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vsx/) | I file con estensione .VSX si riferiscono a stencil che consistono in disegni e forme utilizzati per creare diagrammi in Microsoft Visio. | [VTX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vtx/) | Un file con estensione VTX è un modello di disegno Microsoft Visio che viene salvato su disco in formato XML. | [VDW](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vdw/) | VDW è il formato file Visio Graphics Service che specifica i flussi e gli archivi necessari per il rendering di un disegno Web. Scopri di più su questo formato di file qui. |
| [VDX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vdx/) | Qualsiasi disegno o grafico creato in Microsoft Visio, ma salvato in formato XML, ha estensione .VDX. | [VSTX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vstx/) | I file con estensione VSTX sono file modello di disegno creati con Microsoft Visio 2013 e versioni successive.
