## VSSM field

I file con estensione .VSSM sono file Stencil Microsoft Visio che supportano le macro. Un file VSSM, quando aperto, consente di eseguire le macro per ottenere la formattazione e il posizionamento desiderati delle forme in un diagramma. Scopri di più su questo formato di file qui.
