## STL field

STL, abbreviazione di stereolitografia, è un formato di file intercambiabile che rappresenta la geometria di superficie tridimensionale. Il formato di file è utilizzato in diversi settori come la prototipazione rapida, la stampa 3D e la produzione assistita da computer. Scopri di più su questo formato di file qui.
