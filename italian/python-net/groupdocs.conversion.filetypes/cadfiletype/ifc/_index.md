## IFC field

I file con estensione IFC si riferiscono al formato file Industry Foundation Classes (IFC) che stabilisce standard internazionali per importare ed esportare oggetti edilizi e le loro proprietà. Questo formato file fornisce interoperabilità tra diverse applicazioni software. Scopri di più su questo formato di file qui.
