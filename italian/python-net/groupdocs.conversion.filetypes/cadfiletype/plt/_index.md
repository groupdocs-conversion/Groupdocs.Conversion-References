## PLT field

Il formato file PLT è un file plotter basato su vettori introdotto da Autodesk, Inc. e contiene informazioni per un determinato file CAD. I dettagli della stampa richiedono accuratezza e precisione nella produzione, e l'uso del file PLT garantisce ciò poiché tutte le immagini vengono stampate usando linee invece di punti. Scopri di più su questo formato di file qui.
