## DWF field

Design Web Format (DWF) rappresenta disegni 2D/3D in formato compresso per la visualizzazione, la revisione o la stampa di file di progetto. Contiene grafica e testo come parte dei dati di progetto e riduce le dimensioni del file grazie al suo formato compresso. Scopri di più su questo formato di file qui.
