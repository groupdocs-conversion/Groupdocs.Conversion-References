## DWG field

I file con estensione DWG rappresentano file binari proprietari utilizzati per contenere dati di progettazione 2D e 3D. Come DXF, che sono file ASCII, DWG rappresentano il formato di file binario per disegni CAD (Computer Aided Design). Scopri di più su questo formato di file qui.
