## GLTF field

glTF (GL Transmission Format) è un formato di file 3D che memorizza le informazioni del modello 3D in formato JSON. L'uso di JSON riduce sia le dimensioni delle risorse 3D sia l'elaborazione in tempo reale necessaria per decomprimere e utilizzare tali risorse. Scopri di più su questo formato di file qui.
