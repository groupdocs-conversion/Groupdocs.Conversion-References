## RVM field

I file dati RVM sono correlati ad AVEVA PDMS. Il file RVM è un file di progetto modello del Plant Design Management System di AVEVA. Il Plant Design Management System (PDMS) di AVEVA è il sistema di progettazione 3D più popolare, che utilizza una tecnologia data‑centric per la gestione dei progetti.
