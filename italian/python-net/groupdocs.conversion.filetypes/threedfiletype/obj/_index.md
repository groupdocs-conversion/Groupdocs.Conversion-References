## OBJ field

I file OBJ sono utilizzati dall'applicazione Advanced Visualizer di Wavefront per definire e memorizzare gli oggetti geometrici. La trasmissione retroattiva e avanzata dei dati geometrici è resa possibile tramite i file OBJ. Scopri di più su questo formato di file qui.
