## PLY field

PLY, Polygon File Format, rappresenta un formato di file 3D che memorizza oggetti grafici descritti come una collezione di poligoni. Lo scopo di questo formato di file era di stabilire un tipo di file semplice e facile, sufficientemente generico da essere utile per un'ampia gamma di modelli. Scopri di più su questo formato di file qui.
