## AMF field

Un file AMF consiste in linee guida per la descrizione degli oggetti al fine di essere utilizzato nei processi di produzione additiva. Contiene un tag XML di apertura e termina con un elemento. Questo è preceduto da una riga di dichiarazione XML che specifica la versione XML e la codifica del file. Scopri di più su questo formato di file qui.
