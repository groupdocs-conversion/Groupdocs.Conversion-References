## ASE field

Un file con estensione .ase è un formato di file Autodesk ASCII Scene Export che è una rappresentazione ASCII di una scena, contenente informazioni 2D o 3D durante l'esportazione dei dati della scena utilizzando Autodesk. Scopri di più su questo formato di file qui.
