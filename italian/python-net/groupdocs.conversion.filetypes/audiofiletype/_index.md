| [WMA](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/wma/) | Un file con estensione .wma rappresenta un file audio salvato nel formato Advanced Systems Format (ASF). Scopri di più su questo formato di file qui. |

| [OGG](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/ogg/) | OGG è un Ogg Vorbis Compressed Audio File salvato con l'estensione .ogg. | [WAV](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/wav/) | WAV, noto per WAVE (Waveform Audio File Format), è un sottoinsieme della specifica Resource Interchange File Format (RIFF) di Microsoft per la memorizzazione di file audio digitali.
