## GML field

GML sta per Geography Markup Language, basato su specifiche XML sviluppate dall'Open Geospatial Consortium (OGC). Il formato è usato per memorizzare caratteristiche di dati geografici per lo scambio tra diversi formati di file. Serve sia come linguaggio di modellazione per sistemi geografici sia come formato di scambio aperto per transazioni geografiche su Internet. Scopri di più su questo formato di file qui.
