## GDB field

Il Geodatabase di file ESRI (FileGDB) è una raccolta di file in una cartella su disco che contiene dati geospaziali correlati, come dataset di feature, classi di feature e tabelle associate. Richiede che alcuni altri file siano mantenuti accanto al file .gdb nella stessa directory affinché funzioni. Scopri di più su questo formato di file qui.
