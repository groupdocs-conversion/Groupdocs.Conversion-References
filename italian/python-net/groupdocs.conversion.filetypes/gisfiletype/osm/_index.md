## OSM field

Il formato file OSM è un formato dati strutturato usato per memorizzare dati geografici nel progetto OpenStreetMap. I file OSM sono tipicamente in formato XML e contengono informazioni come la posizione di strade, edifici, punti di interesse e altre caratteristiche sulla mappa. Scopri di più su questo formato di file qui.
