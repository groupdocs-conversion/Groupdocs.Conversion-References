## KML field

KML (Keyhole Markup Language) contiene informazioni geospaziali in notazione XML. I file salvati come KML possono essere aperti in applicazioni Geographic Information System (GIS) a condizione che le supportino. Molte applicazioni hanno iniziato a fornire supporto per il formato file KML dopo che è stato adottato come standard internazionale. KML utilizza una struttura basata su tag con elementi e attributi nidificati. Scopri di più su questo formato di file qui.
