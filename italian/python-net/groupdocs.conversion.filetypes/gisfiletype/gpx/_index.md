## GPX field

I file con estensione GPX rappresentano il formato GPS Exchange per lo scambio di dati GPS tra applicazioni e servizi web su Internet. È un formato file XML leggero che contiene dati GPS, cioè waypoint, percorsi e tracce, da importare e leggere da più programmi. Scopri di più su questo formato di file qui.
