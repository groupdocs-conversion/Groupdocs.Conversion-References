## EOT field

Un file con estensione .eot è un font OpenType incorporato in un documento. Questi sono principalmente usati nei file web come una pagina web. È stato creato da Microsoft ed è supportato dai prodotti Microsoft, inclusi i file di presentazione PowerPoint .pps. Scopri di più su questo formato file qui.
