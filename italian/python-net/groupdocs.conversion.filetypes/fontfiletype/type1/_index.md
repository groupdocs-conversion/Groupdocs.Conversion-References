## TYPE1 field

I font Type 1 sono una tecnologia Adobe deprecata, ampiamente usata nei software di desktop publishing e nelle stampanti che supportano PostScript. Sebbene i font Type 1 non siano supportati in molte piattaforme moderne, browser web e sistemi operativi mobili, sono ancora supportati in alcuni sistemi operativi.
