## TTF field

Un file con estensione .ttf rappresenta i file di font basati sulla tecnologia font TrueType. È stato inizialmente progettato e lanciato da Apple Computer, Inc per Mac OS ed è stato successivamente adottato da Microsoft per Windows OS. Scopri di più su questo formato file qui.
