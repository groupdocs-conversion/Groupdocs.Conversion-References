### Campi
| Campo | Descrizione |
| :- | :- |
| [TTF](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/ttf/) | Un file con estensione .ttf rappresenta i file di font basati sulla tecnologia font TrueType. È stato inizialmente progettato e lanciato da Apple Computer, Inc per Mac OS ed è stato successivamente adottato da Microsoft per Windows OS. Scopri di più su questo formato file qui. |
| [EOT](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/eot/) | Un file con estensione .eot è un font OpenType incorporato in un documento. Questi sono principalmente usati nei file web come una pagina web. È stato creato da Microsoft ed è supportato dai prodotti Microsoft, inclusi i file di presentazione PowerPoint .pps. Scopri di più su questo formato file qui. |
| [OTF](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/otf/) | Un file con estensione .otf si riferisce al formato font OpenType. Il formato font OTF è più scalabile ed estende le funzionalità esistenti dei formati TTF per la tipografia digitale. Sviluppato da Microsoft e Adobe, OTF combina le caratteristiche dei formati font PostScript e TrueType. Scopri di più su questo formato file qui. |
| [CFF](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/cff/) | Un file con estensione .cff è un Compact Font Format, noto anche come PostScript Type 1 o CIDFont. CFF funge da contenitore per memorizzare più font insieme in un'unica unità nota come FontSet. Scopri di più su questo formato file qui. |
| [TYPE1](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/type1/) | I font Type 1 sono una tecnologia Adobe deprecata, ampiamente usata nei software di desktop publishing e nelle stampanti che supportano PostScript. Sebbene i font Type 1 non siano supportati in molte piattaforme moderne, browser web e sistemi operativi mobili, sono ancora supportati in alcuni sistemi operativi. Scopri di più su questo formato file qui. |
| [WOFF](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/woff/) | Un file con estensione .woff è un font web basato sul Web Open Font Format (WOFF). Ha un contenitore compresso specifico del formato basato su font TrueType (.TTF) o OpenType (.OTT). Scopri di più su questo formato file qui. |
| [WOFF2](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/woff2/) | Un file con estensione .woff è un font web basato sul Web Open Font Format (WOFF). Ha un contenitore compresso specifico del formato basato su font TrueType (.TTF) o OpenType (.OTT). Scopri di più su questo formato file qui. |
| [UNKNOWN](/conversion/python-net/groupdocs.conversion.filetypes/filetype/unknown/) | Tipo di file sconosciuto (eredita da [`FileType`](/conversion/python-net/groupdocs.conversion.filetypes/filetype/)) |
