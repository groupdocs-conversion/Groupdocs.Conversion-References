## NSF field

Un file con estensione .nsf (Notes Storage Facility) è un formato di file di database utilizzato dal software IBM Notes, precedentemente noto come Lotus Notes. Definisce lo schema per memorizzare diversi tipi di oggetti come email, appuntamenti, documenti, moduli e viste. Scopri di più su questo formato file qui.
