## SQL field

Un file con estensione .sql è un file Structured Query Language (SQL) che contiene codice per lavorare con database relazionali. Viene usato per scrivere istruzioni SQL per operazioni CRUD (Create, Read, Update, Delete) sui database. Scopri di più su questo formato file qui.
