## XAR field

Un file con estensione .xar è un eXtensible ARchive, un formato costruito attorno a una tabella dei contenuti memorizzata come XML compresso. Viene usato per distribuire pacchetti di installazione macOS e mantiene ogni voce compressa singolarmente. Scopri di più su questo formato di file qui.
