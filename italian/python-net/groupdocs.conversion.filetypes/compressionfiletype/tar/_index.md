## TAR field

I file con estensione .tar sono archivi creati con un'utilità basata su Unix per raccogliere uno o più file. I file multipli sono memorizzati in un formato non compresso con il supporto per aggiungere file e cartelle all'archivio. Scopri di più su questo formato di file qui.
