## ISO field

Un file con estensione .iso è un file immagine disco di archivio non compresso che rappresenta il contenuto di tutti i dati su un disco ottico come CD o DVD. Basato sullo standard ISO-9660, il formato di file immagine ISO contiene i dati del disco insieme alle informazioni del file system memorizzate al suo interno. Scopri di più su questo formato di file qui.
