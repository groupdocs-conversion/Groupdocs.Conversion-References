## LZ field

Un file con estensione .lz è un archivio compresso creato con Lzip, uno strumento da riga di comando gratuito per la compressione. Supporta la concatenazione per comprimere file di supporto. I file LZ hanno tipo MIME application/lzip e supportano rapporti di compressione più elevati rispetto a BZ2. Scopri di più su questo formato di file qui.
