## BZ2 field

BZ2 sono file compressi generati utilizzando il metodo di compressione open source BZIP2, principalmente su sistemi UNIX o Linux. Viene utilizzato per comprimere un singolo file e non è destinato all'archiviazione di più file. Scopri di più su questo formato di file qui.
