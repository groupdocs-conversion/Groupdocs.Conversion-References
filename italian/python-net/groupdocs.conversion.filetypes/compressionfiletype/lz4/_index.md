## LZ4 field

Un file con estensione .lz4 è un file di archivio compresso creato con applicazioni/utilità che supportano la compressione LZ4. L'algoritmo LZ4 si concentra sul compromesso tra velocità e rapporto di compressione. Gli archivi LZ4 compressi possono essere creati usando l'utilità da riga di comando LZ4 e possono essere decompressi con la stessa. Scopri di più su questo formato di file qui.
