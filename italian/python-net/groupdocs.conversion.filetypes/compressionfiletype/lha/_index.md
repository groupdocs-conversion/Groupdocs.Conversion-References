## LHA field

Un file con estensione .lzh o .lha di solito riguarda un formato di compressione di archivio. Questo formato di file è lo stesso di altri formati di compressione come ZIP, RAR, ecc. Lo scopo principale di questi formati è ridurre le dimensioni per facilitare l'invio e mantenerli insieme in forma compressa.
