## LZMA field

Un file con estensione .lzma è un file di archivio compresso creato utilizzando il metodo di compressione LZMA (Lempel-Ziv-Markov chain Algorithm). Questi sono principalmente trovati/utilizzati sui sistemi operativi Unix e sono simili ad altri algoritmi di compressione come ZIP per ridurre le dimensioni del file. Scopri di più su questo formato di file qui.
