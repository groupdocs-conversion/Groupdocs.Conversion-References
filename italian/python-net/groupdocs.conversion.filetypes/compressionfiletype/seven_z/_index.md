## SEVEN_Z field

7z è un formato di archiviazione per comprimere file e cartelle con un alto rapporto di compressione. È basato su un'architettura Open Source che consente di utilizzare qualsiasi algoritmo di compressione e crittografia. Scopri di più su questo formato di file qui.
