| [RAR](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/rar/) | I file con estensione .rar sono file di archivio creati per memorizzare informazioni in forma compressa o normale. RAR, che sta per Roshal ARchive file format. Scopri di più su questo formato di file qui. |

| [TAR](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/tar/) | I file con estensione .tar sono archivi creati con un'utilità basata su Unix per raccogliere uno o più file. | [GZIP](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/gzip/) | Un file Gzip è un archivio compresso creato utilizzando l'algoritmo di compressione standard gzip (GNU zip). Può contenere più file compressi, directory e stub di file. Scopri di più su questo formato di file qui. |
| [BZ2](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/bz2/) | BZ2 sono file compressi generati utilizzando il metodo di compressione open source BZIP2, principalmente su sistemi UNIX o Linux. Viene utilizzato per comprimere un singolo file e non è destinato all'archiviazione di più file. Scopri di più su questo formato di file qui. |
| [LZ](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/lz/) | Un file con estensione .lz è un archivio compresso creato con Lzip, uno strumento da riga di comando gratuito per la compressione. Scopri di più su questo formato di file qui. |

| [XZ](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/xz/) | XZ è un formato di file compresso che utilizza l'algoritmo di compressione LZMA2. | [CPIO](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/cpio/) | Cpio è un'utilità di archiviazione di file generica e il relativo formato di file. È installata principalmente sui sistemi operativi per computer simili a Unix. |

Scopri di più su questo formato di file qui. |
| [LZMA](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/lzma/) | Un file con estensione .lzma è un file di archivio compresso creato utilizzando il metodo di compressione LZMA (Lempel-Ziv-Markov chain Algorithm). Questi sono principalmente trovati/utilizzati sui sistemi operativi Unix e sono simili ad altri algoritmi di compressione come ZIP per ridurre le dimensioni del file. Scopri di più su questo formato di file qui. |
| [ZST](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/zst/) | Un file ZST è un file compresso generato con l'algoritmo di compressione Zstandard (zstd). | [ISO](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/iso/) | Un file con estensione .iso è un file immagine disco di archivio non compresso che rappresenta il contenuto di tutti i dati su un disco ottico come CD o DVD. Basato sullo standard ISO-9660, il formato di file immagine ISO contiene i dati del disco insieme alle informazioni del file system memorizzate al suo interno. Scopri di più su questo formato di file qui. |
| [UUE](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/uue/) | Un archivio uuencoded è un file o una raccolta di file che sono stati codificati usando lo schema di codifica Unix-to-Unix (uuencode). | [LHA](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/lha/) | Un file con estensione .lzh o .lha di solito riguarda un formato di compressione di archivio. Questo formato di file è lo stesso di altri formati di compressione come ZIP, RAR, ecc. Lo scopo principale di questi formati è ridurre le dimensioni per facilitare l'invio e mantenerli insieme in forma compressa. |
| [LZ4](/conversion/python-net/groupdocs.conversion.filetypes/compressionfiletype/lz4/) | Un file con estensione .lz4 è un file di archivio compresso creato con applicazioni/utilità che supportano la compressione LZ4. L'algoritmo LZ4 si concentra sul compromesso tra velocità e rapporto di compressione. Gli archivi LZ4 compressi possono essere creati usando l'utilità da riga di comando LZ4 e possono essere decompressi con la stessa. Scopri di più su questo formato di file qui. |
