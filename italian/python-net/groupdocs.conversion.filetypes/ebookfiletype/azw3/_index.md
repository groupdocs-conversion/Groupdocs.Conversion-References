## AZW3 field

AZW3, noto anche come Kindle Format 8 (KF8), è la versione modificata del formato file digitale AZW sviluppato per i dispositivi Amazon Kindle. Il formato è un miglioramento dei file AZW più vecchi ed è usato sui dispositivi Kindle Fire solo con compatibilità retroattiva per il formato file ancestrale, cioè MOBI e AZW. Scopri di più su questo formato di file qui.
