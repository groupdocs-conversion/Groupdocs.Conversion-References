## BMP field

BMP rappresenta file di immagini bitmap che vengono utilizzati per memorizzare immagini digitali bitmap. Queste immagini sono indipendenti dall'adattatore grafico e sono anche chiamate formato file bitmap indipendente dal dispositivo (DIB). Scopri di più su questo formato file qui.
