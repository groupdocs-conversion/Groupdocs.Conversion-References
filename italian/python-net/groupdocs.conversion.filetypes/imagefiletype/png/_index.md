## PNG field

PNG, Portable Network Graphics, si riferisce a un tipo di formato di file immagine raster che utilizza compressione senza perdita. Questo formato di file è stato creato come sostituto del Graphics Interchange Format (GIF) e non ha limitazioni di copyright. Scopri di più su questo formato di file qui.
