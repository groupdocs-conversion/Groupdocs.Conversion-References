## GIF field

Un GIF o Graphical Interchange Format è un tipo di immagine altamente compressa. Per ogni immagine GIF consente tipicamente fino a 8 bit per pixel e fino a 256 colori sono consentiti nell'immagine. Scopri di più su questo formato di file qui.
