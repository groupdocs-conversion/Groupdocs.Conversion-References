## WMZ field

Un file WMZ è in realtà una versione compressa di un file Microsoft WMF. Questo consente una distribuzione più semplice del file online. Quando un file EWMFMF viene compresso utilizzando l'algoritmo di compressione .GZIP, gli viene assegnata l'estensione .wmz.
