## CDR field

Un file CDR è un file immagine di disegno vettoriale creato nativamente con CorelDRAW per memorizzare immagini digitali codificate e compresse. Tale file di disegno contiene testo, linee, forme, immagini, colori ed effetti per la rappresentazione vettoriale del contenuto dell'immagine. Scopri di più su questo formato file qui.
