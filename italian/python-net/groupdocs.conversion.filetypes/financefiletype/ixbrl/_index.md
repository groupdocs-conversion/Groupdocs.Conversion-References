## IXBRL field

All'interno di iXBRL, i contenuti di XBRL sono avvolti nel formato file xHTML che utilizza tag XML. Come XBRL, è l'elemento radice dei file iXBRL. Il formato XHTML rappresenta i suoi contenuti come una raccolta di diversi tipi di documenti e moduli. Tutti i file in XHTML si basano sul formato file XML e sono conformi agli standard dei documenti XML. Scopri di più su questo formato di file qui.
