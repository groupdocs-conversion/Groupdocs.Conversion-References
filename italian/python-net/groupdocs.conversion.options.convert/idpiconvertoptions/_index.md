## IDpiConvertOptions class

Rappresenta le opzioni di conversione che supportano le impostazioni DPI (Dots Per Inch).

Il tipo IDpiConvertOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [dpi](/conversion/python-net/groupdocs.conversion.options.convert/idpiconvertoptions/dpi/) | Il DPI della pagina desiderato dopo la conversione. |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/idpiconvertoptions/format/) | Il tipo di file desiderato in cui il documento di input dovrebbe essere convertito. |
