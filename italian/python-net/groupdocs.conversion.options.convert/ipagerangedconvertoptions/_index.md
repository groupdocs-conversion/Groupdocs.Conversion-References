## IPageRangedConvertOptions class

Rappresenta le opzioni di conversione che supportano la conversione di un elenco specifico di pagine.

Il tipo IPageRangedConvertOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/format/) | Il tipo di file desiderato in cui il documento di input dovrebbe essere convertito. |
| [pages](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/pages/) | L'elenco degli indici di pagina da convertire. Deve essere specificato per convertire pagine specifiche. |
