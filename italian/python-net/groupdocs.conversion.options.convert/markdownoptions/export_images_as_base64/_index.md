## export_images_as_base64 property

L'opzione export_images_as_base64 determina se le immagini vengono esportate come base64.

Il valore predefinito è True. Ignorato quando [`MarkdownOptions.image_saving_callback`](/conversion/python-net/groupdocs.conversion.options.convert/markdownoptions/image_saving_callback/) è impostato.
