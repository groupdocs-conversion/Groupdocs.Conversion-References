### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [auto_align](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/auto_align/) | Il watermark viene scalato automaticamente per adattarsi alle dimensioni della pagina quando impostato su True. |
| [background](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/background/) | Il watermark è stampato come sfondo; se True, è posizionato in basso, altrimenti è posizionato in alto (il valore predefinito è False). |
| [height](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/height/) | L'altezza del watermark. |
| [left](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/left/) | La posizione sinistra del watermark. |
| [rotation_angle](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/rotation_angle/) | L'angolo di rotazione del watermark. |
| [top](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/top/) | La posizione superiore del watermark. |
| [transparency](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/transparency/) | La trasparenza del watermark. Valore compreso tra 0 e 1. Il valore 0 è completamente visibile, il valore 1 è invisibile. |
| [width](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/width/) | La larghezza del watermark. |
