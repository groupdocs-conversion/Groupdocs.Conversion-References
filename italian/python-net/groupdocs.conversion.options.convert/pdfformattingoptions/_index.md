### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [center_window](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/center_window/) | La posizione della finestra sarà centrata sullo schermo quando True; altrimenti utilizzerà la posizione predefinita. Il valore predefinito è False. |
| [direction](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/direction/) | L'ordine di lettura del testo. Può essere impostato su L2R (da sinistra a destra) o R2L (da destra a sinistra). Il valore predefinito è L2R. |
| [display_doc_title](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/display_doc_title/) | La proprietà specifica se la barra del titolo della finestra del documento deve visualizzare il titolo del documento. Predefinito: False. |
| [fit_window](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/fit_window/) | La finestra del documento viene ridimensionata per adattarsi alla prima pagina visualizzata quando True, altrimenti mantiene le sue dimensioni; il valore predefinito è False. |
| [hide_menu_bar](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/hide_menu_bar/) | Il flag che indica se la barra dei menu deve essere nascosta quando il documento è attivo. Il valore predefinito è False. |
| [hide_tool_bar](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/hide_tool_bar/) | Il flag di visibilità della barra degli strumenti che indica se la barra degli strumenti deve essere nascosta quando il documento è attivo. Il valore predefinito è False. |
| [hide_window_ui](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/hide_window_ui/) | La proprietà indica se gli elementi dell'interfaccia utente devono essere nascosti quando il documento è attivo. Il valore predefinito è False. |
| [non_full_screen_page_mode](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/non_full_screen_page_mode/) | La modalità di pagina che specifica come visualizzare il documento uscendo dalla modalità a schermo intero. |
| [page_layout](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/page_layout/) | Il layout di pagina da utilizzare quando il documento viene aperto. |
| [page_mode](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/page_mode/) | La modalità di pagina, che specifica come il documento deve essere visualizzato quando aperto. |
