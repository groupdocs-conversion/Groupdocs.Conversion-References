## CadConvertOptions class

Rappresenta le opzioni per la conversione al tipo CAD.

Il tipo CadConvertOptions espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/__init__/) | Inizializza una nuova istanza di [`CadConvertOptions`](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/). |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/format/) | Il tipo di file desiderato in cui il documento di input dovrebbe essere convertito. |
| [page_height](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/page_height/) | L'altezza della pagina in punti. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/page_number/) | Il numero di pagina da cui iniziare la conversione. |
| [page_size](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/page_size/) | La dimensione della pagina. Implementa [`PageSize`](/conversion/python-net/groupdocs.conversion.options/pagesize/). |

| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/pages_count/) | Il conteggio delle pagine. |
| [size_settings](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/size_settings/) | Le impostazioni di dimensione. Vedi [`IPageSizeOptions`](/conversion/python-net/groupdocs.conversion.options/ipagesizeoptions/) per i dettagli. |
