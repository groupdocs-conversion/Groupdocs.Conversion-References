## WebConvertOptions class

Rappresenta le opzioni per la conversione al tipo di file Web.

Il tipo WebConvertOptions espone i seguenti membri:

### Costruttori
| Costruttore | Descrizione |
| :- | :- |
| [__init__](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/__init__/) | Inizializza una nuova istanza di [`WebConvertOptions`](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/). |

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [embed_font_resources](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/embed_font_resources/) | Il flag che specifica se incorporare le risorse dei font nell'HTML principale. Il valore predefinito è False. |
| [fixed_layout](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/fixed_layout/) | Il flag di layout fisso. |
| [fixed_layout_show_borders](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/fixed_layout_show_borders/) | I bordi della pagina vengono mostrati durante la conversione a layout fisso. Il valore predefinito è True. |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/format/) | Il tipo di file desiderato in cui il documento di input dovrebbe essere convertito. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/page_number/) | Il numero di pagina da cui iniziare la conversione. |
| [pages](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/pages/) | L'elenco degli indici di pagina da convertire; specificarlo per convertire pagine specifiche. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/pages_count/) | Il numero di pagine da convertire a partire da `PageNumber`. |
| [use_pdf](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/use_pdf/) | La proprietà UsePdf. |
| [watermark](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/watermark/) | Le opzioni specifiche del watermark. |
| [zoom](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/zoom/) | Il livello di zoom in percentuale. Il valore predefinito è 100. |
