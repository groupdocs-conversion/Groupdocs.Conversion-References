## IPagedConvertOptions class

Rappresenta le opzioni di conversione che consentono di limitare le pagine specificando la pagina iniziale e il numero di pagine.

Il tipo IPagedConvertOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | Il tipo di file desiderato in cui il documento di input dovrebbe essere convertito. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | Il numero di pagina da cui iniziare la conversione. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | Il numero di pagine da convertire a partire da `PageNumber`. |
