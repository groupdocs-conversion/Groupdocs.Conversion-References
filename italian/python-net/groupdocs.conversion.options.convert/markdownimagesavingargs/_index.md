## MarkdownImageSavingArgs class

Rappresenta gli argomenti passati a [`IMarkdownImageSavingCallback.image_saving`](/conversion/python-net/groupdocs.conversion.options.convert/imarkdownimagesavingcallback/image_saving/).

Il tipo MarkdownImageSavingArgs espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [image_file_name](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_file_name/) | Il nome file (o ID segnaposto) incorporato come URI dell'immagine nell'output Markdown. Assegna per riscrivere l'URI. |
| [image_stream](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_stream/) | Il flusso di destinazione in cui il convertitore scriverà i byte dell'immagine dopo che questa callback restituisce. |
| [keep_image_stream_open](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/keep_image_stream_open/) | La proprietà determina se il convertitore mantiene aperto il flusso dell'immagine dopo la conversione. |
