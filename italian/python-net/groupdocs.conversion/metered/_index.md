## Metered class

Gestisce la licenza a consumo (pay-per-use).

Le licenze Metered fatturano in base al consumo reale (tipicamente pagine o
documenti elaborati). Imposta la coppia di chiavi pubblica/privata una volta al
avvio dell'applicazione; il wrapper riporta l'utilizzo al server GroupDocs
server di licenza in background.

Il tipo Metered espone i seguenti membri:

### Metodi
| Metodo | Descrizione |
| :- | :- |
| [get_consumption_credit](/conversion/python-net/groupdocs.conversion/metered/get_consumption_credit/) | Restituisce il credito residuo metered per la chiave corrente. |
| [get_consumption_quantity](/conversion/python-net/groupdocs.conversion/metered/get_consumption_quantity/) | Restituisce la quantità totale metered consumata finora. |
| [set_metered_key](/conversion/python-net/groupdocs.conversion/metered/set_metered_key/#public_key-private_key) | Attiva la fatturazione metered con la coppia di chiavi pubblica/privata fornita. |
