## IPageNumberingLoadOptions class

Fornisce opzioni per controllare la numerazione delle pagine nel documento convertito.

Il tipo IPageNumberingLoadOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [page_numbering](/conversion/python-net/groupdocs.conversion.options.load/ipagenumberingloadoptions/page_numbering/) | Il flag di numerazione delle pagine abilita o disabilita la generazione della numerazione delle pagine nel documento convertito (il valore predefinito è False). |
