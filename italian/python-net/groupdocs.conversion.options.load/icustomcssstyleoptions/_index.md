## ICustomCssStyleOptions class

Rappresenta opzioni per lo stile CSS personalizzato durante la conversione del documento.

Il tipo ICustomCssStyleOptions espone i seguenti membri:

### Proprietà
| Proprietà | Descrizione |
| :- | :- |
| [custom_css_style](/conversion/python-net/groupdocs.conversion.options.load/icustomcssstyleoptions/custom_css_style/) | Lo stile CSS personalizzato da applicare al documento durante la conversione, che verrà inserito nel tag `<head>` del documento per personalizzare il rendering. |
