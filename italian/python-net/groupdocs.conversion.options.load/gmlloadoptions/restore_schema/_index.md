## restore_schema property

La proprietà determina se la conversione è autorizzata a analizzare gli attributi in un file GML quando lo schema XML è mancante o non può essere caricato.

Se impostato su True, il lettore di conversione non richiede la presenza di uno schema XML. Il valore predefinito è False.
