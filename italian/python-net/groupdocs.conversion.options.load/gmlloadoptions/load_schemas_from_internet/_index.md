## load_schemas_from_internet property

La proprietà determina se la conversione è autorizzata a caricare gli schemi XML da Internet.

Se impostato su False, gli schemi con URI assoluti che non iniziano con 'file://' non verranno caricati. Il valore predefinito è False.
