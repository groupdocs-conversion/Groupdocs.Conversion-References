## schema_location property

Lo schema_location è un elenco separato da spazi di coppie di URI, dove il primo URI di ogni coppia è l'URI dello spazio dei nomi e il secondo URI è il percorso dello schema XML di quello spazio dei nomi.

Se impostato su None, Conversion proverà a leggere l'attributo schemaLocation dall'elemento radice del documento. Il valore predefinito è None.
