## LoadOptions class

Rappresenta le opzioni di caricamento del documento astratto.

Le classi LoadOptions specificano il tipo di documento da caricare e includono parametri opzionali, come `password`. Sono categorizzate in due gruppi: opzioni per una famiglia di formati e opzioni per un tipo di file specifico.

Il tipo LoadOptions espone i seguenti membri:
