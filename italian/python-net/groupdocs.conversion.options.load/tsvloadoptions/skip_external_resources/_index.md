## skip_external_resources property

La proprietà determina se le risorse esterne vengono caricate; se True, tutte le risorse esterne non verranno caricate eccetto quelle presenti nell'elenco [`IResourceLoadingOptions.whitelisted_resources`](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/). Predefinito: True.
