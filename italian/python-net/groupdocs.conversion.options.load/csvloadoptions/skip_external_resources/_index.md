## skip_external_resources property

La proprietà indica se le risorse esterne vengono caricate. Se True, tutte le risorse esterne non verranno caricate eccetto quelle nella lista [`IResourceLoadingOptions.whitelisted_resources`](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/). Valore predefinito: True.
