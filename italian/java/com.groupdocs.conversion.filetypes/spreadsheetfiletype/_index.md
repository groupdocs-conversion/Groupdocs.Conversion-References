### Xls {#Xls}
```
public static final SpreadsheetFileType Xls
```


XLS rappresenta il formato di file binario di Excel. Tali file possono essere creati da Microsoft Excel così come da altri programmi di fogli di calcolo simili, come OpenOffice Calc o Apple Numbers.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/xls).


### Xlsx {#Xlsx}
```
public static final SpreadsheetFileType Xlsx
```


XLSX è un formato molto noto per i documenti Microsoft Excel, introdotto da Microsoft con il rilascio di Microsoft Office 2007.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/xlsx).


### Xlsm {#Xlsm}
```
public static final SpreadsheetFileType Xlsm
```


XLSM è un tipo di file Spreadsheet che supporta le macro.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/xlsm).


### Xlsb {#Xlsb}
```
public static final SpreadsheetFileType Xlsb
```


Il formato file XLSB specifica l'Excel Binary File Format, che è una raccolta di record e strutture che definiscono il contenuto della cartella di lavoro Excel.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/xlsb).


### Ods {#Ods}
```
public static final SpreadsheetFileType Ods
```


I file con estensione ODS rappresentano il formato OpenDocument Spreadsheet Document, modificabili dall'utente. I dati sono memorizzati all'interno del file ODF in righe e colonne.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/ods).


### Ots {#Ots}
```
public static final SpreadsheetFileType Ots
```


Un file con estensione .ots è un file modello OpenDocument Spreadsheet creato con il software Calc incluso in Apache OpenOffice. Il software Calc è simile a Excel disponibile in Microsoft Office.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/ots).


### Xltx {#Xltx}
```
public static final SpreadsheetFileType Xltx
```


Il file XLTX rappresenta un modello di Microsoft Excel basato sulle specifiche del formato di file Office OpenXML. Viene utilizzato per creare un file modello standard che può essere impiegato per generare file XLSX con le stesse impostazioni specificate nel file XLTX.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/xltx).


### Xlt {#Xlt}
```
public static final SpreadsheetFileType Xlt
```


I file con estensione .XLT sono file modello creati con Microsoft Excel, un'applicazione di fogli di calcolo inclusa nella suite Microsoft Office. Microsoft Office 97-2003 supportava la creazione di nuovi file XLT così come l'apertura di questi.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/xlt).


### Xltm {#Xltm}
```
public static final SpreadsheetFileType Xltm
```


L'estensione di file XLTM rappresenta file generati da Microsoft Excel come modelli abilitati alle macro. I file XLTM sono simili a XLTX nella struttura, tranne per il fatto che quest'ultimo non supporta la creazione di modelli con macro.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/xltm).


### Tsv {#Tsv}
```
public static final SpreadsheetFileType Tsv
```


Un formato di file Tab-Separated Values (TSV) rappresenta dati separati da tabulazioni in formato di testo semplice.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/tsv).


### Xlam {#Xlam}
```
public static final SpreadsheetFileType Xlam
```


XLAM è un file Add-In abilitato alle macro utilizzato per aggiungere nuove funzioni ai fogli di calcolo. Un Add-In è un programma supplementare che esegue codice aggiuntivo e fornisce funzionalità aggiuntive per i fogli di calcolo.
Per saperne di più su questo formato di file [qui](../https://docs.fileformat.com/spreadsheet/xlam/)


### Csv {#Csv}
```
public static final SpreadsheetFileType Csv
```


I file con estensione CSV (Comma Separated Values) rappresentano file di testo semplice che contengono record di dati con valori separati da virgole.
Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/csv).


### Fods {#Fods}
```
public static final SpreadsheetFileType Fods
```


Un file con estensione .fods è un tipo di formato di documento OpenDocument Spreadsheet che memorizza i dati in righe e colonne. Il formato è specificato come parte delle specifiche ODF 1.2 pubblicate e mantenute da OASIS. Per saperne di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/fods).


### Dif {#Dif}
```
public static final SpreadsheetFileType Dif
```


DIF sta per Data Interchange Format ed è usato per importare/esportare dati di fogli di calcolo tra diverse applicazioni. Queste includono Microsoft Excel, OpenOffice Calc, StarCalc e molti altri. Scopri di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/dif).


### Sxc {#Sxc}
```
public static final SpreadsheetFileType Sxc
```


Il formato di file SXC (Sun XML Calc) appartiene a una suite office chiamata OpenOffice.org. Questo formato soddisfa generalmente le esigenze di fogli di calcolo degli utenti poiché è un formato di file di foglio di calcolo basato su XML. Il formato SXC supporta formule, funzioni, macro e grafici insieme a DataPilot. Scopri di più su questo formato di file [qui](../https://wiki.fileformat.com/spreadsheet/sxc).


### Numbers {#Numbers}
```
public static final SpreadsheetFileType Numbers
```


I file con estensione .numbers sono classificati come tipo di file di foglio di calcolo, ecco perché sono simili ai file .xlsx; ma i file Numbers sono creati utilizzando il software di foglio di calcolo Apple iWork Numbers. Scopri di più su questo formato di file [qui](../https://docs.fileformat.com/spreadsheet/numbers).
