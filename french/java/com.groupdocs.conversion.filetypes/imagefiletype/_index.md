### Tiff {#Tiff}
```
public static final ImageFileType Tiff
```


TIFF, Tagged Image File Format, représente des images raster destinées à être utilisées sur une variété d'appareils conformes à cette norme de format de fichier. Il est capable de décrire des données d'image binaire, en niveaux de gris, à palette de couleurs et en couleur complète dans plusieurs espaces colorimétriques.
En savoir plus sur ce format de fichier [ici](../https://wiki.fileformat.com/image/tiff).

### Png {#Png}
```
public static final ImageFileType Png
```


PNG, Portable Network Graphics, désigne un type de format de fichier d'image raster qui utilise une compression sans perte. Ce format de fichier a été créé comme remplacement du Graphics Interchange Format (GIF) et ne comporte aucune limitation de droits d'auteur.
En savoir plus sur ce format de fichier [ici](../https://wiki.fileformat.com/image/png).


### Gif {#Gif}
```
public static final ImageFileType Gif
```

Un GIF ou Graphical Interchange Format est un type d'image fortement compressée. Pour chaque image, le GIF autorise généralement jusqu'à 8 bits par pixel et jusqu'à 256 couleurs sont permises dans l'image.
En savoir plus sur ce format de fichier [ici](../https://wiki.fileformat.com/image/gif).
