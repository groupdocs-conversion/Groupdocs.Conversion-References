## error {#message-exception}

Écrit un message de journal d'erreur.

Les messages de journal d'erreur fournissent des informations sur les événements irrécupérables dans le flux d'application.

```python
def error(self, message, exception):
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| message | `str` | Le message d'erreur. |
| exception | `Exception` | L'exception. |
