### Propriétés
| Propriété | Description |
| :- | :- |
| [auto_align](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/auto_align/) | Le filigrane est automatiquement mis à l'échelle pour s'adapter à la taille de la page lorsqu'il est défini sur True. |
| [background](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/background/) | Le filigrane est appliqué en arrière-plan ; si True, il est placé en bas, sinon il est placé au premier plan (la valeur par défaut est False). |
| [height](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/height/) | La hauteur du filigrane. |
| [left](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/left/) | La position gauche du filigrane. |

| [top](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/top/) | La position supérieure du filigrane. |
| [transparency](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/transparency/) | La transparence du filigrane. Valeur entre 0 et 1. La valeur 0 est entièrement visible, la valeur 1 est invisible. |
| [width](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/width/) | La largeur du filigrane. |
