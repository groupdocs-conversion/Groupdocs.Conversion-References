## IPagedConvertOptions class

Représente les options de conversion qui permettent de limiter les pages en spécifiant la page de début et le nombre de pages.

Le type IPagedConvertOptions expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | Le type de fichier souhaité vers lequel le document d'entrée doit être converti. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | Le numéro de page à partir duquel commencer la conversion. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | Le nombre de pages à convertir à partir de `PageNumber`. |
