## IPageRangedConvertOptions class

Représente les options de conversion qui prennent en charge la conversion d’une liste spécifique de pages.

Le type IPageRangedConvertOptions expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/format/) | Le type de fichier souhaité vers lequel le document d'entrée doit être converti. |
| [pages](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/pages/) | La liste des index de pages à convertir. Doit être spécifiée pour convertir des pages spécifiques. |
