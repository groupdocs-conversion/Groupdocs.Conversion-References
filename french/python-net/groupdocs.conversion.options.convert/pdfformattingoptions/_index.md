| Propriété | Description |

| [hide_menu_bar](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/hide_menu_bar/) | Le drapeau indiquant si la barre de menu doit être masquée lorsque le document est actif. Valeur par défaut : False. |

| [non_full_screen_page_mode](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/non_full_screen_page_mode/) | Le mode de page qui spécifie comment afficher le document lors de la sortie du mode plein écran. |

| [page_mode](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/page_mode/) | Le mode de page, spécifiant comment le document doit être affiché lorsqu'il est ouvert. |
