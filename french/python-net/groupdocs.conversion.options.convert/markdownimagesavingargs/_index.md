## MarkdownImageSavingArgs class

Représente les arguments transmis à [`IMarkdownImageSavingCallback.image_saving`](/conversion/python-net/groupdocs.conversion.options.convert/imarkdownimagesavingcallback/image_saving/).

### Propriétés
| Propriété | Description |
| :- | :- |
| [image_file_name](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_file_name/) | Le nom de fichier (ou l'identifiant de l'espace réservé) intégré en tant qu'URI de l'image dans la sortie Markdown. Attribuez‑le pour réécrire l'URI. |
| [image_stream](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_stream/) | Le flux de destination dans lequel le convertisseur écrira les octets de l'image après le retour de ce rappel. |
