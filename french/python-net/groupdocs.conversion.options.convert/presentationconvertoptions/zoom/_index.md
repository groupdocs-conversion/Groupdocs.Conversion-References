## zoom property

Le niveau de zoom en pourcentage.

Par défaut est 100. Le zoom par défaut est pris en charge jusqu'à Microsoft Powerpoint 2010. À partir de Microsoft Powerpoint 2013, le zoom par défaut n'est plus défini sur le document, il semble plutôt utiliser le facteur de zoom du dernier document ouvert.
