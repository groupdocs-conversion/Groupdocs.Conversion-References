## Metered class

Gère la licence à la consommation (pay-per-use).

Les licences Metered facturent la consommation réelle (généralement les pages ou
documents traités). Définissez la paire de clés publique/privée une fois à
démarrage de l'application ; le wrapper renvoie l'utilisation au serveur GroupDocs
serveur de licence en arrière-plan.

Le type Metered expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [get_consumption_credit](/conversion/python-net/groupdocs.conversion/metered/get_consumption_credit/) | Renvoie le crédit Metered restant pour la clé actuelle. |
| [get_consumption_quantity](/conversion/python-net/groupdocs.conversion/metered/get_consumption_quantity/) | Renvoie la quantité totale Metered consommée jusqu'à présent. |
| [set_metered_key](/conversion/python-net/groupdocs.conversion/metered/set_metered_key/#public_key-private_key) | Active la facturation Metered avec la paire de clés publique/privée fournie. |
