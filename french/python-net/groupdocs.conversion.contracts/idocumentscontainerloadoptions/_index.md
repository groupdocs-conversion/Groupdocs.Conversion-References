## IDocumentsContainerLoadOptions class

Représente les options de chargement pour un conteneur de documents.

Le type IDocumentsContainerLoadOptions expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [convert_owned](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owned/) | L'option permet de contrôler si les documents détenus dans le conteneur de documents doivent être convertis. |
| [convert_owner](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owner/) | L'option permettant de contrôler si le conteneur de documents lui‑même doit être converti. |
| [depth](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/depth/) | L'option permet de contrôler combien de niveaux en profondeur la conversion doit être effectuée. |
