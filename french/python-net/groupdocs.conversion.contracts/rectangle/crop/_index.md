## crop {#crop_left-crop_top-crop_right-crop_bottom}

Crée une version recadrée du rectangle actuel en supprimant les marges spécifiées.

```python
def crop(self, crop_left, crop_top, crop_right, crop_bottom):
    ...
```

| Paramètre | Type | Description |
| :- | :- | :- |
| crop_left | `int` | Le nombre de pixels à supprimer du côté gauche. |
| crop_top | `int` | Le nombre de pixels à supprimer du côté supérieur. |
| crop_right | `int` | Le nombre de pixels à supprimer du côté droit. |
| crop_bottom | `int` | Le nombre de pixels à supprimer du côté inférieur. |

**Returns:** Rectangle: A new cropped rectangle.
