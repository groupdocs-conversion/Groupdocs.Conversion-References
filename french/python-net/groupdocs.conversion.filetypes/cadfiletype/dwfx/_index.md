## DWFX field

Le fichier DWFX est un dessin 2D ou 3D créé avec le logiciel CAD d'Autodesk. Il est enregistré au format DWFx, qui est similaire à un fichier .DWF, mais est formaté en utilisant la spécification XML Paper Specification (XPS) de Microsoft.
