## DWG field

Les fichiers avec l'extension DWG représentent des fichiers binaires propriétaires utilisés pour contenir des données de conception 2D et 3D. Comme le DXF, qui sont des fichiers ASCII, le DWG représente le format de fichier binaire pour les dessins CAD (Computer Aided Design). En savoir plus sur ce format de fichier ici.
