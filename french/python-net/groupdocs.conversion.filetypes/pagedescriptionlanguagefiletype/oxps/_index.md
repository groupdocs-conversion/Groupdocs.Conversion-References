## OXPS field

Le format de fichier OXPS est connu sous le nom d'Open XML Paper Specification. C'est un langage de description de page et un format de document. Microsoft est le développeur de ce format. Le format de fichier OXPS est très similaire aux fichiers PDF. En savoir plus sur ce format de fichier ici.
