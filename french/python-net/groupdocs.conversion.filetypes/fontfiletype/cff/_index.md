## CFF field

Un fichier avec l'extension .cff est un Compact Font Format, également connu sous le nom de PostScript Type 1 ou CIDFont. CFF agit comme un conteneur pour stocker plusieurs polices ensemble dans une unité unique appelée FontSet. En savoir plus sur ce format de fichier ici.
