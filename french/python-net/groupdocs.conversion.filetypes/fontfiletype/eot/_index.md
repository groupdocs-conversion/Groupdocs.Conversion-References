## EOT field

Un fichier avec l'extension .eot est une police OpenType intégrée dans un document. Elles sont principalement utilisées dans les fichiers web tels qu'une page Web. Il a été créé par Microsoft et est pris en charge par les produits Microsoft, y compris les présentations PowerPoint au format .pps. En savoir plus sur ce format de fichier ici.
