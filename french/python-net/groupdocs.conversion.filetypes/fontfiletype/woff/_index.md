## WOFF field

Un fichier avec l'extension .woff est un fichier de police web basé sur le Web Open Font Format (WOFF). Il possède un conteneur compressé spécifique au format, basé soit sur les polices TrueType (.TTF) soit sur les polices OpenType (.OTT). En savoir plus sur ce format de fichier ici.
