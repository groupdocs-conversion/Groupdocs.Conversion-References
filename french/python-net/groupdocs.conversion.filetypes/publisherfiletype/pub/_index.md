## PUB field

Un fichier PUB est un format de document Microsoft Publisher. Il est utilisé pour créer plusieurs types de documents de mise en page tels que des bulletins d’information, des flyers, des brochures, des cartes postales, etc. Les fichiers PUB peuvent contenir du texte, des images raster et vectorielles. En savoir plus sur ce format de fichier ici.
