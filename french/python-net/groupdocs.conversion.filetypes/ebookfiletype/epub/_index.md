## EPUB field

L'extension EPUB est un format de fichier e‑book qui fournit un format de publication numérique standard pour les éditeurs et les consommateurs. Le format est désormais si répandu qu'il est pris en charge par de nombreux lecteurs électroniques et applications logicielles. En savoir plus sur ce format de fichier ici.
