## AZW3 field

AZW3, également connu sous le nom de Kindle Format 8 (KF8), est la version modifiée du format de fichier numérique AZW développé pour les appareils Amazon Kindle. Le format est une amélioration des anciens fichiers AZW et est utilisé uniquement sur les appareils Kindle Fire, tout en restant compatible avec le format ancêtre, c’est‑à‑dire MOBI et AZW. En savoir plus sur ce format de fichier ici.
