## MOBI field

Le format de fichier MOBI est l'un des formats de livre numérique les plus largement utilisés. Le format est une amélioration du vieux format OEB (Open Ebook Format) et était utilisé comme format propriétaire pour le lecteur Mobipocket. En savoir plus sur ce format de fichier ici.
