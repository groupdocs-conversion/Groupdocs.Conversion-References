## USD field

Un fichier avec l'extension .usd est un format de fichier Universal Scene Description qui encode des données dans le but d'échanger et d'enrichir les données entre les applications de création de contenu numérique. Développé par Pixar, USD offre la possibilité d'échanger des actifs élémentaires (comme des modèles) ou des animations. En savoir plus sur ce format de fichier ici.
