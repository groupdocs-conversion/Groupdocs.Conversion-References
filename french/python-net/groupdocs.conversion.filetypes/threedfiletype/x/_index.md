## X field

Un fichier avec l'extension .x fait référence à un format de fichier hérité DirectX 3D Graphics qui a été introduit avec Microsoft DirectX 2.0. Il était utilisé pour le rendu 3D dans les jeux et spécifie les structures pour les maillages, textures, animations et objets définis par l'utilisateur. Il est obsolète depuis 2014, le format de fichier Autodesk FBX étant plus adapté comme format moderne. En savoir plus sur ce format de fichier ici.
