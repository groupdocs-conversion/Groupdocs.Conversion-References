## DAE field

Un fichier DAE est un format de fichier Digital Asset Exchange utilisé pour échanger des données entre des applications 3D interactives. Ce format de fichier est basé sur le schéma XML COLLADA (COLLAborative Design Activity), qui est un schéma XML standard ouvert pour l'échange d'actifs numériques entre les applications logicielles graphiques. En savoir plus sur ce format de fichier ici.
