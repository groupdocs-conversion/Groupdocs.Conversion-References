## MPX field

Microsoft Exchange File Format est un format de fichier ASCII destiné au transfert d'informations de projet entre Microsoft Project (MSP) et d'autres applications qui prennent en charge le format de fichier MPX telles que Primavera Project Planner, Sciforma et Timerline Precision Estimating.
