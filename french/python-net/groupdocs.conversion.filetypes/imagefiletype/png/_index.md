## PNG field

PNG, Portable Network Graphics, désigne un type de format de fichier d'image raster qui utilise une compression sans perte. Ce format de fichier a été créé comme remplacement du Graphics Interchange Format (GIF) et n'a aucune limitation de droits d'auteur. En savoir plus sur ce format de fichier ici.
