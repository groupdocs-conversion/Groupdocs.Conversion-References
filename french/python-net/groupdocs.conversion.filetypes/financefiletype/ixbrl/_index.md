## IXBRL field

Dans le iXBRL, le contenu de XBRL est encapsulé dans un format de fichier xHTML qui utilise des balises XML. Comme XBRL, il constitue l’élément racine des fichiers iXBRL. Le format XHTML représente son contenu comme une collection de différents types de documents et modules. Tous les fichiers en XHTML sont basés sur le format de fichier XML et respectent les normes de documents XML. En savoir plus sur ce format de fichier ici.
