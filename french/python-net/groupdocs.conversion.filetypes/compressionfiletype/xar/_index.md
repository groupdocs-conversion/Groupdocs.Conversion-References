## XAR field

Un fichier avec l'extension .xar est un eXtensible ARchive, un format construit autour d'une table des matières stockée sous forme XML compressé. Il est utilisé pour distribuer les packages d'installation macOS et conserve chaque entrée compressée séparément. En savoir plus sur ce format de fichier ici.
