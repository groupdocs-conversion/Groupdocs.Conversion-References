## LHA field

Un fichier avec les extensions .lzh et .lha se rapporte généralement à un format de compression d'archive. Ce format de fichier est identique à d'autres formats de compression comme ZIP, RAR, etc. Le principal objectif de ces formats est de réduire la taille du fichier pour faciliter l'envoi ainsi que de les conserver ensemble sous forme compressée.
