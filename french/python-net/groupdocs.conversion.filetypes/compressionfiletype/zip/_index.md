## ZIP field

Un fichier avec l'extension .zip est une archive qui peut contenir un ou plusieurs fichiers ou répertoires. L'archive peut être compressée sur les fichiers inclus afin de réduire la taille du fichier ZIP. En savoir plus sur ce format de fichier ici.
