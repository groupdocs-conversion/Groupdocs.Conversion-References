## Z field

Un fichier Z est une catégorie de fichiers appartenant aux fichiers de données compressés UNIX. Les fichiers Unix compressés sont le type d'extension le plus populaire et le plus utilisé du fichier Z. En savoir plus sur ce format de fichier ici.
