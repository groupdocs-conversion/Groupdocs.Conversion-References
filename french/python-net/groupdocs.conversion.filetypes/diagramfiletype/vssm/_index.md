## VSSM field

Les fichiers avec l'extension .VSSM sont des fichiers de pochoir Microsoft Visio qui prennent en charge les macros. Un fichier VSSM, lorsqu'il est ouvert, permet d'exécuter les macros afin d'obtenir le formatage et le placement souhaités des formes dans un diagramme. En savoir plus sur ce format de fichier ici.
