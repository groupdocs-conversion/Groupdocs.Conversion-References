## VTX field

Un fichier avec l'extension VTX est un modèle de dessin Microsoft Visio qui est enregistré sur le disque au format XML. Le modèle vise à fournir un fichier avec des paramètres de base qui peuvent être utilisés pour créer plusieurs fichiers Visio avec les mêmes paramètres. En savoir plus sur ce format de fichier ici.
