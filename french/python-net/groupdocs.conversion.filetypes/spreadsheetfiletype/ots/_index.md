## OTS field

Un fichier avec l'extension .ots est un modèle de feuille de calcul OpenDocument créé avec le logiciel d'application Calc inclus dans Apache OpenOffice. Le logiciel d'application Calc est similaire à Excel disponible dans Microsoft Office. En savoir plus sur ce format de fichier ici.
