## PDF field

Portable Document Format (PDF) est un type de document créé par Adobe dans les années 1990. Le but de ce format de fichier était d’introduire une norme pour la représentation de documents et d’autres supports de référence dans un format indépendant du logiciel d’application, du matériel ainsi que du système d’exploitation.
