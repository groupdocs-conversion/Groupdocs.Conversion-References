## WordProcessingFileType class

La classe WordProcessingFileType définit les formats de fichiers de traitement de texte, couvrant les variantes texte brut et texte enrichi.

Les fichiers texte brut contiennent du texte non formaté sans police ni paramètres de page appliqués. Les fichiers texte enrichi prennent en charge des options de formatage telles que les types de police, les styles (gras, italique, souligné), les marges de page, les titres, les puces, les numéros et d'autres fonctionnalités.

### Exemple

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # Instanciez le Convertisseur avec le document d'entrée
    with Converter("./business-plan.docx") as converter:
        # Définissez les options de conversion ; le format de sortie par défaut est DOCX
        word_convert_options = WordProcessingConvertOptions()
        # Modifiez le format de sortie au sein de la famille de formats de DOCX à TXT
        word_convert_options.format = WordProcessingFileType.Txt

        # Convertissez le document d'entrée en TXT
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
