## PPTX field

Les fichiers avec l'extension PPTX sont des présentations créées avec l'application populaire Microsoft PowerPoint. Contrairement à la version précédente du format de fichier de présentation PPT qui était binaire, le format PPTX repose sur le format de présentation Open XML de Microsoft PowerPoint. En savoir plus sur ce format de fichier ici.
