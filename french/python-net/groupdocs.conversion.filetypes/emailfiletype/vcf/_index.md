## VCF field

VCF (Virtual Card Format) ou vCard est un format de fichier numérique pour stocker des informations de contact. Le format est largement utilisé pour l'échange de données entre les applications d'échange d'informations populaires. En savoir plus sur ce format de fichier ici.
