## OLM field

Un fichier avec l'extension .olm est un fichier Microsoft Outlook pour le système d'exploitation Mac. Un fichier OLM stocke des messages électroniques, des journaux, des données de calendrier et d'autres types de données d'application. Ceux-ci sont similaires aux fichiers PST utilisés par Outlook sur le système d'exploitation Windows. Cependant, les fichiers OLM créés par Outlook pour Mac ne peuvent pas être ouverts dans Outlook pour Windows. En savoir plus sur ce format de fichier ici.
