## TOPO_JSON field

TopoJSON est une extension de GeoJSON qui encode la topologie. Plutôt que de représenter les géométries de façon distincte, les géométries dans les fichiers TopoJSON sont assemblées à partir de segments de ligne partagés appelés arcs.
