## SHP field

SHP est l'extension de fichier pour l'un des principaux types de fichiers utilisés pour la représentation du Shapefile ESRI. Il représente des informations géospatiales sous forme de données vectorielles à utiliser par les applications de systèmes d'information géographique (GIS). En savoir plus sur ce format de fichier ici.
