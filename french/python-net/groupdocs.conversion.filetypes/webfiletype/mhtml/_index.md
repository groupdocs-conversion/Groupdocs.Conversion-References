## MHTML field

Les fichiers avec l'extension MHTML représentent un format d'archive de page web qui peut être créé par plusieurs applications différentes. Ce format est appelé format d'archive car il enregistre le code HTML web et les ressources associées dans un seul fichier. En savoir plus sur ce format de fichier ici.
