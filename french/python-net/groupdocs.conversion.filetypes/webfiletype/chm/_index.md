## CHM field

Le format de fichier CHM représente le fichier d'aide HTML de Microsoft qui consiste en une collection de pages HTML. Il fournit un index pour accéder rapidement aux sujets et une navigation vers les différentes parties du document d'aide. En savoir plus sur ce format de fichier ici.
