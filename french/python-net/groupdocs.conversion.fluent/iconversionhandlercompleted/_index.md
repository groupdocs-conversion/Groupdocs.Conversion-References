## IConversionHandlerCompleted class

Représente l'interface fluide après que `OnConversionFailed` soit défini, permettant de définir `OnConversionCompleted` ou de passer à `Convert`/`Compress`.

Le type IConversionHandlerCompleted expose les membres suivants :

| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/convert/) | Exécute la chaîne de conversion. |
