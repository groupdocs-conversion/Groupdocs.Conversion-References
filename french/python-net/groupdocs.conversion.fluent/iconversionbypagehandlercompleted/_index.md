## IConversionByPageHandlerCompleted class

Fournit une interface fluide après que `OnConversionFailed` soit défini pour la conversion de page. Permet de définir `OnConversionCompleted` ou de passer à `Convert`/`Compress`.

Le type IConversionByPageHandlerCompleted expose les membres suivants :
