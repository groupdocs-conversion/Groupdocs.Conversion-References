## IConversionByPageHandlerSetup class

Fournit une interface fluide pour définir les gestionnaires de conversion de page.

Permet de définir `OnConversionCompleted` et/ou `OnConversionFailed` dans n'importe quel ordre, au plus une fois chacun, ou d'ignorer les deux.

Le type IConversionByPageHandlerSetup expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [compress](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/compress/#options) | Compresse les résultats de la conversion en utilisant les options spécifiées. |
| [compress_compression_convert_options](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/compress_compression_convert_options/) |  |
| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/convert/) | Exécute la chaîne de conversion. |
| [on_conversion_completed](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/on_conversion_completed/#on_completed) | Enregistre un rappel à invoquer lorsqu’une conversion de page se termine avec succès. |
| [on_conversion_completed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/on_conversion_completed_action/) |  |
