## restore_schema property

La propriété détermine si la conversion est autorisée à analyser les attributs d'un fichier GML lorsque le schéma XML est manquant ou ne peut pas être chargé.

Si défini sur True, le lecteur de conversion ne nécessite pas la présence d'un schéma XML. La valeur par défaut est False.
