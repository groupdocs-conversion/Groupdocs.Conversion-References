## schema_location property

Le schema_location est une liste d'URI séparés par des espaces, où le premier URI de chaque paire est l'URI de l'espace de noms et le second URI est le chemin vers le schéma XML de cet espace de noms.

Si défini sur None, Conversion tentera de lire l'attribut schemaLocation de l'élément racine du document. La valeur par défaut est None.
