## load_schemas_from_internet property

La propriété détermine si la conversion est autorisée à charger des schémas XML depuis Internet.

Si défini sur False, les schémas avec des URI absolus qui ne commencent pas par 'file://' ne seront pas chargés. La valeur par défaut est False.
