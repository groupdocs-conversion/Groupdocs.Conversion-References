## ICustomCssStyleOptions class

Représente des options pour le style CSS personnalisé lors de la conversion de documents.

Le type ICustomCssStyleOptions expose les membres suivants :

### Propriétés
| Propriété | Description |
| :- | :- |
| [custom_css_style](/conversion/python-net/groupdocs.conversion.options.load/icustomcssstyleoptions/custom_css_style/) | Le style CSS personnalisé à appliquer au document lors de la conversion, qui sera inséré dans la balise `<head>` du document pour personnaliser le rendu. |
