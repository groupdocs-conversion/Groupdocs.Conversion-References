## LoadOptions class

Représente les options de chargement de documents abstraits.

Les classes LoadOptions spécifient le type de document à charger et incluent des paramètres optionnels, tels que `password`. Elles sont catégorisées en deux groupes: les options pour une famille de formats et les options pour un type de fichier spécifique.
