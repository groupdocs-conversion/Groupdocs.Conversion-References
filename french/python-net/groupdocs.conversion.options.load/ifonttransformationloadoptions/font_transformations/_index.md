## font_transformations property

Les transformations de police appliquées après le chargement du document et la substitution de police.

Les transformations sont appliquées dans l'ordre où elles apparaissent dans la liste.

Utilisez ceci pour le style, la marque ou les changements de police d'accessibilité.
