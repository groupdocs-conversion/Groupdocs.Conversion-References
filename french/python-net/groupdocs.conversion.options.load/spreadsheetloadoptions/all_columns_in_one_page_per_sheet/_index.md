## all_columns_in_one_page_per_sheet property

La propriété détermine si tout le contenu des colonnes d’une feuille est rendu sur une seule page dans le résultat.

Lorsqu'elle est définie sur True, la largeur du format de papier dans la configuration de la page est ignorée, tandis que les autres paramètres de configuration de page restent effectifs.
