## skip_external_resources property

La propriété détermine si les ressources externes sont chargées ; si True, toutes les ressources externes ne seront pas chargées sauf celles de la liste [`IResourceLoadingOptions.whitelisted_resources`](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/). Valeur par défaut : True.
