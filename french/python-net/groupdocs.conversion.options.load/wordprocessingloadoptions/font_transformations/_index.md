## font_transformations property

Les transformations de police appliquées après le chargement du document et la substitution de police sont terminées, permettant la modification de toutes les polices du document, y compris celles chargées avec succès.

Remarque : les transformations de police sont appliquées après que toutes les étapes de substitution de police sont terminées.

Les transformations sont traitées dans l'ordre où elles apparaissent dans la liste.

Cas d'utilisation : modifications de style, exigences de marque, améliorations d'accessibilité.
