## PdfConvertOptions.EmbedFullFonts property

Lorsqu'il est défini sur true, le fichier de police complet est intégré dans le PDF au lieu d'un sous-ensemble. Cela augmente la taille du fichier de sortie mais garantit une meilleure compatibilité lors de l'édition du PDF résultant. S'applique uniquement lors de la conversion à partir de documents WordProcessing.

public bool EmbedFullFonts { get; set; }
