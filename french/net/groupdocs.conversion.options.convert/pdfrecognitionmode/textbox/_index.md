## PdfRecognitionMode.Textbox field

Ce mode est rapide et permet de préserver au maximum l'apparence originale du fichier PDF, mais l'édition du document résultant peut être limitée. Chaque bloc de texte visuellement groupé dans le fichier PDF original est converti en zone de texte dans le document résultant. Cela assure une ressemblance maximale du document de sortie avec le fichier PDF original. Le document de sortie aura une bonne apparence, mais il sera entièrement composé de zones de texte, ce qui peut rendre l'édition ultérieure du document dans Microsoft Word assez difficile. C'est le mode par défaut.

```csharp
public static readonly PdfRecognitionMode Textbox;
```
