## ImageConvertOptions.MinResolution property

Limite inférieure par axe appliquée au DPI de rendu limité lorsque [`CapResolutionToPageContent`](../capresolutiontopagecontent) est activé. Le DPI limité n'est jamais réduit en dessous de cette valeur. La valeur par défaut est `0` (pas de plancher).

public int MinResolution { get; set; }
