## EvaluationLimitReachedException class

Exception GroupDocs levée lorsque le quota de conversion d'évaluation pour le processus en cours est épuisé.

```csharp
public sealed class EvaluationLimitReachedException : GroupDocsConversionException
```

### Remarques

Toujours levée uniquement sans licence. L'application d'une licence supprime la limitation, ainsi un processus sous licence ne rencontre jamais cette exception, quel que soit le nombre de documents qu'il convertit.
