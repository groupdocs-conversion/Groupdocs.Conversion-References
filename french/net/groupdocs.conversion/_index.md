L'espace de noms fournit des classes pour convertir des documents en tous les formats de fichiers populaires de manière simple et intuitive.

## Classes

| Classe | Description |
| --- | --- |
| [ConversionEvents](./conversionevents) | Regroupe les gestionnaires d'événements du cycle de vie de la conversion. Passez une instance au paramètre `events` du constructeur [`Converter`](../groupdocs.conversion/converter) ou à la méthode fluide `WithEvents`. Préférez cela aux propriétés de gestionnaire individuelles de [`ConverterSettings`](../groupdocs.conversion/convertersettings), qui sont obsolètes. |
| [ConvertContext](./convertcontext) | Définit le contexte de conversion. |
| [ConvertedContext](./convertedcontext) | Définit le contexte de conversion. |
| [ConvertedPageContext](./convertedpagecontext) | Définit le contexte de page de conversion. |
| [Converter](./converter) | Représente la classe principale qui contrôle le processus de conversion de documents. |
| [ConverterSettings](./convertersettings) | Définit les paramètres pour personnaliser le comportement de [`Converter`](../groupdocs.conversion/converter). |
| [FluentConverter](./fluentconverter) | Classe pour la configuration fluide de la conversion. |
| [License](./license) | Fournit des méthodes pour licencier le composant. En savoir plus sur la licence [ici](https://purchase.groupdocs.com/faqs/licensing). |
| [LoadContext](./loadcontext) | Définit le contexte de chargement. |
| [Metered](./metered) | Fournit des méthodes pour appliquer une licence [Metered](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SaveContext](./savecontext) | Définit le contexte d'enregistrement. |
| [SavePageContext](./savepagecontext) | Définit le contexte de page d'enregistrement. |
