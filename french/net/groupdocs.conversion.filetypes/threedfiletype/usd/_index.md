## ThreeDFileType.Usd field

Un fichier avec l'extension .usd est un format de fichier Universal Scene Description qui encode des données dans le but d'échanger et d'augmenter les données entre les applications de création de contenu numérique. Développé par Pixar, USD offre la possibilité d'échanger des actifs élémentaires (tels que des modèles) ou des animations. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/3d/usd).
