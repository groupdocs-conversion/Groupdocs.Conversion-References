## ThreeDFileType.Rvm field

Les fichiers de données RVM sont liés à AVEVA PDMS. Le fichier RVM est un fichier de projet Modèle du système de gestion de conception d'usine AVEVA. Le système de gestion de conception d'usine (PDMS) d'AVEVA est le système de conception 3D le plus populaire, utilisant une technologie centrée sur les données pour gérer les projets. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/3d/rvm).
