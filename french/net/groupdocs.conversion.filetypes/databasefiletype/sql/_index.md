## DatabaseFileType.Sql field

Un fichier avec l'extension .sql est un fichier Structured Query Language (SQL) qui contient du code pour travailler avec des bases de données relationnelles. Il est utilisé pour écrire des instructions SQL pour les opérations CRUD (Create, Read, Update, Delete) sur les bases de données. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/database/sql).
