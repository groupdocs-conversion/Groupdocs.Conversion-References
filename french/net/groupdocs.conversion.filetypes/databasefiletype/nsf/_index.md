## DatabaseFileType.Nsf field

Un fichier avec l'extension .nsf (Notes Storage Facility) est un format de fichier de base de données utilisé par le logiciel IBM Notes, auparavant connu sous le nom de Lotus Notes. Il définit le schéma pour stocker différents types d'objets tels que les e‑mails, les rendez‑vous, les documents, les formulaires et les vues. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/database/nsf).
