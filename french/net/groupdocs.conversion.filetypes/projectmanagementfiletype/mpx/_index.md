## ProjectManagementFileType.Mpx field

Microsoft Exchange File Format est un format de fichier ASCII pour le transfert d'informations de projet entre Microsoft Project (MSP) et d'autres applications qui prennent en charge le format de fichier MPX telles que Primavera Project Planner, Sciforma et Timerline Precision Estimating. En savoir plus sur ce format de fichier [ici](https://wiki.fileformat.com/project-management/mpx).
