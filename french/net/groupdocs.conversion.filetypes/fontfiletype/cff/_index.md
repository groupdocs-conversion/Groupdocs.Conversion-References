## FontFileType.Cff field

Un fichier avec l'extension .cff est un Compact Font Format et est également connu sous le nom de PostScript Type 1, ou CIDFont. CFF agit comme un conteneur pour stocker plusieurs polices ensemble dans une unité unique appelée FontSet. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/font/cff/).
