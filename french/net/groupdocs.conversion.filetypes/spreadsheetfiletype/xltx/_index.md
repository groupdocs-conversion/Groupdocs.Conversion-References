## SpreadsheetFileType.Xltx field

Le fichier XLTX représente le modèle Microsoft Excel basé sur les spécifications du format de fichier Office OpenXML. Il est utilisé pour créer un fichier modèle standard qui peut être utilisé pour générer des fichiers XLSX présentant les mêmes paramètres que ceux spécifiés dans le fichier XLTX. En savoir plus sur ce format de fichier [ici](https://wiki.fileformat.com/spreadsheet/xltx).
