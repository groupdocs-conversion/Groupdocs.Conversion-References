## WebFileType.Mhtml field

Les fichiers avec l'extension MHTML représentent un format d'archive de page Web qui peut être créé par un certain nombre d'applications différentes. Ce format est connu comme format d'archive car il enregistre le code HTML du Web et les ressources associées dans un seul fichier. En savoir plus sur ce format de fichier [ici](https://wiki.fileformat.com/web/mhtml).
