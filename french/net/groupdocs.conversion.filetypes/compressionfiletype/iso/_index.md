## CompressionFileType.Iso field

Un fichier avec l'extension .iso est un fichier image disque d'archive non compressé qui représente le contenu complet des données sur un disque optique tel qu'un CD ou un DVD. Basé sur la norme ISO-9660, le format de fichier image ISO contient les données du disque ainsi que les informations du système de fichiers qui y sont stockées. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/compression/iso/).
