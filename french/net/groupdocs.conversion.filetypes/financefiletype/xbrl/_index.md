## FinanceFileType.Xbrl field

XBRL est une norme internationale ouverte pour le reporting d'entreprise numérique largement utilisée dans le monde. C'est un langage basé sur XML qui utilise des éléments XBRL, appelés balises, pour décrire chaque élément de données commerciales afin de formuler des données pour le tri et l'analyse des rapports.
