## WordProcessingBookmarksOptions.ExpandedOutlineLevels property

Spécifie le nombre de niveaux du plan du document à afficher développés lors de la visualisation du fichier. La valeur par défaut est 0. La plage valide est de 0 à 9. Notez que cette option ne fonctionnera pas lors de l'enregistrement au format XPS.

public int ExpandedOutlineLevels { get; set; }
