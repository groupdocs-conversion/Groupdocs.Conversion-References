## GmlLoadOptions.SchemaLocation property

Liste d’URI séparées par des espaces. La première URI de chaque paire est l’URI de l’espace de noms, la seconde URI est le chemin vers le schéma XML de l’espace de noms. Si la valeur est null, la conversion tentera de lire schemaLocation à partir de l’élément racine du document. La valeur par défaut est null.
