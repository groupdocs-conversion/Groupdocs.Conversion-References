## GmlLoadOptions.LoadSchemasFromInternet property

Détermine si la conversion est autorisée à charger le schéma XML depuis Internet. Si la valeur est false, les schémas avec des URI absolus qui ne commencent pas par ‘file://’ ne seront pas chargés. La valeur par défaut est false.

public bool LoadSchemasFromInternet { get; set; }
