## EmailLoadOptions.AttachmentIcons property

Obtient ou définit la liste des icônes de pièces jointes. La liste peut être personnalisée pour fournir des icônes spécifiques à différents types de fichiers. Par défaut, elle contient les icônes des types de fichiers courants.

public IList<AttachmentIcon> AttachmentIcons { get; set; }
