## IConversionByPageOptionsOrHandlerSetup interface

Interface fluide pour définir les options de conversion par page ou la configuration des gestionnaires. Permet de définir les options ou les gestionnaires dans n'importe quel ordre, mais une seule fois chacun, ou d'ignorer les deux.
