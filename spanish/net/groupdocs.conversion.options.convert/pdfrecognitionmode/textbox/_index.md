## PdfRecognitionMode.Textbox field

Este modo es rápido y bueno para preservar al máximo el aspecto original del archivo PDF, pero la editabilidad del documento resultante podría ser limitada. Cada bloque de texto agrupado visualmente en el archivo PDF original se convierte en un cuadro de texto en el documento resultante. Esto logra una semejanza máxima del documento de salida con el archivo PDF original. El documento de salida tendrá buen aspecto, pero consistirá completamente de cuadros de texto y podría dificultar la edición posterior del documento en Microsoft Word. Este es el modo predeterminado.

public static readonly PdfRecognitionMode Textbox;
