## ImageConvertOptions.MinResolution property

Límite inferior por eje aplicado al DPI de renderizado limitado cuando [`CapResolutionToPageContent`](../capresolutiontopagecontent) está habilitado. El DPI limitado nunca se reduce por debajo de este valor. El valor predeterminado es `0` (sin límite).

public int MinResolution { get; set; }
