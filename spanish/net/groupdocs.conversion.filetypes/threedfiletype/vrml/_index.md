## ThreeDFileType.Vrml field

El Lenguaje de Modelado de Realidad Virtual (VRML) es un formato de archivo para la representación de objetos 3D interactivos en la World Wide Web (www). Se utiliza para crear representaciones tridimensionales de escenas complejas, como ilustraciones, definiciones y presentaciones de realidad virtual.
