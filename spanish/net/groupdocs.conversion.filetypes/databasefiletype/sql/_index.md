## DatabaseFileType.Sql field

Un archivo con extensión .sql es un archivo Structured Query Language (SQL) que contiene código para trabajar con bases de datos relacionales. Se usa para escribir sentencias SQL para operaciones CRUD (Crear, Leer, Actualizar y Eliminar) en bases de datos. Obtén más información sobre este formato de archivo [aquí](https://docs.fileformat.com/database/sql).
