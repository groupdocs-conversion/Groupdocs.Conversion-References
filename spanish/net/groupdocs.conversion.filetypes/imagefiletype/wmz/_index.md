## ImageFileType.Wmz field

Un archivo WMZ es en realidad una versión comprimida de un archivo Microsoft WMF. Esto permite una distribución más fácil del archivo en línea. Cuando un archivo EWMFMF se comprime usando el algoritmo de compresión .GZIP, se le asigna la extensión de archivo .wmz.
