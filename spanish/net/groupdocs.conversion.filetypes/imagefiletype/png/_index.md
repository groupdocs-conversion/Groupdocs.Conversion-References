## ImageFileType.Png field

PNG, Portable Network Graphics, se refiere a un tipo de formato de archivo de imagen raster que usa compresión sin pérdida. Este formato de archivo se creó como reemplazo del Graphics Interchange Format (GIF) y no tiene limitaciones de derechos de autor. Obtén más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/image/png).
