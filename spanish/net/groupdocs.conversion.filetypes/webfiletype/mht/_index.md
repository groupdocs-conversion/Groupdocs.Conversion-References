## WebFileType.Mht field

Los archivos con extensión MHTML representan un formato de archivo de archivo de página web que puede ser creado por varias aplicaciones diferentes. El formato se conoce como formato de archivo de archivo porque guarda el código HTML web y los recursos asociados en un solo archivo. Obtenga más información sobre este formato de archivo [aquí](https://wiki.fileformat.com/web/mhtml).
