## WebFileType.Chm field

El formato de archivo CHM representa el archivo de ayuda HTML de Microsoft que consta de una colección de páginas HTML. Proporciona un índice para acceder rápidamente a los temas y navegar a diferentes partes del documento de ayuda. Obtenga más información sobre este formato de archivo [aquí](https://docs.fileformat.com/web/chm).
