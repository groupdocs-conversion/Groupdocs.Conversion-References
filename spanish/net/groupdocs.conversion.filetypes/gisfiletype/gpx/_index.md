## GisFileType.Gpx field

Los archivos con extensión GPX representan el formato GPS Exchange para el intercambio de datos GPS entre aplicaciones y servicios web en internet. Es un formato de archivo XML ligero que contiene datos GPS, es decir, puntos de referencia, rutas y rastros, que pueden ser importados y leídos por múltiples programas. Obtén más información sobre este formato de archivo [aquí](https://docs.fileformat.com/gis/gpx/).
