## CompressionFileType.Wim field

Un archivo con extensión .wim es un archivo de Windows Imaging Format, una imagen de disco basada en archivos que Microsoft usa para implementar Windows. Un solo archivo contiene una o más imágenes y almacena cada archivo una sola vez, sin importar cuántas imágenes lo referencien. Obtén más información sobre este formato de archivo [aquí](https://docs.fileformat.com/disc-and-media/wim/).
