## CompressionFileType.Xar field

Un archivo con extensión .xar es un eXtensible ARchive, un formato construido alrededor de una tabla de contenidos almacenada como XML comprimido. Se utiliza para distribuir paquetes instaladores de macOS y mantiene cada entrada comprimida por separado. Obtén más información sobre este formato de archivo [aquí](https://docs.fileformat.com/compression/xar/).
