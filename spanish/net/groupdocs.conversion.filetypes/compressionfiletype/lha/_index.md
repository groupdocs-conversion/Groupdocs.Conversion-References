## CompressionFileType.Lha field

Un archivo con extensión .lzh y .lha generalmente se refiere a un formato de archivo de compresión de archivo. Este formato de archivo es el mismo que otros formatos de compresión como ZIP, RAR, etc. El objetivo principal de estos formatos de archivo es reducir el tamaño del archivo para enviarlo fácilmente, así como mantenerlos juntos en forma comprimida.
