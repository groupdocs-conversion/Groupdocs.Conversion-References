## FinanceFileType.Xbrl field

XBRL es un estándar internacional abierto para la presentación digital de informes empresariales que se utiliza ampliamente a nivel mundial. Es un lenguaje basado en XML que usa elementos XBRL, conocidos como etiquetas, para describir cada elemento de datos empresariales y formular datos para la clasificación y análisis de informes. Obtén más información sobre este formato de archivo [aquí](https://docs.fileformat.com/finance/xbrl/).
