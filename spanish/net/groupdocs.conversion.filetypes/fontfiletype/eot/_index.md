## FontFileType.Eot field

Un archivo con extensión .eot es una fuente OpenType que se incrusta en un documento. Estas se usan mayormente en archivos web como una página web. Fue creado por Microsoft y es compatible con productos de Microsoft, incluyendo presentaciones PowerPoint .pps. Obtén más información sobre este formato de archivo [aquí](https://docs.fileformat.com/font/eot/).
