## PublisherFileType.Pub field

Un archivo PUB es un formato de archivo de documento Microsoft Publisher. Se utiliza para crear varios tipos de documentos de diseño como boletines, folletos, volantes, postales, etc. Los archivos PUB pueden contener texto, imágenes raster y vectoriales. Obtén más información sobre este formato de archivo [aquí](https://docs.fileformat.com/publisher/pub/).
