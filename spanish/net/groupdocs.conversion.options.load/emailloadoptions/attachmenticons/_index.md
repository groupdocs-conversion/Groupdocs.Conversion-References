## EmailLoadOptions.AttachmentIcons property

Obtiene o establece la lista de íconos de adjuntos. La lista puede personalizarse para proporcionar íconos específicos para diferentes tipos de archivo. Por defecto, contiene íconos comunes de tipos de archivo.
