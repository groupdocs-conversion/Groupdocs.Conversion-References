## WordProcessingBookmarksOptions.ExpandedOutlineLevels property

Especifica cuántos niveles del esquema del documento se mostrarán expandidos al visualizar el archivo. El valor predeterminado es 0. El rango válido es de 0 a 9. Tenga en cuenta que esta opción no funcionará al guardar en XPS.

public int ExpandedOutlineLevels { get; set; }
