## TxtLoadOptions.DefaultFont property

Fuente a usar al renderizar contenido de texto plano durante la conversión. Dado que los archivos TXT no contienen información de fuentes, esta propiedad especifica la fuente de visualización para el contenido de texto. Predeterminado: Arial 10pt.

public Font DefaultFont { get; set; }
