## LoadOptions class

Representa opciones abstractas de carga de documentos.

Las clases LoadOptions especifican el tipo de documento que se cargará e incluyen parámetros opcionales, como `password`. Se clasifican en dos grupos: opciones para una familia de formatos y opciones para un tipo de archivo específico.
