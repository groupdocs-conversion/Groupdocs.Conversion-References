## all_columns_in_one_page_per_sheet property

La propiedad determina si todo el contenido de columnas de una hoja se renderiza en una sola página en el resultado.

Cuando se establece en True, se ignora el ancho del tamaño de papel en la configuración de página, mientras que los demás ajustes de configuración de página siguen siendo efectivos.
