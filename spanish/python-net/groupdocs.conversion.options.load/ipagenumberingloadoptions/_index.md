## IPageNumberingLoadOptions class

Proporciona opciones para controlar la numeración de páginas en el documento convertido.

El tipo IPageNumberingLoadOptions expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [page_numbering](/conversion/python-net/groupdocs.conversion.options.load/ipagenumberingloadoptions/page_numbering/) | La bandera de numeración de página habilita o deshabilita la generación de numeración de página en el documento convertido (el valor predeterminado es False). |
