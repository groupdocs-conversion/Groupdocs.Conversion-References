## ICustomCssStyleOptions class

Representa opciones para estilo CSS personalizado durante la conversión de documentos.

El tipo ICustomCssStyleOptions expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [custom_css_style](/conversion/python-net/groupdocs.conversion.options.load/icustomcssstyleoptions/custom_css_style/) | El estilo CSS personalizado que se aplicará al documento durante la conversión, el cual se insertará en la etiqueta `<head>` del documento para personalizar la renderización. |
