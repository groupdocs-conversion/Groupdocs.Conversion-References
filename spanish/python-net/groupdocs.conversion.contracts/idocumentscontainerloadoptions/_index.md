## IDocumentsContainerLoadOptions class

Representa opciones de carga para un contenedor de documentos.

El tipo IDocumentsContainerLoadOptions expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [convert_owned](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owned/) | La opción para controlar si los documentos propiedad del contenedor de documentos deben convertirse. |
| [convert_owner](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owner/) | La opción para controlar si el contenedor de documentos debe convertirse. |
| [depth](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/depth/) | La opción para controlar cuántos niveles de profundidad se deben convertir. |
