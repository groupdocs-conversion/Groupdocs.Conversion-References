## export_images_as_base64 property

La opción export_images_as_base64 determina si las imágenes se exportan como base64.

El predeterminado es True. Se ignora cuando [`MarkdownOptions.image_saving_callback`](/conversion/python-net/groupdocs.conversion.options.convert/markdownoptions/image_saving_callback/) está configurado.
