## IPageRangedConvertOptions class

Representa opciones de conversión que admiten la conversión de una lista específica de páginas.

El tipo IPageRangedConvertOptions expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/format/) | El tipo de archivo deseado al que debe convertirse el documento de entrada. |
| [pages](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/pages/) | La lista de índices de página que se convertirán. Debe especificarse para convertir páginas específicas. |
