## MarkdownImageSavingArgs class

Representa los argumentos pasados a [`IMarkdownImageSavingCallback.image_saving`](/conversion/python-net/groupdocs.conversion.options.convert/imarkdownimagesavingcallback/image_saving/).

El tipo MarkdownImageSavingArgs expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [image_file_name](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_file_name/) | El nombre de archivo (o id de marcador de posición) incrustado como la URI de la imagen en la salida Markdown. Asigne para reescribir la URI. |
| [image_stream](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_stream/) | El flujo de destino en el que el convertidor escribirá los bytes de la imagen después de que este callback devuelva. |
| [keep_image_stream_open](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/keep_image_stream_open/) | La propiedad determina si el convertidor mantiene abierto el flujo de imagen después de la conversión. |
