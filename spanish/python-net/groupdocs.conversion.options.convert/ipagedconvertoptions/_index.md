## IPagedConvertOptions class

Representa opciones de conversión que permiten limitar páginas especificando la página inicial y la cantidad de páginas.

El tipo IPagedConvertOptions expone los siguientes miembros:

### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | El tipo de archivo deseado al que debe convertirse el documento de entrada. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | El número de página desde la cual iniciar la conversión. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | El número de páginas a convertir a partir de `PageNumber`. |
