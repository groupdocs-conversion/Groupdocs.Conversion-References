### Propiedades
| Propiedad | Descripción |
| :- | :- |
| [center_window](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/center_window/) | La posición de la ventana se centrará en la pantalla cuando sea True; de lo contrario usará la ubicación predeterminada. El valor predeterminado es False. |

| [hide_menu_bar](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/hide_menu_bar/) | La bandera que indica si la barra de menú debe ocultarse cuando el documento está activo. El valor predeterminado es False. |

| [hide_window_ui](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/hide_window_ui/) | La propiedad indica si los elementos de la interfaz de usuario deben ocultarse cuando el documento está activo. El valor predeterminado es False. |
| [non_full_screen_page_mode](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/non_full_screen_page_mode/) | El modo de página que especifica cómo mostrar el documento al salir del modo de pantalla completa. |
| [page_layout](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/page_layout/) | El diseño de página que se utilizará cuando se abra el documento. |
| [page_mode](/conversion/python-net/groupdocs.conversion.options.convert/pdfformattingoptions/page_mode/) | El modo de página, que especifica cómo debe mostrarse el documento al abrirse. |
