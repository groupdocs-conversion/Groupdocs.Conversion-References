## NSF field

Un archivo con extensión .nsf (Notes Storage Facility) es un formato de archivo de base de datos utilizado por el software IBM Notes, anteriormente conocido como Lotus Notes. Define el esquema para almacenar diferentes tipos de objetos como correos electrónicos, citas, documentos, formularios y vistas. Obtén más información sobre este formato de archivo aquí.
