## WOFF2 field

Un archivo con extensión .woff es un archivo de fuente web basado en el Web Open Font Format (WOFF). Tiene un contenedor comprimido específico del formato basado en fuentes TrueType (.TTF) o OpenType (.OTT). Obtén más información sobre este formato de archivo aquí.
