## TTF field

Un archivo con extensión .ttf representa archivos de fuentes basados en la tecnología de fuentes de especificaciones TrueType. Fue diseñado y lanzado inicialmente por Apple Computer, Inc para Mac OS y posteriormente adoptado por Microsoft para Windows OS. Obtén más información sobre este formato de archivo aquí.
