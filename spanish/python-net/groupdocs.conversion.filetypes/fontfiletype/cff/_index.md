## CFF field

Un archivo con extensión .cff es un Compact Font Format y también se conoce como PostScript Type 1, o CIDFont. CFF actúa como un contenedor para almacenar múltiples fuentes juntas en una única unidad conocida como FontSet. Obtén más información sobre este formato de archivo aquí.
