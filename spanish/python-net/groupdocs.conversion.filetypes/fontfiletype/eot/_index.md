## EOT field

Un archivo con extensión .eot es una fuente OpenType que se incrusta en un documento. Estas se utilizan mayormente en archivos web, como una página web. Fue creado por Microsoft y es compatible con productos de Microsoft, incluidos los archivos de presentación PowerPoint .pps. Obtén más información sobre este formato de archivo aquí.
