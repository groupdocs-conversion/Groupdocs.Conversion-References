## GIF field

Un GIF o Graphical Interchange Format es un tipo de imagen altamente comprimida. Para cada imagen, GIF típicamente permite hasta 8 bits por píxel y se permiten hasta 256 colores en toda la imagen. Obtenga más información sobre este formato de archivo aquí.
