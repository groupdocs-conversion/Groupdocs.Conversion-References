## BMP field

BMP representa archivos de imagen Bitmap que se utilizan para almacenar imágenes digitales de mapa de bits. Estas imágenes son independientes del adaptador gráfico y también se denominan formato de archivo bitmap independiente del dispositivo (DIB). Obtenga más información sobre este formato de archivo aquí.
