## CDR field

Un archivo CDR es un archivo de imagen de dibujo vectorial creado de forma nativa con CorelDRAW para almacenar imágenes digitales codificadas y comprimidas. Este tipo de archivo de dibujo contiene texto, líneas, formas, imágenes, colores y efectos para la representación vectorial del contenido de la imagen. Obtenga más información sobre este formato de archivo aquí.
