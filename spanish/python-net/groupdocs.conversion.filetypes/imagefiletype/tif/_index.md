## TIF field

TIF, Tagged Image File Format, representa imágenes raster que están destinadas a usarse en una variedad de dispositivos que cumplen con este estándar de formato de archivo. Es capaz de describir datos de imagen binaria, en escala de grises, con paleta de colores y a todo color en varios espacios de color. Obtenga más información sobre este formato de archivo aquí.
