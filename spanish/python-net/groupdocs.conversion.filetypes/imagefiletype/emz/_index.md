## EMZ field

Un archivo EMZ es en realidad una versión comprimida de un archivo EMF de Microsoft. Esto permite una distribución más fácil del archivo en línea. Cuando un archivo EMF se comprime utilizando el algoritmo de compresión .GZIP, se le asigna la extensión .emz.
