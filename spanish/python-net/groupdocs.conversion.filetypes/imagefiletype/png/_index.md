## PNG field

PNG, Portable Network Graphics, se refiere a un tipo de formato de archivo de imagen raster que utiliza compresión sin pérdida. Este formato de archivo fue creado como reemplazo del Graphics Interchange Format (GIF) y no tiene limitaciones de derechos de autor. Obtenga más información sobre este formato de archivo aquí.
