## VST field

Los archivos con extensión VST son archivos de imagen vectorial creados con Microsoft Visio y actúan como plantilla para crear más archivos. Estos archivos de plantilla están en formato de archivo binario y contienen el diseño y la configuración predeterminados que se utilizan para crear nuevos dibujos de Visio. Obtén más información sobre este formato de archivo aquí.
