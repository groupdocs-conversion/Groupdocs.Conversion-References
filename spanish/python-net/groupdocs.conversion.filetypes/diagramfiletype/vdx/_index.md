## VDX field

Cualquier dibujo o gráfico creado en Microsoft Visio, pero guardado en formato XML tiene la extensión .VDX. Un archivo XML de dibujo de Visio se crea en el software Visio, que es desarrollado por Microsoft. Aprende más sobre este formato de archivo aquí.
