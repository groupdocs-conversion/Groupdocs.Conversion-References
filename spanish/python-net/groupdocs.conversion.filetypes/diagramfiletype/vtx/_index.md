## VTX field

Un archivo con extensión VTX es una plantilla de dibujo de Microsoft Visio que se guarda en disco en formato de archivo XML. La plantilla está diseñada para proporcionar un archivo con configuraciones básicas que pueden usarse para crear múltiples archivos Visio con los mismos ajustes. Aprende más sobre este formato de archivo aquí.
