## DRAWIO field

Un archivo con extensión DRAWIO es un diagrama creado con diagrams.net (anteriormente draw.io). Se almacena en formato de archivo XML con el elemento raíz mxfile y contiene el contenido y formato de los elementos del diagrama, como texto, imágenes, diseño, formas y posicionamiento. Aprende más sobre este formato de archivo aquí.
