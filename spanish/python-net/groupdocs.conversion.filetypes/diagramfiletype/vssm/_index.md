## VSSM field

Los archivos con extensión .VSSM son archivos de plantilla de Microsoft Visio que admiten macros. Un archivo VSSM, al abrirse, permite ejecutar las macros para lograr el formato y la ubicación deseados de las formas en un diagrama. Aprende más sobre este formato de archivo aquí.
