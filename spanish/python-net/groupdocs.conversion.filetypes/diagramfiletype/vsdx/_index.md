## VSDX field

Los archivos con extensión .VSDX representan el formato de archivo Microsoft Visio introducido a partir de Microsoft Office 2013. Fue desarrollado para reemplazar el formato de archivo binario, .VSD, que es compatible con versiones anteriores de Microsoft Visio. Obtén más información sobre este formato de archivo aquí.
