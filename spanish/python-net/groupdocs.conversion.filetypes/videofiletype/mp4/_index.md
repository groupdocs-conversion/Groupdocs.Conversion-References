## MP4 field

MP4 (abreviatura de MPEG-4 Part 14) es un formato de archivo basado en ISO/IEC 14496-12:2004 que se basa en el formato QuickTime File Format pero especifica formalmente el soporte para Descriptores de Objeto Inicial (IOD) y otras características MPEG. Aprende más sobre este formato de archivo aquí.
