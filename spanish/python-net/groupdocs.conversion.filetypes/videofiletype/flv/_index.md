## FLV field

FLV (Flash Video) es un formato de archivo contenedor con la extensión .flv. FLV se utiliza para entregar contenido de audio/video a través de internet mediante Adobe Flash Player o Adobe Air. Aprende más sobre este formato de archivo aquí.
