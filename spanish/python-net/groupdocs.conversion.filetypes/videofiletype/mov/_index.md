## MOV field

El formato de archivo MOV o QuickTime es un contenedor multimedia desarrollado por Apple: contiene una o más pistas, cada pista contiene un tipo particular de datos, p.ej. Video, Audio, texto, etc. Obtén más información sobre este formato de archivo aquí.
