## WordProcessingFileType class

La clase WordProcessingFileType define formatos de archivo de procesamiento de texto, cubriendo variantes de texto plano y texto enriquecido.

Los archivos de texto sin formato contienen texto sin formato sin fuentes ni configuraciones de página aplicadas. Los archivos de texto enriquecido admiten opciones de formato como tipos de fuente, estilos (negrita, cursiva, subrayado), márgenes de página, encabezados, viñetas, numeración y otras características.

### Ejemplo

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # Instanciar el Convertidor con el documento de entrada
    with Converter("./business-plan.docx") as converter:
        # Define las opciones de conversión; el formato de salida predeterminado es DOCX
        word_convert_options = WordProcessingConvertOptions()
        # Cambiar el formato de salida dentro de la familia de formatos de DOCX a TXT
        word_convert_options.format = WordProcessingFileType.Txt

        # Convertir el documento de entrada a TXT
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
