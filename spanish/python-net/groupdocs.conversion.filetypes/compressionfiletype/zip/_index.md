## ZIP field

Un archivo con extensión .zip es un archivo comprimido que puede contener uno o más archivos o directorios. Al archivo se le puede aplicar compresión a los archivos incluidos para reducir el tamaño del archivo ZIP. Obtén más información sobre este formato de archivo aquí.
