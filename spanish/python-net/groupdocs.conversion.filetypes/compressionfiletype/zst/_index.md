## ZST field

Un archivo ZST es un archivo comprimido generado con el algoritmo de compresión Zstandard (zstd). Es un archivo comprimido creado con compresión sin pérdida mediante el algoritmo. Obtenga más información sobre este formato de archivo aquí.
