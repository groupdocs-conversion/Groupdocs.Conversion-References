## ISO field

Un archivo con extensión .iso es un archivo de imagen de disco sin comprimir que representa el contenido completo de un disco óptico como CD o DVD. Basado en el estándar ISO-9660, el formato de archivo de imagen ISO contiene los datos del disco junto con la información del sistema de archivos que se almacena en él. Obtenga más información sobre este formato de archivo aquí.
