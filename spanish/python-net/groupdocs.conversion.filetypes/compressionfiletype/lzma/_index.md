## LZMA field

Un archivo con extensión .lzma es un archivo comprimido creado usando el método de compresión LZMA (Lempel-Ziv-Markov chain Algorithm). Estos se encuentran/usan principalmente en sistemas operativos Unix y son similares a otros algoritmos de compresión como ZIP para minimizar el tamaño del archivo. Obtenga más información sobre este formato de archivo aquí.
