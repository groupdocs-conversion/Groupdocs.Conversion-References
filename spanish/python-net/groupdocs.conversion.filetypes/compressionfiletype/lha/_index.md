## LHA field

Un archivo con extensión .lzh y .lha generalmente corresponde a un formato de compresión de archivos. Este formato es el mismo que otros formatos de compresión como ZIP, RAR, etc. El objetivo principal de estos formatos es reducir el tamaño del archivo para facilitar su envío y mantenerlos juntos en forma comprimida.
