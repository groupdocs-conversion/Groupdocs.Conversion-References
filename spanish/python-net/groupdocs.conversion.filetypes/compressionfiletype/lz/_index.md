## LZ field

Un archivo con extensión .lz es un archivo comprimido creado con Lzip, que es una herramienta de línea de comandos gratuita para compresión. Soporta la concatenación para comprimir archivos de soporte. Los archivos LZ tienen el tipo de medio application/lzip y soportan ratios de compresión más altos que BZ2. Obtén más información sobre este formato de archivo aquí.
