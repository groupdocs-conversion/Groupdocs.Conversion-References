## GZIP field

Un archivo Gzip es un archivo comprimido creado con el algoritmo estándar de compresión gzip (GNU zip). Puede contener varios archivos comprimidos, directorios y fragmentos de archivo. Obtén más información sobre este formato de archivo aquí.
