## CAB field

Un archivo con extensión .cab pertenece a un archivo cabinet de Windows que forma parte de la categoría de archivos del sistema. Es un archivo que se guarda en formato de archivo de archivo en las versiones de Microsoft Windows que admiten algoritmos de datos comprimidos, como LZX, Quantum y ZIP. Obtenga más información sobre este formato de archivo aquí.
