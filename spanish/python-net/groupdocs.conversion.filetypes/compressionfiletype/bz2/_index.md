## BZ2 field

BZ2 son archivos comprimidos generados con el método de compresión de código abierto BZIP2, mayormente en sistemas UNIX o Linux. Se utiliza para comprimir un solo archivo y no está destinado al archivado de varios archivos. Obtén más información sobre este formato de archivo aquí.
