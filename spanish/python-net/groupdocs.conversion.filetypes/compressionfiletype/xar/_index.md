## XAR field

Un archivo con extensión .xar es un eXtensible ARchive, un formato construido alrededor de una tabla de contenidos almacenada como XML comprimido. Se utiliza para distribuir paquetes instaladores de macOS y mantiene cada entrada comprimida por separado. Obtenga más información sobre este formato de archivo aquí.
