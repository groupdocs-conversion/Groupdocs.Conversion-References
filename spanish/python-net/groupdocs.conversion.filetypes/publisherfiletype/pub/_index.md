## PUB field

Un archivo PUB es un formato de documento de Microsoft Publisher. Se utiliza para crear varios tipos de documentos de diseño como boletines, folletos, trípticos, postales, etc. Los archivos PUB pueden contener texto, imágenes raster y vectoriales. Obtén más información sobre este formato de archivo aquí.
