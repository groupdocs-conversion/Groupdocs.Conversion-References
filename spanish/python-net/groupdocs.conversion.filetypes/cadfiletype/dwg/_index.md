## DWG field

Los archivos con extensión DWG representan archivos binarios propietarios utilizados para contener datos de diseño 2D y 3D. Al igual que DXF, que son archivos ASCII, DWG representa el formato de archivo binario para dibujos CAD (Diseño Asistido por Computadora). Obtenga más información sobre este formato de archivo aquí.
