## IFC field

Los archivos con extensión IFC se refieren al formato de archivo Industry Foundation Classes (IFC) que establece normas internacionales para importar y exportar objetos de construcción y sus propiedades. Este formato de archivo proporciona interoperabilidad entre diferentes aplicaciones de software. Obtén más información sobre este formato de archivo aquí.
