## XPS field

Un archivo XPS representa archivos de diseño de página basados en XML Paper Specifications creadas por Microsoft. Este formato fue desarrollado por Microsoft como reemplazo del formato de archivo EMF y es similar al formato de archivo PDF, pero utiliza XML en el diseño, la apariencia y la información de impresión de un documento. Obtenga más información sobre este formato de archivo aquí.
