## SVGZ field

Un archivo SVGZ es en realidad una versión comprimida de un archivo SVG. Esto permite una distribución más fácil del archivo en línea. Cuando un archivo SVG se comprime utilizando el algoritmo de compresión .GZIP, se le asigna la extensión de archivo .svgz.
