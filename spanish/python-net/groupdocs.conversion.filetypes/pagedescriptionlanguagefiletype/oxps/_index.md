## OXPS field

El formato de archivo OXPS se conoce como Open XML Paper Specification. Es un lenguaje de descripción de página y formato de documento. Microsoft es el desarrollador de este formato. El formato de archivo OXPS es muy similar a los archivos PDF. Obtenga más información sobre este formato de archivo aquí.
