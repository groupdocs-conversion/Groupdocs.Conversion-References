## ONE field

Los archivos representados por la extensión .ONE son creados por la aplicación Microsoft OneNote. OneNote te permite recopilar información usando la aplicación como si estuvieras usando tu cuaderno de borradores para tomar notas. Obtén más información sobre este formato de archivo aquí.
