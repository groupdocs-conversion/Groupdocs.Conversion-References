## DIF field

DIF significa Formato de Intercambio de Datos y se utiliza para importar/exportar datos de hojas de cálculo entre diferentes aplicaciones. Estas incluyen Microsoft Excel, OpenOffice Calc, StarCalc y muchas otras. Obtenga más información sobre este formato de archivo aquí.
