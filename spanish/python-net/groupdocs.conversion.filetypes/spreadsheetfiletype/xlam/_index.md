## XLAM field

XLAM es un archivo de complemento habilitado para macros que se utiliza para añadir nuevas funciones a las hojas de cálculo. Un complemento es un programa suplementario que ejecuta código adicional y brinda funcionalidad extra para las hojas de cálculo. Obtenga más información sobre este formato de archivo aquí.
