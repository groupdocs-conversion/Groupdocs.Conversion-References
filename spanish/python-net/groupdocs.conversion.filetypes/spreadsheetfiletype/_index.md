Obtenga más información sobre este formato de archivo aquí. |
| [XLSM](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlsm/) | XLSM es un tipo de archivo de hoja de cálculo que admite macros. Obtenga más información sobre este formato de archivo aquí. |
| [XLSB](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlsb/) | El formato de archivo XLSB especifica el Formato de Archivo Binario de Excel, que es una colección de registros y estructuras que definen el contenido del libro de Excel. Obtenga más información sobre este formato de archivo aquí. |
| [ODS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/ods/) | Los archivos con extensión ODS corresponden al formato de Documento de Hoja de Cálculo OpenDocument, que es editable por el usuario. Los datos se almacenan dentro del archivo ODF en filas y columnas. Obtenga más información sobre este formato de archivo aquí. |
| [OTS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/ots/) | Un archivo con extensión .ots es un archivo de Plantilla de Hoja de Cálculo OpenDocument que se crea con el software de aplicación Calc incluido en Apache OpenOffice. El software de aplicación Calc es similar a Excel disponible en Microsoft Office. Obtenga más información sobre este formato de archivo aquí. |
| [XLTX](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xltx/) | El archivo XLTX representa una plantilla de Microsoft Excel basada en las especificaciones del formato de archivo Office OpenXML. Se utiliza para crear un archivo de plantilla estándar que puede emplearse para generar archivos XLSX que presenten la misma configuración especificada en el archivo XLTX. Obtenga más información sobre este formato de archivo aquí. |
| [XLT](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlt/) | Los archivos con extensión .XLT son archivos de plantilla creados con Microsoft Excel, que es una aplicación de hoja de cálculo que forma parte del conjunto Microsoft Office. Microsoft Office 97-2003 permitía crear nuevos archivos XLT así como abrirlos. Obtenga más información sobre este formato de archivo aquí. |
| [XLTM](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xltm/) | La extensión de archivo XLTM representa archivos generados por Microsoft Excel como plantillas habilitadas para macros. Los archivos XLTM son similares a los XLTX en estructura, salvo que estos últimos no admiten crear archivos de plantilla con macros. Obtenga más información sobre este formato de archivo aquí. |
| [TSV](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/tsv/) | Un formato de archivo de valores separados por tabulaciones (TSV) representa datos separados por tabuladores en formato de texto plano. Obtenga más información sobre este formato de archivo aquí. |
| [XLAM](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlam/) | XLAM es un archivo de complemento habilitado para macros que se utiliza para añadir nuevas funciones a las hojas de cálculo. Un complemento es un programa suplementario que ejecuta código adicional y brinda funcionalidad extra para las hojas de cálculo. Obtenga más información sobre este formato de archivo aquí. |
| [CSV](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/csv/) | Los archivos con extensión CSV (Valores Separados por Comas) representan archivos de texto plano que contienen registros de datos con valores separados por comas. Obtenga más información sobre este formato de archivo aquí. |
| [FODS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/fods/) | Un archivo con extensión .fods es un tipo de formato de documento OpenDocument Spreadsheet que almacena datos en filas y columnas. El formato está especificado como parte de las especificaciones ODF 1.2 publicadas y mantenidas por OASIS. Obtenga más información sobre este formato de archivo aquí. |
| [DIF](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/dif/) | DIF significa Formato de Intercambio de Datos y se utiliza para importar/exportar datos de hojas de cálculo entre diferentes aplicaciones. Estas incluyen Microsoft Excel, OpenOffice Calc, StarCalc y muchas otras. Obtenga más información sobre este formato de archivo aquí. |
| [SXC](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/sxc/) | El formato de archivo SXC (Sun XML Calc) pertenece a una suite de oficina llamada OpenOffice.org. Este formato satisface generalmente las necesidades de hojas de cálculo de los usuarios, ya que es un formato de archivo de hoja de cálculo basado en XML. El formato SXC admite fórmulas, funciones, macros y gráficos junto con DataPilot. Obtenga más información sobre este formato de archivo aquí. |
| [NUMBERS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/numbers/) | Los archivos con extensión .numbers se clasifican como tipo de archivo de hoja de cálculo, por lo que son similares a los archivos .xlsx; pero los archivos Numbers se crean utilizando el software de hoja de cálculo Apple iWork Numbers. Obtenga más información sobre este formato de archivo aquí. |
| [FLAT_OPC](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/flat_opc/) | Flat OPC Excel es Office Open XML SpreadsheetML almacenado en un archivo XML plano en lugar de un paquete ZIP. |
