### Campos
| Campo | Descripción |
| :- | :- |
| [MP3](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/mp3/) | Los archivos con extensión .mp3 son formatos de archivo codificados digitalmente para archivos de audio que se basan formalmente en MPEG-1 Audio Layer III o MPEG-2 Audio Layer III. Aprende más sobre este formato de archivo aquí. |
| [AAC](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/aac/) | AAC (Advanced Audio Coding) se refiere al estándar de codificación de audio digital que representa archivos de audio basados en compresión de audio con pérdida. Aprende más sobre este formato de archivo aquí. |
| [AIFF](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/aiff/) | El AIFF (Audio Interchange File Format) es un formato de archivo de audio sin comprimir desarrollado por Apple en 1998, pero se basa en EA IFF 85. Aprende más sobre este formato de archivo aquí. |
| [FLAC](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/flac/) | FLAC (Free Lossless Audio Codec) es un formato de codificación de audio con compresión sin pérdida desarrollado por Xiph.Org Foundation. Aprende más sobre este formato de archivo aquí. |
| [M4A](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/m4a/) | El formato de archivo M4A es un archivo de audio creado mediante el uso de AAC (Advanced Audio Coding), que se conoce como compresión con pérdida. Aprende más sobre este formato de archivo aquí. |
| [WMA](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/wma/) | Un archivo con extensión .wma representa un archivo de audio que se guarda en el formato Advanced Systems Format (ASF). Aprende más sobre este formato de archivo aquí. |
| [AC3](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/ac3/) | Un archivo con extensión .ac3 es un archivo Audio Codec 3, introducido por Dolby Laboratories. Es un formato de audio que puede contener hasta seis canales de salida de audio. Aprende más sobre este formato de archivo aquí. |
| [OGG](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/ogg/) | OGG es un Archivo de Audio Comprimido Ogg Vorbis que se guarda con la extensión .ogg. Los archivos OGG se utilizan para almacenar datos de audio y también pueden incluir información de artista y pista, así como metadatos. Aprende más sobre este formato de archivo aquí. |
| [WAV](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/wav/) | WAV, conocido por WAVE (Waveform Audio File Format), es un subconjunto de la especificación Resource Interchange File Format (RIFF) de Microsoft para almacenar archivos de audio digital. Aprende más sobre este formato de archivo aquí. |
