## KML field

KML (Keyhole Markup Language) contiene información geoespacial en notación XML. Los archivos guardados como KML pueden abrirse en aplicaciones de Sistemas de Información Geográfica (GIS) siempre que las soporten. Muchas aplicaciones han comenzado a ofrecer soporte para el formato de archivo KML después de que se adoptara como estándar internacional. KML utiliza una estructura basada en etiquetas con elementos y atributos anidados. Obtenga más información sobre este formato de archivo aquí.
