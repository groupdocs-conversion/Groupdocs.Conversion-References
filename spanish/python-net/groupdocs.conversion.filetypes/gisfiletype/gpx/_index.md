## GPX field

Los archivos con extensión GPX representan el formato GPS Exchange para el intercambio de datos GPS entre aplicaciones y servicios web en internet. Es un formato de archivo XML liviano que contiene datos GPS, es decir, puntos de referencia, rutas y rastros que pueden ser importados y leídos por múltiples programas. Obtenga más información sobre este formato de archivo aquí.
