## SHP field

SHP es la extensión de archivo para uno de los tipos de archivo principales utilizados para la representación de ESRI Shapefile. Representa información geoespacial en forma de datos vectoriales para ser utilizada por aplicaciones de Sistemas de Información Geográfica (GIS). Aprende más sobre este formato de archivo aquí.
