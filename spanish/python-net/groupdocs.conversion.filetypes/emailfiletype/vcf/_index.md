## VCF field

VCF (Formato de Tarjeta Virtual) o vCard es un formato de archivo digital para almacenar información de contactos. El formato se usa ampliamente para el intercambio de datos entre aplicaciones populares de intercambio de información. Obtén más información sobre este formato de archivo aquí.
