## MOBI field

El formato de archivo MOBI es uno de los formatos de libro electrónico más utilizados. El formato es una mejora del antiguo formato OEB (Open Ebook Format) y se utilizó como formato propietario para el lector Mobipocket. Obtenga más información sobre este formato de archivo aquí.
