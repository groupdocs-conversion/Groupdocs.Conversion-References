## AZW3 field

AZW3, también conocido como Kindle Format 8 (KF8), es la versión modificada del formato de archivo digital AZW desarrollado para dispositivos Amazon Kindle. El formato es una mejora de los archivos AZW más antiguos y se usa en dispositivos Kindle Fire solo con compatibilidad retroactiva para el formato de archivo ancestral, es decir, MOBI y AZW. Obtenga más información sobre este formato de archivo aquí.
