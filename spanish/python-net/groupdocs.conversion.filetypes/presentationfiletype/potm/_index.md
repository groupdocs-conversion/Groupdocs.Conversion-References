## POTM field

Los archivos con extensión POTM son plantillas de Microsoft PowerPoint con soporte para macros. Los archivos POTM se crean con PowerPoint 2007 o versiones posteriores y contienen configuraciones predeterminadas que pueden usarse para crear más archivos de presentación. Obtenga más información sobre este formato de archivo aquí.
