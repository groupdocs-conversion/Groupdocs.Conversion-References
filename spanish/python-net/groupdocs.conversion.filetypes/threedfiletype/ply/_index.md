## PLY field

PLY, Polygon File Format, representa un formato de archivo 3D que almacena objetos gráficos descritos como una colección de polígonos. El propósito de este formato de archivo era establecer un tipo de archivo simple y fácil que fuera lo suficientemente general como para ser útil en una amplia gama de modelos. Obtenga más información sobre este formato de archivo aquí.
