## ASE field

Un archivo con extensión .ase es un formato de archivo Autodesk ASCII Scene Export que es una representación ASCII de una escena, que contiene información 2D o 3D al exportar datos de escena usando Autodesk. Obtenga más información sobre este formato de archivo aquí.
