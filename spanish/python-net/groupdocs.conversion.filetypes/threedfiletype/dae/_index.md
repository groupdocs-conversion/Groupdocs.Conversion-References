## DAE field

Un archivo DAE es un formato de archivo Digital Asset Exchange que se utiliza para intercambiar datos entre aplicaciones 3D interactivas. Este formato de archivo se basa en el esquema XML COLLADA (COLLAborative Design Activity), que es un esquema XML de estándar abierto para el intercambio de activos digitales entre aplicaciones de software gráfico. Obtenga más información sobre este formato de archivo aquí.
