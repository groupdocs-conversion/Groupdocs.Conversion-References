## USD field

Un archivo con extensión .usd es un formato de archivo Universal Scene Description que codifica datos con el propósito de intercambiar y ampliar datos entre aplicaciones de creación de contenido digital. Desarrollado por Pixar, USD brinda la capacidad de intercambiar activos elementales (como modelos) o animaciones. Obtenga más información sobre este formato de archivo aquí.
