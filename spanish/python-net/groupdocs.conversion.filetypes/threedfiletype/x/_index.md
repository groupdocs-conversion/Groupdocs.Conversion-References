## X field

Un archivo con extensión .x se refiere al formato de archivo heredado DirectX 3D Graphics que se introdujo con Microsoft DirectX 2.0. Se utilizó para la renderización de gráficos 3D en juegos y especifica las estructuras para mallas, texturas, animaciones y objetos definidos por el usuario. Ha quedado obsoleto desde 2014, ya que el formato de archivo Autodesk FBX funciona mejor como un formato más moderno. Obtén más información sobre este formato de archivo aquí.
