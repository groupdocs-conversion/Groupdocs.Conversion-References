## U3D field

U3D (Universal 3D) es un formato de archivo comprimido y una estructura de datos para gráficos por computadora 3D. Contiene información de modelos 3D como mallas triangulares, iluminación, sombreado, datos de movimiento, líneas y puntos con color y estructura. Obtenga más información sobre este formato de archivo aquí.
