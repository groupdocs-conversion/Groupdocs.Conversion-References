Aprende más sobre los formatos de hoja de cálculo [aquí][].

[here]: https://wiki.fileformat.com/spreadsheet/xlsx

```
public static final SpreadsheetFileType Xlsb
```

[here]: https://wiki.fileformat.com/spreadsheet/xlsb

### Ods {#Ods}
```
public static final SpreadsheetFileType Ods
```


Los archivos con extensión ODS representan el formato de documento de hoja de cálculo OpenDocument que es editable por el usuario. Los datos se almacenan dentro del archivo ODF en filas y columnas. Obtén más información sobre este formato de archivo [here][].


[here]: https://wiki.fileformat.com/spreadsheet/ods

### Ots {#Ots}
```
public static final SpreadsheetFileType Ots
```


Un archivo con extensión .ots es un archivo de plantilla de hoja de cálculo OpenDocument que se crea con el software de aplicación Calc incluido en Apache OpenOffice. El software Calc es similar a Excel disponible en Microsoft Office. Obtén más información sobre este formato de archivo [here][].


[here]: https://wiki.fileformat.com/spreadsheet/ots

### Xltx {#Xltx}
```
public static final SpreadsheetFileType Xltx
```


El archivo XLTX representa una plantilla de Microsoft Excel basada en las especificaciones del formato de archivo Office OpenXML. Se utiliza para crear un archivo de plantilla estándar que puede emplearse para generar archivos XLSX que presenten la misma configuración especificada en el archivo XLTX. Obtén más información sobre este formato de archivo [here][].


[here]: https://wiki.fileformat.com/spreadsheet/xltx

### Xlt {#Xlt}
```
public static final SpreadsheetFileType Xlt
```


Los archivos con extensión .XLT son archivos de plantilla creados con Microsoft Excel, que es una aplicación de hoja de cálculo incluida en la suite Microsoft Office. Microsoft Office 97-2003 permitía crear nuevos archivos XLT así como abrirlos. Obtén más información sobre este formato de archivo [here][].


[here]: https://wiki.fileformat.com/spreadsheet/xlt

### Xltm {#Xltm}
```
public static final SpreadsheetFileType Xltm
```


La extensión de archivo XLTM representa archivos que son generados por Microsoft Excel como archivos de plantilla con macros habilitadas. Los archivos XLTM son similares a los XLTX en estructura, salvo que estos últimos no admiten crear archivos de plantilla con macros. Obtén más información sobre este formato de archivo [here][].


[here]: https://wiki.fileformat.com/spreadsheet/xltm

### Fods {#Fods}
```
public static final SpreadsheetFileType Fods
```


Un archivo con extensión .fods es un tipo de formato de documento de hoja de cálculo OpenDocument que almacena datos en filas y columnas. El formato está especificado como parte de las especificaciones ODF 1.2 publicadas y mantenidas por OASIS. Obtén más información sobre este formato de archivo [here][].


[here]: https://wiki.fileformat.com/spreadsheet/fods

### Dif {#Dif}
```
public static final SpreadsheetFileType Dif
```


DIF significa Data Interchange Format y se utiliza para importar/exportar datos de hojas de cálculo entre diferentes aplicaciones. Estas incluyen Microsoft Excel, OpenOffice Calc, StarCalc y muchas otras. Obtenga más información sobre este formato de archivo [here][].


[here]: https://wiki.fileformat.com/spreadsheet/dif

### Sxc {#Sxc}
```
public static final SpreadsheetFileType Sxc
```


El formato de archivo SXC (Sun XML Calc) pertenece a una suite de oficina llamada OpenOffice.org. Este formato generalmente cubre las necesidades de hojas de cálculo de los usuarios, ya que es un formato de archivo de hoja de cálculo basado en XML. El formato SXC admite fórmulas, funciones, macros y gráficos junto con DataPilot. Obtenga más información sobre este formato de archivo [here][].


[here]: https://wiki.fileformat.com/spreadsheet/sxc

### Numbers {#Numbers}
```
public static final SpreadsheetFileType Numbers
```

Los archivos con extensión .numbers se clasifican como tipo de archivo de hoja de cálculo, por eso son similares a los archivos .xlsx; pero los archivos Numbers se crean usando el software de hoja de cálculo Apple iWork Numbers. Obtenga más información sobre este formato de archivo [here][].


[here]: https://docs.fileformat.com/spreadsheet/numbers
