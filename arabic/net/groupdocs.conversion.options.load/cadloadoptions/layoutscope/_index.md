## CadLoadOptions.LayoutScope property

يحصل أو يعيّن أي مساحات الرسم يتم تحويلها. القيمة الافتراضية هي [`Both`](../../cadlayoutscope/both)، والتي لا تقيد التحويل. يتم تجاهلها عندما يتم توفير [`LayoutNames`](../layoutnames)، لأن أسماء التخطيطات الصريحة تفوز دائمًا. يتم التعامل مع القيمة `null` كـ [`Both`](../../cadlayoutscope/both).

```csharp
public CadLayoutScope LayoutScope { get; set; }
```

### ملاحظات

النطاق الذي لا يختار أيًا من الأوراق التي يقدمها الرسم يؤدي إلى فشل التحويل مع [`InvalidLoadOptionsException`](../../../groupdocs.conversion.exceptions/invalidloadoptionsexception) يذكر النطاق والأوراق الموجودة، بدلاً من عرض المساحات التي استبعدها النطاق. الرسم الذي لا يقدم أي ورقة على الإطلاق لا يتأثر ولا يزال يتحول كوحدة واحدة. لا يتم احترامها عند التحويل إلى PDF/UA-1، للسبب المذكور في [`LayoutNames`](../layoutnames).
