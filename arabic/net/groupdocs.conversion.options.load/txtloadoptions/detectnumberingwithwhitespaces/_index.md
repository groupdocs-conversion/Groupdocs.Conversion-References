## TxtLoadOptions.DetectNumberingWithWhitespaces property

يسمح بتحديد كيفية التعرف على عناصر القوائم المرقمة عندما يتم تحويل مستند نص عادي. القيمة الافتراضية هي true.

```csharp
public bool DetectNumberingWithWhitespaces { get; set; }
```

### ملاحظات

إذا تم تعيين هذا الخيار إلى false، فإن خوارزمية التعرف على القوائم تكتشف فقرات القوائم عندما تنتهي أرقام القوائم إما بنقطة أو قوس يميني أو رموز نقطية (مثل "•", "*", "-" أو "o").

إذا تم تعيين هذا الخيار إلى true، فإن المسافات البيضاء تُستخدم أيضًا كفواصل لأرقام القوائم: خوارزمية التعرف على القوائم للترقيم النمط العربي (1., 1.1.2.) تستخدم كلًا من المسافات البيضاء ورمز النقطة (".").
