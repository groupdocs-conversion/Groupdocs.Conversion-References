## MarkdownImageSavingArgs.KeepImageStreamOpen property

عند كون القيمة false (الافتراضي)، يغلق المحول [`ImageStream`](../imagestream) بعد الكتابة — وهو سلوك شائع لاستبدالات FileStream التي يجب تفريغها إلى القرص. اضبطه على true لإبقاء الدفق مفتوحًا بعد إكمال التحويل (نمط شائع لـ MemoryStream إذا كنت تنوي قراءته بنفسك)؛ المتصل يصبح مسؤولاً عن إغلاقه.

public bool KeepImageStreamOpen { get; set; }
