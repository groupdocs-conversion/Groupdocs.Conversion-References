## ConversionEvents.OnFontSubstituted property

يتم إطلاقه عندما يكون الخط المشار إليه في المستند المصدر غير متوفر ويتم استبداله (إما بواسطة قاعدة يقدمها العميل [`FontSubstitute`](../../../groupdocs.conversion.contracts/fontsubstitute) أو بواسطة الخط الافتراضي المُكوَّن أو بواسطة fallback الداخلي لأنابيب التحويل).

```csharp
public Action<FontSubstitutionContext> OnFontSubstituted { get; set; }
```

### ملاحظات

يتم إزالة التكرار للحدث حسب `(SourceFileName, OriginalFontName)` داخل استدعاء واحد لـ `Converter.Convert(...)` — يتلقى المشتركون إشعارًا واحدًا على الأكثر لكل خط مفقود في كل مستند مصدر. يتم إطلاقه بشكل متزامن على خيط التحويل. لا يتم رفعه لتحويلات الصور.

بالنسبة لمستندات العرض، يتم اكتشاف استبدال الخط فقط على نظام Windows، لأن المحرك يحلّه من خلال مطابقة خطوط خاصة بالمنصة غير متوفرة على أنظمة التشغيل الأخرى.
