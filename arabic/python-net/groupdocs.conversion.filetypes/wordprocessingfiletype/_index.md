## WordProcessingFileType class

تحدد فئة WordProcessingFileType صيغ ملفات معالجة النصوص، وتشمل تنسيقات النص العادي والنص المنسق.

ملفات النص العادي تحتوي على نص غير منسق دون أي إعدادات للخط أو الصفحة. تدعم ملفات النص المنسق خيارات تنسيق مثل أنواع الخطوط، الأنماط (عريض، مائل، تحته خط)، هوامش الصفحة، العناوين، القوائم النقطية، الأرقام، وغيرها من الميزات.

### مثال

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # إنشاء كائن Converter باستخدام المستند الإدخالي
    with Converter("./business-plan.docx") as converter:
        # حدد خيارات التحويل؛ تنسيق الإخراج الافتراضي هو DOCX
        word_convert_options = WordProcessingConvertOptions()
        # غيّر تنسيق الإخراج داخل عائلة التنسيقات من DOCX إلى TXT
        word_convert_options.format = WordProcessingFileType.Txt

        # حوّل المستند الإدخالي إلى TXT
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
