| [`DiagramFileType`](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/) | يعرف أنواع مستندات المخططات. يتضمن الأنواع التالية: |

| [`EmailFileType`](/conversion/python-net/groupdocs.conversion.filetypes/emailfiletype/) | يعرف صيغ ملفات البريد الإلكتروني المستخدمة من قبل تطبيقات البريد لتخزين الرسائل، المرفقات، المجلدات، دفاتر العناوين، وغيرها من البيانات. |
| [`FileType`](/conversion/python-net/groupdocs.conversion.filetypes/filetype/) | يمثل الفئة الأساسية لنوع الملف. |

| [`FontFileType`](/conversion/python-net/groupdocs.conversion.filetypes/fontfiletype/) | يمثل أنواع مستندات الخطوط. |

| [`PageDescriptionLanguageFileType`](/conversion/python-net/groupdocs.conversion.filetypes/pagedescriptionlanguagefiletype/) | يحدد أنواع ملفات وثائق وصف الصفحة. |
| [`PdfFileType`](/conversion/python-net/groupdocs.conversion.filetypes/pdffiletype/) | يمثل مستندات PDF. |
| [`PresentationFileType`](/conversion/python-net/groupdocs.conversion.filetypes/presentationfiletype/) | يمثل صيغ ملفات العروض التي تخزن مجموعة من السجلات لاستيعاب بيانات العرض مثل الشرائح، الأشكال، النص، الرسوم المتحركة، الفيديو، الصوت والكائنات المدمجة. |
| [`ProjectManagementFileType`](/conversion/python-net/groupdocs.conversion.filetypes/projectmanagementfiletype/) | يحدد صيغ ملفات المشروع التي يتم إنشاؤها بواسطة برامج إدارة المشاريع مثل Microsoft Project، Primavera P6 وغيرها. |

| [`WordProcessingFileType`](/conversion/python-net/groupdocs.conversion.filetypes/wordprocessingfiletype/) | تحدد فئة WordProcessingFileType صيغ ملفات معالجة النصوص، وتشمل تنسيقات النص العادي والنص المنسق. |
