## schema_location property

Το schema_location είναι μια λίστα ζευγών URI χωρισμένων με κενά, όπου το πρώτο URI σε κάθε ζεύγος είναι το URI του χώρου ονομάτων και το δεύτερο URI είναι η διαδρομή προς το σχήμα XML εκείνου του χώρου ονομάτων.

Εάν οριστεί σε None, το Conversion θα προσπαθήσει να διαβάσει το χαρακτηριστικό schemaLocation από το ριζικό στοιχείο του εγγράφου. Η προεπιλεγμένη τιμή είναι None.
