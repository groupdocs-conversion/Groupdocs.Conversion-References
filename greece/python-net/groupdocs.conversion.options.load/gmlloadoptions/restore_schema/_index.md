## restore_schema property

Η ιδιότητα καθορίζει εάν επιτρέπεται στη μετατροπή να αναλύσει χαρακτηριστικά σε αρχείο GML όταν το σχήμα XML λείπει ή δεν μπορεί να φορτωθεί.

Εάν οριστεί σε True, ο αναγνώστης μετατροπής δεν απαιτεί την παρουσία ενός σχήματος XML. Η προεπιλεγμένη τιμή είναι False.
