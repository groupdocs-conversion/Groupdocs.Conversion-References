## load_schemas_from_internet property

Η ιδιότητα καθορίζει εάν επιτρέπεται στη μετατροπή να φορτώσει σχήματα XML από το Διαδίκτυο.

Εάν οριστεί σε False, τα σχήματα με απόλυτες URI που δεν ξεκινούν με 'file://' δεν θα φορτωθούν. Η προεπιλεγμένη τιμή είναι False.
