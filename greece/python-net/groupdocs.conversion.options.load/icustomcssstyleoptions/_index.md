## ICustomCssStyleOptions class

Αντιπροσωπεύει επιλογές για προσαρμοσμένο στυλ CSS κατά τη μετατροπή εγγράφων.

Ο τύπος ICustomCssStyleOptions εκθέτει τα παρακάτω μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [custom_css_style](/conversion/python-net/groupdocs.conversion.options.load/icustomcssstyleoptions/custom_css_style/) | Το προσαρμοσμένο στυλ CSS που θα εφαρμοστεί στο έγγραφο κατά τη μετατροπή, το οποίο θα εισαχθεί στην ετικέτα `<head>` του εγγράφου για την προσαρμογή της απόδοσης. |
