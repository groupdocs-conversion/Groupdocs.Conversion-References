## skip_external_resources property

Η ιδιότητα υποδεικνύει εάν φορτώνονται εξωτερικοί πόροι. Εάν είναι True, όλοι οι εξωτερικοί πόροι δεν θα φορτωθούν εκτός από εκείνους που βρίσκονται στη λίστα [`IResourceLoadingOptions.whitelisted_resources`](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/). Η προεπιλογή: True.
