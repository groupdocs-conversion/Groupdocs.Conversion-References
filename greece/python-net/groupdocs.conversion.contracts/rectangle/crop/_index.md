## crop {#crop_left-crop_top-crop_right-crop_bottom}

Δημιουργεί μια περικομμένη έκδοση του τρέχοντος rectangle αφαιρώντας τα καθορισμένα περιθώρια.

```python
def crop(self, crop_left, crop_top, crop_right, crop_bottom):
    ...
```

| Παράμετρος | Τύπος | Περιγραφή |
| :- | :- | :- |
| crop_left | `int` | Ο αριθμός των εικονοστοιχείων που πρέπει να αφαιρεθούν από την αριστερή πλευρά. |
| crop_top | `int` | Ο αριθμός των εικονοστοιχείων που πρέπει να αφαιρεθούν από την επάνω πλευρά. |
| crop_right | `int` | Ο αριθμός των εικονοστοιχείων που πρέπει να αφαιρεθούν από τη δεξιά πλευρά. |
| crop_bottom | `int` | Ο αριθμός των εικονοστοιχείων που πρέπει να αφαιρεθούν από την κάτω πλευρά. |

**Returns:** Rectangle: A new cropped rectangle.
