## get_hash_code

Λειτουργεί ως η προεπιλεγμένη συνάρτηση κατακερματισμού.

Τα στοιχεία των πινάκων, λιστών και λεξικών κατακερματίζονται βάσει του περιεχομένου τους, ταιριάζοντας με τον τρόπο που η ισότητα τα συγκρίνει, έτσι ώστε δύο αντικείμενα που συγκρίνονται ίσα να έχουν επίσης ίσο hash και να μπορούν να χρησιμοποιηθούν ως κλειδιά λεξικού ή μέλη συνόλου.

Αυτό δεν επεκτείνεται σε ένα στοιχείο που είναι κάποιο άλλο `System.Collections.IEnumerable`: ένα τέτοιο στοιχείο κατακερματίζεται με βάση την αναφορά, και ένα που εκτίθεται ως αργός επαναλήπτης αποδίδει διαφορετική τιμή σε κάθε πρόσβαση, έτσι ένα αντικείμενο που το περιέχει δεν μπορεί καθόλου να χρησιμοποιηθεί ως κλειδί. Οι ένθετοι συλλογές συγκρίνονται και κατακερματίζονται επίσης με βάση την αναφορά αντί για αναδρομική επεξεργασία.

Η άλλη συνέπεια είναι ότι η τροποποίηση μιας συλλογής που εκτίθεται από ένα αντικείμενο τιμής — προσθήκη σε λίστα σελίδων ή εγγραφή σε πίνακα ονομάτων διάταξης — αλλάζει το hash του αντικειμένου, έτσι ένα στιγμιότυπο που είναι ήδη αποθηκευμένο σε δοχείο hash γίνεται απροσπέλαστο. Θεωρήστε ένα αντικείμενο τιμής ως πάγωτο μόλις χρησιμοποιηθεί ως κλειδί.

```python
def get_hash_code(self):
    ...
```

**Returns:** A hash code for the current object.
