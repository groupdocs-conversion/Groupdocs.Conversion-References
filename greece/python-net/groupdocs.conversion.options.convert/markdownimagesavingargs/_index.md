## MarkdownImageSavingArgs class

Αντιπροσωπεύει τα επιχειρήματα που περνιούνται στο [`IMarkdownImageSavingCallback.image_saving`](/conversion/python-net/groupdocs.conversion.options.convert/imarkdownimagesavingcallback/image_saving/).

Ο τύπος MarkdownImageSavingArgs εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [image_file_name](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_file_name/) | Το όνομα αρχείου (ή το αναγνωριστικό placeholder) ενσωματωμένο ως URI εικόνας στην έξοδο Markdown. Αναθέστε για να ξαναγράψετε το URI. |
| [image_stream](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_stream/) | Το ρεύμα προορισμού στο οποίο ο μετατροπέας θα γράψει τα byte της εικόνας μετά την επιστροφή αυτού του callback. |
| [keep_image_stream_open](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/keep_image_stream_open/) | Η ιδιότητα καθορίζει αν ο μετατροπέας διατηρεί το ρεύμα εικόνας ανοιχτό μετά τη μετατροπή. |
