## IPagedConvertOptions class

Αντιπροσωπεύει επιλογές μετατροπής που επιτρέπουν περιορισμό σελίδων καθορίζοντας τη σελίδα έναρξης και τον αριθμό σελίδων.

Ο τύπος IPagedConvertOptions εκθέτει τα ακόλουθα μέλη:

### Ιδιότητες
| Ιδιότητα | Περιγραφή |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | Ο επιθυμητός τύπος αρχείου στο οποίο πρέπει να μετατραπεί το εισαγόμενο έγγραφο. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | Ο αριθμός σελίδας από την οποία ξεκινά η μετατροπή. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | Ο αριθμός των σελίδων που θα μετατραπούν ξεκινώντας από το `PageNumber`. |
