## PUB field

Ένα αρχείο PUB είναι μια μορφή αρχείου εγγράφου του Microsoft Publisher. Χρησιμοποιείται για τη δημιουργία διαφόρων τύπων εγγράφων σχεδίασης όπως ενημερωτικά δελτία, φυλλάδια, φυλλάδια προώθησης, κάρτες, κ.λπ. Τα αρχεία PUB μπορούν να περιέχουν κείμενο, ραστροειδείς και διανυσματικές εικόνες. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
