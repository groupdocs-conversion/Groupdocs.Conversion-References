## GIF field

Ένα GIF ή Graphical Interchange Format είναι ένας τύπος έντονα συμπιεσμένης εικόνας. Για κάθε εικόνα, το GIF συνήθως επιτρέπει έως 8 bits ανά pixel και έως 256 χρώματα επιτρέπονται σε όλη την εικόνα. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου εδώ.
