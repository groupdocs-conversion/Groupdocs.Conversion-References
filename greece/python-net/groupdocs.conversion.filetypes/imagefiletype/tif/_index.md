## TIF field

Το TIF, Tagged Image File Format, αντιπροσωπεύει ραστερ εικόνες που προορίζονται για χρήση σε μια ποικιλία συσκευών που συμμορφώνονται με αυτό το πρότυπο μορφότυπου αρχείου. Είναι ικανό να περιγράφει διπλού επιπέδου, γκρι κλίμακας, χρωματιστές παλέτες και πλήρους χρώματος δεδομένα εικόνας σε διάφορους χρωματικούς χώρους.
