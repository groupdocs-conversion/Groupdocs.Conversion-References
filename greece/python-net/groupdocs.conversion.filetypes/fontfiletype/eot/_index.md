## EOT field

Ένα αρχείο με επέκταση .eot είναι μια γραμματοσειρά OpenType που ενσωματώνεται σε ένα έγγραφο. Αυτές χρησιμοποιούνται κυρίως σε αρχεία ιστού όπως μια ιστοσελίδα. Δημιουργήθηκε από τη Microsoft και υποστηρίζεται από προϊόντα της Microsoft, συμπεριλαμβανομένου του αρχείου παρουσίασης PowerPoint .pps. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
