## WOFF2 field

Ένα αρχείο με επέκταση .woff είναι ένα αρχείο γραμματοσειράς ιστού βασισμένο στο Web Open Font Format (WOFF). Διαθέτει συμπιεσμένο κοντέινερ ειδικό για τη μορφή, βασισμένο είτε σε τύπους γραμματοσειρών TrueType (.TTF) είτε OpenType (.OTT). Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
