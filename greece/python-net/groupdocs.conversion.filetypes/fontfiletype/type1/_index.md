## TYPE1 field

Οι γραμματοσειρές Type 1 είναι μια παρωχημένη τεχνολογία της Adobe που χρησιμοποιήθηκε ευρέως σε λογισμικό επιτραπέζιας δημοσίευσης και εκτυπωτές που μπορούσαν να χρησιμοποιήσουν PostScript. Παρόλο που οι γραμματοσειρές Type 1 δεν υποστηρίζονται σε πολλές σύγχρονες πλατφόρμες, προγράμματα περιήγησης και κινητά λειτουργικά συστήματα, παραμένουν υποστηριζόμενες σε ορισμένα λειτουργικά συστήματα.
