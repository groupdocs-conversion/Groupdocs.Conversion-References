## CFF field

Ένα αρχείο με επέκταση .cff είναι μια Compact Font Format και είναι επίσης γνωστή ως PostScript Type 1 ή CIDFont. Η CFF λειτουργεί ως κοντέινερ για την αποθήκευση πολλαπλών γραμματοσειρών μαζί σε μια ενιαία μονάδα γνωστή ως FontSet. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
