## PresentationFileType class

Αντιπροσωπεύει μορφές αρχείων παρουσίασης που αποθηκεύουν μια συλλογή εγγραφών για τη διαχείριση δεδομένων παρουσίασης όπως διαφάνειες, σχήματα, κείμενο, κινούμενα σχέδια, βίντεο, ήχο και ενσωματωμένα αντικείμενα.
