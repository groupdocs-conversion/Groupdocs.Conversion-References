## GPX field

Τα αρχεία με επέκταση GPX αντιπροσωπεύουν τη μορφή GPS Exchange για ανταλλαγή δεδομένων GPS μεταξύ εφαρμογών και διαδικτυακών υπηρεσιών. Είναι μια ελαφριά μορφή αρχείου XML που περιέχει δεδομένα GPS, δηλαδή σημεία, διαδρομές και ίχνη, τα οποία μπορούν να εισαχθούν και να διαβαστούν από πολλαπλά προγράμματα.
