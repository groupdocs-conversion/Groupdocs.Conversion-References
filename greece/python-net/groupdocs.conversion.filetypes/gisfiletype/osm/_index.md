## OSM field

Η μορφή αρχείου OSM είναι μια δομημένη μορφή δεδομένων που χρησιμοποιείται για την αποθήκευση γεωγραφικών δεδομένων στο έργο OpenStreetMap. Τα αρχεία OSM είναι συνήθως σε μορφή XML και περιέχουν πληροφορίες όπως η θέση δρόμων, κτιρίων, σημείων ενδιαφέροντος και άλλων χαρακτηριστικών στον χάρτη.
