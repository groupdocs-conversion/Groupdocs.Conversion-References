## ZIP field

Ένα αρχείο με επέκταση .zip είναι ένα αρχείο συμπίεσης που μπορεί να περιέχει ένα ή περισσότερα αρχεία ή καταλόγους. Το αρχείο μπορεί να έχει εφαρμοσμένη συμπίεση στα περιλαμβανόμενα αρχεία ώστε να μειωθεί το μέγεθος του αρχείου ZIP. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
