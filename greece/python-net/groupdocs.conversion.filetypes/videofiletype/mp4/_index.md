## MP4 field

MP4 (συντομογραφία για MPEG-4 Part 14) είναι μια μορφή αρχείου βασισμένη στο ISO/IEC 14496-12:2004, η οποία βασίζεται στο QuickTime File Format αλλά καθορίζει επίσημα την υποστήριξη για Initial Object Descriptors (IOD) και άλλα χαρακτηριστικά MPEG.
