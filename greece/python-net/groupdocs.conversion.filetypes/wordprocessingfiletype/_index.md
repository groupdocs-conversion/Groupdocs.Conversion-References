## WordProcessingFileType class

Η κλάση WordProcessingFileType ορίζει μορφές αρχείων Επεξεργασίας Κειμένου, καλύπτοντας παραλλαγές απλού κειμένου και εμπλουτισμένου κειμένου.

Τα αρχεία απλού κειμένου περιέχουν αμορφοποιημένο κείμενο χωρίς εφαρμοσμένες γραμματοσειρές ή ρυθμίσεις σελίδας. Τα αρχεία εμπλουτισμένου κειμένου υποστηρίζουν επιλογές μορφοποίησης όπως τύποι γραμματοσειρών, στυλ (έντονα, πλάγια, υπογράμμιση), περιθώρια σελίδας, επικεφαλίδες, κουκίδες, αριθμούς και άλλα χαρακτηριστικά.

### Παράδειγμα

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # Αρχικοποιήστε τον Converter με το έγγραφο εισόδου.
    with Converter("./business-plan.docx") as converter:
        # Ορίστε τις επιλογές μετατροπής· η προεπιλεγμένη μορφή εξόδου είναι DOCX.
        word_convert_options = WordProcessingConvertOptions()
        # Αλλάξτε τη μορφή εξόδου εντός της οικογένειας μορφών από DOCX σε TXT.
        word_convert_options.format = WordProcessingFileType.Txt

        # Μετατρέψτε το έγγραφο εισόδου σε TXT.
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
