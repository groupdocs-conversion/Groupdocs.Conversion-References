## SXC field

Η μορφή αρχείου SXC (Sun XML Calc) ανήκει σε μια σουίτα γραφείου που ονομάζεται OpenOffice.org. Αυτή η μορφή εξυπηρετεί γενικά τις ανάγκες λογιστικών φύλλων των χρηστών, καθώς είναι μια μορφή λογιστικού φύλλου βασισμένη σε XML. Η μορφή SXC υποστηρίζει τύπους, συναρτήσεις, μακροεντολές και διαγράμματα μαζί με DataPilot. Μάθετε περισσότερα για αυτή τη μορφή αρχείου εδώ.
