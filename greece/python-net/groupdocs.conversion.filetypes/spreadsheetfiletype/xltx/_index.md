## XLTX field

Το αρχείο XLTX αντιπροσωπεύει ένα πρότυπο Microsoft Excel που βασίζεται στις προδιαγραφές μορφής αρχείου Office OpenXML. Χρησιμοποιείται για τη δημιουργία ενός τυπικού αρχείου προτύπου που μπορεί να αξιοποιηθεί για τη δημιουργία αρχείων XLSX που εμφανίζουν τις ίδιες ρυθμίσεις όπως ορίζονται στο αρχείο XLTX.
