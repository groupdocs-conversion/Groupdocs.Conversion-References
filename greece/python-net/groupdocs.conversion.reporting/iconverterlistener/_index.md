## IConverterListener class

Ορίζει τις μεθόδους που χρησιμοποιούνται για την παρακολούθηση του μετατροπέα.

Μάθετε περισσότερα.

- More about monitoring conversion progress: https://docs.groupdocs.com/display/conversionnet/Listening

Ο τύπος IConverterListener εκθέτει τα ακόλουθα μέλη:

### Μέθοδοι
| Μέθοδος | Περιγραφή |
| :- | :- |
| [completed](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/completed/) | Καλείται όταν ολοκληρωθεί η μετατροπή. |
| [progress](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress/#current) | Καλείται κάθε φορά που η πρόοδος της μετατροπής αλλάζει. |
| [progress_byte](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress_byte/) |  |
| [started](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/started/) | Καλείται αμέσως μόλις ξεκινήσει η πραγματική μετατροπή. |
