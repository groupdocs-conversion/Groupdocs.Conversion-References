### Cgm {#Cgm}
```
public static final PageDescriptionLanguageFileType Cgm
```


Το Computer Graphics Metafile (CGM) είναι δωρεάν, ανεξάρτητο από πλατφόρμα, διεθνές πρότυπο μορφή μετααρχείου για την αποθήκευση και ανταλλαγή διανυσματικών γραφικών (2Δ), ραστερ γραφικών και κειμένου. Το CGM χρησιμοποιεί αντικειμενοστραφή προσέγγιση και πολλές λειτουργικές παροχές για την παραγωγή εικόνων. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://wiki.fileformat.com/page-description-language/cgm).


### Xps {#Xps}
```
public static final PageDescriptionLanguageFileType Xps
```


Ένα αρχείο XPS αντιπροσωπεύει αρχεία διάταξης σελίδων που βασίζονται στις XML Paper Specifications που δημιουργήθηκαν από τη Microsoft. Αυτή η μορφή αναπτύχθηκε από τη Microsoft ως αντικατάσταση της μορφής αρχείου EMF και είναι παρόμοια με τη μορφή αρχείου PDF, αλλά χρησιμοποιεί XML στη διάταξη, την εμφάνιση και τις πληροφορίες εκτύπωσης ενός εγγράφου. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://wiki.fileformat.com/page-description-language/xps).


### Tex {#Tex}
```
public static final PageDescriptionLanguageFileType Tex
```


Το TeX είναι μια γλώσσα που περιλαμβάνει προγραμματισμό καθώς και δυνατότητες σήμανσης, χρησιμοποιείται για τη στοιχειοθέτηση εγγράφων. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://wiki.fileformat.com/page-description-language/tex).


### Ps {#Ps}
```
public static final PageDescriptionLanguageFileType Ps
```


Το PostScript (PS) είναι μια γενικού σκοπού γλώσσα περιγραφής σελίδων που χρησιμοποιείται στον χώρο της επιτραπέζιας και ηλεκτρονικής έκδοσης. Η κύρια εστίαση του PostScript (PS) είναι η διευκόλυνση του δισδιάστατου γραφικού σχεδιασμού. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://wiki.fileformat.com/page-description-language/ps).


### Pcl {#Pcl}
```
public static final PageDescriptionLanguageFileType Pcl
```


Το PCL σημαίνει Printer Command Language, η οποία είναι μια γλώσσα περιγραφής σελίδων που εισήχθη από την Hewlett Packard (HP). Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://wiki.fileformat.com/page-description-language/pcl).


### Oxps {#Oxps}
```
public static final PageDescriptionLanguageFileType Oxps
```


Η μορφή αρχείου OXPS είναι γνωστή ως Open XML Paper Specification. Είναι μια γλώσσα περιγραφής σελίδων και μορφή εγγράφου. Η Microsoft είναι ο δημιουργός αυτής της μορφής. Η μορφή αρχείου OXPS είναι πολύ παρόμοια με αυτά τα αρχεία PDF. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/page-description-language/oxps).
