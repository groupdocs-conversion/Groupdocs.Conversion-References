### Tiff {#Tiff}
```
public static final ImageFileType Tiff
```


TIFF, Tagged Image File Format, αντιπροσωπεύει εικόνες raster που προορίζονται για χρήση σε ποικίλες συσκευές που συμμορφώνονται με αυτό το πρότυπο μορφής αρχείου. Μπορεί να περιγράψει δεδομένα εικόνας διπλού επιπέδου, γκρι κλίμακας, χρωματιστής παλέτας και πλήρους χρώματος σε διάφορους χρωματικούς χώρους.

Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://wiki.fileformat.com/image/gif).
