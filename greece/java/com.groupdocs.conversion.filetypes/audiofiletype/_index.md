### Aac {#Aac}
```
public static final AudioFileType Aac
```


Το AAC (Advanced Audio Coding) αναφέρεται σε πρότυπο κωδικοποίησης ψηφιακού ήχου που αντιπροσωπεύει αρχεία ήχου βασισμένα σε συμπίεση με απώλειες. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/audio/aac/).


### Aiff {#Aiff}
```
public static final AudioFileType Aiff
```


Το AIFF (Audio Interchange File Format) είναι μια ασυμπίεστη μορφή αρχείου ήχου που αναπτύχθηκε από την Apple το 1998, αλλά βασίζεται στο EA IFF 85. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/audio/aiff/).


### Flac {#Flac}
```
public static final AudioFileType Flac
```


FLAC (Free Lossless Audio Codec) είναι μια μορφή κωδικοποίησης ήχου χωρίς απώλειες που αναπτύχθηκε από το Ίδρυμα Xiph.Org. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/audio/flac/).


### M4a {#M4a}
```
public static final AudioFileType M4a
```


Η μορφή αρχείου M4A είναι ένα αρχείο ήχου που δημιουργείται με τη χρήση του AAC (Advanced Audio Coding), το οποίο είναι γνωστό ως συμπίεση με απώλειες. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/audio/m4a/).


### Wma {#Wma}
```
public static final AudioFileType Wma
```


Ένα αρχείο με επέκταση .wma αντιπροσωπεύει ένα αρχείο ήχου που αποθηκεύεται σε μορφή Advanced Systems Format (ASF). Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/audio/wma/).


### Ac3 {#Ac3}
```
public static final AudioFileType Ac3
```


Ένα αρχείο με επέκταση .ac3 είναι ένα αρχείο Audio Codec 3, που εισήχθη από την Dolby Laboratories. Είναι μια μορφή ήχου που μπορεί να περιέχει έως και έξι κανάλια εξόδου ήχου. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/audio/ac3/).


### Ogg {#Ogg}
```
public static final AudioFileType Ogg
```


Το OGG είναι ένα συμπιεσμένο αρχείο ήχου Ogg Vorbis που αποθηκεύεται με την επέκταση .ogg. Τα αρχεία OGG χρησιμοποιούνται για την αποθήκευση δεδομένων ήχου και μπορούν επίσης να περιλαμβάνουν πληροφορίες καλλιτέχνη, κομματιού και μεταδεδομένων. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/audio/ogg/).


### Wav {#Wav}
```
public static final AudioFileType Wav
```


WAV, γνωστό για το WAVE (Waveform Audio File Format), είναι ένα υποσύνολο της προδιαγραφής Resource Interchange File Format (RIFF) της Microsoft για την αποθήκευση ψηφιακών αρχείων ήχου. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/audio/ogg/).
