### Mht {#Mht}
```
public static final WebFileType Mht
```


Τα αρχεία με την επέκταση MHTML αντιπροσωπεύουν μορφότυπο αρχείου αρχειοθέτησης ιστοσελίδας που μπορεί να δημιουργηθεί από διάφορες εφαρμογές. Η μορφή αυτή είναι γνωστή ως μορφή αρχειοθέτησης επειδή αποθηκεύει τον κώδικα HTML του ιστού και τους σχετικούς πόρους σε ένα μόνο αρχείο. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου [εδώ](../https://wiki.fileformat.com/web/mhtml).

### Chm {#Chm}
```

```


Το μορφότυπο αρχείου CHM αντιπροσωπεύει το αρχείο βοήθειας Microsoft HTML που αποτελείται από μια συλλογή σελίδων HTML. Παρέχει ευρετήριο για γρήγορη πρόσβαση στα θέματα και πλοήγηση σε διαφορετικά τμήματα του εγγράφου βοήθειας.
