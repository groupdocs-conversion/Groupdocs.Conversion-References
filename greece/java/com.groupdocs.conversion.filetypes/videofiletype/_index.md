### Mp4 {#Mp4}
```
public static final VideoFileType Mp4
```


MP4 (συντομογραφία του MPEG-4 Part 14) είναι μια μορφή αρχείου βασισμένη στο ISO/IEC 14496-12:2004 που βασίζεται στο QuickTime File Format, αλλά καθορίζει επίσημα την υποστήριξη για Initial Object Descriptors (IOD) και άλλα χαρακτηριστικά MPEG. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/video/mp4/).


### Avi {#Avi}
```
public static final VideoFileType Avi
```


Η μορφή αρχείου AVI είναι ένα πολυμέσο κοντέινερ ήχου-βίντεο που εισήχθη από τη Microsoft. Περιέχει τα δεδομένα ήχου και βίντεο που δημιουργήθηκαν και συμπιέστηκαν χρησιμοποιώντας διάφορους κωδικοποιητές (Coders/Decoders) όπως XVid και DivX. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/video/avi/).


### Flv {#Flv}
```
public static final VideoFileType Flv
```


FLV (Flash Video) είναι μια μορφή αρχείου κοντέινερ με την επέκταση .flv. Το FLV χρησιμοποιείται για τη διανομή περιεχομένου ήχου/βίντεο μέσω του διαδικτύου χρησιμοποιώντας το Adobe Flash Player ή το Adobe Air. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/video/flv/).


### Mkv {#Mkv}
```
public static final VideoFileType Mkv
```


Το MKV (Matroska Video) είναι ένα πολυμέσο κοντέινερ παρόμοιο με τις μορφές MOV και AVI, αλλά υποστηρίζει περισσότερα από ένα κανάλια ήχου και υπότιτλων στο ίδιο αρχείο. Ένα αρχείο MKV είναι η μορφή κοντέινερ πολυμέσων Matroska που χρησιμοποιείται για βίντεο. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/video/mkv/).


### Mov {#Mov}
```
public static final VideoFileType Mov
```


Η μορφή αρχείου MOV ή QuickTime είναι ένα πολυμέσο κοντέινερ που αναπτύχθηκε από την Apple: περιέχει ένα ή περισσότερα κομμάτια, κάθε κομμάτι κρατά έναν συγκεκριμένο τύπο δεδομένων, π.χ. Βίντεο, Ήχος, κείμενο κ.λπ. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/video/mov/).


### Webm {#Webm}
```
public static final VideoFileType Webm
```


Ένα αρχείο με επέκταση .webm είναι ένα αρχείο βίντεο βασισμένο στην ανοιχτή, χωρίς δικαιώματα χρήσης μορφή αρχείου WebM. Έχει σχεδιαστεί για κοινή χρήση βίντεο στο διαδίκτυο και ορίζει τη δομή του κοντέινερ αρχείου, συμπεριλαμβανομένων των μορφών βίντεο και ήχου. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/video/webm//).


### Wmv {#Wmv}
```
public static final VideoFileType Wmv
```


Το Windows Media Video είναι η συμπιεσμένη μορφή βίντεο που αναπτύχθηκε από τη Microsoft. Μετά την τυποποίηση από την Εταιρεία Μηχανικών Κινηματογράφου και Τηλεόρασης (SMPTE), το WMV θεωρείται πλέον ανοιχτή πρότυπη μορφή. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](../https://docs.fileformat.com/video/wmv/).
