Ορίζει αρχεία επεξεργασίας κειμένου που περιέχουν πληροφορίες χρήστη σε απλό κείμενο ή μορφή εμπλουτισμένου κειμένου. Μια μορφή αρχείου απλού κειμένου περιέχει αμορφοποιημένο κείμενο και δεν μπορούν να εφαρμοστούν ρυθμίσεις γραμματοσειράς ή σελίδας κ.λπ. Αντίθετα, μια μορφή αρχείου εμπλουτισμένου κειμένου επιτρέπει επιλογές μορφοποίησης όπως ο καθορισμός τύπου γραμματοσειρών, στυλ (έντονο, πλάγιο, υπογράμμιση κ.λπ.), περιθώρια σελίδας, επικεφαλίδες, κουκίδες και αριθμούς, καθώς και πολλές άλλες δυνατότητες μορφοποίησης.

Τα αρχεία κειμένου που δημιουργούνται με διαλέκτους της γλώσσας Markdown αποθηκεύονται με την επέκταση .MD ή .MARKDOWN.
