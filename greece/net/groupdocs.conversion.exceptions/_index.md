Ο χώρος ονομάτων παρέχει διαφορετικές κλάσεις εξαιρέσεων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ConversionByPageFailedException](./conversionbypagefailedexception) | Αποτυχία εξαίρεσης μετατροπής ανά σελίδα |
| [ConversionFailedException](./conversionfailedexception) | Αποτυχία εξαίρεσης μετατροπής |
| [ConversionNotSupportedException](./conversionnotsupportedexception) | GroupDocs εξαίρεση που εκτοξεύεται όταν η μετατροπή από το αρχείο προέλευσης στον τύπο αρχείου προορισμού δεν υποστηρίζεται |
| [CorruptOrDamagedFileException](./corruptordamagedfileexception) | GroupDocs εξαίρεση που εκτοξεύεται όταν το αρχείο είναι κατεστραμμένο ή ζημιωμένο |
| [EvaluationLimitReachedException](./evaluationlimitreachedexception) | GroupDocs εξαίρεση που εκτοξεύεται όταν η άδεια αξιολόγησης μετατροπής για τη τρέχουσα διαδικασία έχει εξαντληθεί. |
| [FileTypeNotSupportedException](./filetypenotsupportedexception) | GroupDocs εξαίρεση που εκτοξεύεται όταν ο τύπος αρχείου δεν υποστηρίζεται |
| [FontSubstituteException](./fontsubstituteexception) | Εκτοξεύεται εάν η αντικατάσταση γραμματοσειράς είναι παράνομη |
| [GroupDocsConversionException](./groupdocsconversionexception) | GroupDocs.Conversion γενική εξαίρεση |
| [IncorrectPasswordException](./incorrectpasswordexception) | GroupDocs εξαίρεση που εκτοξεύεται όταν το αρχείο είναι προστατευμένο με κωδικό, ο κωδικός παρέχεται αλλά είναι λανθασμένος |
| [InvalidConverterSettingsException](./invalidconvertersettingsexception) | Εκτοξεύεται εάν οι παρεχόμενες ρυθμίσεις μετατροπέα είναι μη έγκυρες |
| [InvalidConvertOptionsException](./invalidconvertoptionsexception) | Εκτοξεύεται εάν οι παρεχόμενες επιλογές μετατροπής είναι μη έγκυρες |
| [InvalidLoadOptionsException](./invalidloadoptionsexception) | Εκτοξεύεται εάν οι παρεχόμενες επιλογές φόρτωσης είναι μη έγκυρες |
| [MissingDependencyException](./missingdependencyexception) | GroupDocs εξαίρεση που εκτοξεύεται όταν μια μετατροπή δεν μπορεί να εκτελεστεί επειδή μια συναρμολόγηση από την οποία εξαρτάται δεν υπάρχει στην έξοδο της εφαρμογής. Το έγγραφο δεν είναι υπεύθυνο. |
| [PasswordRequiredException](./passwordrequiredexception) | GroupDocs εξαίρεση που εκτοξεύεται όταν το αρχείο είναι προστατευμένο με κωδικό και ο κωδικός δεν παρέχεται |
| [SourceDocumentFactoryNotProvidedException](./sourcedocumentfactorynotprovidedexception) | GroupDocs εξαίρεση που εκτοξεύεται όταν το εργοστάσιο εγγράφων προέλευσης δεν παρέχεται |
