## EvaluationLimitReachedException class

GroupDocs εξαίρεση που εκτοξεύεται όταν η άδεια αξιολόγησης μετατροπής για τη τρέχουσα διαδικασία έχει εξαντληθεί.

```csharp
public sealed class EvaluationLimitReachedException : GroupDocsConversionException
```

### Παρατηρήσεις

Εκτοξεύεται μόνο όταν δεν υπάρχει άδεια. Η εφαρμογή άδειας αφαιρεί τον περιορισμό, έτσι μια διαδικασία με άδεια δεν βλέπει ποτέ αυτήν την εξαίρεση, όσα και έγγραφα και να μετατρέπει.
