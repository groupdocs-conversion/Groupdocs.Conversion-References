## ThreeDFileType.Amf field

Ένα αρχείο AMF αποτελείται από οδηγίες για την περιγραφή αντικειμένων ώστε να χρησιμοποιείται από διαδικασίες Προσθετικής Κατασκευής. Περιέχει μια εναρκτήρια ετικέτα XML και τελειώνει με ένα στοιχείο. Αυτό προηγείται από μια γραμμή δήλωσης XML που καθορίζει την έκδοση XML και την κωδικοποίηση του αρχείου. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://docs.fileformat.com/3d/amf).

public static readonly ThreeDFileType Amf;
