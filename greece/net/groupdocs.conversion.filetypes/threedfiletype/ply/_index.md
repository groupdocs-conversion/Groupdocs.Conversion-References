## ThreeDFileType.Ply field

Το PLY, Polygon File Format, αντιπροσωπεύει μια μορφή 3D αρχείου που αποθηκεύει γραφικά αντικείμενα περιγραφόμενα ως συλλογή πολυγώνων. Σκοπός αυτής της μορφής αρχείου ήταν η δημιουργία ενός απλού και εύχρηστου τύπου αρχείου που είναι αρκετά γενικό για να είναι χρήσιμο σε ευρύ φάσμα μοντέλων. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://docs.fileformat.com/3d/ply).

public static readonly ThreeDFileType Ply;
