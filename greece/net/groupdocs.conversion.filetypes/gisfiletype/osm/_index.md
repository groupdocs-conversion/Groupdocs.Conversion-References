## GisFileType.Osm field

Η μορφή αρχείου OSM είναι μια δομημένη μορφή δεδομένων που χρησιμοποιείται για την αποθήκευση γεωγραφικών δεδομένων στο έργο OpenStreetMap. Τα αρχεία OSM είναι συνήθως σε μορφή XML και περιέχουν πληροφορίες όπως η θέση των δρόμων, κτιρίων, σημείων ενδιαφέροντος και άλλων χαρακτηριστικών στο χάρτη. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://docs.fileformat.com/gis/osm/).

public static readonly GisFileType Osm;
