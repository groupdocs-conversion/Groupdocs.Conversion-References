## PublisherFileType.Pub field

Ένα αρχείο PUB είναι μορφότυπο αρχείου εγγράφου Microsoft Publisher. Χρησιμοποιείται για τη δημιουργία διαφόρων τύπων σχεδίων διάταξης, όπως ενημερωτικά δελτία, φυλλάδια, μπροσούρες, καρτ ποστάλ κ.λπ. Τα αρχεία PUB μπορούν να περιέχουν κείμενο, ραστερικές και διανυσματικές εικόνες. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου [εδώ](https://docs.fileformat.com/publisher/pub/).

```csharp
public static readonly PublisherFileType Pub;
```
