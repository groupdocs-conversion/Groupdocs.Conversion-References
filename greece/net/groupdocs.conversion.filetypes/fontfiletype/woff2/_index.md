## FontFileType.Woff2 field

Ένα αρχείο με επέκταση .woff είναι ένα αρχείο γραμματοσειράς ιστού βασισμένο στο Web Open Font Format (WOFF). Διαθέτει συμπιεσμένο κοντέινερ ειδικό για τη μορφή, βασισμένο είτε σε TrueType (.TTF) είτε σε OpenType (.OTT) τύπους γραμματοσειρών. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://docs.fileformat.com/font/woff/).

public static readonly FontFileType Woff2;
