## ImageFileType.Png field

Το PNG, Portable Network Graphics, αναφέρεται σε έναν τύπο μορφής αρχείου raster εικόνας που χρησιμοποιεί συμπίεση χωρίς απώλειες. Αυτή η μορφή αρχείου δημιουργήθηκε ως αντικατάσταση του Graphics Interchange Format (GIF) και δεν έχει περιορισμούς πνευματικών δικαιωμάτων. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://wiki.fileformat.com/image/png).

```csharp
public static readonly ImageFileType Png;
```
