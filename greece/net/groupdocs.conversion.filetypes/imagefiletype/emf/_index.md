## ImageFileType.Emf field

Η μορφή Enhanced metafile (EMF) αποθηκεύει γραφικές εικόνες ανεξάρτητα από τη συσκευή. Τα μετααρχεία EMF αποτελούνται από μεταβλητού μήκους εγγραφές σε χρονολογική σειρά που μπορούν να αποδώσουν την αποθηκευμένη εικόνα μετά την ανάλυση σε οποιαδήποτε έξοδο συσκευής. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου [here](https://wiki.fileformat.com/image/emf).

```csharp
public static readonly ImageFileType Emf;
```
