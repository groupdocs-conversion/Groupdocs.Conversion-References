## FontSubstitutionContext.Reason property

Το μήνυμα αντικατάστασης ακριβώς όπως αναφέρεται από τη γραμμή μετατροπής, κυριολεκτικά και αδιάσπαστο. Για έγγραφα που εκθέτουν δομικά τα ονόματα γραμματοσειρών, αυτό μπορεί να είναι `null` (χρησιμοποιήστε [`OriginalFontName`](../originalfontname) / [`SubstituteFontName`](../substitutefontname)); για τα άλλα μεταφέρει την πλήρη περιγραφή που είναι αναγνώσιμη από άνθρωπο, η οποία ονομάζει τόσο τη χαμένη όσο και τη γραμματοσειρά αντικατάστασης.

public string Reason { get; }
