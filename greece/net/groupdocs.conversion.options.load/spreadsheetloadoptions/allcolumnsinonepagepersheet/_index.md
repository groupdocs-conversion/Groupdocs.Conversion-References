## SpreadsheetLoadOptions.AllColumnsInOnePagePerSheet property

Εάν το AllColumnsInOnePagePerSheet είναι true, όλο το περιεχόμενο των στηλών ενός φύλλου θα εξάγεται σε μία μόνο σελίδα στο αποτέλεσμα. Το πλάτος του μεγέθους χαρτιού του pagesetup θα είναι άκυρο, ενώ οι άλλες ρυθμίσεις του pagesetup θα παραμείνουν σε ισχύ.

```csharp
public bool AllColumnsInOnePagePerSheet { get; set; }
```
