## GmlLoadOptions.LoadSchemasFromInternet property

Καθορίζει εάν η Conversion επιτρέπεται να φορτώσει σχήμα XML από το Διαδίκτυο. Εάν οριστεί σε false, τα σχήματα με απόλυτες URI που δεν ξεκινούν με ‘file://’ δεν θα φορτωθούν. Η προεπιλογή είναι false.

```csharp
public bool LoadSchemasFromInternet { get; set; }
```
