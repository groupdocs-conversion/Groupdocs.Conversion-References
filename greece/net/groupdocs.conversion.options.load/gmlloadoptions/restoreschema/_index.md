## GmlLoadOptions.RestoreSchema property

Καθορίζει εάν η Conversion επιτρέπεται να αναλύσει τα χαρακτηριστικά σε ένα αρχείο Gml στο οποίο λείπει ή δεν μπορεί να φορτωθεί σχήμα XML. Εάν οριστεί σε true, ο αναγνώστης Conversion δεν απαιτεί την παρουσία σχήματος XML. Η προεπιλογή είναι false.

```csharp
public bool RestoreSchema { get; set; }
```
