## PdfLoadOptions.FontTransformations property

Μετασχηματίζει τις υπάρχουσες γραμματοσειρές μετά τη φόρτωση του εγγράφου και την ολοκλήρωση της αντικατάστασης γραμματοσειρών. Οι μετασχηματισμοί γραμματοσειρών μπορούν να τροποποιήσουν οποιεσδήποτε γραμματοσειρές στο έγγραφο, συμπεριλαμβανομένων των γραμματοσειρών που φορτώθηκαν επιτυχώς.

```csharp
public IList<FontTransformation> FontTransformations { get; set; }
```

### Παρατηρήσεις

**Note:** Font transformations are applied after all font substitution steps are complete.

Οι μετασχηματισμοί επεξεργάζονται με τη σειρά που εμφανίζονται στη λίστα.

Περιστατικά χρήσης: Αλλαγές στυλ, απαιτήσεις branding, βελτιώσεις προσβασιμότητας.
