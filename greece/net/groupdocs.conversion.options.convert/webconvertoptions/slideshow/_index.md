## WebConvertOptions.SlideShow property

Ισχύει μόνο κατά τη μετατροπή μιας παρουσίασης σε [`Html`](../../../groupdocs.conversion.filetypes/webfiletype/html) ή [`Htm`](../../../groupdocs.conversion.filetypes/webfiletype/htm), και παραβλέπεται για κάθε άλλη μετατροπή. Καθορίζει εάν η παρουσίαση θα γίνει μια διαδραστική παρουσίαση HTML με μεταβάσεις διαφανειών και κινήσεις σχημάτων, αντί για την προεπιλεγμένη στατική σελίδα HTML. Η προεπιλογή είναι ψευδής.

### Παρατηρήσεις

Το αποτέλεσμα είναι ένα ενιαίο αρχείο HTML με ενσωματωμένα στυλ, σενάρια, εικόνες, γραμματοσειρές και πολυμέσα. Οι δύο βιβλιοθήκες JavaScript που τροφοδοτούν την παρουσίαση φορτώνονται από CDN, έτσι η σελίδα χρειάζεται σύνδεση στο διαδίκτυο για να κάνει animation και πλοήγηση.
