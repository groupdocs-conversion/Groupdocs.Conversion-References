## ImageConvertOptions.MinResolution property

Το κατώτερο όριο ανά άξονα εφαρμόζεται στην περιορισμένη απόδοση DPI όταν το [`CapResolutionToPageContent`](../capresolutiontopagecontent) είναι ενεργοποιημένο. Το περιορισμένο DPI δεν μειώνεται ποτέ κάτω από αυτήν την τιμή. Η προεπιλογή είναι `0` (χωρίς όριο).

```csharp
public int MinResolution { get; set; }
```
