## MarkdownImageSavingArgs.KeepImageStreamOpen property

Όταν είναι ψευδές (προεπιλογή), ο μετατροπέας κλείνει το [`ImageStream`](../imagestream) μετά τη γραφή — κάτι σύνηθες για αντικαταστάσεις FileStream που πρέπει να εκκενωθούν στο δίσκο. Ορίστε σε αληθές για να διατηρήσετε τη ροή ανοιχτή μετά την ολοκλήρωση της μετατροπής (τυπικό για ένα MemoryStream που σκοπεύετε να διαβάσετε μόνοι σας); ο καλώντ τότε αναλαμβάνει την αποδέσμευση.

```csharp
public bool KeepImageStreamOpen { get; set; }
```
