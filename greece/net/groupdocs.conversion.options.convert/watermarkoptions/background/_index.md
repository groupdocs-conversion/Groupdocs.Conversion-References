## WatermarkOptions.Background property

Δείχνει ότι το υδατογράφημα είναι τοποθετημένο ως φόντο. Εάν η τιμή είναι true, το υδατογράφημα τοποθετείται στο κάτω μέρος. Από προεπιλογή είναι false και το υδατογράφημα τοποθετείται στην κορυφή.

```csharp
public bool Background { get; set; }
```
