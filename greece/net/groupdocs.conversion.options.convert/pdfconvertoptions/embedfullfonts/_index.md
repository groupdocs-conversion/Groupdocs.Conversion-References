## PdfConvertOptions.EmbedFullFonts property

Όταν οριστεί σε true, το πλήρες αρχείο γραμματοσειράς ενσωματώνεται στο PDF αντί για ένα υποσύνολο. Αυτό αυξάνει το μέγεθος του αρχείου εξόδου αλλά εξασφαλίζει καλύτερη συμβατότητα κατά την επεξεργασία του παραγόμενου PDF. Ισχύει μόνο κατά τη μετατροπή από έγγραφα WordProcessing.

```csharp
public bool EmbedFullFonts { get; set; }
```
