Ο χώρος ονομάτων παρέχει κλάσεις για τη μετατροπή εγγράφων σε όλες τις δημοφιλείς μορφές αρχείων με απλό και διαισθητικό τρόπο.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ConversionEvents](./conversionevents) | Συγκεντρώνει χειριστές συμβάντων κύκλου ζωής μετατροπής. Περνάτε μια παρουσία στον κατασκευαστή του [`Converter`](../groupdocs.conversion/converter) στη παράμετρο `events` ή στη fluent μέθοδο `WithEvents`. Προτιμήστε αυτό αντί για τις μεμονωμένες ιδιότητες χειριστών του [`ConverterSettings`](../groupdocs.conversion/convertersettings), οι οποίες είναι παρωχημένες. |
| [ConvertContext](./convertcontext) | Ορίζει το πλαίσιο μετατροπής. |
| [ConvertedContext](./convertedcontext) | Ορίζει το πλαίσιο μετατροπής. |
| [ConvertedPageContext](./convertedpagecontext) | Ορίζει το πλαίσιο σελίδας μετατροπής. |
| [Converter](./converter) | Αναπαριστά την κύρια κλάση που ελέγχει τη διαδικασία μετατροπής εγγράφων. |
| [ConverterSettings](./convertersettings) | Ορίζει ρυθμίσεις για την προσαρμογή της συμπεριφοράς του [`Converter`](../groupdocs.conversion/converter). |
| [FluentConverter](./fluentconverter) | Κλάση για ρύθμιση fluent μετατροπής. |
| [License](./license) | Παρέχει μεθόδους για την αδειοδότηση του στοιχείου. Μάθετε περισσότερα για την αδειοδότηση [εδώ](https://purchase.groupdocs.com/faqs/licensing). |
| [LoadContext](./loadcontext) | Ορίζει το πλαίσιο φόρτωσης. |
| [Metered](./metered) | Παρέχει μεθόδους για την εφαρμογή της άδειας [Metered](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SaveContext](./savecontext) | Ορίζει το πλαίσιο αποθήκευσης. |
| [SavePageContext](./savepagecontext) | Ορίζει το πλαίσιο σελίδας αποθήκευσης. |
