### Tiff {#Tiff}
```
public static final ImageFileType Tiff
```


TIFF（Tagged Image File Format）表示用于各种符合此文件格式标准的设备上的光栅图像。它能够在多种色彩空间中描述二值、灰度、调色板颜色和全彩图像数据。
了解更多关于此文件格式的信息，请点击[here](../https://wiki.fileformat.com/image/tiff)。

### Gif {#Gif}

GIF（图形交换格式）是一种高度压缩的图像。对于每张图像，GIF 通常支持每像素最多 8 位，并且整个图像最多可使用 256 种颜色。
了解更多关于此文件格式的信息，请点击[此处](../https://wiki.fileformat.com/image/gif)。
