## PdfConvertOptions.EmbedFullFonts property

设置为 true 时，完整的字体文件会嵌入 PDF，而不是子集。这会增加输出文件大小，但在编辑生成的 PDF 时可确保更好的兼容性。仅在从 WordProcessing 文档转换时适用。

public bool EmbedFullFonts { get; set; }
