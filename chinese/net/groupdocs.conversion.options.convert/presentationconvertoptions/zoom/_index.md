## PresentationConvertOptions.Zoom property

指定缩放级别（百分比）。默认值为 100。默认缩放在 Microsoft Powerpoint 2010 之前受支持。从 Microsoft Powerpoint 2013 开始，默认缩放不再设置到文档，而是似乎使用上一次打开的文档的缩放因子。

public int Zoom { get; set; }
