## PdfRecognitionMode.Textbox field

此模式快速且能够最大程度保留 PDF 文件的原始外观，但生成文档的可编辑性可能受限。原始 PDF 文件中每个视觉上分组的文本块都会转换为生成文档中的文本框。这实现了输出文档与原始 PDF 文件的最大相似度。输出文档外观良好，但它完全由文本框组成，这会使在 Microsoft Word 中进一步编辑文档变得相当困难。这是默认模式。

```csharp
public static readonly PdfRecognitionMode Textbox;
```
