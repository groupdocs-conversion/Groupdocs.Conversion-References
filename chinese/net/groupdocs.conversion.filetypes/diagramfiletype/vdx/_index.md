## DiagramFileType.Vdx field

任何在 Microsoft Visio 中创建的绘图或图表，如果以 XML 格式保存，则使用 .VDX 扩展名。Visio 绘图 XML 文件由 Microsoft 开发的 Visio 软件创建。了解更多关于此文件格式的信息，请点击[此处](https://wiki.fileformat.com/image/vdx)。
