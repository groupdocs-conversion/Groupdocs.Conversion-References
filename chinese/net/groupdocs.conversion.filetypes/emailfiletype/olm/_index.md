## EmailFileType.Olm field

扩展名为 .olm 的文件是适用于 macOS 的 Microsoft Outlook 文件。OLM 文件存储电子邮件、日志、日历数据以及其他类型的应用数据。这些文件类似于 Windows 上 Outlook 使用的 PST 文件。然而，Mac 版 Outlook 创建的 OLM 文件无法在 Windows 版 Outlook 中打开。了解更多关于此文件格式的信息[此处](https://wiki.fileformat.com/email/olm)。
