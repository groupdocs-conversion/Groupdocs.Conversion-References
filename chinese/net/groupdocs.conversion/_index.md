该命名空间提供类，以一种简单直观的方式将文档转换为所有流行的文件格式。

## 类

| 类 | 描述 |
| --- | --- |
| [ConversionEvents](./conversionevents) | 聚合转换生命周期事件处理程序。将实例传递给 [`Converter`](../groupdocs.conversion/converter) 构造函数的 `events` 参数或流式 `WithEvents` 方法。建议使用此方式，而不是已废弃的单独 [`ConverterSettings`](../groupdocs.conversion/convertersettings) 处理程序属性。 |
| [ConvertContext](./convertcontext) | 定义转换上下文。 |
| [ConvertedContext](./convertedcontext) | 定义转换上下文。 |
| [ConvertedPageContext](./convertedpagecontext) | 定义转换页面上下文。 |
| [Converter](./converter) | 表示控制文档转换过程的主类。 |
| [ConverterSettings](./convertersettings) | 定义用于自定义 [`Converter`](../groupdocs.conversion/converter) 行为的设置。 |
| [FluentConverter](./fluentconverter) | 用于流式转换设置的类。 |
| [License](./license) | 提供对组件授权的方法。了解授权的更多信息，请访问[此处](https://purchase.groupdocs.com/faqs/licensing)。 |
| [LoadContext](./loadcontext) | 定义加载上下文。 |
| [Metered](./metered) | 提供应用[计量](https://purchase.groupdocs.com/faqs/licensing/metered)授权的方法。 |
| [SaveContext](./savecontext) | 定义保存上下文。 |
| [SavePageContext](./savepagecontext) | 定义保存页面上下文。 |
