## GmlLoadOptions.SchemaLocation property

以空格分隔的 URI 对列表。每对中的第一个 URI 是命名空间的 URI，第二个 URI 是该命名空间的 XML 架构路径。如果设置为 null，Conversion 将尝试从文档根元素读取 schemaLocation。默认值为 null。
