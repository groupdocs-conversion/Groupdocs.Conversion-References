## GmlLoadOptions.RestoreSchema property

确定是否允许 Conversion 在缺少或无法加载 XML Schema 的 Gml 文件中解析属性。如果设置为 true，Conversion 读取器不需要 XML Schema 的存在。默认值为 false。

public bool RestoreSchema { get; set; }
