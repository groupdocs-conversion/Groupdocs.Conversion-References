## IPagedConvertOptions class

表示通过指定起始页和页数来限制页面的转换选项。

IPagedConvertOptions 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | 输入文档应转换为的目标文件类型。 |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | 开始转换的页码。 |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | 从 `PageNumber` 开始要转换的页数。 |
