## MarkdownImageSavingArgs class

MarkdownImageSavingArgs 类型公开以下成员：

| 属性 | 描述 |
| :- | :- |
| [image_file_name](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_file_name/) | 文件名（或占位符 id），嵌入为 Markdown 输出中的图像 URI。分配以重写 URI。 |
| [image_stream](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_stream/) | 转换器将在此回调返回后写入图像字节的目标流。 |
| [keep_image_stream_open](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/keep_image_stream_open/) | 该属性决定转换后转换器是否保持图像流打开。 |
