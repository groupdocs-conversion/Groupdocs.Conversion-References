## IResourceLoadingOptions class

表示一组用于控制外部资源加载方式的选项。

IResourceLoadingOptions 类型公开以下成员：

### 属性
| 属性 | 描述 |
| :- | :- |
| [skip_external_resources](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/skip_external_resources/) | 该属性指示是否加载外部资源。 |
| [whitelisted_resources](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/) | 始终会被加载的外部资源。 |
