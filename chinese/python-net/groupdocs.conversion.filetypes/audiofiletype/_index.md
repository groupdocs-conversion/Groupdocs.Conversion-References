## AudioFileType class

定义音频文档。

包括以下类型：
- [`AudioFileType.mp3`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/mp3/)
- [`AudioFileType.aac`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/aac/)
- [`AudioFileType.aiff`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/aiff/)
- [`AudioFileType.flac`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/flac/)
- [`AudioFileType.m4a`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/m4a/)
- [`AudioFileType.wma`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/wma/)
- [`AudioFileType.ac3`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/ac3/)
- [`AudioFileType.ogg`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/ogg/)
- [`AudioFileType.wav`](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/wav/)

了解更多关于音频格式的信息 https://docs.fileformat.com/audio/。

### 字段
| 字段 | 描述 |
| :- | :- |
| [MP3](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/mp3/) | .mp3 扩展名的文件是基于 MPEG-1 音频层 III 或 MPEG-2 音频层 III 的数字编码音频文件格式。了解此文件格式的更多信息，请点击此处。 |
| [AAC](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/aac/) | AAC（Advanced Audio Coding，高级音频编码）是指基于有损音频压缩的数字音频编码标准，用于表示音频文件。了解此文件格式的更多信息，请点击此处。 |
| [AIFF](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/aiff/) | AIFF（Audio Interchange File Format，音频互换文件格式）是一种由 Apple 于 1998 年开发的无压缩音频文件格式，但基于 EA IFF 85。了解此文件格式的更多信息，请点击此处。 |
| [FLAC](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/flac/) | FLAC（Free Lossless Audio Codec，免费无损音频编解码器）是一种由 Xiph.Org Foundation 开发的无损压缩音频编码格式。了解此文件格式的更多信息，请点击此处。 |
| [M4A](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/m4a/) | M4A 文件格式是一种使用 AAC（Advanced Audio Coding，高级音频编码）创建的音频文件，属于有损压缩。了解此文件格式的更多信息，请点击此处。 |
| [WMA](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/wma/) | .wma 扩展名的文件表示以高级系统格式（ASF）保存的音频文件。了解此文件格式的更多信息，请点击此处。 |
| [AC3](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/ac3/) | .ac3 扩展名的文件是 Dolby Laboratories 推出的 Audio Codec 3 文件。这是一种可包含多达六个声道的音频格式。了解此文件格式的更多信息，请点击此处。 |
| [OGG](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/ogg/) | OGG 是一种以 .ogg 扩展名保存的 Ogg Vorbis 压缩音频文件。OGG 文件用于存储音频数据，并且可以包含艺术家、曲目信息以及元数据。了解此文件格式的更多信息，请点击此处。 |
| [WAV](/conversion/python-net/groupdocs.conversion.filetypes/audiofiletype/wav/) | WAV（即 WAVE，Waveform Audio File Format，波形音频文件格式）是 Microsoft 资源互换文件格式（RIFF）规范的一个子集，用于存储数字音频文件。了解此文件格式的更多信息，请点击此处。 |
| [UNKNOWN](/conversion/python-net/groupdocs.conversion.filetypes/filetype/unknown/) | 未知文件类型（继承自 [`FileType`](/conversion/python-net/groupdocs.conversion.filetypes/filetype/)） |
