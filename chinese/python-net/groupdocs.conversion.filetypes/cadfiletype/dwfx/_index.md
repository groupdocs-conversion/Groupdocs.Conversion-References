## DWFX field

DWFX 文件是使用 Autodesk CAD 软件创建的 2D 或 3D 图纸。它以 DWFx 格式保存，该格式类似于 DWF 文件，但采用 Microsoft 的 XML Paper Specification（XPS）进行格式化。
