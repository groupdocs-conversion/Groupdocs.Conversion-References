## MPX field

Microsoft Exchange 文件格式是一种 ASCII 文件格式，用于在 Microsoft Project（MSP）与支持 MPX 文件格式的其他应用程序（如 Primavera Project Planner、Sciforma 和 Timerline Precision Estimating）之间传输项目信息。了解此文件格式的更多信息请访问此处。
