| [ASE](/conversion/python-net/groupdocs.conversion.filetypes/threedfiletype/ase/) | .ase 扩展名的文件是 Autodesk ASCII 场景导出文件格式，它是场景的 ASCII 表示，包含使用 Autodesk 导出时的 2D 或 3D 信息。了解更多关于此文件格式的信息。 |

| [GLTF](/conversion/python-net/groupdocs.conversion.filetypes/threedfiletype/gltf/) | glTF（GL Transmission Format）是一种将 3D 模型信息存储为 JSON 格式的 3D 文件格式。使用 JSON 可同时减小 3D 资产的体积并降低运行时解包和使用这些资产的处理开销。了解更多关于此文件格式的信息。 |
