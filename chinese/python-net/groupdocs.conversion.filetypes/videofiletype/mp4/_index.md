## MP4 field

MP4（全称 MPEG-4 Part 14）是一种基于 ISO/IEC 14496-12:2004 的文件格式，源自 QuickTime File Format，但正式规定了对 Initial Object Descriptors（IOD）及其他 MPEG 特性的支持。了解更多关于此文件格式的信息。
