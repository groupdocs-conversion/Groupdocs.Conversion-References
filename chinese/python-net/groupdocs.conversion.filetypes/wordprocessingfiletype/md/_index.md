## MD field

使用 Markdown 语言方言创建的文本文件保存为 .MD 或 .MARKDOWN 扩展名。MD 文件以纯文本格式保存，使用 Markdown 语言，其中还包括内联文本符号，定义文本的格式方式，如缩进、表格格式、字体和标题。了解更多关于此文件格式的信息，请点击此处。
