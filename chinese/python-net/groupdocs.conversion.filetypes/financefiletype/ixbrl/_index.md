## IXBRL field

在 iXBRL 中，XBRL 的内容被包装在使用 XML 标签的 xHTML 文件格式中。与 XBRL 类似，xHTML 是 iXBRL 文件的根元素。XHTML 格式将其内容表示为不同文档类型和模块的集合。所有 XHTML 文件均基于 XML 文件格式，并符合 XML 文档标准。了解更多关于此文件格式的信息，请点击此处。
