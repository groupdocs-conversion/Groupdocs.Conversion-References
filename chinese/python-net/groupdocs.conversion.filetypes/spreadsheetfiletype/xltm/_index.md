## XLTM field

XLTM 文件扩展名表示由 Microsoft Excel 生成的宏启用模板文件。XLTM 文件在结构上类似于 XLTX，但后者不支持创建带宏的模板文件。了解更多关于此文件格式的信息，请点击此处。
