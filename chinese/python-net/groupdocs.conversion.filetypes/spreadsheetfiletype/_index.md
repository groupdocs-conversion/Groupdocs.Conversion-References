| [XLSB](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlsb/) | XLSB 文件格式指定了 Excel 二进制文件格式，它是一组记录和结构，用于定义 Excel 工作簿的内容。了解更多关于此文件格式的信息，请点击此处。 |
| [ODS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/ods/) | 带有 ODS 扩展名的文件代表 OpenDocument 电子表格文档格式，用户可以编辑。数据以行列的形式存储在 ODF 文件中。了解更多关于此文件格式的信息，请点击此处。 |
| [OTS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/ots/) | 带有 .ots 扩展名的文件是使用 Apache OpenOffice 中包含的 Calc 应用软件创建的 OpenDocument 电子表格模板文件。Calc 应用软件类似于 Microsoft Office 中的 Excel。了解更多关于此文件格式的信息，请点击此处。 |

| [XLT](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlt/) | 带有 .XLT 扩展名的文件是使用 Microsoft Excel 创建的模板文件，Excel 是 Microsoft Office 套件的一部分。Microsoft Office 97-2003 支持创建和打开新的 XLT 文件。了解更多关于此文件格式的信息，请点击此处。 |
| [XLTM](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xltm/) | XLTM 文件扩展名表示由 Microsoft Excel 生成的宏启用模板文件。XLTM 文件在结构上类似于 XLTX，但后者不支持创建带宏的模板文件。了解更多关于此文件格式的信息，请点击此处。 |
| [TSV](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/tsv/) | 制表符分隔值（TSV）文件格式表示以制表符分隔的纯文本数据。了解更多关于此文件格式的信息，请点击此处。 |
| [XLAM](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlam/) | XLAM 是一种宏启用的加载项文件，用于向电子表格添加新功能。加载项是运行额外代码并为电子表格提供附加功能的补充程序。了解更多关于此文件格式的信息，请点击此处。 |
| [CSV](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/csv/) | 带有 CSV（逗号分隔值）扩展名的文件是包含以逗号分隔的数据记录的纯文本文件。了解更多关于此文件格式的信息，请点击此处。 |
| [FODS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/fods/) | 带有 .fods 扩展名的文件是一种 OpenDocument 电子表格文档格式，以行列方式存储数据。该格式是 OASIS 发布并维护的 ODF 1.2 规范的一部分。了解更多关于此文件格式的信息，请点击此处。 |
| [DIF](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/dif/) | DIF 代表数据交换格式，用于在不同应用程序之间导入/导出电子表格数据。这些应用包括 Microsoft Excel、OpenOffice Calc、StarCalc 等众多软件。了解更多关于此文件格式的信息，请点击此处。 |
| [SXC](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/sxc/) | SXC（Sun XML Calc）文件格式属于名为 OpenOffice.org 的办公套件。该格式基于 XML，满足用户的电子表格需求。SXC 格式支持公式、函数、宏、图表以及 DataPilot。了解更多关于此文件格式的信息，请点击此处。 |
| [NUMBERS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/numbers/) | 带有 .numbers 扩展名的文件被归类为电子表格文件类型，因此它们类似于 .xlsx 文件；但 Numbers 文件是使用 Apple iWork Numbers 电子表格软件创建的。了解更多关于此文件格式的信息，请点击此处。 |
