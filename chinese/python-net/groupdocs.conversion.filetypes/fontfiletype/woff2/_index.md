## WOFF2 field

.woff 扩展名的文件是基于 Web Open Font Format（WOFF）的网络字体文件。它使用基于 TrueType（.TTF）或 OpenType（.OTT）字体类型的特定格式压缩容器。了解更多关于此文件格式的信息，请访问此处。
