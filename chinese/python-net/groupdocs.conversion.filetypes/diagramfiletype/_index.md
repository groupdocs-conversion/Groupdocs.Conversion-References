### 字段
| 字段 | 描述 |
| :- | :- |
| [VSD](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vsd/) | VSD 文件是使用 Microsoft Visio 应用程序创建的绘图，用于表示各种图形对象及其相互连接。了解更多关于此文件格式的信息。 |
| [VSDX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vsdx/) | .VSDX 扩展名的文件代表自 Microsoft Office 2013 起引入的 Microsoft Visio 文件格式。它用于取代早期版本 Microsoft Visio 支持的二进制文件格式 .VSD。了解更多关于此文件格式的信息。 |
| [VSS](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vss/) | VSS 是在 Microsoft Visio 2007 及更早版本中创建的模板文件。模板文件提供可包含在 .VSD Visio 绘图中的绘图对象。了解更多关于此文件格式的信息。 |
| [VST](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vst/) | VST 扩展名的文件是使用 Microsoft Visio 创建的矢量图像文件，充当进一步创建文件的模板。这些模板文件采用二进制文件格式，包含用于创建新 Visio 绘图的默认布局和设置。了解更多关于此文件格式的信息。 |
| [VSX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vsx/) | .VSX 扩展名的文件指的是用于在 Microsoft Visio 中创建图表的模板，包含绘图和形状。VSX 文件以 XML 文件格式保存，并在 Visio 2013 之前受支持。了解更多关于此文件格式的信息。 |
| [VTX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vtx/) | VTX 扩展名的文件是以 XML 文件格式保存到磁盘的 Microsoft Visio 绘图模板。该模板旨在提供带有基本设置的文件，可用于创建多个具有相同设置的 Visio 文件。了解更多关于此文件格式的信息。 |
| [VDW](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vdw/) | VDW 是 Visio Graphics Service 文件格式，指定渲染 Web 绘图所需的流和存储。了解更多关于此文件格式的信息。 |
| [VDX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vdx/) | 任何在 Microsoft Visio 中创建但以 XML 格式保存的绘图或图表都具有 .VDX 扩展名。Visio 绘图 XML 文件是在 Microsoft 开发的 Visio 软件中创建的。了解更多关于此文件格式的信息。 |
| [VSSX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vssx/) | .VSSX 扩展名的文件是使用 Microsoft Visio 2013 及以上版本创建的绘图模板。VSSX 文件格式可在 Visio 2013 及以上版本中打开。Visio 文件以表示各种绘图元素而闻名，如形状集合、连接线、流程图、网络布局、UML 图等。了解更多关于此文件格式的信息。 |
| [VSTX](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vstx/) | VSTX 扩展名的文件是使用 Microsoft Visio 2013 及以上版本创建的绘图模板文件。这些 VSTX 文件提供创建 Visio 绘图（保存为 .VSDX 文件）的起始点，包含默认布局和设置。了解更多关于此文件格式的信息。 |
| [VSDM](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vsdm/) | VSDM 扩展名的文件是由支持宏的 Microsoft Visio 应用程序创建的绘图文件。VSDM 文件是类似于 VSDX 的 OPC/XML 绘图，但还提供在打开文件时运行宏的功能。了解更多关于此文件格式的信息。 |
| [VSSM](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vssm/) | .VSSM 扩展名的文件是支持宏的 Microsoft Visio 模板文件。打开 VSSM 文件时，可运行宏以实现图表中形状的所需格式化和放置。了解更多关于此文件格式的信息。 |
| [VSTM](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/vstm/) | VSTM 扩展名的文件是由支持宏的 Microsoft Visio 创建的模板文件。与 VSDX 文件不同，基于 VSTM 模板创建的文件可以运行使用 Visual Basic for Applications (VBA) 代码开发的宏。了解更多关于此文件格式的信息。 |
| [DRAWIO](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/drawio/) | DRAWIO 扩展名的文件是使用 diagrams.net（前身为 draw.io）创建的图表。它以包含 mxfile 根元素的 XML 文件格式存储，保存图表元素的内容和格式，如文本、图像、布局、形状和定位。了解更多关于此文件格式的信息。 |
| [MMD](/conversion/python-net/groupdocs.conversion.filetypes/diagramfiletype/mmd/) | MMD 扩展名的文件是使用 Mermaid 标记语言编写的图表。它以纯文本文档形式存储，文档以图表声明（如 flowchart 或 sequenceDiagram）开头，随后是节点及其之间连接的定义。了解更多关于此文件格式的信息。 |
| [UNKNOWN](/conversion/python-net/groupdocs.conversion.filetypes/filetype/unknown/) | 未知文件类型（继承自 [`FileType`](/conversion/python-net/groupdocs.conversion.filetypes/filetype/)） |
