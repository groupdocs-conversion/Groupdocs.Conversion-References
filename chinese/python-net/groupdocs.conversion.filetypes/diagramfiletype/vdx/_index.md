## VDX field

任何在 Microsoft Visio 中创建但以 XML 格式保存的绘图或图表都具有 .VDX 扩展名。Visio 绘图 XML 文件是在 Microsoft 开发的 Visio 软件中创建的。了解更多关于此文件格式的信息。
