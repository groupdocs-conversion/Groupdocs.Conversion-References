## GEO_JSON field

GeoJSON 是一种基于 JSON 的格式，旨在表示带有非空间属性的地理特征。该格式定义了不同的 JSON（JavaScript Object Notation）对象及其关联方式。JSON 格式呈现关于地理特征、其空间范围和属性的综合信息。了解此文件格式的更多信息，请点击此处。
