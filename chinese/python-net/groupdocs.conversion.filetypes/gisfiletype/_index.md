### 字段
| 字段 | 描述 |
| :- | :- |
| [SHP](/conversion/python-net/groupdocs.conversion.filetypes/gisfiletype/shp/) | SHP 是用于表示 ESRI Shapefile 的主要文件类型之一的文件扩展名。它以矢量数据的形式表示地理空间信息，可供地理信息系统（GIS）应用程序使用。了解此文件格式的更多信息，请点击此处。 |
| [GEO_JSON](/conversion/python-net/groupdocs.conversion.filetypes/gisfiletype/geo_json/) | GeoJSON 是一种基于 JSON 的格式，旨在表示带有非空间属性的地理特征。该格式定义了不同的 JSON（JavaScript Object Notation）对象及其关联方式。JSON 格式呈现关于地理特征、其空间范围和属性的综合信息。了解此文件格式的更多信息，请点击此处。 |
| [GDB](/conversion/python-net/groupdocs.conversion.filetypes/gisfiletype/gdb/) | ESRI 文件地理数据库（FileGDB）是一组位于磁盘文件夹中的文件，存储相关的地理空间数据，如要素数据集、要素类和关联表。它需要将某些其他文件与 .gdb 文件一起保存在同一目录中才能正常工作。了解此文件格式的更多信息，请点击此处。 |
| [GML](/conversion/python-net/groupdocs.conversion.filetypes/gisfiletype/gml/) | GML 代表地理标记语言（Geography Markup Language），基于开放地理空间联盟（OGC）制定的 XML 规范。该格式用于存储地理数据特征，以便在不同文件格式之间进行交换。它既是地理系统的建模语言，也是互联网上地理事务的开放交换格式。了解更多关于此文件格式的信息。 |
| [KML](/conversion/python-net/groupdocs.conversion.filetypes/gisfiletype/kml/) | KML（Keyhole 标记语言）包含以 XML 形式表示的地理空间信息。以 KML 保存的文件可以在支持的地理信息系统（GIS）应用程序中打开。许多应用在 KML 被采纳为国际标准后开始提供对 KML 文件格式的支持。KML 使用基于标签的结构，包含嵌套元素和属性。了解更多关于此文件格式的信息。 |
| [GPX](/conversion/python-net/groupdocs.conversion.filetypes/gisfiletype/gpx/) | 带有 GPX 扩展名的文件表示 GPS 交换格式，用于在互联网上的应用程序和 Web 服务之间交换 GPS 数据。它是一种轻量级的 XML 文件格式，包含 GPS 数据，即航点、路线和轨迹，可被多个程序导入和读取。了解更多关于此文件格式的信息。 |
| [TOPO_JSON](/conversion/python-net/groupdocs.conversion.filetypes/gisfiletype/topo_json/) | TopoJSON 是 GeoJSON 的扩展，能够对拓扑进行编码。与离散表示几何形状不同，TopoJSON 文件中的几何形状是由称为弧的共享线段拼接而成的。 |
| [OSM](/conversion/python-net/groupdocs.conversion.filetypes/gisfiletype/osm/) | OSM 文件格式是一种结构化数据格式，用于在 OpenStreetMap 项目中存储地理数据。OSM 文件通常为 XML 格式，包含道路、建筑物、兴趣点以及地图上其他要素的位置等信息。了解更多关于此文件格式的信息。 |
| [UNKNOWN](/conversion/python-net/groupdocs.conversion.filetypes/filetype/unknown/) | 未知文件类型（继承自 [`FileType`](/conversion/python-net/groupdocs.conversion.filetypes/filetype/)） |
