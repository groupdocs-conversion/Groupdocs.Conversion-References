## PPTX field

PPTX 扩展名的文件是使用流行的 Microsoft PowerPoint 应用程序创建的演示文件。不同于二进制的 PPT 旧版演示文件格式，PPTX 格式基于 Microsoft PowerPoint 开放 XML 演示文件格式。了解更多关于此文件格式的信息，请访问此处。
