## SpreadsheetLoadOptions.AllColumnsInOnePagePerSheet property

AllColumnsInOnePagePerSheet가 true이면, 하나의 시트에 있는 모든 열 내용이 결과에서 한 페이지에만 출력됩니다. 페이지 설정의 용지 크기 너비는 무효화되지만, 페이지 설정의 다른 항목은 여전히 적용됩니다.
