## CadLoadOptions.LayoutScope property

변환되는 도면 공간을 가져오거나 설정합니다. 기본값은 [`Both`](../../cadlayoutscope/both)이며, 변환을 제한하지 않습니다. [`LayoutNames`](../layoutnames)이 제공되면 무시됩니다. 이는 명시적인 레이아웃 이름이 항상 우선하기 때문입니다. `null` 값은 [`Both`](../../cadlayoutscope/both)으로 처리됩니다.

```csharp
public CadLayoutScope LayoutScope { get; set; }
```

### 비고

도면이 제공하는 시트 중 어느 것도 선택하지 않는 범위는 변환을 실패시키며, 범위와 해당 시트를 명시하는 [`InvalidLoadOptionsException`](../../../groupdocs.conversion.exceptions/invalidloadoptionsexception)을 발생시킵니다. 이는 범위가 제외한 공간을 렌더링하는 대신입니다. 시트를 전혀 제공하지 않는 도면은 영향을 받지 않으며 여전히 단일 단위로 변환됩니다. PDF/UA-1 로 변환할 때는 적용되지 않으며, 이는 [`LayoutNames`](../layoutnames)에서 제시된 이유와 같습니다.
