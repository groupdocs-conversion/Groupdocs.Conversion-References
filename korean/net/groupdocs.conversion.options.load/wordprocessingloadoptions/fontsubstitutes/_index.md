## WordProcessingLoadOptions.FontSubstitutes property

WordsProcessing 문서를 변환할 때 특정 글꼴을 대체합니다.

```csharp
public IList<FontSubstitute> FontSubstitutes { get; set; }
```

### 비고

**Note:** The order of substitution is as follows:

1) 폰트 이름을 기준으로 누락된 폰트를 자동으로 대체합니다 (활성화된 경우).

2) FontConfig을 기준으로 누락된 폰트를 자동으로 대체합니다 (활성화된 경우).

3) FontSubstitutes를 기준으로 누락된 폰트를 대체합니다 (설정된 경우).

4) FontInfo를 기준으로 누락된 폰트를 자동으로 대체합니다 (활성화된 경우).

5) DefaultFont을 기준으로 누락된 폰트를 대체합니다 (설정된 경우).
