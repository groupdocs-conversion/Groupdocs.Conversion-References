## GmlLoadOptions.SchemaLocation property

URI 쌍의 공백으로 구분된 목록입니다. 각 쌍의 첫 번째 URI는 네임스페이스의 URI이며, 두 번째 URI는 네임스페이스의 XML 스키마 경로입니다. null로 설정하면 Conversion은 문서 루트 요소에서 schemaLocation을 읽으려고 시도합니다. 기본값은 null입니다.

public string SchemaLocation { get; set; }
