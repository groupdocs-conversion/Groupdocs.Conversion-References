## ConversionEvents.OnFontSubstituted property

소스 문서에서 참조된 글꼴이 없을 때 발생하며, (고객이 제공한 [`FontSubstitute`](../../../groupdocs.conversion.contracts/fontsubstitute) 규칙, 구성된 기본 글꼴, 또는 변환 파이프라인의 내부 대체 중 하나에 의해) 대체됩니다.

```csharp
public Action<FontSubstitutionContext> OnFontSubstituted { get; set; }
```

### 비고

`Converter.Convert(...)` 호출 하나 내에서 `(SourceFileName, OriginalFontName)` 별로 이벤트가 중복 제거됩니다 — 구독자는 소스 문서당 누락된 글꼴당 최대 한 번의 알림을 받습니다. 변환 스레드에서 동기식으로 발생합니다. 이미지 변환에서는 발생하지 않습니다.

프레젠테이션 문서의 경우, 글꼴 대체는 Windows에서만 감지됩니다. 이는 엔진이 다른 운영 체제에서는 사용할 수 없는 플랫폼별 글꼴 매칭을 통해 해결하기 때문입니다.
