## WebConvertOptions.SlideShow property

프레젠테이션을 [`Html`](../../../groupdocs.conversion.filetypes/webfiletype/html) 또는 [`Htm`](../../../groupdocs.conversion.filetypes/webfiletype/htm) 로 변환할 때만 적용되며, 다른 모든 변환에서는 무시됩니다. 프레젠테이션을 기본 정적 HTML 페이지 대신 슬라이드 전환 및 도형 애니메이션이 포함된 인터랙티브 HTML 슬라이드쇼로 만들지 여부를 지정합니다. 기본값은 false입니다.

```csharp
public bool SlideShow { get; set; }
```

### 비고

결과는 스타일, 스크립트, 이미지, 글꼴 및 미디어가 인라인된 단일 HTML 파일입니다. 슬라이드쇼를 구동하는 두 개의 JavaScript 라이브러리는 CDN에서 로드되므로 페이지가 애니메이션 및 탐색을 수행하려면 인터넷 연결이 필요합니다.
