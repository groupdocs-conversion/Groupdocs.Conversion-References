## ImageConvertOptions.CapResolutionToPageContent property

설정된 경우, 페이지당 PDF 렌더 해상도를 페이지 고유 래스터 해상도로 제한하여 페이지가 포함된 이미지보다 높은 DPI로 렌더링되지 않으며, 요청된 DPI로 다시 확대하는 대신 해당 페이지를 고유(작은) 픽셀 크기와 고유 DPI로 최종 출력에 포함합니다. 이미지 중심(스캔) 페이지에만 적용되며, 텍스트나 벡터 콘텐츠가 있는 페이지는 절대 소프트되지 않고 요청된 DPI로 출력됩니다. 명시적인 출력 [`Width`](../width) 또는 [`Height`](../height)이 설정된 경우 건너뜁니다. 기본값은 `false` (제한 없음; 모든 페이지가 요청된 DPI로 렌더링되고 출력됩니다).

public bool CapResolutionToPageContent { get; set; }
