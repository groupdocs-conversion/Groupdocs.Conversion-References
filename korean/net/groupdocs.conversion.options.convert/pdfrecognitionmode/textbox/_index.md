## PdfRecognitionMode.Textbox field

이 모드는 빠르고 PDF 파일의 원본 모양을 최대한 보존하는 데 적합하지만, 결과 문서의 편집 가능성이 제한될 수 있습니다. 원본 PDF 파일에서 시각적으로 그룹화된 텍스트 블록마다 결과 문서의 텍스트 상자로 변환됩니다. 이는 출력 문서가 원본 PDF 파일과 최대한 유사하도록 합니다. 출력 문서는 보기 좋지만 텍스트 상자로만 구성되어 Microsoft Word에서 문서를 추가로 편집하기가 매우 어려울 수 있습니다. 이것이 기본 모드입니다.

```csharp
public static readonly PdfRecognitionMode Textbox;
```
