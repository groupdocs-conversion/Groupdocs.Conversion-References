## ImageFileType.Tif field

TIF, Tagged Image File Format은 다양한 장치에서 사용하도록 설계된 래스터 이미지를 나타냅니다. 이 형식은 이진, 그레이스케일, 팔레트 색상 및 풀 컬러 이미지 데이터를 여러 색 공간에서 설명할 수 있습니다. 이 파일 형식에 대해 자세히 알아보려면 [here](https://wiki.fileformat.com/image/tiff).
