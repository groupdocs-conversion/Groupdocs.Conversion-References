## CompressionFileType.Wim field

.wim 확장자를 가진 파일은 Windows Imaging Format 아카이브로, Microsoft가 Windows 배포에 사용하는 파일 기반 디스크 이미지입니다. 하나의 아카이브에 하나 이상의 이미지가 포함되며, 각 파일은 이미지가 몇 개이든 한 번만 저장됩니다. 이 파일 형식에 대해 자세히 알아보려면 [여기](https://docs.fileformat.com/disc-and-media/wim/)를 클릭하십시오.
