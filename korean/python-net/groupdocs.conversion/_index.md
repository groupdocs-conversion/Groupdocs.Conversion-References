최상위 API 클래스를 포함하는 주요 GroupDocs.Conversion 네임스페이스.

| 클래스 | 설명 |
| :- | :- |
| [`ConversionEvents`](/conversion/python-net/groupdocs.conversion/conversionevents/) | 변환 수명 주기 이벤트 핸들러를 집계합니다. |
| [`ConvertContext`](/conversion/python-net/groupdocs.conversion/convertcontext/) | 변환 컨텍스트를 나타냅니다. |
| [`ConvertedContext`](/conversion/python-net/groupdocs.conversion/convertedcontext/) | 변환 컨텍스트를 정의합니다. |
| [`ConvertedPageContext`](/conversion/python-net/groupdocs.conversion/convertedpagecontext/) | 변환 페이지 컨텍스트를 정의합니다. |
| [`Converter`](/conversion/python-net/groupdocs.conversion/converter/) | 문서 변환 프로세스를 제어하는 주요 클래스를 나타냅니다. |
| [`ConverterSettings`](/conversion/python-net/groupdocs.conversion/convertersettings/) | Converter 동작을 사용자 정의하기 위한 설정을 정의합니다. |
| [`FluentConverter`](/conversion/python-net/groupdocs.conversion/fluentconverter/) | 유창한 변환 설정을 나타냅니다. |
| [`License`](/conversion/python-net/groupdocs.conversion/license/) | GroupDocs.Conversion 라이선스를 관리합니다. |

| [`Metered`](/conversion/python-net/groupdocs.conversion/metered/) | 계량(사용량 기반) 라이선스를 관리합니다. |
| [`SaveContext`](/conversion/python-net/groupdocs.conversion/savecontext/) | 저장 컨텍스트를 나타냅니다. |
| [`SavePageContext`](/conversion/python-net/groupdocs.conversion/savepagecontext/) | 저장 페이지 컨텍스트를 정의합니다. |
