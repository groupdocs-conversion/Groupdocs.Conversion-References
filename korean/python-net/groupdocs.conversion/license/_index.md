## License class

GroupDocs.Conversion 라이선스를 관리합니다.

라이선스가 적용된 빌드는 래퍼의 전체 기능 세트를 잠금 해제합니다.
런타임에서. 라이선스가 없는 빌드는 동일한 API로 평가 모드에서 실행됩니다.
표면이 동일하지만 출력 크기와 워터마크가 있는 콘텐츠에 제한이 있습니다.

License 유형은 다음 멤버를 노출합니다:

### 메서드
| 메서드 | 설명 |
| :- | :- |
| [set_license](/conversion/python-net/groupdocs.conversion/license/set_license/#license_source) | 현재 프로세스에 라이선스를 적용합니다. |
