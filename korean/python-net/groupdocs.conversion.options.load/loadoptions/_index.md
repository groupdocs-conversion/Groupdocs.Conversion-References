## LoadOptions class

추상 문서 로드 옵션을 나타냅니다.

LoadOptions 클래스는 로드할 문서 유형을 지정하고 `password`와 같은 선택적 매개변수를 포함합니다. 이들은 두 그룹으로 구분됩니다: 형식 패밀리 옵션과 특정 파일 유형 옵션.
