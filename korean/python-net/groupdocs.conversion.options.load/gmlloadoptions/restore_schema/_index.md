## restore_schema property

이 속성은 XML 스키마가 없거나 로드할 수 없을 때 GML 파일의 속성을 구문 분석하도록 변환이 허용되는지 여부를 결정합니다.

True로 설정하면, 변환 리더는 XML 스키마가 존재할 필요가 없습니다. 기본값은 False입니다.
