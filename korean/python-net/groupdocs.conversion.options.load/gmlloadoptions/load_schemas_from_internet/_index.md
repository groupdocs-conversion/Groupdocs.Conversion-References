## load_schemas_from_internet property

이 속성은 변환이 인터넷에서 XML 스키마를 로드하도록 허용되는지 여부를 결정합니다.

False로 설정하면, 'file://'로 시작하지 않는 절대 URI를 가진 스키마는 로드되지 않습니다. 기본값은 False입니다.
