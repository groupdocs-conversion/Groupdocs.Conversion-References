## embed_full_fonts property

이 속성은 전체 글꼴 파일을 부분 집합 대신 PDF에 포함시킬지 여부를 결정합니다.

True로 설정하면 출력 파일 크기가 증가하지만 결과 PDF를 편집할 때 호환성이 향상됩니다. WordProcessing 문서에서 변환할 때만 적용됩니다.
