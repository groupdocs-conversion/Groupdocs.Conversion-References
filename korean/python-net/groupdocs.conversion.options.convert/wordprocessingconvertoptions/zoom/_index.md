## zoom property

백분율로 표시된 확대 수준입니다.

기본값은 100입니다. 기본 확대/축소는 Microsoft Word 2010까지 지원됩니다. Microsoft Word 2013부터는 기본 확대/축소가 문서에 설정되지 않으며, 대신 마지막으로 열린 문서의 확대/축소 비율을 사용하는 것으로 보입니다.
