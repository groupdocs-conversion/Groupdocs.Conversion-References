## PNG field

PNG(Portable Network Graphics)는 무손실 압축을 사용하는 래스터 이미지 파일 형식입니다. 이 파일 형식은 Graphics Interchange Format(GIF)을 대체하기 위해 만들어졌으며 저작권 제한이 없습니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
