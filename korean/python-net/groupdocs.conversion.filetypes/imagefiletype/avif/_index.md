## AVIF field

AVIF(AV1 Image File Format)는 AV1로 압축된 이미지를 HEIF 파일 형식에 저장하는 이미지 파일 형식입니다. AVIF 파일은 .avif 확장자로 저장됩니다. AVIF 버전 1은 2019년 2월에 최종 확정되었습니다. HDR(High Dynamic Range), 8, 10, 12 비트 색 깊이 지원, ISO/IEC CICP 및 ICC 프로파일, 와이드 컬러 gamut 등 다양한 색 공간을 지원하는 기능을 갖추고 있습니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
