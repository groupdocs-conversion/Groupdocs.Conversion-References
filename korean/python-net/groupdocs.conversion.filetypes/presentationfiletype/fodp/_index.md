## FODP field

FODP 확장자를 가진 파일은 OpenDocument Flat XML 프레젠테이션을 나타냅니다. 프레젠테이션 파일은 OpenDocument 형식으로 저장되지만, 표준 .ODP 파일에서 사용되는 .ZIP 컨테이너 대신 플랫 XML 형식으로 저장됩니다.
