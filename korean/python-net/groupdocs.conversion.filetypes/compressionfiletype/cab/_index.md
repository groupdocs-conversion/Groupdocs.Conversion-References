## CAB field

.cab 확장자를 가진 파일은 시스템 파일 범주에 속하는 Windows 캐비닛 파일입니다. LZX, Quantum, ZIP과 같은 압축 데이터 알고리즘을 지원하는 Microsoft Windows 버전에서 아카이브 파일 형식으로 저장됩니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
