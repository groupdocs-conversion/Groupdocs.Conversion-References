## VTX field

VTX 확장자를 가진 파일은 XML 파일 형식으로 디스크에 저장된 Microsoft Visio 도면 템플릿입니다. 이 템플릿은 동일한 설정을 가진 여러 Visio 파일을 만들 때 사용할 수 있는 기본 설정을 제공하도록 설계되었습니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
