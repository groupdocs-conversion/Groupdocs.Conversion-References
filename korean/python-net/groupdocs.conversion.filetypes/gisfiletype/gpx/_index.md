## GPX field

GPX 확장자를 가진 파일은 인터넷상의 애플리케이션 및 웹 서비스 간에 GPS 데이터를 교환하기 위한 GPS Exchange 형식을 나타냅니다. 이는 경량 XML 파일 형식으로, 웨이포인트, 경로 및 트랙과 같은 GPS 데이터를 포함하며 여러 프로그램에서 가져오고 읽을 수 있습니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하십시오.
