## GEO_JSON field

GeoJSON은 비공간 속성을 가진 지리적 특징을 표현하도록 설계된 JSON 기반 형식입니다. 이 형식은 다양한 JSON(JavaScript Object Notation) 객체와 그 결합 방식을 정의합니다. JSON 형식은 지리적 특징, 그 공간 범위 및 속성에 대한 종합 정보를 나타냅니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
