## DWF field

Design Web Format(DWF)은 디자인 파일을 보기, 검토 또는 인쇄하기 위해 압축된 형식으로 2D/3D 도면을 나타냅니다. 디자인 데이터의 일부로 그래픽과 텍스트를 포함하며, 압축 형식 덕분에 파일 크기를 줄입니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
