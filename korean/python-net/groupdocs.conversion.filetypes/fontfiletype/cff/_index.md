## CFF field

.cff 확장자를 가진 파일은 Compact Font Format이며 PostScript Type 1 또는 CIDFont이라고도 합니다. CFF는 여러 폰트를 하나의 FontSet이라는 단위에 함께 저장하는 컨테이너 역할을 합니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
