## MHTML field

MHTML 확장자를 가진 파일은 다양한 애플리케이션에서 생성할 수 있는 웹 페이지 아카이브 형식을 나타냅니다. 이 형식은 웹 HTML 코드와 관련 리소스를 하나의 파일에 저장하기 때문에 아카이브 형식으로 알려져 있습니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
