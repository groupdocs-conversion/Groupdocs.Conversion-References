## CHM field

CHM 파일 형식은 HTML 페이지 모음으로 구성된 Microsoft HTML 도움말 파일을 나타냅니다. 이는 주제에 빠르게 접근하고 도움말 문서의 다양한 부분으로 이동할 수 있는 인덱스를 제공합니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
