## MPX field

Microsoft Exchange 파일 형식은 Microsoft Project(MSP)와 Primavera Project Planner, Sciforma, Timerline Precision Estimating과 같이 MPX 파일 형식을 지원하는 다른 애플리케이션 간에 프로젝트 정보를 전송하기 위한 ASCII 파일 형식입니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
