## SXC field

SXC(Sun XML Calc) 파일 형식은 OpenOffice.org라는 오피스 제품군에 속합니다. 이 형식은 XML 기반 스프레드시트 파일 형식으로, 사용자의 스프레드시트 요구를 충족합니다. SXC 형식은 수식, 함수, 매크로, 차트 및 DataPilot을 지원합니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
