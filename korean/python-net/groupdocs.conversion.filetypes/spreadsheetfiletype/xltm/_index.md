## XLTM field

XLTM 파일 확장자는 Microsoft Excel에서 매크로 사용 템플릿 파일로 생성된 파일을 나타냅니다. XLTM 파일은 구조적으로 XLTX와 유사하지만, XLTX는 매크로가 포함된 템플릿 파일 생성을 지원하지 않습니다. 여기에서 이 파일 형식에 대해 자세히 알아보세요.
