## SVGZ field

SVGZ 파일은 실제로 SVG 파일의 압축 버전입니다. 이는 파일을 온라인에서 더 쉽게 배포할 수 있게 합니다. SVG 파일을 .GZIP 압축 알고리즘으로 압축하면 .svgz 파일 확장자가 부여됩니다.
