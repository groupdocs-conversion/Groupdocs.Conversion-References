## X field

.x 확장자를 가진 파일은 Microsoft DirectX 2.0에 도입된 DirectX 3D Graphics 레거시 파일 형식을 의미합니다. 게임에서 3D 그래픽 렌더링에 사용되었으며 메쉬, 텍스처, 애니메이션 및 사용자 정의 객체의 구조를 지정합니다. 2014년부터는 Autodesk FBX 파일 형식이 보다 현대적인 형식으로 더 적합해짐에 따라 사용이 중단되었습니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
