## USD field

.usd 확장자를 가진 파일은 Universal Scene Description 파일 형식으로, 디지털 콘텐츠 제작 애플리케이션 간 데이터 교환 및 보강을 위해 데이터를 인코딩합니다. Pixar가 개발한 USD는 모델이나 애니메이션과 같은 기본 자산을 교환할 수 있는 기능을 제공합니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
