## AMF field

AMF 파일은 적층 제조 프로세스에서 사용되도록 객체 설명을 위한 지침으로 구성됩니다. 파일은 시작 XML 태그로 시작하여 요소로 끝납니다. 이는 파일의 XML 버전 및 인코딩을 지정하는 XML 선언 라인으로 앞서 있습니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
