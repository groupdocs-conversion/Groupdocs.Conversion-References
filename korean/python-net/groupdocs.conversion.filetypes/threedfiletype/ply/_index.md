## PLY field

PLY(Polygon File Format)는 다각형 컬렉션으로 설명되는 그래픽 객체를 저장하는 3D 파일 형식입니다. 이 파일 형식의 목적은 다양한 모델에 유용할 만큼 일반적이면서도 간단하고 쉬운 파일 유형을 만드는 것이었습니다. 이 파일 형식에 대해 자세히 알아보려면 여기에서 확인하세요.
