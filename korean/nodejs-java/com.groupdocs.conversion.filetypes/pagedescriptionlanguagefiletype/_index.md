### Eps {#Eps}
```
public static final PageDescriptionLanguageFileType Eps
```


EPS 확장자를 가진 파일은 기본적으로 단일 페이지의 모습을 설명하는 캡슐화된 PostScript 언어 프로그램을 나타냅니다. 이 파일 형식에 대해 자세히 알아보려면 [here][].


[here]: https://wiki.fileformat.com/page-description-language/eps

### Cgm {#Cgm}
```
public static final PageDescriptionLanguageFileType Cgm
```


Computer Graphics Metafile (CGM)은 벡터 그래픽(2D), 래스터 그래픽 및 텍스트를 저장하고 교환하기 위한 무료이며 플랫폼에 독립적인 국제 표준 메타파일 형식입니다. CGM은 객체 지향 접근 방식과 이미지 제작을 위한 다양한 기능을 제공합니다. 이 파일 형식에 대해 자세히 알아보려면 [here][].


[here]: https://wiki.fileformat.com/page-description-language/cgm

### Xps {#Xps}
```
public static final PageDescriptionLanguageFileType Xps
```


XPS 파일은 Microsoft에서 만든 XML Paper Specification을 기반으로 하는 페이지 레이아웃 파일을 나타냅니다. 이 형식은 EMF 파일 형식을 대체하기 위해 Microsoft에서 개발되었으며 PDF 파일 형식과 유사하지만 문서의 레이아웃, 외관 및 인쇄 정보를 XML로 사용합니다. 이 파일 형식에 대해 자세히 알아보려면 [here][].


[here]: https://wiki.fileformat.com/page-description-language/xps

### Tex {#Tex}
```
public static final PageDescriptionLanguageFileType Tex
```


TeX는 문서 조판에 사용되는 프로그래밍 및 마크업 기능을 포함하는 언어입니다. 이 파일 형식에 대해 자세히 알아보려면 [here][].


[here]: https://wiki.fileformat.com/page-description-language/tex

### Ps {#Ps}
```
public static final PageDescriptionLanguageFileType Ps
```


PostScript (PS)는 데스크톱 및 전자 출판 분야에서 사용되는 범용 페이지 설명 언어입니다. PostScript (PS)의 주요 목표는 2차원 그래픽 디자인을 용이하게 하는 것입니다. 이 파일 형식에 대해 자세히 알아보려면 [here][].


[here]: https://wiki.fileformat.com/page-description-language/ps

### Pcl {#Pcl}
```
public static final PageDescriptionLanguageFileType Pcl
```


PCL은 Hewlett Packard (HP)에서 도입한 페이지 설명 언어인 프린터 명령 언어(Printer Command Language)를 의미합니다. 이 파일 형식에 대해 자세히 알아보려면 [here][].


[here]: https://wiki.fileformat.com/page-description-language/pcl

### Oxps {#Oxps}
```
public static final PageDescriptionLanguageFileType Oxps
```


OXPS 파일 형식은 Open XML Paper Specification으로 알려져 있습니다. 이는 페이지 설명 언어 및 문서 형식입니다. Microsoft는 이 형식의 개발자입니다. OXPS 파일 형식은 이러한 PDF 파일과 매우 유사합니다. 이 파일 형식에 대해 자세히 알아보려면 [here][].


[here]: https://docs.fileformat.com/page-description-language/oxps
