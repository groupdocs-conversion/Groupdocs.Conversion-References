この名前空間は、ドキュメントをすべての一般的なファイル形式にシンプルで直感的な方法で変換するクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [ConversionEvents](./conversionevents) | 変換ライフサイクルのイベントハンドラを集約します。インスタンスを [`Converter`](../groupdocs.conversion/converter) コンストラクタの `events` パラメータ、またはフルエントな `WithEvents` メソッドに渡してください。個別の [`ConverterSettings`](../groupdocs.conversion/convertersettings) ハンドラプロパティは廃止予定なので、こちらを使用することを推奨します。 |
| [ConvertContext](./convertcontext) | 変換コンテキストを定義します。 |
| [ConvertedContext](./convertedcontext) | 変換コンテキストを定義します。 |
| [ConvertedPageContext](./convertedpagecontext) | 変換ページコンテキストを定義します。 |
| [Converter](./converter) | ドキュメント変換プロセスを制御するメインクラスを表します。 |
| [ConverterSettings](./convertersettings) | [`Converter`](../groupdocs.conversion/converter) の動作をカスタマイズする設定を定義します。 |
| [FluentConverter](./fluentconverter) | フルエントな変換設定用のクラスです。 |
| [License](./license) | コンポーネントのライセンス付与用メソッドを提供します。ライセンスに関する詳細は[こちら](https://purchase.groupdocs.com/faqs/licensing)をご覧ください。 |
| [LoadContext](./loadcontext) | ロードコンテキストを定義します。 |
| [Metered](./metered) | [Metered](https://purchase.groupdocs.com/faqs/licensing/metered) ライセンスを適用するためのメソッドを提供します。 |
| [SaveContext](./savecontext) | 保存コンテキストを定義します。 |
| [SavePageContext](./savepagecontext) | 保存ページコンテキストを定義します。 |
