## EmailFileType.Olm field

.olm 拡張子のファイルは、Mac 用 Microsoft Outlook のファイルです。OLM ファイルはメールメッセージ、ジャーナル、カレンダー データ、その他のアプリケーションデータを保存します。これは Windows 用 Outlook の PST ファイルに似ていますが、Mac 用 Outlook で作成された OLM ファイルは Windows 用 Outlook では開けません。このファイル形式の詳細は[こちら](https://wiki.fileformat.com/email/olm)をご覧ください。

public static readonly EmailFileType Olm;
