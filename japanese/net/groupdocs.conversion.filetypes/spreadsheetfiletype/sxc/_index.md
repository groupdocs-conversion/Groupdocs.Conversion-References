## SpreadsheetFileType.Sxc field

SXC（Sun XML Calc）ファイル形式は OpenOffice.org というオフィススイートに属します。この形式は XML ベースのスプレッドシート ファイル形式で、ユーザーのスプレッドシートニーズに対応します。SXC 形式は数式、関数、マクロ、チャートに加えて DataPilot をサポートしています。このファイル形式の詳細は[here](https://wiki.fileformat.com/spreadsheet/sxc)でご覧ください。

public static readonly SpreadsheetFileType Sxc;
