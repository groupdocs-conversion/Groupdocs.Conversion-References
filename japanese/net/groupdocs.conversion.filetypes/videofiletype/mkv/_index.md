## VideoFileType.Mkv field

MKV (Matroska Video) is a multimedia container similar to MOV and AVI format but it supports more than one audio and subtitle track in the same file. An MKV file is the Matroska multimedia container format used for video. Learn more about this file format [here](https://docs.fileformat.com/video/mkv/).
