## VideoFileType.Webm field

A file with a .webm extension is a video file based on the open, royalty-free WebM file format. It has been designed for sharing video on the web and defines the file container structure including video and audio formats. Learn more about this file format [here](https://docs.fileformat.com/video/webm//).
