## EvaluationLimitReachedException class

現在のプロセスの評価変換許容量が使い果たされた場合にスローされるGroupDocs例外。

```csharp
public sealed class EvaluationLimitReachedException : GroupDocsConversionException
```

### 備考

ライセンスがない場合にのみスローされます。ライセンスを適用すると許可がクリアされるため、ライセンスが付与されたプロセスでは、変換するドキュメント数に関係なくこの例外は発生しません。
