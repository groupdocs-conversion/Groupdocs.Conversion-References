## GmlLoadOptions.LoadSchemasFromInternet property

Conversion がインターネットから XML スキーマを読み込むことを許可するかどうかを決定します。false に設定すると、‘file://’ で始まらない絶対 URI を持つスキーマは読み込まれません。既定値は false です。

public bool LoadSchemasFromInternet { get; set; }
