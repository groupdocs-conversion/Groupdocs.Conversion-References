## GmlLoadOptions.SchemaLocation property

スペースで区切られた URI ペアのリストです。各ペアの最初の URI は名前空間の URI で、2 番目の URI はその名前空間の XML スキーマへのパスです。null に設定すると、Conversion はドキュメントのルート要素から schemaLocation の読み取りを試みます。デフォルトは null です。

public string SchemaLocation { get; set; }
