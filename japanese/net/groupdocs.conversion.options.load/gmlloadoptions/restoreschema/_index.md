## GmlLoadOptions.RestoreSchema property

XML スキーマが欠落しているかロードできない Gml ファイルの属性を解析することを Conversion が許可するかどうかを決定します。true に設定すると、Conversion リーダーは XML スキーマの存在を必要としません。デフォルトは false です。

public bool RestoreSchema { get; set; }
