## PresentationConvertOptions.Zoom property

ズームレベルをパーセンテージで指定します。デフォルトは 100 です。デフォルトのズームは Microsoft PowerPoint 2010 までサポートされています。Microsoft PowerPoint 2013 以降は、デフォルトのズームはドキュメントに設定されず、代わりに最後に開いたドキュメントのズーム倍率が使用されるようです。

public int Zoom { get; set; }
