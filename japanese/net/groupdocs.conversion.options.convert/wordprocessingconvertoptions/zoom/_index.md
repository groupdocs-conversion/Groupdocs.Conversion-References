## WordProcessingConvertOptions.Zoom property

ズームレベルをパーセンテージで指定します。デフォルトは 100 です。デフォルトのズームは Microsoft Word 2010 までサポートされています。Microsoft Word 2013 以降、デフォルトズームはドキュメントに設定されず、代わりに最後に開いたドキュメントのズーム係数が使用されるようです。

public int Zoom { get; set; }
