## PdfConvertOptions.EmbedFullFonts property

true に設定すると、サブセットではなくフォント全体が PDF に埋め込まれます。これにより出力ファイルサイズは増加しますが、生成された PDF の編集時により高い互換性が確保されます。WordProcessing ドキュメントから変換する場合にのみ適用されます。

public bool EmbedFullFonts { get; set; }
