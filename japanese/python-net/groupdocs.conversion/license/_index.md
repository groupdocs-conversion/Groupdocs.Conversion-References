## License class

GroupDocs.Conversion のライセンスを管理します。

ライセンス認証されたビルドは、ラッパーのフル機能セットを次の場所で利用可能にします
ランタイムです。未ライセンスのビルドは、同じ API で評価モードとして実行されます
表面上は同じですが、出力サイズと透かし付きコンテンツに制限があります。

License 型は以下のメンバーを公開します：

### メソッド
| メソッド | 説明 |
| :- | :- |
| [set_license](/conversion/python-net/groupdocs.conversion/license/set_license/#license_source) | 現在のプロセスにライセンスを適用します。 |
