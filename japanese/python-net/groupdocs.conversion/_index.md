主要な GroupDocs.Conversion 名前空間で、トップレベルの API クラスが含まれます。

### クラス
| クラス | 説明 |
| :- | :- |
| [`ConversionEvents`](/conversion/python-net/groupdocs.conversion/conversionevents/) | 変換ライフサイクルのイベントハンドラを集約します。 |
| [`ConvertContext`](/conversion/python-net/groupdocs.conversion/convertcontext/) | 変換コンテキストを表します。 |
| [`ConvertedContext`](/conversion/python-net/groupdocs.conversion/convertedcontext/) | 変換コンテキストを定義します。 |
| [`ConvertedPageContext`](/conversion/python-net/groupdocs.conversion/convertedpagecontext/) | 変換ページコンテキストを定義します。 |
| [`Converter`](/conversion/python-net/groupdocs.conversion/converter/) | ドキュメント変換プロセスを制御するメインクラスを表します。 |
| [`ConverterSettings`](/conversion/python-net/groupdocs.conversion/convertersettings/) | Converter の動作をカスタマイズする設定を定義します。 |
| [`FluentConverter`](/conversion/python-net/groupdocs.conversion/fluentconverter/) | 流暢な変換設定を表します。 |
| [`License`](/conversion/python-net/groupdocs.conversion/license/) | GroupDocs.Conversion のライセンスを管理します。 |
| [`LoadContext`](/conversion/python-net/groupdocs.conversion/loadcontext/) | ロードコンテキストを定義します。 |
| [`Metered`](/conversion/python-net/groupdocs.conversion/metered/) | 従量課金（使用量に応じた支払い）ライセンスを管理します。 |
| [`SaveContext`](/conversion/python-net/groupdocs.conversion/savecontext/) | 保存コンテキストを表します。 |
| [`SavePageContext`](/conversion/python-net/groupdocs.conversion/savepagecontext/) | 保存ページコンテキストを定義します。 |

| [`ConversionNotSupportedException`](/conversion/python-net/groupdocs.conversion/conversionnotsupportedexception/) | GroupDocs 例外が、ソースファイルからターゲットファイルタイプへの変換がサポートされていない場合にスローされます |
| [`CorruptOrDamagedFileException`](/conversion/python-net/groupdocs.conversion/corruptordamagedfileexception/) | ファイルが破損または損傷している場合にスローされる GroupDocs 例外 |
| [`FileTypeNotSupportedException`](/conversion/python-net/groupdocs.conversion/filetypenotsupportedexception/) | ファイルタイプがサポートされていない場合にスローされる GroupDocs 例外 |
| [`FontSubstituteException`](/conversion/python-net/groupdocs.conversion/fontsubstituteexception/) | フォント置換が不正な場合にスローされます |

| [`InvalidConvertOptionsException`](/conversion/python-net/groupdocs.conversion/invalidconvertoptionsexception/) | 指定された変換オプションが無効な場合にスローされます |
| [`InvalidConverterSettingsException`](/conversion/python-net/groupdocs.conversion/invalidconvertersettingsexception/) | 指定されたコンバータ設定が無効な場合にスローされます |

| [`MissingDependencyException`](/conversion/python-net/groupdocs.conversion/missingdependencyexception/) | 依存しているアセンブリがアプリケーションの出力に存在しないため変換を実行できない場合にスローされる GroupDocs 例外。ドキュメントに問題はありません。 |
| [`PasswordRequiredException`](/conversion/python-net/groupdocs.conversion/passwordrequiredexception/) | ファイルがパスワードで保護されており、パスワードが提供されていない場合にスローされる GroupDocs 例外 |
| [`SourceDocumentFactoryNotProvidedException`](/conversion/python-net/groupdocs.conversion/sourcedocumentfactorynotprovidedexception/) | ソースドキュメントファクトリが提供されていない場合にスローされる GroupDocs 例外 |
