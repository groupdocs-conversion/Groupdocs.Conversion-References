## AMF field

AMF ファイルは、オブジェクト記述のガイドラインで構成されており、付加製造プロセスで使用されます。XML の開始タグで始まり、要素で終了します。ファイルの先頭には XML バージョンとエンコーディングを指定する XML 宣言行が付いています。このファイル形式の詳細はここをご覧ください。
