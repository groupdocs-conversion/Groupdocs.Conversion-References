## VDX field

Microsoft Visio で作成された任意の図面やチャートでも、XML 形式で保存すると .VDX 拡張子になります。Visio ソフトウェア（Microsoft が開発）で作成された Visio 図面 XML ファイルです。このファイル形式の詳細については、こちらをご覧ください。
