## MP4 field

MP4（MPEG-4 Part 14 の略）は、ISO/IEC 14496-12:2004 に基づくファイル形式で、QuickTime File Format をベースにしていますが、Initial Object Descriptors（IOD）やその他の MPEG 機能のサポートを正式に規定しています。こちらでこのファイル形式の詳細をご覧ください。
