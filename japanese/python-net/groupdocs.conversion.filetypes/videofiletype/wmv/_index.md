## WMV field

Windows Media Video は Microsoft が開発した圧縮動画形式です。映画テレビ技術者協会（SMPTE）による標準化の後、WMV は現在オープンスタンダード形式と見なされています。こちらでこのファイル形式の詳細をご覧ください。
