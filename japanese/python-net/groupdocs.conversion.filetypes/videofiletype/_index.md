## VideoFileType class

ビデオドキュメントタイプを表します。

以下のタイプが含まれます:
- [`VideoFileType.mp4`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mp4/)
- [`VideoFileType.avi`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/avi/)
- [`VideoFileType.flv`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/flv/)
- [`VideoFileType.mkv`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mkv/)
- [`VideoFileType.mov`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mov/)
- [`VideoFileType.webm`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/webm/)
- [`VideoFileType.wmv`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/wmv/)

こちらでビデオ形式の詳細をご覧ください: https://docs.fileformat.com/video/.

### フィールド
| フィールド | 説明 |
| :- | :- |
| [MP4](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mp4/) | MP4（MPEG-4 Part 14 の略）は、ISO/IEC 14496-12:2004 に基づくファイル形式で、QuickTime File Format をベースにしていますが、Initial Object Descriptors（IOD）やその他の MPEG 機能のサポートを正式に規定しています。こちらでこのファイル形式の詳細をご覧ください。 |
| [AVI](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/avi/) | AVI ファイル形式は、Microsoft が導入したオーディオビデオマルチメディアコンテナ形式です。XVid や DivX などの複数のコーデック（エンコーダ/デコーダ）を使用して作成・圧縮された音声と動画データを保持します。こちらでこのファイル形式の詳細をご覧ください。 |
| [FLV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/flv/) | FLV（Flash Video）は .flv 拡張子を持つコンテナファイル形式です。FLV は Adobe Flash Player または Adobe Air を使用してインターネット上で音声/動画コンテンツを配信するために使用されます。こちらでこのファイル形式の詳細をご覧ください。 |
| [MKV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mkv/) | MKV（Matroska Video）は、MOV や AVI 形式に似たマルチメディアコンテナですが、同一ファイル内で複数の音声および字幕トラックをサポートします。MKV ファイルは動画に使用される Matroska マルチメディアコンテナ形式です。こちらでこのファイル形式の詳細をご覧ください。 |
| [MOV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mov/) | MOV（または QuickTime）ファイル形式は、Apple が開発したマルチメディアコンテナで、1 つ以上のトラックを含み、各トラックは動画、音声、テキストなど特定のデータタイプを保持します。こちらでこのファイル形式の詳細をご覧ください。 |
| [WEBM](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/webm/) | .webm 拡張子を持つファイルは、オープンでロイヤリティフリーの WebM ファイル形式に基づく動画ファイルです。ウェブ上で動画を共有するために設計され、動画および音声フォーマットを含むファイルコンテナ構造を定義しています。こちらでこのファイル形式の詳細をご覧ください。 |
| [WMV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/wmv/) | Windows Media Video は Microsoft が開発した圧縮動画形式です。映画テレビ技術者協会（SMPTE）による標準化の後、WMV は現在オープンスタンダード形式と見なされています。こちらでこのファイル形式の詳細をご覧ください。 |
