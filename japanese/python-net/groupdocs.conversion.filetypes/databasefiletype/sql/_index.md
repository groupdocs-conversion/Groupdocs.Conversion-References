## SQL field

.sql 拡張子のファイルは、構造化照会言語（SQL）ファイルで、リレーショナルデータベースで動作するコードを含みます。データベースに対する CRUD（作成、読み取り、更新、削除）操作のための SQL 文を書くために使用されます。このファイル形式の詳細はここをご覧ください。
