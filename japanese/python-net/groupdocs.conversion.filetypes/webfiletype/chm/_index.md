## CHM field

CHM ファイル形式は、HTML ページのコレクションで構成された Microsoft HTML ヘルプファイルを表します。トピックへの迅速なアクセスとヘルプドキュメントのさまざまな部分へのナビゲーションのためのインデックスを提供します。このファイル形式の詳細については、こちらをご覧ください。
