## DIF field

DIF は Data Interchange Format の略で、異なるアプリケーション間でスプレッドシートデータのインポート/エクスポートに使用されます。対象には Microsoft Excel、OpenOffice Calc、StarCalc など多数があります。こちらでこのファイル形式の詳細を確認してください。
