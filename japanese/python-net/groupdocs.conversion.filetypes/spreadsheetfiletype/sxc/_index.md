## SXC field

SXC（Sun XML Calc）ファイル形式は OpenOffice.org というオフィススイートに属します。この形式は XML ベースのスプレッドシートファイル形式で、ユーザーのスプレッドシートニーズに対応します。SXC 形式は数式、関数、マクロ、チャート、DataPilot をサポートしています。こちらでこのファイル形式の詳細を確認してください。
