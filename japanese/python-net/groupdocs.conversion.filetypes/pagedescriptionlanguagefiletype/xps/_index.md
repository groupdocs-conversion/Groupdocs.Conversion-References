## XPS field

XPS ファイルは、Microsoft が作成した XML Paper Specification に基づくページレイアウトファイルを表します。この形式は Microsoft によって EMF ファイル形式の代替として開発され、PDF ファイル形式に似ていますが、文書のレイアウト、外観、印刷情報に XML を使用します。このファイル形式の詳細はここで確認できます。
