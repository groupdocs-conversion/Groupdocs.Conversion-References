## WAV field

WAV（WAVE：Waveform Audio File Format）は、Microsoft の Resource Interchange File Format（RIFF）仕様のサブセットで、デジタルオーディオファイルの保存に使用されます。このファイル形式の詳細はここをご覧ください。
