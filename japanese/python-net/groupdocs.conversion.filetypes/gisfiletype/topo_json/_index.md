## TOPO_JSON field

TopoJSON は GeoJSON の拡張で、トポロジーをエンコードします。個別にジオメトリを表すのではなく、TopoJSON ファイル内のジオメトリは「アーク」と呼ばれる共有線分から組み合わされています。
