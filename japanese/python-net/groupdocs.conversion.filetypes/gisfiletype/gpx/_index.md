## GPX field

GPX 拡張子のファイルは、インターネット上のアプリケーションやウェブサービス間で GPS データを交換するための GPS Exchange フォーマットを表します。これは、ウェイポイント、ルート、トラックなどの GPS データを含む軽量な XML ファイル形式で、複数のプログラムでインポートおよび読み取りが可能です。このファイル形式の詳細はここをご覧ください。
