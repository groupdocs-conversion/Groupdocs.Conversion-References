## JFIF field

JFIF（JPEG File Interchange Format）は .jfif 拡張子を使用する画像形式ファイルです。JFIF は JIF（JPEG Interchange Format）に比べて複雑さを削減し、制限を解消する形で構築されています。このファイル形式の詳細はここで確認できます。
