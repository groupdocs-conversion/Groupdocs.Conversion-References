## TIF field

TIF（Tagged Image File Format）は、さまざまなデバイスで使用できるラスタ画像を表し、このファイル形式標準に準拠しています。二値、グレースケール、パレットカラー、フルカラーの画像データを複数のカラースペースで記述できます。このファイル形式の詳細はここで確認できます。
