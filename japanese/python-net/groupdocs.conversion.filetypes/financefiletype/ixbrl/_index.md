## IXBRL field

iXBRL の内部では、XBRL の内容が XML タグを使用する xHTML ファイル形式でラップされています。XBRL と同様に、iXBRL ファイルのルート要素です。XHTML 形式は、その内容をさまざまな文書タイプやモジュールのコレクションとして表現します。XHTML のすべてのファイルは XML ファイル形式に基づき、XML 文書標準に準拠しています。こちらでこのファイル形式の詳細をご覧ください。
