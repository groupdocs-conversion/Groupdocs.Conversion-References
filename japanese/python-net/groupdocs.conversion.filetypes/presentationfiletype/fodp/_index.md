## FODP field

FODP 拡張子のファイルは、OpenDocument フラット XML プレゼンテーションを表します。プレゼンテーションファイルは OpenDocument 形式で保存されますが、標準の .ODP ファイルが使用する .ZIP コンテナの代わりにフラット XML 形式で保存されます。
