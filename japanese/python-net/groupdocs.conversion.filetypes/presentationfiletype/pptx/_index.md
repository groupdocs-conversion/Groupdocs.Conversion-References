## PPTX field

PPTX 拡張子のファイルは、人気のある Microsoft PowerPoint アプリケーションで作成されたプレゼンテーションファイルです。従来のバイナリ形式 PPT と異なり、PPTX 形式は Microsoft PowerPoint のオープン XML プレゼンテーションファイル形式に基づいています。このファイル形式の詳細はここをご覧ください。
