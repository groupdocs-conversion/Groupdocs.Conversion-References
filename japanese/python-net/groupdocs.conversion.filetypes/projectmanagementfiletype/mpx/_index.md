## MPX field

Microsoft Exchange File Format は、Microsoft Project（MSP）と、Primavera Project Planner、Sciforma、Timerline Precision Estimating など MPX ファイル形式をサポートする他のアプリケーション間でプロジェクト情報を転送するための ASCII ファイル形式です。このファイル形式の詳細はここでご覧ください。
