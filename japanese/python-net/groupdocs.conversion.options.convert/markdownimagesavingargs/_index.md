## MarkdownImageSavingArgs class

[`IMarkdownImageSavingCallback.image_saving`](/conversion/python-net/groupdocs.conversion.options.convert/imarkdownimagesavingcallback/image_saving/) に渡される引数を表します。

MarkdownImageSavingArgs 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [image_file_name](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_file_name/) | Markdown 出力の画像 URI として埋め込まれるファイル名（またはプレースホルダー ID）。URI を書き換えるには割り当てます。 |
| [image_stream](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_stream/) | このコールバックが戻った後、コンバータが画像バイトを書き込む宛先ストリーム。 |
