## embed_full_fonts property

このプロパティは、サブセットではなくフォント全体のファイルを PDF に埋め込むかどうかを決定します。

True に設定すると、出力ファイルのサイズは増加しますが、生成された PDF の編集時に互換性が向上します。WordProcessing ドキュメントから変換する場合にのみ適用されます。
