## CadConvertOptions class

CAD タイプへの変換オプションを表します。

CadConvertOptions 型は次のメンバーを公開します:

### コンストラクター
| コンストラクター | 説明 |
| :- | :- |
| [__init__](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/__init__/) | 新しい [`CadConvertOptions`](/conversion/python-net/groupdocs.conversion.options.convert/cadconvertoptions/) インスタンスを初期化します。 |

| プロパティ | 説明 |
| :- | :- |
