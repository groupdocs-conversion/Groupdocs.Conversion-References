## IUsePdfConvertOptions class

IUsePdfConvertOptions 型は次のメンバーを公開します:

### プロパティ
| プロパティ | 説明 |
| :- | :- |
| [use_pdf](/conversion/python-net/groupdocs.conversion.options.convert/iusepdfconvertoptions/use_pdf/) | 入力は最初に PDF に変換され、True に設定された場合は目的の形式に変換されます。 |
