## all_columns_in_one_page_per_sheet property

このプロパティは、シートのすべての列コンテンツが結果の単一ページにレンダリングされるかどうかを決定します。

True に設定すると、ページ設定の用紙サイズの幅は無視されますが、他のページ設定は有効なままです。
