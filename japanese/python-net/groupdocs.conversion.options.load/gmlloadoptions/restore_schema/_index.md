## restore_schema property

このプロパティは、XML スキーマが存在しない、またはロードできない場合に、変換が GML ファイルの属性を解析できるかどうかを決定します。

True に設定すると、変換リーダーは XML スキーマの存在を必要としません。デフォルト値は False です。
