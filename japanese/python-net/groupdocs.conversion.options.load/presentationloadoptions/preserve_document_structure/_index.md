## preserve_document_structure property

このプロパティは、PDF に変換する際にドキュメント構造を保持するかどうかを決定します。デフォルト: False。

ドキュメント構造をエクスポートすると、特に大きなドキュメントでメモリ消費が大幅に増加することに注意してください。
