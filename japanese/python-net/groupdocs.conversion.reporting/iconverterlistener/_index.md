## IConverterListener class

コンバータのリスニングを実行するために使用されるメソッドを定義します。

詳しく見る。

- More about monitoring conversion progress: https://docs.groupdocs.com/display/conversionnet/Listening

IConverterListener 型は次のメンバーを公開します:

### メソッド
| メソッド | 説明 |
| :- | :- |
| [completed](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/completed/) | 変換が完了したときに呼び出されます。 |
| [progress](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress/#current) | 変換の進行状況が変化するたびに呼び出されます。 |
| [progress_byte](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress_byte/) |  |
| [started](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/started/) | 実際の変換が開始された直後に呼び出されます。 |
