### Tiff {#Tiff}
```
public static final ImageFileType Tiff
```


TIFF, Tagged Image File Format, vertegenwoordigt rasterafbeeldingen die bedoeld zijn voor gebruik op verschillende apparaten die voldoen aan deze bestandsformaatstandaard. Het kan bilevel-, grijswaarden-, paletkleur- en full-color-beeldgegevens beschrijven in verschillende kleurenschema's. Meer informatie over dit bestandsformaat [here][].
