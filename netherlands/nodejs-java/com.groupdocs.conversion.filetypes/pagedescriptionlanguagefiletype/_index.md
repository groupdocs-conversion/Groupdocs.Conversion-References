### Cgm {#Cgm}
```
public static final PageDescriptionLanguageFileType Cgm
```


Computer Graphics Metafile (CGM) is een gratis, platformonafhankelijk, internationaal standaardmetabestandformaat voor het opslaan en uitwisselen van vectorafbeeldingen (2D), rasterafbeeldingen en tekst. CGM maakt gebruik van een objectgeoriënteerde aanpak en vele functievoorzieningen voor beeldproductie. Meer informatie over dit bestandsformaat [here][].


[here]: https://wiki.fileformat.com/page-description-language/cgm

### Xps {#Xps}
```
public static final PageDescriptionLanguageFileType Xps
```


Een XPS-bestand vertegenwoordigt paginalay-outbestanden die gebaseerd zijn op XML Paper Specifications, gemaakt door Microsoft. Dit formaat werd door Microsoft ontwikkeld als vervanging van het EMF-bestandsformaat en is vergelijkbaar met het PDF-bestandsformaat, maar gebruikt XML voor de lay-out, het uiterlijk en de afdrukinformatie van een document. Meer informatie over dit bestandsformaat [here][].


[here]: https://wiki.fileformat.com/page-description-language/xps

[here]: https://wiki.fileformat.com/page-description-language/ps

### Oxps {#Oxps}
```
public static final PageDescriptionLanguageFileType Oxps
```


Het bestandsformaat OXPS staat bekend als Open XML Paper Specification. Het is een paginabeschrijvingstaal en documentformaat. Microsoft is de ontwikkelaar van dit formaat. Het OXPS-bestandsformaat is sterk verwant aan deze PDF-bestanden. Meer informatie over dit bestandsformaat [here][].


[here]: https://docs.fileformat.com/page-description-language/oxps
