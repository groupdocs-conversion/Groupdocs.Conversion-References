## IConversionHandlerOnly class

Biedt een vloeiende interface voor het instellen van alleen conversie‑handlers.

Erft [`IConversionHandlersStage`](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlersstage/) voor `Convert`/`Compress`; de gestage `OnConversion*` overloads worden behouden via het `new`‑keyword om de bestaande return‑types en backward compatibility te behouden.

Het type IConversionHandlerOnly exposeert de volgende leden:
