## IConversionHandlerCompleted class

Stelt de vloeiende interface voor nadat `OnConversionFailed` is ingesteld, en maakt het mogelijk `OnConversionCompleted` in te stellen of door te gaan naar `Convert`/`Compress`.

Het IConversionHandlerCompleted type geeft de volgende leden weer:

| [compress_compression_convert_options](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/compress_compression_convert_options/) |  |
| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/convert/) | Voer conversieketen uit. |

| [on_conversion_completed_action](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlercompleted/on_conversion_completed_action/) |  |
