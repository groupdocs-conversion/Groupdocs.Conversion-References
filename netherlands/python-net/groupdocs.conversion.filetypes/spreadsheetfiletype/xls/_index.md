## XLS field

XLS staat voor het Excel Binary File Format. Dergelijke bestanden kunnen worden gemaakt door Microsoft Excel evenals andere vergelijkbare spreadsheetprogramma's zoals OpenOffice Calc of Apple Numbers. Meer informatie over dit bestandsformaat vind je hier.
