## PNG field

PNG, Portable Network Graphics, verwijst naar een type raster‑beeldformaat dat verliesloze compressie gebruikt. Dit bestandsformaat werd gecreëerd als vervanging van Graphics Interchange Format (GIF) en heeft geen auteursrechtelijke beperkingen. Meer informatie over dit bestandsformaat hier.
