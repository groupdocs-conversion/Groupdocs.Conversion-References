## GIF field

Een GIF of Graphical Interchange Format is een type sterk gecomprimeerde afbeelding. Voor elke afbeelding staat GIF doorgaans tot 8 bits per pixel toe en zijn er maximaal 256 kleuren toegestaan in de afbeelding. Meer informatie over dit bestandsformaat hier.
