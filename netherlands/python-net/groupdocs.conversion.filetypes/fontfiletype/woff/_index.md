## WOFF field

Een bestand met de extensie .woff is een weblettertypebestand gebaseerd op het Web Open Font Format (WOFF). Het heeft een formaat-specifieke gecomprimeerde container gebaseerd op respectievelijk TrueType (.TTF) of OpenType (.OTT) lettertype‑typen. Leer meer over dit bestandsformaat hier.
