## PLY field

PLY, Polygon File Format, is een 3D‑bestandsformaat dat grafische objecten opslaat die worden beschreven als een verzameling polygonen. Het doel van dit bestandsformaat was het creëren van een eenvoudig en gemakkelijk bestandstype dat algemeen genoeg is om bruikbaar te zijn voor een breed scala aan modellen. Meer informatie over dit bestandsformaat vind je hier.
