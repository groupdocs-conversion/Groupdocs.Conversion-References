## GDB field

ESRI File Geodatabase (FileGDB) is een verzameling bestanden in een map op schijf die gerelateerde georuimtelijke gegevens bevatten, zoals feature-datasets, feature-classes en bijbehorende tabellen. Het vereist dat bepaalde andere bestanden naast het .gdb-bestand in dezelfde map worden bewaard om te functioneren. Meer informatie over dit bestandsformaat vind je hier.
