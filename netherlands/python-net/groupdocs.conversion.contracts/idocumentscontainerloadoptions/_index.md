## IDocumentsContainerLoadOptions class

Stelt laadopties voor een documentencontainer voor.

Het IDocumentsContainerLoadOptions-type geeft de volgende leden weer:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [convert_owned](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owned/) | De optie om te bepalen of de eigendom-documenten in de documentencontainer moeten worden geconverteerd. |
| [convert_owner](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owner/) | De optie om te bepalen of de documentencontainer zelf moet worden geconverteerd. |
| [depth](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/depth/) | De optie om te bepalen hoeveel niveaus diep de conversie moet worden uitgevoerd. |
