## crop {#crop_left-crop_top-crop_right-crop_bottom}

Maakt een bijgesneden versie van de huidige Rectangle door opgegeven marges te verwijderen.

```python
def crop(self, crop_left, crop_top, crop_right, crop_bottom):
    ...
```

| Parameter | Type | Beschrijving |
| :- | :- | :- |
| crop_left | `int` | Het aantal pixels om te verwijderen van de linkerkant. |
| crop_top | `int` | Het aantal pixels om te verwijderen van de bovenkant. |
| crop_right | `int` | Het aantal pixels om te verwijderen van de rechterkant. |
| crop_bottom | `int` | Het aantal pixels om te verwijderen van de onderkant. |

**Returns:** Rectangle: A new cropped rectangle.
