## License class

Beheert de licenties van GroupDocs.Conversion.

Gelicentieerde builds ontgrendelen de volledige functionaliteit van de wrapper op
runtime. Niet-gelicentieerde builds draaien in evaluatiemodus met dezelfde API
oppervlak maar met beperkingen op de outputgrootte en watermerkinhoud.
