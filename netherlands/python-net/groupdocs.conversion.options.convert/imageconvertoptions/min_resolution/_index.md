## min_resolution property

De per-as ondergrens die wordt toegepast op de begrensde render-DPI wanneer [`ImageConvertOptions.CapResolutionToPageContent`](/conversion/python-net/groupdocs.conversion.options.convert/imageconvertoptions/cap_resolution_to_page_content/) is ingeschakeld.

De begrensde DPI wordt nooit lager dan deze waarde gezet. Standaard is 0 (geen ondergrens).
