## IPagedConvertOptions class

Stelt conversieopties voor die conversie mogelijk maken met paginabeperking door startpagina en aantal pagina's op te geven.

Het IPagedConvertOptions-type geeft de volgende leden weer:

### Eigenschappen
| Eigenschap | Beschrijving |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | Het gewenste bestandstype waarnaar het invoerdocument moet worden geconverteerd. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | Het paginanummer waar de conversie moet beginnen. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | Het aantal pagina's dat moet worden geconverteerd, beginnend bij `PageNumber`. |
