## restore_schema property

De eigenschap bepaalt of conversie attributen in een GML-bestand mag parseren wanneer het XML-schema ontbreekt of niet kan worden geladen.

Indien ingesteld op True, vereist de conversielezer niet de aanwezigheid van een XML‑schema. De standaardwaarde is False.
