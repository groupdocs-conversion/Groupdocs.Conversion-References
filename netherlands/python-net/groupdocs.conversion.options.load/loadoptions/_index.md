## LoadOptions class

Stelt abstracte documentlaadopties voor.

LoadOptions-klassen geven het type document op dat geladen moet worden en bevatten optionele parameters, zoals `password`. Ze zijn onderverdeeld in twee groepen: opties voor een bestandsformaatfamilie en opties voor een specifiek bestandstype.
