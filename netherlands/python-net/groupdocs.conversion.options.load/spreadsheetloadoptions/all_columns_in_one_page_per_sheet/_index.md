## all_columns_in_one_page_per_sheet property

De eigenschap bepaalt of alle kolominhoud van een blad op één enkele pagina in het resultaat wordt weergegeven.

Wanneer ingesteld op True, wordt de breedte van de papiergrootte in de pagina‑instelling genegeerd, terwijl andere pagina‑instellingsopties effectief blijven.
