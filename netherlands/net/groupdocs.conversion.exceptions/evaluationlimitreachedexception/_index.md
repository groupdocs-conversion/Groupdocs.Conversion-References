## EvaluationLimitReachedException class

GroupDocs exception gegooid wanneer de evaluatie-conversietoewijzing voor het huidige proces is opgebruikt.

```csharp
public sealed class EvaluationLimitReachedException : GroupDocsConversionException
```

### Opmerkingen

Wordt alleen gegooid zonder licentie. Het toepassen van een licentie wist de limiet, zodat een gelicentieerd proces deze uitzondering nooit ziet, ongeacht hoeveel documenten het converteert.
