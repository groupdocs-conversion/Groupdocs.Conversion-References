## WordProcessingConvertOptions.Zoom property

Specificeert het zoomniveau in procenten. Standaard is 100. Standaardzoom wordt ondersteund tot Microsoft Word 2010. Vanaf Microsoft Word 2013 wordt de standaardzoom niet meer op het document ingesteld; in plaats daarvan lijkt deze de zoomfactor van het laatst geopende document te gebruiken.

public int Zoom { get; set; }
