## ImageConvertOptions.MinResolution property

Per-as ondergrens toegepast op de begrensde render-DPI wanneer [`CapResolutionToPageContent`](../capresolutiontopagecontent) is ingeschakeld. De begrensde DPI wordt nooit lager dan deze waarde gebracht. Standaard is `0` (geen ondergrens).

public int MinResolution { get; set; }
