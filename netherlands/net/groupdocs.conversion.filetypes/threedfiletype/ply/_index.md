## ThreeDFileType.Ply field

PLY, Polygon File Format, is een 3D-bestandsformaat dat grafische objecten opslaat die worden beschreven als een verzameling polygonen. Het doel van dit bestandsformaat was om een eenvoudig en gemakkelijk type bestand te creëren dat algemeen genoeg is om bruikbaar te zijn voor een breed scala aan modellen. Meer informatie over dit bestandsformaat [hier](https://docs.fileformat.com/3d/ply).
