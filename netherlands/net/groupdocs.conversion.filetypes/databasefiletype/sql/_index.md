## DatabaseFileType.Sql field

Een bestand met de extensie .sql is een Structured Query Language (SQL)-bestand dat code bevat om met relationele databases te werken. Het wordt gebruikt om SQL‑statements te schrijven voor CRUD‑ (Create, Read, Update, Delete) bewerkingen op databases. Meer informatie over dit bestandsformaat [hier](https://docs.fileformat.com/database/sql).
