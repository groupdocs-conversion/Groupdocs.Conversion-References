## VideoFileType.Mp4 field

MP4 (kort voor MPEG‑4 Part 14) is een bestandsformaat gebaseerd op ISO/IEC 14496-12:2004, dat is gebaseerd op QuickTime File Format maar formeel ondersteuning biedt voor Initial Object Descriptors (IOD) en andere MPEG‑functies. Meer informatie over dit bestandsformaat vind je [hier](https://docs.fileformat.com/video/mp4/).
