## ProjectManagementFileType.Mpx field

Microsoft Exchange File Format is een ASCII-bestandsformaat voor het overdragen van projectinformatie tussen Microsoft Project (MSP) en andere toepassingen die het MPX-bestandsformaat ondersteunen, zoals Primavera Project Planner, Sciforma en Timerline Precision Estimating.
