De naamruimte biedt klassen om documenten te converteren naar alle populaire bestandsformaten op een eenvoudige en intuïtieve manier.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ConversionEvents](./conversionevents) | Aggregaat eventhandlers voor de levenscyclus van conversie. Geef een instantie door aan de `events`-parameter van de [`Converter`](../groupdocs.conversion/converter) constructor of aan de fluente `WithEvents`-methode. Geef de voorkeur aan dit boven de individuele [`ConverterSettings`](../groupdocs.conversion/convertersettings) handler-eigenschappen, die verouderd zijn. |
| [ConvertContext](./convertcontext) | Definieert conversie-context. |
| [ConvertedContext](./convertedcontext) | Definieert conversie-context. |
| [ConvertedPageContext](./convertedpagecontext) | Definieert paginaconversie-context. |
| [Converter](./converter) | Stelt de hoofdklasse voor die het documentconversieproces beheert. |
| [ConverterSettings](./convertersettings) | Definieert instellingen voor het aanpassen van het gedrag van [`Converter`](../groupdocs.conversion/converter). |
| [FluentConverter](./fluentconverter) | Klasse voor fluente conversie-configuratie. |
| [License](./license) | Biedt methoden om het component te licentiëren. Meer informatie over licenties [hier](https://purchase.groupdocs.com/faqs/licensing). |
| [LoadContext](./loadcontext) | Definieert laad-context. |
| [Metered](./metered) | Biedt methoden voor het toepassen van een [Metered](https://purchase.groupdocs.com/faqs/licensing/metered) licentie. |
| [SaveContext](./savecontext) | Definieert opslaan-context. |
| [SavePageContext](./savepagecontext) | Definieert opslaan-paginacontext. |
