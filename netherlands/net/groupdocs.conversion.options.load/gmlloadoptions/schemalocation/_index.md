## GmlLoadOptions.SchemaLocation property

Spatiegescheiden lijst van URI-paren. De eerste URI in elk paar is een URI van de namespace, de tweede URI is een pad naar het XML-schema van de namespace. Indien ingesteld op null, probeert Conversie de schemaLocation uit het root‑element van het document te lezen. Standaard is null
