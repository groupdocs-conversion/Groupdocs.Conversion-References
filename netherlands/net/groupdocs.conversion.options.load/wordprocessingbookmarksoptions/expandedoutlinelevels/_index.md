## WordProcessingBookmarksOptions.ExpandedOutlineLevels property

Specificeert hoeveel niveaus in de documentstructuur worden uitgeklapt wanneer het bestand wordt bekeken. Standaard is 0. Geldig bereik is 0 tot 9. Merk op dat deze optie niet werkt bij het opslaan naar XPS.

public int ExpandedOutlineLevels { get; set; }
