### Svg {#Svg}
```
public static final PageDescriptionLanguageFileType Svg
```


Файл SVG — это файл Scalar Vector Graphics, использующий основанный на XML текстовый формат для описания внешнего вида изображения. Узнайте больше об этом формате файла [here](../https://wiki.fileformat.com/page-description-language/svg).


### Eps {#Eps}
```
public static final PageDescriptionLanguageFileType Eps
```


Файлы с расширением EPS по сути описывают программу Encapsulated PostScript, которая определяет внешний вид отдельной страницы. Узнайте больше об этом формате файла [here](../https://wiki.fileformat.com/page-description-language/eps).


### Cgm {#Cgm}
```
public static final PageDescriptionLanguageFileType Cgm
```


Computer Graphics Metafile (CGM) — бесплатный, независимый от платформы, международный стандартный формат метафайла для хранения и обмена векторной графикой (2D), растровой графикой и текстом. CGM использует объектно‑ориентированный подход и множество функциональных возможностей для создания изображений. Узнайте больше об этом формате файла [here](../https://wiki.fileformat.com/page-description-language/cgm).


### Xps {#Xps}
```
public static final PageDescriptionLanguageFileType Xps
```


Файл XPS представляет собой файлы макета страниц, основанные на XML Paper Specifications, созданные Microsoft. Этот формат был разработан Microsoft как замена формата EMF и похож на формат PDF, но использует XML для описания макета, внешнего вида и печатной информации документа. Узнайте больше об этом формате файла [here](../https://wiki.fileformat.com/page-description-language/xps).


### Tex {#Tex}
```
public static final PageDescriptionLanguageFileType Tex
```


TeX — это язык, включающий возможности программирования и разметки, используемый для наборa документов. Узнайте больше об этом формате файла [here](../https://wiki.fileformat.com/page-description-language/tex).


### Ps {#Ps}
```
public static final PageDescriptionLanguageFileType Ps
```


PostScript (PS) — это универсальный язык описания страниц, используемый в сфере настольных и электронных публикаций. Основная цель PostScript (PS) — облегчить двухмерное графическое проектирование. Узнайте больше об этом формате файла [here](../https://wiki.fileformat.com/page-description-language/ps).


### Pcl {#Pcl}
```
public static final PageDescriptionLanguageFileType Pcl
```


PCL расшифровывается как Printer Command Language, который является языком описания страниц, разработанным Hewlett Packard (HP). Узнайте больше об этом формате файла [here](../https://wiki.fileformat.com/page-description-language/pcl).


### Oxps {#Oxps}
```
public static final PageDescriptionLanguageFileType Oxps
```


Формат файла OXPS известен как Open XML Paper Specification. It\\\\u2019s язык описания страниц и формат документа. Microsoft является разработчиком этого формата. Формат OXPS очень похож на файлы PDF. Узнайте больше об этом формате файла [here](../https://docs.fileformat.com/page-description-language/oxps).
