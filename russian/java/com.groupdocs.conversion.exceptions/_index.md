Пространство имен GroupDocs.Conversion.Exceptions предоставляет различные классы исключений.



## Классы

| Класс | Описание |
| --- | --- |
| [ConversionNotSupportedException](../com.groupdocs.conversion.exceptions/conversionnotsupportedexception) | Исключение GroupDocs, выбрасываемое, когда конвертация из исходного файла в целевой тип файла не поддерживается |
| [CorruptOrDamagedFileException](../com.groupdocs.conversion.exceptions/corruptordamagedfileexception) | Исключение GroupDocs, выбрасываемое, когда файл повреждён или испорчен |
| [FileTypeNotSupportedException](../com.groupdocs.conversion.exceptions/filetypenotsupportedexception) | Исключение GroupDocs, выбрасываемое, когда тип файла не поддерживается |
| [FontSubstituteException](../com.groupdocs.conversion.exceptions/fontsubstituteexception) | Выбрасывается, если замена шрифта является недопустимой. |
| [GroupDocsConversionException](../com.groupdocs.conversion.exceptions/groupdocsconversionexception) | Общее исключение GroupDocs.Conversion. |
| [IncorrectPasswordException](../com.groupdocs.conversion.exceptions/incorrectpasswordexception) | Исключение GroupDocs, выбрасываемое, когда файл защищён паролем, пароль предоставлен, но неверен. |
| [InvalidConvertOptionsException](../com.groupdocs.conversion.exceptions/invalidconvertoptionsexception) | Выбрасывается, если предоставленные параметры конвертации недействительны. |
| [InvalidConverterSettingsException](../com.groupdocs.conversion.exceptions/invalidconvertersettingsexception) | Выбрасывается, если предоставленные настройки конвертера недействительны |
| [PasswordRequiredException](../com.groupdocs.conversion.exceptions/passwordrequiredexception) | Исключение GroupDocs выбрасывается, когда файл защищён паролем и пароль не предоставлен |
