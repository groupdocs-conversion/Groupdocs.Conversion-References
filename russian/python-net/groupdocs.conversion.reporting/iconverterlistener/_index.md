## IConverterListener class

Определяет методы, используемые для прослушивания конвертера.

Узнать больше.

- More about monitoring conversion progress: https://docs.groupdocs.com/display/conversionnet/Listening

Тип IConverterListener раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [completed](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/completed/) | Вызывается при завершении конвертации. |
| [progress](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress/#current) | Вызывается каждый раз, когда изменяется прогресс конвертации. |
| [progress_byte](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress_byte/) |  |
| [started](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/started/) | Вызывается сразу же, как только начинается фактическая конвертация. |
