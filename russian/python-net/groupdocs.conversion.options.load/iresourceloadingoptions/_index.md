## IResourceLoadingOptions class

Представляет набор параметров для управления загрузкой внешних ресурсов.

Тип IResourceLoadingOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [skip_external_resources](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/skip_external_resources/) | Свойство указывает, загружаются ли внешние ресурсы. |
| [whitelisted_resources](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/) | Внешние ресурсы, которые всегда будут загружаться. |
