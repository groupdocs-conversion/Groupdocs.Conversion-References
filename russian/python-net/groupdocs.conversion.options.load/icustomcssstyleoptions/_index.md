## ICustomCssStyleOptions class

Представляет параметры для пользовательского CSS‑оформления во время конвертации документов.

Тип ICustomCssStyleOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [custom_css_style](/conversion/python-net/groupdocs.conversion.options.load/icustomcssstyleoptions/custom_css_style/) | Пользовательский CSS‑стиль, который будет применён к документу во время конвертации и вставлен в тег `<head>` документа для настройки отображения. |
