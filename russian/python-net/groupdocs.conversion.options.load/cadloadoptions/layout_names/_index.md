## layout_names property

Имена макетов, которые будут преобразованы.

Не учитывается при конвертации в PDF/UA-1. Эта цель отображает чертеж как одну помеченную страницу, которая не может содержать один лист на выбранный макет, поэтому весь чертеж конвертируется вместо этого, и ничего здесь к нему не применяется.

Каждая другая цель, включая PDF, учитывает выбор. На этих целях имена точно сопоставляются с макетами, содержащимися в чертеже, поэтому имя, отличающееся только регистром, считается другим именем. Имя, которое ни с чем не совпадает, отбрасывается и стоит вызывающему только один лист; список, в котором ничего не совпадает, приводит к ошибке конвертации с `InvalidLoadOptionsException`, указывающей имена, которые не найдены, и макеты, присутствующие в чертеже, вместо рендеринга листов, которые вызывающий не запрашивал. Чертёж, не содержащий никаких макетов, освобождается от этого: для имени нет чего сопоставлять, поэтому ни одно не отклоняется.
