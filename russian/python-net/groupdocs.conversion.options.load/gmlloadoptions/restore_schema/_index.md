## restore_schema property

Свойство определяет, разрешено ли конвертации разбирать атрибуты в файле GML, когда XML-схема отсутствует или не может быть загружена.

Если установить в True, конвертирующий читатель не требует наличия XML‑схемы. Значение по умолчанию — False.
