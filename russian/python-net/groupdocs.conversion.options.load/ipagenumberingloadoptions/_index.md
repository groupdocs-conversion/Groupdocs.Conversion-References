## IPageNumberingLoadOptions class

Предоставляет параметры для управления нумерацией страниц в конвертированном документе.

Тип IPageNumberingLoadOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [page_numbering](/conversion/python-net/groupdocs.conversion.options.load/ipagenumberingloadoptions/page_numbering/) | Флаг нумерации страниц включает или отключает генерацию нумерации страниц в преобразованном документе (по умолчанию False). |
