## LoadOptions class

Представляет абстрактные параметры загрузки документа.

Классы LoadOptions определяют тип загружаемого документа и включают необязательные параметры, такие как `password`. Они классифицируются в две группы: параметры для семейства форматов и параметры для конкретного типа файла.

Тип LoadOptions раскрывает следующие члены:
