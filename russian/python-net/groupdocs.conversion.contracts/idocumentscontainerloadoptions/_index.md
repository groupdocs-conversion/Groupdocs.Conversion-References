## IDocumentsContainerLoadOptions class

Представляет параметры загрузки для контейнера документов.

Тип IDocumentsContainerLoadOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [convert_owned](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owned/) | Опция, контролирующая, должны ли преобразовываться принадлежащие документы в контейнере документов. |
| [convert_owner](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owner/) | Опция, позволяющая контролировать, должен ли сам контейнер документов быть преобразован. |
| [depth](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/depth/) | Опция, контролирующая, сколько уровней глубины выполнять преобразование. |
