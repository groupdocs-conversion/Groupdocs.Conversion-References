## get_hash_code

Служит в качестве функции хеширования по умолчанию.

Компоненты массивов, списков и словарей хешируются по их содержимому, соответствуя тому, как сравнение проверяет их равенство, поэтому два объекта, которые считаются равными, также имеют одинаковый хеш и могут использоваться в качестве ключей словаря или элементов множества.

Это НЕ распространяется на компонент, который является другим `System.Collections.IEnumerable`: такой компонент хешируется по ссылке, а компонент, представленный как ленивый итератор, возвращает разное значение при каждом доступе, поэтому объект, содержащий его, вовсе не может использоваться в качестве ключа. Вложенные коллекции также сравниваются и хешируются по ссылке, а не рекурсивно.

Другим следствием является то, что изменение коллекции, раскрытой объектом-значением — добавление в список страниц или запись в массив имён макетов — изменяет хеш этого объекта, поэтому экземпляр, уже хранящийся в хеш‑контейнере, становится недоступным. Рассматривайте объект-значение как неизменяемый, как только он используется в качестве ключа.

```python
def get_hash_code(self):
    ...
```

**Returns:** A hash code for the current object.
