## IDpiConvertOptions class

Тип IDpiConvertOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [dpi](/conversion/python-net/groupdocs.conversion.options.convert/idpiconvertoptions/dpi/) | Желаемое DPI страницы после конвертации. |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/idpiconvertoptions/format/) | Желаемый тип файла, в который следует преобразовать входной документ. |
