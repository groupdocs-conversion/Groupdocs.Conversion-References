## WebConvertOptions class

Представляет параметры конвертации в тип файла Web.

Тип WebConvertOptions раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/__init__/) | Инициализирует новый экземпляр [`WebConvertOptions`](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/). |

### Свойства
| Свойство | Описание |
| :- | :- |
| [embed_font_resources](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/embed_font_resources/) | Флаг, указывающий, следует ли встраивать ресурсы шрифтов в основной HTML. По умолчанию False. |
| [fixed_layout](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/fixed_layout/) | Флаг фиксированного макета. |
| [fixed_layout_show_borders](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/fixed_layout_show_borders/) | Границы страниц отображаются при конвертации в фиксированный макет. По умолчанию True. |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/format/) | Желаемый тип файла, в который следует преобразовать входной документ. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/page_number/) | Номер страницы, с которой начинается конвертация. |
| [pages](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/pages/) | Список индексов страниц для конвертации; укажите его, чтобы конвертировать определённые страницы. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/pages_count/) | Количество страниц для конвертации, начиная с `PageNumber`. |
| [use_pdf](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/use_pdf/) | Свойство UsePdf. |
| [watermark](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/watermark/) | Специфические параметры водяного знака. |
| [zoom](/conversion/python-net/groupdocs.conversion.options.convert/webconvertoptions/zoom/) | Уровень масштабирования в процентах. По умолчанию 100. |
