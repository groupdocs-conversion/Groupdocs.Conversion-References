## WatermarkOptions class

Предоставляет параметры установки водяного знака в конвертированном документе.

Тип WatermarkOptions раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [clone](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/clone/) | Клонировать текущий экземпляр. |
| [equals](/conversion/python-net/groupdocs.conversion.contracts/valueobject/equals/) | Определяет, равны ли два экземпляра объекта. (наследовано от [`ValueObject`](/conversion/python-net/groupdocs.conversion.contracts/valueobject/)) |
| [equals_object](/conversion/python-net/groupdocs.conversion.contracts/valueobject/equals_object/) | (наследовано от [`ValueObject`](/conversion/python-net/groupdocs.conversion.contracts/valueobject/)) |
| [equals_value_object](/conversion/python-net/groupdocs.conversion.contracts/valueobject/equals_value_object/) | (наследовано от [`ValueObject`](/conversion/python-net/groupdocs.conversion.contracts/valueobject/)) |
| [get_hash_code](/conversion/python-net/groupdocs.conversion.contracts/valueobject/get_hash_code/) | Служит функцией хеширования по умолчанию. (наследовано от [`ValueObject`](/conversion/python-net/groupdocs.conversion.contracts/valueobject/)) |

### Свойства
| Свойство | Описание |
| :- | :- |
| [auto_align](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/auto_align/) | Водяной знак автоматически масштабируется до размера страницы, когда установлено значение True. |
| [background](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/background/) | Водяной знак наносится как фон; если True, он размещается внизу, иначе — поверх (по умолчанию False). |
| [height](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/height/) | Высота водяного знака. |
| [left](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/left/) | Позиция водяного знака слева. |
| [rotation_angle](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/rotation_angle/) | Угол поворота водяного знака. |
| [top](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/top/) | Позиция водяного знака сверху. |
| [transparency](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/transparency/) | Прозрачность водяного знака. Значение от 0 до 1. Значение 0 — полностью видимый, значение 1 — невидимый. |
| [width](/conversion/python-net/groupdocs.conversion.options.convert/watermarkoptions/width/) | Ширина водяного знака. |
