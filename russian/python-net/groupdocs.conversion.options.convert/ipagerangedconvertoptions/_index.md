## IPageRangedConvertOptions class

Представляет параметры конвертации, поддерживающие конвертацию конкретного списка страниц.

Тип IPageRangedConvertOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/format/) | Желаемый тип файла, в который следует преобразовать входной документ. |
| [pages](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/pages/) | Список индексов страниц для конвертации. Должен быть указан для конвертации конкретных страниц. |
