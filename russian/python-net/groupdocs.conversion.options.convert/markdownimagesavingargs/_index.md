## MarkdownImageSavingArgs class

Представляет аргументы, передаваемые в [`IMarkdownImageSavingCallback.image_saving`](/conversion/python-net/groupdocs.conversion.options.convert/imarkdownimagesavingcallback/image_saving/).

Тип MarkdownImageSavingArgs раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [image_file_name](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_file_name/) | Имя файла (или идентификатор заполнителя), встроенное как URI изображения в выводе Markdown. Присвойте значение, чтобы переписать URI. |
| [image_stream](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_stream/) | Поток назначения, в который конвертер запишет байты изображения после возврата из этого обратного вызова. |
| [keep_image_stream_open](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/keep_image_stream_open/) | Свойство определяет, оставляет ли конвертер поток изображения открытым после конвертации. |
