## zoom property

Уровень масштабирования в процентах.

По умолчанию 100. Масштаб по умолчанию поддерживается до Microsoft Powerpoint 2010. Начиная с Microsoft Powerpoint 2013 масштаб по умолчанию больше не устанавливается в документ, вместо этого, кажется, используется коэффициент масштабирования последнего открытого документа.
