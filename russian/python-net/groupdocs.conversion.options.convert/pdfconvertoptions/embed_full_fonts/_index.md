## embed_full_fonts property

Свойство определяет, будет ли полный файл шрифта встроен в PDF вместо подмножества.

Когда установлено в True, размер выходного файла увеличивается, но обеспечивается лучшая совместимость при редактировании полученного PDF. Применяется только при конвертации из документов WordProcessing.
