## IUsePdfConvertOptions class

Представляет параметры, поддерживающие конвертацию в PDF при необходимости.

Тип IUsePdfConvertOptions раскрывает следующие члены:

### Свойства
| Свойство | Описание |
| :- | :- |
| [use_pdf](/conversion/python-net/groupdocs.conversion.options.convert/iusepdfconvertoptions/use_pdf/) | Входные данные сначала конвертируются в PDF, а затем в требуемый формат, если параметр установлен в True. |
