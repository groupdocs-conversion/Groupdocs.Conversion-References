## min_resolution property

Нижняя граница по каждой оси, применяемая к ограниченному DPI рендеринга, когда включена опция [`ImageConvertOptions.CapResolutionToPageContent`](/conversion/python-net/groupdocs.conversion.options.convert/imageconvertoptions/cap_resolution_to_page_content/).

Ограниченный DPI никогда не опускается ниже этого значения. По умолчанию 0 (без ограничения).
