## License class

Управляет лицензированием GroupDocs.Conversion.

Лицензированные сборки разблокируют полный набор функций обёртки по адресу
runtime. Нелицензированные сборки работают в режиме оценки с тем же API
поверхность, но с ограничениями на размер вывода и наличие водяных знаков.
