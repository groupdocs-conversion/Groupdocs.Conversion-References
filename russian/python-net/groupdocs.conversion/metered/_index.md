## Metered class

Управляет измеряемым (по-использованию) лицензированием.

Лицензии Metered выставляются по фактическому потреблению (обычно страниц или
обработанных документов). Установите пару публичного/приватного ключа один раз в
запуске приложения; обертка отправляет данные об использовании обратно в GroupDocs
лицензионный сервер в фоновом режиме.

Тип Metered раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [get_consumption_credit](/conversion/python-net/groupdocs.conversion/metered/get_consumption_credit/) | Возвращает оставшийся метрированный кредит для текущего ключа. |
| [get_consumption_quantity](/conversion/python-net/groupdocs.conversion/metered/get_consumption_quantity/) | Возвращает общее количество метрированного потребления до текущего момента. |
| [set_metered_key](/conversion/python-net/groupdocs.conversion/metered/set_metered_key/#public_key-private_key) | Активировать метрированную оплату с указанной парой публичного/приватного ключа. |
