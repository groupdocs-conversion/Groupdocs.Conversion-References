## TextLine class

Представляет текст, извлечённый из изображения в результате процесса распознавания.

Тип TextLine раскрывает следующие члены:

### Конструкторы
| Конструктор | Описание |
| :- | :- |
| [__init__](/conversion/python-net/groupdocs.conversion.integration.ocr/textline/__init__/#fragments) | Инициализирует новый экземпляр строки текста, извлечённой OCR‑движком из изображения. |

### Свойства
| Свойство | Описание |
| :- | :- |
| [fragments](/conversion/python-net/groupdocs.conversion.integration.ocr/textline/fragments/) | Массив текстовых фрагментов, таких как символы и слова, распознанных в строке. |
