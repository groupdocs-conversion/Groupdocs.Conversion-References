## IConversionCompressResultCompletedOrConvert class

Продолжение после `Compress(...)`. Перейдите напрямую к `Convert`; унаследованный [`IConversionCompressResultCompleted.OnCompressionCompleted`](/conversion/python-net/groupdocs.conversion.fluent/iconversioncompressresultcompleted/on_compression_completed/) устарел — вместо этого зарегистрируйте обработчик на этапе входа через [`IConversionSettings.WithEvents`](/conversion/python-net/groupdocs.conversion.fluent/iconversionsettings/with_events/).

Тип IConversionCompressResultCompletedOrConvert раскрывает следующие члены:

### Методы
| Метод | Описание |
| :- | :- |
| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversioncompressresultcompletedorconvert/convert/) | Выполняет цепочку конвертации. |
| [on_compression_completed](/conversion/python-net/groupdocs.conversion.fluent/iconversioncompressresultcompletedorconvert/on_compression_completed/#compressed_document_stream) | Получает поток сжатого документа. Срабатывает только если `Compress(CompressionConvertOptions)` установлен. |
