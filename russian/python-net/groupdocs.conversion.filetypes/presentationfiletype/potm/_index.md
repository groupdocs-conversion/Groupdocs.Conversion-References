## POTM field

Файлы с расширением POTM — это шаблоны Microsoft PowerPoint с поддержкой макросов. Файлы POTM создаются в PowerPoint 2007 и новее и содержат настройки по умолчанию, которые можно использовать для создания последующих презентаций. Узнайте больше об этом файловом формате здесь.
