## PPT field

Файл с расширением PPT представляет файл PowerPoint, который состоит из набора слайдов для отображения в виде SlideShow. Он использует двоичный файловый формат, применяемый в Microsoft PowerPoint 97‑2003. Узнайте больше об этом файловом формате здесь.
