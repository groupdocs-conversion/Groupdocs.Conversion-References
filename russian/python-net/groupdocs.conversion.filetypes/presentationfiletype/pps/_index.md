## PPS field

PPS, PowerPoint Slide Show, файлы создаются с помощью Microsoft PowerPoint для целей показа слайдов. Чтение и создание файлов PPS поддерживается в Microsoft PowerPoint 97‑2003. Узнайте больше об этом файловом формате здесь.
