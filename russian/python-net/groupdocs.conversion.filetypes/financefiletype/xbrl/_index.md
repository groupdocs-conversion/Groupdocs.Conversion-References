## XBRL field

XBRL — открытый международный стандарт цифровой бизнес-отчетности, широко используемый по всему миру. Это язык на основе XML, который использует элементы XBRL, известные как теги, для описания каждого элемента бизнес-данных с целью формирования данных для сортировки и анализа отчетов.
