## XAR field

Файл с расширением .xar — это eXtensible ARchive, формат, построенный вокруг таблицы содержимого, хранящейся в виде сжатого XML. Он используется для распространения пакетов установщика macOS и хранит каждую запись сжатой отдельно. Узнайте больше об этом формате файла здесь.
