## LZ field

Файл с расширением .lz — это сжатый архив, созданный с помощью Lzip, бесплатного инструмента командной строки для сжатия. Он поддерживает конкатенацию для сжатия поддерживаемых файлов. LZ‑файлы имеют тип медиа application/lzip и обеспечивают более высокие коэффициенты сжатия, чем BZ2. Узнайте больше об этом формате файла здесь.
