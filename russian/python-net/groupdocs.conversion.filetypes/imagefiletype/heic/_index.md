## HEIC field

Файл HEIC — это формат изображений High‑Efficiency Container Image, который может хранить несколько изображений в виде коллекции в одном файле. Этот формат был принят Apple как вариант HEIF с выпуском iOS 11. Узнайте больше об этом формате файла здесь.
