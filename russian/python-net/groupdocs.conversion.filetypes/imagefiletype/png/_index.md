## PNG field

PNG, Portable Network Graphics, относится к типу растрового формата изображения, использующего без потерь сжатие. Этот формат был создан как замена Graphics Interchange Format (GIF) и не имеет ограничений по авторским правам. Узнайте больше об этом формате файла здесь.
