## WMZ field

Файл WMZ на самом деле является сжатой версией файла Microsoft WMF. Это позволяет более удобно распространять файл в интернете. Когда файл EWMFMF сжимается с помощью алгоритма сжатия .GZIP, ему присваивается расширение .wmz.
