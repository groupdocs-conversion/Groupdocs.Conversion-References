## SQL field

Файл с расширением .sql — это файл Structured Query Language (SQL), содержащий код для работы с реляционными базами данных. Он используется для написания SQL‑запросов для операций CRUD (Create, Read, Update, Delete) над базами данных. Узнайте больше об этом формате файла здесь.
