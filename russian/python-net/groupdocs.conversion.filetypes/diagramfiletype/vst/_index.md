## VST field

Файлы с расширением VST — это векторные изображения, созданные в Microsoft Visio и используемые в качестве шаблона для создания последующих файлов. Эти шаблонные файлы находятся в бинарном формате и содержат макет и настройки по умолчанию, используемые при создании новых чертежей Visio. Узнайте больше об этом файловом формате здесь.
