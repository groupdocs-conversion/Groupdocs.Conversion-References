## VSDX field

Файлы с расширением .VSDX представляют файловый формат Microsoft Visio, введённый, начиная с Microsoft Office 2013. Он был разработан для замены бинарного формата файлов .VSD, поддерживаемого более ранними версиями Microsoft Visio. Узнайте больше об этом файловом формате здесь.
