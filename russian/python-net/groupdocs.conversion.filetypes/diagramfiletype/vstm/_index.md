## VSTM field

Файлы с расширением VSTM — это шаблоны, созданные в Microsoft Visio с поддержкой макросов. В отличие от файлов VSDX, файлы, созданные из шаблонов VSTM, могут выполнять макросы, разработанные на языке Visual Basic for Applications (VBA). Узнайте больше об этом формате файла здесь.
