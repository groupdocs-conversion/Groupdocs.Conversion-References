## VSSM field

Файлы с расширением .VSSM — это файлы шаблонов Microsoft Visio, поддерживающие макросы. При открытии файла VSSM можно выполнять макросы для получения требуемого форматирования и размещения фигур в диаграмме. Узнайте больше об этом формате файла здесь.
