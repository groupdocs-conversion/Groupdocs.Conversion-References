## VTX field

Файл с расширением VTX — это шаблон чертежа Microsoft Visio, сохраняемый на диск в формате XML. Шаблон предназначен для предоставления файла с базовыми настройками, которые можно использовать для создания нескольких файлов Visio с одинаковыми настройками. Узнайте больше об этом формате файла здесь.
