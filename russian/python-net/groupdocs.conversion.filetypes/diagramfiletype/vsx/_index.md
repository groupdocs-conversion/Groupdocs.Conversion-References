## VSX field

Файлы с расширением .VSX относятся к шаблонам, состоящим из чертежей и фигур, используемых для создания диаграмм в Microsoft Visio. Файлы VSX сохраняются в формате XML и поддерживались до Visio 2013. Узнайте больше об этом файловом формате здесь.
