## VSTX field

Файлы с расширением VSTX — это шаблоны чертежей, созданные в Microsoft Visio 2013 и более новых версиях. Эти файлы VSTX предоставляют отправную точку для создания чертежей Visio, сохраняемых как файлы .VSDX, с макетом и настройками по умолчанию. Узнайте больше об этом формате файла здесь.
