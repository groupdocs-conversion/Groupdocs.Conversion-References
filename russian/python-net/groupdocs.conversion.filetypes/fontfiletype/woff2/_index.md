## WOFF2 field

Файл с расширением .woff — это веб‑шрифт, основанный на формате Web Open Font Format (WOFF). Он представляет собой форматно‑специфичный сжатый контейнер, основанный либо на шрифтах TrueType (.TTF), либо OpenType (.OTT). Узнайте больше об этом формате файла здесь.
