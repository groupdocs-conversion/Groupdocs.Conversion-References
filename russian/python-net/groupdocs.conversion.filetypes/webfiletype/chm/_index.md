## CHM field

Формат файла CHM представляет справочный файл Microsoft HTML, состоящий из набора HTML‑страниц. Он предоставляет индекс для быстрого доступа к темам и навигацию по различным частям справочного документа. Узнайте больше об этом файловом формате здесь.
