## PUB field

Файл PUB — это файловый формат документов Microsoft Publisher. Он используется для создания различных типов макетных документов, таких как информационные бюллетени, листовки, брошюры, открытки и т.д. Файлы PUB могут содержать текст, растровые и векторные изображения. Узнайте больше об этом файловом формате здесь.
