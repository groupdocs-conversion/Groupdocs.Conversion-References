## OLM field

Файл с расширением .olm — это файл Microsoft Outlook для операционной системы macOS. Файл OLM хранит электронные сообщения, журналы, данные календаря и другие типы данных приложений. Он аналогичен файлам PST, используемым Outlook в Windows. Однако файлы OLM, созданные Outlook для Mac, нельзя открыть в Outlook для Windows. Узнайте больше об этом формате файла здесь.
