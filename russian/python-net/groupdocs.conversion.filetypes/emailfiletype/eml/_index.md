## EML field

Формат файла EML представляет собой электронные сообщения, сохранённые с помощью Outlook и других соответствующих приложений. Практически все почтовые клиенты поддерживают этот формат файла благодаря его соответствию стандарту RFC‑822 Internet Message Format. Узнайте больше об этом формате файла здесь.
