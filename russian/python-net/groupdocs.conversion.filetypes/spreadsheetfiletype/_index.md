## SpreadsheetFileType class

Определяет документы электронных таблиц.

Включает следующие типы файлов:
- [`SpreadsheetFileType.csv`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/csv/)
- [`SpreadsheetFileType.fods`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/fods/)
- [`SpreadsheetFileType.ods`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/ods/)
- [`SpreadsheetFileType.ots`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/ots/)
- [`SpreadsheetFileType.tsv`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/tsv/)
- [`SpreadsheetFileType.xlam`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlam/)
- [`SpreadsheetFileType.xls`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xls/)
- [`SpreadsheetFileType.xlsb`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlsb/)
- [`SpreadsheetFileType.xlsm`](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlsm/)

### Поля
| Поле | Описание |
| :- | :- |
| [XLS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xls/) | XLS представляет формат Excel Binary File Format. Такие файлы могут быть созданы Microsoft Excel, а также другими аналогичными программами для электронных таблиц, такими как OpenOffice Calc или Apple Numbers. Узнайте больше об этом формате файла здесь. |
| [XLSX](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlsx/) | XLSX — известный формат документов Microsoft Excel, который был представлен Microsoft в выпуске Microsoft Office 2007. Узнайте больше об этом формате файла здесь. |
| [XLSM](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlsm/) | XLSM — тип файлов электронных таблиц, поддерживающих макросы. Узнайте больше об этом формате файла здесь. |
| [XLSB](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlsb/) | Формат файла XLSB определяет Excel Binary File Format, который представляет собой набор записей и структур, описывающих содержимое книги Excel. Узнайте больше об этом формате файла здесь. |
| [ODS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/ods/) | Файлы с расширением ODS представляют формат OpenDocument Spreadsheet Document, который может редактироваться пользователем. Данные хранятся в файле ODF в виде строк и столбцов. Узнайте больше об этом формате файла здесь. |
| [OTS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/ots/) | Файл с расширением .ots — это шаблон OpenDocument Spreadsheet, созданный с помощью программного обеспечения Calc, включённого в Apache OpenOffice. Программное обеспечение Calc аналогично Excel, доступному в Microsoft Office. Узнайте больше об этом формате файла здесь. |
| [XLTX](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xltx/) | Файл XLTX представляет шаблон Microsoft Excel, основанный на спецификациях формата файлов Office OpenXML. Он используется для создания стандартного шаблона, который может быть использован для генерации файлов XLSX с теми же настройками, указанными в файле XLTX. Узнайте больше об этом формате файла здесь. |
| [XLT](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlt/) | Файлы с расширением .XLT являются шаблонными файлами, созданными с помощью Microsoft Excel, который является приложением для работы с электронными таблицами и входит в состав пакета Microsoft Office. Microsoft Office 97-2003 поддерживал создание новых файлов XLT, а также их открытие. Узнайте больше об этом формате файла здесь. |
| [XLTM](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xltm/) | Расширение файла XLTM представляет файлы, генерируемые Microsoft Excel как шаблоны с поддержкой макросов. Файлы XLTM похожи на XLTX по структуре, за исключением того, что последние не поддерживают создание шаблонных файлов с макросами. Узнайте больше об этом формате файла здесь. |
| [TSV](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/tsv/) | Формат файлов Tab-Separated Values (TSV) представляет данные, разделённые табуляциями, в простом текстовом формате. Узнайте больше об этом формате файла здесь. |
| [XLAM](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/xlam/) | XLAM — это файл надстройки с поддержкой макросов, используемый для добавления новых функций в электронные таблицы. Надстройка — это дополнительная программа, которая выполняет дополнительный код и предоставляет расширенную функциональность для электронных таблиц. Узнайте больше об этом формате файла здесь. |
| [CSV](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/csv/) | Файлы с расширением CSV (Comma Separated Values) представляют собой простые текстовые файлы, содержащие записи данных со значениями, разделёнными запятыми. Узнайте больше об этом формате файла здесь. |
| [FODS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/fods/) | Файл с расширением .fods — это тип формата документа OpenDocument Spreadsheet, который хранит данные в строках и столбцах. Формат указан в спецификациях ODF 1.2, опубликованных и поддерживаемых OASIS. Узнайте больше об этом формате файла здесь. |
| [DIF](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/dif/) | DIF расшифровывается как Data Interchange Format и используется для импорта/экспорта данных электронных таблиц между различными приложениями. К ним относятся Microsoft Excel, OpenOffice Calc, StarCalc и многие другие. Узнайте больше об этом формате файла здесь. |
| [SXC](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/sxc/) | Формат файла SXC (Sun XML Calc) относится к офисному пакету под названием OpenOffice.org. Этот формат в целом удовлетворяет потребности пользователей в электронных таблицах, так как представляет собой основанный на XML формат файлов таблиц. Формат SXC поддерживает формулы, функции, макросы и диаграммы, а также DataPilot. Узнайте больше об этом формате файла здесь. |
| [NUMBERS](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/numbers/) | Файлы с расширением .numbers классифицируются как тип файлов электронных таблиц, поэтому они похожи на файлы .xlsx; однако файлы Numbers создаются с помощью программы Apple iWork Numbers для работы с таблицами. Узнайте больше об этом формате файла здесь. |
| [FLAT_OPC](/conversion/python-net/groupdocs.conversion.filetypes/spreadsheetfiletype/flat_opc/) | Flat OPC Excel — это Office Open XML SpreadsheetML, хранящийся в плоском XML‑файле вместо ZIP‑пакета. |
| [UNKNOWN](/conversion/python-net/groupdocs.conversion.filetypes/filetype/unknown/) | Неизвестный тип файла (унаследовано от [`FileType`](/conversion/python-net/groupdocs.conversion.filetypes/filetype/)) |
