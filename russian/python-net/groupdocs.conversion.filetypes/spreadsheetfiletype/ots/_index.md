## OTS field

Файл с расширением .ots — это шаблон OpenDocument Spreadsheet, созданный с помощью программного обеспечения Calc, включённого в Apache OpenOffice. Программное обеспечение Calc аналогично Excel, доступному в Microsoft Office. Узнайте больше об этом формате файла здесь.
