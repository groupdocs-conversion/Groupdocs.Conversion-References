## XLT field

Файлы с расширением .XLT являются шаблонными файлами, созданными с помощью Microsoft Excel, который является приложением для работы с электронными таблицами и входит в состав пакета Microsoft Office. Microsoft Office 97-2003 поддерживал создание новых файлов XLT, а также их открытие. Узнайте больше об этом формате файла здесь.
