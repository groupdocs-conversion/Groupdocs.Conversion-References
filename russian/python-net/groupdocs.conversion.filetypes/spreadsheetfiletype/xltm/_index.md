## XLTM field

Расширение файла XLTM представляет файлы, генерируемые Microsoft Excel как шаблоны с поддержкой макросов. Файлы XLTM похожи на XLTX по структуре, за исключением того, что последние не поддерживают создание шаблонных файлов с макросами. Узнайте больше об этом формате файла здесь.
