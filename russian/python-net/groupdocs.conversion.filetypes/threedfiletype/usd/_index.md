## USD field

Файл с расширением .usd — это формат Universal Scene Description, который кодирует данные для обмена и дополнения между приложениями создания цифрового контента. Разработанный Pixar, USD обеспечивает возможность обмена элементарными активами (например, моделями) или анимацией. Узнайте больше об этом формате файла здесь.
