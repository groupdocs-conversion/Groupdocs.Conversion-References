## AMF field

Файл AMF состоит из рекомендаций по описанию объектов, предназначенных для использования в процессах аддитивного производства. Он содержит открывающий тег XML и заканчивается элементом. Перед этим находится строка объявления XML, указывающая версию XML и кодировку файла. Узнайте больше об этом формате файла здесь.
