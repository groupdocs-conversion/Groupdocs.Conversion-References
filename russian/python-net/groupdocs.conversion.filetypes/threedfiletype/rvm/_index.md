## RVM field

Файлы данных RVM связаны с AVEVA PDMS. Файл RVM — это файл проекта модели системы управления проектированием заводов AVEVA (Plant Design Management System). Система управления проектированием заводов AVEVA (PDMS) является самым популярным 3D‑системой проектирования, использующей технологию, ориентированную на данные, для управления проектами.
