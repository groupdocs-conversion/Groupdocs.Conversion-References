## PLY field

PLY, Polygon File Format, представляет собой 3D‑формат, который хранит графические объекты, описанные как набор полигонов. Цель этого формата — создать простой и удобный тип файла, достаточно общий, чтобы быть полезным для широкого спектра моделей. Узнайте больше об этом формате файла здесь.
