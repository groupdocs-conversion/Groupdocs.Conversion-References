## XPS field

Файл XPS представляет собой файлы разметки страниц, основанные на XML Paper Specifications, созданных Microsoft. Этот формат был разработан Microsoft как замена формата EMF и похож на формат PDF, но использует XML для разметки, внешнего вида и информации о печати документа. Узнайте больше об этом формате файла здесь.
