## VideoFileType class

Представляет типы видеодокументов.

Включает следующие типы:
- [`VideoFileType.mp4`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mp4/)
- [`VideoFileType.avi`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/avi/)
- [`VideoFileType.flv`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/flv/)
- [`VideoFileType.mkv`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mkv/)
- [`VideoFileType.mov`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mov/)
- [`VideoFileType.webm`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/webm/)
- [`VideoFileType.wmv`](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/wmv/)

Узнайте больше о видеоформатах здесь: https://docs.fileformat.com/video/.

### Поля
| Поле | Описание |
| :- | :- |
| [MP4](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mp4/) | MP4 (сокращение от MPEG-4 Part 14) — это формат файла, основанный на ISO/IEC 14496-12:2004, который базируется на QuickTime File Format, но официально определяет поддержку Initial Object Descriptors (IOD) и других функций MPEG. Узнайте больше об этом формате файла здесь. |
| [AVI](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/avi/) | Формат файла AVI — это мультимедийный контейнер Audio Video, представленный компанией Microsoft. Он содержит аудио‑ и видеоданные, созданные и сжатые с использованием нескольких кодеков (кодировщиков/декодеров), таких как XVid и DivX. Узнайте больше об этом формате файла здесь. |
| [FLV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/flv/) | FLV (Flash Video) — это контейнерный формат файла с расширением .flv. FLV используется для доставки аудио/видео контента через интернет с помощью Adobe Flash Player или Adobe Air. Узнайте больше об этом формате файла здесь. |
| [MKV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mkv/) | MKV (Matroska Video) — это мультимедийный контейнер, похожий на форматы MOV и AVI, но поддерживающий более одной аудио‑ и субтитровой дорожки в одном файле. Файл MKV — это формат контейнера Matroska, используемый для видео. Узнайте больше об этом формате файла здесь. |
| [MOV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mov/) | MOV или QuickTime — это мультимедийный контейнер, разработанный Apple: содержит одну или несколько дорожек, каждая из которых хранит определённый тип данных, например видео, аудио, текст и т.д. Узнайте больше об этом формате файла здесь. |
| [WEBM](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/webm/) | Файл с расширением .webm — это видеофайл, основанный на открытом, не требующем роялти формате WebM. Он разработан для обмена видео в интернете и определяет структуру контейнера файла, включая видео и аудио форматы. Узнайте больше об этом формате файла здесь. |
| [WMV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/wmv/) | Windows Media Video — это сжатый видеоформат, разработанный Microsoft. После стандартизации Обществом инженеров кино и телевидения (SMPTE) WMV теперь считается открытым стандартным форматом. Узнайте больше об этом формате файла здесь. |
