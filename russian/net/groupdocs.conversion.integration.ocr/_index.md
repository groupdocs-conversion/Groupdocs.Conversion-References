Пространство имён предоставляет интерфейсы и классы, необходимые для поддержки оптического распознавания символов (OCR).

## Классы

| Класс | Описание |
| --- | --- |
| [RecognizedImage](./recognizedimage) | Представляет текст, извлечённый из изображения в результате процесса распознавания. |
| [TextFragment](./textfragment) | Представляет часть распознанного текста (слово, символ и т.д.), извлечённую OCR‑движком. |
| [TextLine](./textline) | Представляет текст, извлечённый из изображения в результате процесса распознавания. |
## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IOcrConnector](./iocrconnector) | Определяет методы, необходимые для применения OCR к документам‑изображениям и встроенным изображениям. |
