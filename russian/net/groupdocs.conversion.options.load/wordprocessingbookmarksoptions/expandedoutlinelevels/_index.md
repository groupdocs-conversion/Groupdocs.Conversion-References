## WordProcessingBookmarksOptions.ExpandedOutlineLevels property

Указывает, сколько уровней в структуре документа будет развернуто при просмотре файла. По умолчанию 0. Допустимый диапазон от 0 до 9. Обратите внимание, что эта опция не будет работать при сохранении в XPS.

```csharp
public int ExpandedOutlineLevels { get; set; }
```
