## VectorizationOptions.ImageSizeLimit property

Получает или задаёт максимальное измерение изображения, определяемое произведением ширины и высоты изображения. Размер изображения будет масштабироваться на основе этого свойства. Значение по умолчанию — 1800000.

```csharp
public int ImageSizeLimit { get; set; }
```
