## SpreadsheetLoadOptions.AllColumnsInOnePagePerSheet property

Если параметр AllColumnsInOnePagePerSheet установлен в true, всё содержимое столбцов одного листа будет выводиться на одну страницу в результате. Ширина размера бумаги в настройках страницы (pagesetup) станет недействительной, а остальные параметры pagesetup по‑прежнему будут применяться.

```csharp
public bool AllColumnsInOnePagePerSheet { get; set; }
```
