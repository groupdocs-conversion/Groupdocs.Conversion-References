## SpreadsheetLoadOptions.IgnoreFormulaCalculationErrors property

Указывает, следует ли игнорировать ошибки вычисления формул. Ошибка может быть вызвана неподдерживаемой функцией, внешними ссылками и т.д. По умолчанию false.

```csharp
public bool IgnoreFormulaCalculationErrors { get; set; }
```
