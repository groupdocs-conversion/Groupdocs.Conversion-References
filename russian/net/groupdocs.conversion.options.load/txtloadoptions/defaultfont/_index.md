## TxtLoadOptions.DefaultFont property

Шрифт, используемый при отображении содержимого простого текста во время конвертации. Поскольку TXT‑файлы не содержат информацию о шрифте, это свойство указывает шрифт отображения для текстового содержимого. По умолчанию: Arial 10pt.

```csharp
public Font DefaultFont { get; set; }
```
