## PageLayoutOptions.ScaleToPageHeight field

Этот флаг указывает, что содержимое документа будет масштабировано до высоты первой страницы. Всё содержимое документа будет размещено только на одной странице.

```csharp
public static readonly PageLayoutOptions ScaleToPageHeight;
```
