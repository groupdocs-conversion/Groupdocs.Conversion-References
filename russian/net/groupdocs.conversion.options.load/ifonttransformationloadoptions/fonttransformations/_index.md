## IFontTransformationLoadOptions.FontTransformations property

Преобразовать существующие шрифты после загрузки документа и замены шрифтов. Преобразования применяются в том порядке, в котором они указаны в списке. Используйте это для стилизации, брендинга или изменения шрифтов в целях доступности.

```csharp
public IList<FontTransformation> FontTransformations { get; set; }
```
