## GmlLoadOptions.LoadSchemasFromInternet property

Определяет, разрешено ли Conversion загружать XML‑схему из Интернета. Если установлено false, схемы с абсолютными URI, которые не начинаются с ‘file://’, не будут загружаться. По умолчанию false.

```csharp
public bool LoadSchemasFromInternet { get; set; }
```
