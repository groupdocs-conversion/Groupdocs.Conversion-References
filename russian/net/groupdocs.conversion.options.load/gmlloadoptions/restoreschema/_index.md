## GmlLoadOptions.RestoreSchema property

Определяет, разрешено ли Conversion разбирать атрибуты в файле Gml, когда XML‑схема отсутствует или не может быть загружена. Если установлено true, чтение Conversion не требует наличия XML‑схемы. По умолчанию false.

```csharp
public bool RestoreSchema { get; set; }
```
