## WebLoadOptions.Zoom property

Указывает уровень масштабирования в процентах. Уровень масштабирования применяется к тегу &lt;body&gt; документа перед конвертацией, изменяя визуальное отображение документа. Значение 100 % соответствует оригинальному размеру. Значение по умолчанию — 100.

public int Zoom { get; set; }
