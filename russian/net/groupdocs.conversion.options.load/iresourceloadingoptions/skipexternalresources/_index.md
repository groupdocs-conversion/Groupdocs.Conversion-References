## IResourceLoadingOptions.SkipExternalResources property

Если true, все внешние ресурсы не будут загружаться, за исключением тех, что находятся в списке [`WhitelistedResources`](../whitelistedresources). По умолчанию: true.

```csharp
public bool SkipExternalResources { get; set; }
```
