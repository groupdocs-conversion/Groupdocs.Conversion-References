## PageDescriptionLanguageConvertOptions.Width property

Желаемая ширина страницы после конвертации, в независимых от устройства пикселях размером 1/96 дюйма каждый. Оставьте 0, чтобы целевой объект сохранял ширину страницы, которую он определит самостоятельно.

public int Width { get; set; }
