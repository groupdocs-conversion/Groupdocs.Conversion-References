## PageDescriptionLanguageConvertOptions.Height property

Желаемая высота страницы после конвертации, в независимых от устройства пикселях размером 1/96 дюйма каждый. Оставьте 0, чтобы целевой объект сохранял высоту страницы, которую он определит самостоятельно.

```csharp
public int Height { get; set; }
```
