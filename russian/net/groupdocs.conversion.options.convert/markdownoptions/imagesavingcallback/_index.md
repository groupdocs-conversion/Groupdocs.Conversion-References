## MarkdownOptions.ImageSavingCallback property

Обратный вызов, вызываемый один раз для каждого изображения при сохранении Markdown. Позволяет вызывающему сохранять изображения внешне и заменять URI, встроенный в документ. Имеет приоритет над [`ExportImagesAsBase64`](../exportimagesasbase64), если не null.

```csharp
public IMarkdownImageSavingCallback ImageSavingCallback { get; set; }
```
