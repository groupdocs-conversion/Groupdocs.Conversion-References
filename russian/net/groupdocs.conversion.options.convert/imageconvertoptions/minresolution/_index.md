## ImageConvertOptions.MinResolution property

Нижняя граница по каждой оси, применяемая к ограниченному DPI рендеринга, когда включён [`CapResolutionToPageContent`](../capresolutiontopagecontent). Ограниченный DPI никогда не опускается ниже этого значения. По умолчанию `0` (без ограничения).

```csharp
public int MinResolution { get; set; }
```
