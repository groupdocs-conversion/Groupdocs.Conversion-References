## WebConvertOptions.EmbedFontResources property

Указывает, следует ли внедрять ресурсы шрифтов в основной HTML. По умолчанию false. Примечание: если FixedLayout установлено в true, ресурсы шрифтов всегда будут внедрены.

```csharp
public bool EmbedFontResources { get; set; }
```
