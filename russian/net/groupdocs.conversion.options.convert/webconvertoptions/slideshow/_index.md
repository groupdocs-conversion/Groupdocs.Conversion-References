## WebConvertOptions.SlideShow property

Применяется только при конвертации презентации в [`Html`](../../../groupdocs.conversion.filetypes/webfiletype/html) или [`Htm`](../../../groupdocs.conversion.filetypes/webfiletype/htm) и игнорируется для всех остальных конвертаций. Указывает, будет ли презентация интерактивным HTML‑слайдшоу с переходами слайдов и анимацией фигур вместо стандартной статической HTML‑страницы. По умолчанию false.

```csharp
public bool SlideShow { get; set; }
```

### Примечания

Результатом является один HTML‑файл со встроенными стилями, скриптами, изображениями, шрифтами и медиа. Две JavaScript‑библиотеки, управляющие слайдшоу, загружаются из CDN, поэтому странице требуется подключение к интернету для анимации и навигации.
