## VideoFileType class

Определяет видеодокументы. Включает следующие типы: [`Mp4`](./mp4), [`Avi`](./avi), [`Flv`](./flv), [`Mkv`](./mkv), [`Mov`](./mov), [`Webm`](./webm), [`Wmv`](./wmv). Узнайте больше о видеоформатах [здесь](https://docs.fileformat.com/video/).

```csharp
public sealed class VideoFileType : FileType
```

Узнайте больше о этом формате файла [здесь](https://docs.fileformat.com/video/mp4/). |
