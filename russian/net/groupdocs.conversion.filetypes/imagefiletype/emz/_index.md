## ImageFileType.Emz field

Файл EMZ на самом деле является сжатой версией файла Microsoft EMF. Это упрощает распространение файла в сети. Когда файл EMF сжимается с помощью алгоритма сжатия .GZIP, ему присваивается расширение .emz.

public static readonly ImageFileType Emz;
