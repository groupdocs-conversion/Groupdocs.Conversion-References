## ImageFileType.Cdr field

Файл CDR — это векторный графический файл, который изначально создаётся в CorelDRAW для хранения цифрового изображения, закодированного и сжатого. Такой файл рисунка содержит текст, линии, формы, изображения, цвета и эффекты для векторного представления содержимого изображения. Узнайте больше о этом формате файла [здесь](https://wiki.fileformat.com/image/cdr).
