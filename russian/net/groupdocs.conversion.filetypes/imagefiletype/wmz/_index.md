## ImageFileType.Wmz field

Файл WMZ на самом деле является сжатой версией файла Microsoft WMF. Это упрощает распространение файла в сети. Когда файл EWMFMF сжимается с помощью алгоритма сжатия .GZIP, ему присваивается расширение .wmz.

public static readonly ImageFileType Wmz;
