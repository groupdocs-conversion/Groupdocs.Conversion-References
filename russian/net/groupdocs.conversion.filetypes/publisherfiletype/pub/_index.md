## PublisherFileType.Pub field

Файл PUB — это формат документа Microsoft Publisher. Он используется для создания различных типов макетов, таких как информационные бюллетени, листовки, брошюры, открытки и т.д. Файлы PUB могут содержать текст, растровые и векторные изображения. Узнайте больше о этом формате файла [здесь](https://docs.fileformat.com/publisher/pub/).

public static readonly PublisherFileType Pub;
