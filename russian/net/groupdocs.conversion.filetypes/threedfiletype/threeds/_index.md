## ThreeDFileType.ThreeDS field

Файл с расширением .3ds представляет собой формат файлов сетки 3D Studio (DOS), используемый Autodesk 3D Studio. Autodesk 3D Studio присутствует на рынке 3D‑форматов файлов с 1990‑х годов и теперь эволюционировал в 3D Studio MAX для работы с 3D‑моделированием, анимацией и рендерингом. Узнайте больше о этом формате файла [здесь](https://docs.fileformat.com/3d/3ds).

public static readonly ThreeDFileType ThreeDS;
