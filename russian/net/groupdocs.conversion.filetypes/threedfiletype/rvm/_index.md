## ThreeDFileType.Rvm field

Файлы данных RVM связаны с AVEVA PDMS. Файл RVM — это проектный файл модели системы управления проектированием заводов AVEVA (Plant Design Management System). Система управления проектированием заводов AVEVA (PDMS) является самым популярным 3D‑системой проектирования, использующей технологию, ориентированную на данные, для управления проектами. Узнайте больше о этом формате файла [здесь](https://docs.fileformat.com/3d/rvm).

public static readonly ThreeDFileType Rvm;
