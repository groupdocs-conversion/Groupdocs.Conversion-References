## ThreeDFileType.Amf field

Файл AMF состоит из рекомендаций по описанию объектов для использования в процессах аддитивного производства. Он содержит открывающий тег XML и заканчивается элементом. Перед этим находится строка декларации XML, указывающая версию XML и кодировку файла. Узнайте больше об этом формате файла [здесь](https://docs.fileformat.com/3d/amf).

public static readonly ThreeDFileType Amf;
