## PageDescriptionLanguageFileType.Xps field

Файл XPS представляет файлы разметки страниц, основанные на спецификации XML Paper, созданной Microsoft. Этот формат был разработан Microsoft как замена формата EMF и похож на формат PDF, но использует XML для описания макета, внешнего вида и параметров печати документа. Узнайте больше об этом формате файла [здесь](https://wiki.fileformat.com/page-description-language/xps).

public static readonly PageDescriptionLanguageFileType Xps;
