## PageDescriptionLanguageFileType.Svgz field

Файл SVGZ фактически представляет собой сжатую версию файла SVG. Это упрощает распространение файла в сети. Когда файл SVG сжимается с помощью алгоритма сжатия .GZIP, ему присваивается расширение .svgz.

public static readonly PageDescriptionLanguageFileType Svgz;
