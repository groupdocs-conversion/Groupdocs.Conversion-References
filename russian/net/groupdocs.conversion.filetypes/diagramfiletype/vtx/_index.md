## DiagramFileType.Vtx field

Файл с расширением VTX — это шаблон чертежа Microsoft Visio, сохраняемый на диск в формате XML. Шаблон предназначен для предоставления файла с базовыми настройками, которые можно использовать для создания нескольких файлов Visio с одинаковыми параметрами. Узнайте больше о этом формате файлов [здесь](https://wiki.fileformat.com/image/vtx).
