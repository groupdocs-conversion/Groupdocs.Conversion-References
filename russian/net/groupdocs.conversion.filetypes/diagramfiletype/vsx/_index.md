## DiagramFileType.Vsx field

Файлы с расширением .VSX относятся к шаблонам, содержащим чертежи и фигуры, используемые для создания диаграмм в Microsoft Visio. Файлы VSX сохраняются в формате XML и поддерживались до Visio 2013. Узнайте больше о этом формате файлов [здесь](https://wiki.fileformat.com/image/vsx).

public static readonly DiagramFileType Vsx;
