## DiagramFileType.Vsdx field

Файлы с расширением .VSDX представляют формат файлов Microsoft Visio, введённый, начиная с Microsoft Office 2013. Он был разработан для замены бинарного формата файлов .VSD, поддерживаемого более ранними версиями Microsoft Visio. Узнайте больше о этом формате файлов [здесь](https://wiki.fileformat.com/image/vsdx).

public static readonly DiagramFileType Vsdx;
