## CompressionFileType.Lz4 field

Файл с расширением .lz4 — это сжатый архив, созданный приложениями/утилитами, поддерживающими сжатие L4. Алгоритм LZ4 ориентирован на компромисс между скоростью и коэффициентом сжатия. Сжатые архивы LZ4 можно создавать с помощью утилиты командной строки LZ4 и распаковывать её же. Узнайте больше об этом формате файла [здесь](https://docs.fileformat.com/compression/lz4/).

```csharp
public static readonly CompressionFileType Lz4;
```
