## FontFileType.Woff field

Файл с расширением .woff — это веб‑шрифт, основанный на формате Web Open Font Format (WOFF). Он представляет собой специфичный для формата сжатый контейнер, основанный либо на TrueType (.TTF), либо на OpenType (.OTT) типах шрифтов. Узнайте больше об этом формате файла [здесь](https://docs.fileformat.com/font/woff/).
