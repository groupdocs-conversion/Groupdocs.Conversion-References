## FontFileType.Ttf field

Файл с расширением .ttf представляет собой шрифтовые файлы, основанные на технологии шрифтов TrueType. Изначально он был разработан и выпущен компанией Apple Computer, Inc для Mac OS, а позже принят Microsoft для Windows OS. Узнайте больше об этом формате файла [здесь](https://docs.fileformat.com/font/ttf/).
