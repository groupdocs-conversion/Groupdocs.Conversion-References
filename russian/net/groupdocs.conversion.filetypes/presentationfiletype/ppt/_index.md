## PresentationFileType.Ppt field

Файл с расширением PPT представляет файл PowerPoint, содержащий коллекцию слайдов для отображения в виде слайд-шоу. Он определяет двоичный формат файла, используемый Microsoft PowerPoint 97‑2003. Узнайте больше об этом формате файлов [здесь](https://wiki.fileformat.com/presentation/ppt).
