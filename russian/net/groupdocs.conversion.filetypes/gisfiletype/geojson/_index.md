## GisFileType.GeoJson field

GeoJSON — это основанный на JSON формат, предназначенный для представления географических объектов с их не пространственными атрибутами. Этот формат определяет различные объекты JSON (JavaScript Object Notation) и способ их объединения. Формат JSON представляет совокупную информацию о географических объектах, их пространственных охватах и свойствах. Узнайте больше об этом формате файла [здесь](https://docs.fileformat.com/gis/geojson/).
