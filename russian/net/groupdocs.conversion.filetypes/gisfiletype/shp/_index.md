## GisFileType.Shp field

SHP — это расширение файла для одного из основных типов файлов, используемых для представления ESRI Shapefile. Он представляет геопространственную информацию в виде векторных данных, которые могут использоваться приложениями Geographic Information Systems (GIS). Узнайте больше о этом формате файлов [здесь](https://docs.fileformat.com/gis/shp/).
