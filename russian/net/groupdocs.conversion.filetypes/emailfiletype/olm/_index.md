## EmailFileType.Olm field

Файл с расширением .olm — это файл Microsoft Outlook для операционной системы macOS. Файл OLM хранит сообщения электронной почты, журналы, данные календаря и другие типы данных приложения. Они похожи на файлы PST, используемые Outlook в операционной системе Windows. Однако файлы OLM, созданные Outlook для Mac, нельзя открыть в Outlook для Windows. Узнайте больше об этом формате файла [здесь](https://wiki.fileformat.com/email/olm).
