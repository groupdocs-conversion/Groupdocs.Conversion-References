## FontSubstitutionContext.Reason property

Сообщение о замене точно так, как оно было сообщено конверсионным конвейером, дословно и без разбора. Для документов, которые структурно раскрывают имена шрифтов, это может быть `null` (используйте [`OriginalFontName`](../originalfontname) / [`SubstituteFontName`](../substitutefontname)); для остальных оно содержит полное человекочитаемое описание, в котором указаны как отсутствующий, так и заменяющий шрифт.

```csharp
public string Reason { get; }
```
