## FontTransformation.MatchAnyStyle property

Если true, сопоставляет любой стиль шрифта (жирный, курсив, подчеркивание) для оригинального шрифта. Если false, сопоставляет точный стиль шрифта, указанный в OriginalFont.

public bool MatchAnyStyle { get; }
