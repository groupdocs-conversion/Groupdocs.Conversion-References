Пространство имён предоставляет классы для преобразования документов во все популярные форматы файлов простым и интуитивным способом.

## Классы

| Класс | Описание |
| --- | --- |
| [ConversionEvents](./conversionevents) | Агрегирует обработчики событий жизненного цикла конверсии. Передайте экземпляр в конструктор [`Converter`](../groupdocs.conversion/converter) параметр `events` или во fluent‑метод `WithEvents`. Предпочтите это вместо отдельных свойств обработчиков [`ConverterSettings`](../groupdocs.conversion/convertersettings), которые устарели. |
| [ConvertContext](./convertcontext) | Определяет контекст конверсии. |
| [ConvertedContext](./convertedcontext) | Определяет контекст конверсии. |
| [ConvertedPageContext](./convertedpagecontext) | Определяет контекст страницы конверсии. |
| [Converter](./converter) | Представляет основной класс, который управляет процессом конверсии документов. |
| [ConverterSettings](./convertersettings) | Определяет настройки для настройки поведения [`Converter`](../groupdocs.conversion/converter). |
| [FluentConverter](./fluentconverter) | Класс для fluent‑настройки конверсии. |
| [License](./license) | Предоставляет методы для лицензирования компонента. Узнайте больше о лицензировании [здесь](https://purchase.groupdocs.com/faqs/licensing). |
| [LoadContext](./loadcontext) | Определяет контекст загрузки. |
| [Metered](./metered) | Предоставляет методы для применения лицензии [Metered](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SaveContext](./savecontext) | Определяет контекст сохранения. |
| [SavePageContext](./savepagecontext) | Определяет контекст страницы сохранения. |
