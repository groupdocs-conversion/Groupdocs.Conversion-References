## EvaluationLimitReachedException class

Исключение GroupDocs, выброшенное, когда лимит оценочной конвертации для текущего процесса исчерпан.

```csharp
public sealed class EvaluationLimitReachedException : GroupDocsConversionException
```

### Примечания

Выбрасывается только без лицензии. Применение лицензии сбрасывает ограничение, поэтому процесс с лицензией никогда не сталкивается с этим исключением, независимо от количества конвертируемых документов.
