
## Методы

| Имя | Описание |
| --- | --- |
| [Error](../../groupdocs.conversion.logging/ilogger/error)(string, Exception) | Записывает сообщение об ошибке в журнал; сообщения об ошибках предоставляют информацию о непоправимых событиях в потоке приложения. |
