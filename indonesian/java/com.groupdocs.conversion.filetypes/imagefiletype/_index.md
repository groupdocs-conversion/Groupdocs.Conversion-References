TIFF, Tagged Image File Format, mewakili gambar raster yang dimaksud untuk digunakan pada berbagai perangkat yang mematuhi standar format file ini. Format ini mampu menggambarkan data gambar blevel, skala abu-abu, palet-warna, dan warna penuh dalam beberapa ruang warna.
Pelajari lebih lanjut tentang format file ini [di sini](../https://wiki.fileformat.com/image/tiff).

### Gif {#Gif}

GIF atau Graphical Interchange Format adalah jenis gambar yang sangat terkompresi. Untuk setiap gambar, GIF biasanya memungkinkan hingga 8 bit per piksel dan hingga 256 warna diizinkan di seluruh gambar.
Pelajari lebih lanjut tentang format file ini [di sini](../https://wiki.fileformat.com/image/gif).
