## GEO_JSON field

GeoJSON adalah format berbasis JSON yang dirancang untuk merepresentasikan fitur geografis beserta atribut non-spasialnya. Format ini mendefinisikan berbagai objek JSON (JavaScript Object Notation) dan cara penggabungannya. Format JSON menyajikan informasi kolektif tentang fitur geografis, ekstensi spasial, dan properti mereka. Pelajari lebih lanjut tentang format file ini di sini.
