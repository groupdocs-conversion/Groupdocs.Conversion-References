## GDB field

Geodatabase file ESRI (FileGDB) adalah kumpulan file dalam sebuah folder di disk yang menyimpan data geospasial terkait seperti dataset fitur, kelas fitur, dan tabel terkait. Dibutuhkan beberapa file lain yang disimpan bersama file .gdb di direktori yang sama agar dapat berfungsi. Pelajari lebih lanjut tentang format file ini di sini.
