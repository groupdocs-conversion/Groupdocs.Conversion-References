## WOFF field

File dengan ekstensi .woff adalah file font web yang berbasis pada Web Open Font Format (WOFF). File ini memiliki wadah terkompresi khusus format yang berbasis pada jenis font TrueType (.TTF) atau OpenType (.OTT). Pelajari lebih lanjut tentang format file ini di sini.
