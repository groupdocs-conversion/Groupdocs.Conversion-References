## OTF field

File dengan ekstensi .otf mengacu pada format font OpenType. Format font OTF lebih skalabel dan memperluas fitur yang ada pada format TTF untuk tipografi digital. Dikembangkan oleh Microsoft dan Adobe, OTF menggabungkan fitur-fitur format font PostScript dan TrueType. Pelajari lebih lanjut tentang format file ini di sini.
