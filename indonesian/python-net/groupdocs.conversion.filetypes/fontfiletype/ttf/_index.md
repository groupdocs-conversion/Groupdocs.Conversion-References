## TTF field

File dengan ekstensi .ttf mewakili file font yang berbasis pada teknologi font spesifikasi TrueType. File ini awalnya dirancang dan diluncurkan oleh Apple Computer, Inc untuk Mac OS dan kemudian diadopsi oleh Microsoft untuk Windows OS. Pelajari lebih lanjut tentang format file ini di sini.
