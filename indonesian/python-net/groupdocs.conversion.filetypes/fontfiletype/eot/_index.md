## EOT field

File dengan ekstensi .eot adalah font OpenType yang disematkan dalam sebuah dokumen. Font ini sebagian besar digunakan dalam file web seperti halaman Web. Font ini dibuat oleh Microsoft dan didukung oleh Produk Microsoft termasuk file presentasi PowerPoint .pps. Pelajari lebih lanjut tentang format file ini di sini.
