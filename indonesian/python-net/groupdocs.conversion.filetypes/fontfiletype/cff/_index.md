## CFF field

File dengan ekstensi .cff adalah Compact Font Format dan juga dikenal sebagai PostScript Type 1, atau CIDFont. CFF berfungsi sebagai wadah untuk menyimpan beberapa font bersama dalam satu unit yang disebut FontSet. Pelajari lebih lanjut tentang format file ini di sini.
