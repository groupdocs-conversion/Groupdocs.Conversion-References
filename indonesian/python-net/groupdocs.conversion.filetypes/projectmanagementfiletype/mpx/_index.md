## MPX field

Microsoft Exchange File Format adalah format file ASCII untuk mentransfer informasi proyek antara Microsoft Project (MSP) dan aplikasi lain yang mendukung format file MPX seperti Primavera Project Planner, Sciforma, dan Timerline Precision Estimating. Pelajari lebih lanjut tentang format file ini di sini.
