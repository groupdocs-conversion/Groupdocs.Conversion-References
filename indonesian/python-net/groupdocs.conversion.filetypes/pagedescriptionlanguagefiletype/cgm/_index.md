## CGM field

Computer Graphics Metafile (CGM) adalah format metafile standar internasional yang gratis, lintas platform, untuk menyimpan dan bertukar grafik vektor (2D), grafik raster, dan teks. CGM menggunakan pendekatan berorientasi objek dan banyak fungsi untuk produksi gambar. Pelajari lebih lanjut tentang format file ini di sini.
