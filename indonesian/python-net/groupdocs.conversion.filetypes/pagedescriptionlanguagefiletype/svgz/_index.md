## SVGZ field

File SVGZ sebenarnya adalah versi terkompresi dari file SVG. Ini memungkinkan distribusi file yang lebih mudah secara online. Ketika file SVG dikompresi menggunakan algoritma kompresi .GZIP, maka diberikan ekstensi file .svgz.
