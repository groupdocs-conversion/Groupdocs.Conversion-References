## SQL field

File dengan ekstensi .sql adalah file Structured Query Language (SQL) yang berisi kode untuk bekerja dengan basis data relasional. File ini digunakan untuk menulis pernyataan SQL untuk operasi CRUD (Create, Read, Update, and Delete) pada basis data. Pelajari lebih lanjut tentang format file ini di sini.
