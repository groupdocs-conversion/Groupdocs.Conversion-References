### Bidang
| Bidang | Deskripsi |
| :- | :- |
| [NSF](/conversion/python-net/groupdocs.conversion.filetypes/databasefiletype/nsf/) | File dengan ekstensi .nsf (Notes Storage Facility) adalah format file basis data yang digunakan oleh perangkat lunak IBM Notes, yang sebelumnya dikenal sebagai Lotus Notes. File ini mendefinisikan skema untuk menyimpan berbagai jenis objek seperti email, janji temu, dokumen, formulir, dan tampilan. Pelajari lebih lanjut tentang format file ini di sini. |
| [LOG](/conversion/python-net/groupdocs.conversion.filetypes/databasefiletype/log/) | File dengan ekstensi .log berisi daftar teks polos dengan cap waktu. Biasanya, detail aktivitas tertentu dicatat oleh perangkat lunak atau sistem operasi untuk membantu pengembang atau pengguna melacak apa yang terjadi pada periode waktu tertentu. Pelajari lebih lanjut tentang format file ini di sini. |
| [SQL](/conversion/python-net/groupdocs.conversion.filetypes/databasefiletype/sql/) | File dengan ekstensi .sql adalah file Structured Query Language (SQL) yang berisi kode untuk bekerja dengan basis data relasional. File ini digunakan untuk menulis pernyataan SQL untuk operasi CRUD (Create, Read, Update, and Delete) pada basis data. Pelajari lebih lanjut tentang format file ini di sini. |
| [UNKNOWN](/conversion/python-net/groupdocs.conversion.filetypes/filetype/unknown/) | Tipe file tidak diketahui (diturunkan dari [`FileType`](/conversion/python-net/groupdocs.conversion.filetypes/filetype/)) |
