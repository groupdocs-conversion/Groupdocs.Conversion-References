## LOG field

File dengan ekstensi .log berisi daftar teks polos dengan cap waktu. Biasanya, detail aktivitas tertentu dicatat oleh perangkat lunak atau sistem operasi untuk membantu pengembang atau pengguna melacak apa yang terjadi pada periode waktu tertentu. Pelajari lebih lanjut tentang format file ini di sini.
