## DNG field

DNG adalah format gambar kamera digital yang digunakan untuk penyimpanan file mentah. Format ini dikembangkan oleh Adobe pada September 2004. Pada dasarnya dikembangkan untuk fotografi digital. Pelajari lebih lanjut tentang format file ini di sini.
