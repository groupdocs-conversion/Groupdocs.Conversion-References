## EMF field

Format metafile yang ditingkatkan (EMF) menyimpan gambar grafis secara independen dari perangkat. Metafile EMF terdiri dari rekaman berukuran variabel secara berurutan kronologis yang dapat menampilkan gambar yang disimpan setelah diparsing pada perangkat output apa pun. Pelajari lebih lanjut tentang format file ini di sini.
