## WEBP field

WebP, yang diperkenalkan oleh Google, adalah format file gambar raster web modern yang berbasis pada kompresi lossless dan lossy. Format ini memberikan kualitas gambar yang sama sambil secara signifikan mengurangi ukuran gambar. Pelajari lebih lanjut tentang format file ini di sini.
