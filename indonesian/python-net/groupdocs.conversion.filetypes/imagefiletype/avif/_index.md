## AVIF field

AVIF (AV1 Image File Format) adalah format file gambar yang menyimpan gambar yang dikompresi dengan AV1 dalam format file HEIF. File AVIF disimpan dengan ekstensi .avif. Versi 1 AVIF diselesaikan pada Februari 2019. Ia memiliki fitur seperti High Dynamic Range (HDR), dukungan untuk kedalaman warna 8, 10, dan 12, dukungan untuk ruang warna apa pun (ISO/IEC CICP dan profil ICC, gamut warna luas), dll. Pelajari lebih lanjut tentang format file ini di sini.
