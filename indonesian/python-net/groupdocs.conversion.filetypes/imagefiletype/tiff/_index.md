## TIFF field

TIFF, Tagged Image File Format, mewakili gambar raster yang ditujukan untuk digunakan pada berbagai perangkat yang mematuhi standar format file ini. TIFF mampu menggambarkan data gambar blevel, skala abu-abu, warna palet, dan warna penuh dalam beberapa ruang warna. Pelajari lebih lanjut tentang format file ini di sini.
