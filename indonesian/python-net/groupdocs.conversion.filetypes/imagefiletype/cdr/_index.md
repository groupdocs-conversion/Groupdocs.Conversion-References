## CDR field

File CDR adalah file gambar vektor yang secara asli dibuat dengan CorelDRAW untuk menyimpan gambar digital yang terkodekan dan terkompresi. File gambar tersebut berisi teks, garis, bentuk, gambar, warna, dan efek untuk representasi vektor dari konten gambar. Pelajari lebih lanjut tentang format file ini di sini.
