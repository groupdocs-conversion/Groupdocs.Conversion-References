## ISO field

File dengan ekstensi .iso adalah file gambar disk arsip yang tidak terkompresi yang mewakili isi seluruh data pada disc optik seperti CD atau DVD. Berdasarkan standar ISO-9660, format file gambar ISO berisi data disc beserta informasi sistem berkas yang disimpan di dalamnya. Pelajari lebih lanjut tentang format file ini di sini.
