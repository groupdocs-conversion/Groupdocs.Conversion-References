## BZ2 field

BZ2 adalah file terkompresi yang dihasilkan menggunakan metode kompresi open source BZIP2, biasanya pada sistem UNIX atau Linux. Metode ini digunakan untuk mengompresi satu file dan tidak dimaksudkan untuk mengarsipkan banyak file. Pelajari lebih lanjut tentang format file ini di sini.
