## LHA field

File dengan ekstensi .lzh dan .lha biasanya terkait dengan format file kompresi arsip. Format file ini sama dengan format kompresi file lainnya seperti ZIP, RAR, dll. Tujuan utama format ini adalah mengurangi ukuran file agar mudah dikirim serta menyimpannya dalam bentuk terkompresi.
