## LZ4 field

File dengan ekstensi .lz4 adalah file arsip terkompresi yang dibuat dengan aplikasi/utilitas yang mendukung kompresi LZ4. Algoritma LZ4 menekankan keseimbangan antara kecepatan dan rasio kompresi. Arsip LZ4 terkompresi dapat dibuat menggunakan utilitas baris perintah LZ4 dan dapat didekompresi dengan utilitas yang sama. Pelajari lebih lanjut tentang format file ini di sini.
