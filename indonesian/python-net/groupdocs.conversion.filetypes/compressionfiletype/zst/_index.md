## ZST field

File ZST adalah file terkompresi yang dihasilkan dengan algoritma kompresi Zstandard (zstd). Ini adalah file terkompresi yang dibuat dengan kompresi lossless oleh algoritma tersebut. Pelajari lebih lanjut tentang format file ini di sini.
