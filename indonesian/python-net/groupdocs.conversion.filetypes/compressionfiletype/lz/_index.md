## LZ field

File dengan ekstensi .lz adalah file arsip terkompresi yang dibuat dengan Lzip, yaitu alat baris perintah gratis untuk kompresi. Ia mendukung penggabungan untuk mengompresi file pendukung. File LZ memiliki tipe media application/lzip dan mendukung rasio kompresi yang lebih tinggi dibandingkan BZ2. Pelajari lebih lanjut tentang format file ini di sini.
