## ZIP field

File dengan ekstensi .zip adalah arsip yang dapat menampung satu atau lebih file atau direktori. Arsip dapat diberi kompresi pada file yang termasuk untuk mengurangi ukuran file ZIP. Pelajari lebih lanjut tentang format file ini di sini.
