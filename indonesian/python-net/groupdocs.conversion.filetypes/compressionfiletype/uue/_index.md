## UUE field

Arsip uuencoded adalah file atau kumpulan file yang telah dienkode menggunakan skema enkoding Unix-to-Unix (uuencode). Metode enkoding ini mengubah data biner menjadi format teks, sehingga lebih mudah mengirim file melalui saluran yang hanya mendukung teks, seperti email.
