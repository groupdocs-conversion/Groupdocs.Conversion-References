## SEVEN_Z field

7z adalah format pengarsipan untuk mengompresi file dan folder dengan rasio kompresi tinggi. Format ini berbasis arsitektur Open Source yang memungkinkan penggunaan algoritma kompresi dan enkripsi apa pun. Pelajari lebih lanjut tentang format file ini di sini.
