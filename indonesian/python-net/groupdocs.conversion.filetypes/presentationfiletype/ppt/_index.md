## PPT field

File dengan ekstensi PPT mewakili file PowerPoint yang terdiri dari kumpulan slide untuk ditampilkan sebagai SlideShow. File ini menggunakan Binary File Format yang dipakai oleh Microsoft PowerPoint 97-2003. Pelajari lebih lanjut tentang format file ini di sini.
