## POTM field

File dengan ekstensi POTM adalah file templat Microsoft PowerPoint yang mendukung Makro. File POTM dibuat dengan PowerPoint 2007 atau lebih tinggi dan berisi pengaturan default yang dapat digunakan untuk membuat file presentasi selanjutnya. Pelajari lebih lanjut tentang format file ini di sini.
