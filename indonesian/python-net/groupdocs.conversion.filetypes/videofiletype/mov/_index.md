## MOV field

Format file MOV atau QuickTime adalah kontainer multimedia yang dikembangkan oleh Apple: berisi satu atau lebih trek, setiap trek menyimpan jenis data tertentu yaitu Video, Audio, teks, dll. Pelajari lebih lanjut tentang format file ini di sini.
