## AVI field

Format file AVI adalah format kontainer multimedia Audio Video yang diperkenalkan oleh Microsoft. Format ini menyimpan data audio dan video yang dibuat dan dikompresi menggunakan beberapa codec (Pengode/Pengurai) seperti XVid dan DivX. Pelajari lebih lanjut tentang format file ini di sini.
