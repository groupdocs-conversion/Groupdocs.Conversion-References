## MP4 field

MP4 (singkatan dari MPEG-4 Part 14) adalah format file berdasarkan ISO/IEC 14496-12:2004 yang berakar pada QuickTime File Format tetapi secara resmi menentukan dukungan untuk Initial Object Descriptors (IOD) dan fitur MPEG lainnya. Pelajari lebih lanjut tentang format file ini di sini.
