## MKV field

MKV (Matroska Video) adalah kontainer multimedia yang mirip dengan format MOV dan AVI tetapi mendukung lebih dari satu trek audio dan subtitle dalam satu file. File MKV adalah format kontainer multimedia Matroska yang digunakan untuk video. Pelajari lebih lanjut tentang format file ini di sini.
