| [MKV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/mkv/) | MKV (Matroska Video) adalah kontainer multimedia yang mirip dengan format MOV dan AVI tetapi mendukung lebih dari satu trek audio dan subtitle dalam satu file. Pelajari lebih lanjut tentang format file ini di sini. |

File ini dirancang untuk berbagi video di web dan mendefinisikan struktur kontainer file termasuk format video dan audio. Pelajari lebih lanjut tentang format file ini di sini. |
| [WMV](/conversion/python-net/groupdocs.conversion.filetypes/videofiletype/wmv/) | Windows Media Video adalah format video terkompresi yang dikembangkan oleh Microsoft.
