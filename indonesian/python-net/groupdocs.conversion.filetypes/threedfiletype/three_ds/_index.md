## THREE_DS field

File dengan ekstensi .3ds mewakili format file mesh 3D Sudio (DOS) yang digunakan oleh Autodesk 3D Studio. Autodesk 3D Studio telah berada di pasar format file 3D sejak tahun 1990-an dan kini telah berkembang menjadi 3D Studio MAX untuk bekerja dengan pemodelan, animasi, dan rendering 3D. Pelajari lebih lanjut tentang format file ini di sini.
