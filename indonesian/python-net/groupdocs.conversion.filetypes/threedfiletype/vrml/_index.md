## VRML field

Virtual Reality Modeling Language (VRML) adalah format file untuk representasi objek dunia 3D interaktif di seluruh World Wide Web (www). Format ini digunakan untuk membuat representasi tiga dimensi dari adegan kompleks seperti ilustrasi, definisi, dan presentasi realitas virtual. Pelajari lebih lanjut tentang format file ini di sini.
