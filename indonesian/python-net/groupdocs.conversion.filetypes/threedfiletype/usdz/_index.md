## USDZ field

File dengan ekstensi .usdz adalah arsip ZIP yang tidak terkompresi dan tidak terenkripsi untuk format file USD (Universal Scene Description) yang berisi dan menjadi proksi untuk file format lain (seperti tekstur, dan animasi) yang disematkan dalam arsip dan menjalankannya langsung dengan runtime USD tanpa perlu membuka arsip. Pelajari lebih lanjut tentang format file ini di sini.
