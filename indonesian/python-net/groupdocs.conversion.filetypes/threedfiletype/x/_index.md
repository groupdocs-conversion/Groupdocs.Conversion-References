## X field

File dengan ekstensi .x mengacu pada format file warisan DirectX 3D Graphics yang diperkenalkan bersama Microsoft DirectX 2.0. File ini digunakan untuk rendering grafis 3D dalam game dan menentukan struktur untuk mesh, tekstur, animasi, dan objek yang didefinisikan pengguna. File ini telah dihentikan sejak 2014 karena format file Autodesk FBX lebih baik sebagai format yang lebih modern. Pelajari lebih lanjut tentang format file ini di sini.
