## GLTF field

glTF (GL Transmission Format) adalah format file 3D yang menyimpan informasi model 3D dalam format JSON. Penggunaan JSON meminimalkan ukuran aset 3D serta pemrosesan runtime yang diperlukan untuk membuka dan menggunakan aset tersebut. Pelajari lebih lanjut tentang format file ini di sini.
