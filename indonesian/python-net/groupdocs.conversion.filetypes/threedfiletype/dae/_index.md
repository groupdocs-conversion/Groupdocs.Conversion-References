## DAE field

File DAE adalah format file Digital Asset Exchange yang digunakan untuk pertukaran data antar aplikasi 3D interaktif. Format file ini didasarkan pada skema XML COLLADA (COLLAborative Design Activity) yang merupakan skema XML standar terbuka untuk pertukaran aset digital di antara aplikasi perangkat lunak grafis. Pelajari lebih lanjut tentang format file ini di sini.
