## XLTX field

File XLTX mewakili Template Microsoft Excel yang berbasis pada spesifikasi format file Office OpenXML. File ini digunakan untuk membuat file template standar yang dapat digunakan untuk menghasilkan file XLSX yang memiliki pengaturan yang sama seperti yang ditentukan dalam file XLTX. Pelajari lebih lanjut tentang format file ini di sini.
