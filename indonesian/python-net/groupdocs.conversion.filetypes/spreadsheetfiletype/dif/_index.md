## DIF field

DIF merupakan singkatan dari Data Interchange Format yang digunakan untuk mengimpor/mengekspor data spreadsheet antara berbagai aplikasi. Ini termasuk Microsoft Excel, OpenOffice Calc, StarCalc, dan banyak lainnya. Pelajari lebih lanjut tentang format file ini di sini.
