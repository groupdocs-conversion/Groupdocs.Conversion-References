## OTS field

File dengan ekstensi .ots adalah file Template OpenDocument Spreadsheet yang dibuat dengan perangkat lunak aplikasi Calc yang termasuk dalam Apache OpenOffice. Perangkat lunak aplikasi Calc serupa dengan Excel yang tersedia di Microsoft Office.
