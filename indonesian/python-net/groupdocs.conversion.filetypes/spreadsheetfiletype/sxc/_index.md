## SXC field

Format file SXC (Sun XML Calc) merupakan bagian dari suite perkantoran yang disebut OpenOffice.org. Format ini umumnya memenuhi kebutuhan spreadsheet pengguna karena merupakan format file spreadsheet berbasis XML. Format SXC mendukung formula, fungsi, makro, dan diagram bersama dengan DataPilot. Pelajari lebih lanjut tentang format file ini di sini.
