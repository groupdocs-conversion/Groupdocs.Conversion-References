## XLTM field

Ekstensi file XLTM mewakili file yang dihasilkan oleh Microsoft Excel sebagai file template yang mendukung makro. File XLTM mirip dengan XLTX dalam struktur kecuali bahwa yang terakhir tidak mendukung pembuatan file template dengan makro. Pelajari lebih lanjut tentang format file ini di sini.
