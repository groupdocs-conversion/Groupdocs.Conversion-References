## XLAM field

XLAM adalah file Add-In yang mendukung Makro yang digunakan untuk menambahkan fungsi baru ke spreadsheet. Add-In adalah program tambahan yang menjalankan kode tambahan dan menyediakan fungsionalitas tambahan untuk spreadsheet. Pelajari lebih lanjut tentang format file ini di sini.
