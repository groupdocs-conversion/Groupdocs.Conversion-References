## XLT field

File dengan ekstensi .XLT adalah file template yang dibuat dengan Microsoft Excel yang merupakan aplikasi spreadsheet yang merupakan bagian dari paket Microsoft Office. Microsoft Office 97-2003 mendukung pembuatan file XLT baru serta membuka file tersebut. Pelajari lebih lanjut tentang format file ini di sini.
