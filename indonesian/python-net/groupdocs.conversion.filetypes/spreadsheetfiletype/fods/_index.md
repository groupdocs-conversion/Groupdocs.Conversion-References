## FODS field

File dengan ekstensi .fods adalah jenis format dokumen OpenDocument Spreadsheet yang menyimpan data dalam baris dan kolom. Format ini ditentukan sebagai bagian dari spesifikasi ODF 1.2 yang dipublikasikan dan dipelihara oleh OASIS. Pelajari lebih lanjut tentang format file ini di sini.
