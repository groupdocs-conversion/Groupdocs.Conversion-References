## DWFX field

File DWFX adalah gambar 2D atau 3D yang dibuat dengan perangkat lunak Autodesk CAD. File ini disimpan dalam format DWFx, yang mirip dengan file .DWF, tetapi diformat menggunakan Microsoft XML Paper Specification (XPS).
