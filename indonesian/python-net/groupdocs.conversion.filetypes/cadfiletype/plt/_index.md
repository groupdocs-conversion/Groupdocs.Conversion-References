## PLT field

Format file PLT adalah file plotter berbasis vektor yang diperkenalkan oleh Autodesk, Inc. dan berisi informasi untuk file CAD tertentu. Detail plotting memerlukan akurasi dan presisi dalam produksi, dan penggunaan file PLT menjamin hal ini karena semua gambar dicetak menggunakan garis bukan titik. Pelajari lebih lanjut tentang format file ini di sini.
