## DWF field

Design Web Format (DWF) mewakili gambar 2D/3D dalam format terkompresi untuk melihat, meninjau, atau mencetak file desain. Format ini berisi grafik dan teks sebagai bagian dari data desain serta mengurangi ukuran file karena formatnya yang terkompresi. Pelajari lebih lanjut tentang format file ini di sini.
