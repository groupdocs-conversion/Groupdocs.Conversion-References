## IFC field

File dengan ekstensi IFC mengacu pada format file Industry Foundation Classes (IFC) yang menetapkan standar internasional untuk mengimpor dan mengekspor objek bangunan serta propertinya. Format file ini menyediakan interoperabilitas antara berbagai aplikasi perangkat lunak. Pelajari lebih lanjut tentang format file ini di sini.
