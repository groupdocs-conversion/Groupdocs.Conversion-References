## WordProcessingFileType class

Kelas WordProcessingFileType mendefinisikan format file Pengolahan Kata, mencakup varian teks biasa dan teks kaya.

File teks biasa berisi teks tidak terformat tanpa pengaturan font atau halaman yang diterapkan. File teks kaya mendukung opsi pemformatan seperti jenis font, gaya (tebal, miring, bergaris bawah), margin halaman, heading, bullet, nomor, dan fitur lainnya.

### Contoh

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # Buat instance Converter dengan dokumen input
    with Converter("./business-plan.docx") as converter:
        # Tetapkan opsi konversi; format output default adalah DOCX
        word_convert_options = WordProcessingConvertOptions()
        # Ubah format output dalam keluarga format dari DOCX ke TXT
        word_convert_options.format = WordProcessingFileType.Txt

        # Konversi dokumen input ke TXT
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
