## AC3 field

File dengan ekstensi .ac3 adalah file Audio Codec 3, yang diperkenalkan oleh Dolby Laboratories. Ini adalah format audio yang dapat berisi hingga enam saluran output audio. Pelajari lebih lanjut tentang format file ini di sini.
