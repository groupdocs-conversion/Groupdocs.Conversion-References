## AIFF field

AIFF (Audio Interchange File Format) adalah format file audio tidak terkompresi yang dikembangkan oleh Apple pada tahun 1998, namun didasarkan pada EA IFF 85. Pelajari lebih lanjut tentang format file ini di sini.
