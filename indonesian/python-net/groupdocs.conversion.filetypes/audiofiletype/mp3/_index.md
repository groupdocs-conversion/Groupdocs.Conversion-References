## MP3 field

File dengan ekstensi .mp3 adalah format file yang dikodekan secara digital untuk file audio yang secara resmi didasarkan pada MPEG-1 Audio Layer III atau MPEG-2 Audio Layer III. Pelajari lebih lanjut tentang format file ini di sini.
