## DRAWIO field

File dengan ekstensi DRAWIO adalah diagram yang dibuat dengan diagrams.net (sebelumnya draw.io). File ini disimpan dalam format file XML dengan elemen root mxfile dan menyimpan konten serta pemformatan elemen diagram seperti teks, gambar, tata letak, bentuk, dan posisi. Pelajari lebih lanjut tentang format file ini di sini.
