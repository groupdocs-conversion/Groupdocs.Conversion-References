## VSSM field

File dengan ekstensi .VSSM adalah file Stensil Microsoft Visio yang mendukung makro. File VSSM ketika dibuka memungkinkan menjalankan makro untuk mencapai pemformatan dan penempatan bentuk yang diinginkan dalam diagram. Pelajari lebih lanjut tentang format file ini di sini.
