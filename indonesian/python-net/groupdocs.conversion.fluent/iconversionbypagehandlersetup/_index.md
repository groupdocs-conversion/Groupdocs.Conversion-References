## IConversionByPageHandlerSetup class

Menyediakan antarmuka fluida untuk mengatur penangan konversi halaman.

Memungkinkan pengaturan `OnConversionCompleted` dan/atau `OnConversionFailed` dalam urutan apa pun, masing-masing paling banyak sekali, atau melewatkan keduanya.

Tipe IConversionByPageHandlerSetup mengekspos anggota berikut:

| [compress_compression_convert_options](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/compress_compression_convert_options/) |  |
| [convert](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/convert/) | Jalankan rantai konversi. |
| [on_conversion_completed](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/on_conversion_completed/#on_completed) | Mendaftarkan callback yang akan dipanggil ketika konversi halaman selesai dengan sukses. |
