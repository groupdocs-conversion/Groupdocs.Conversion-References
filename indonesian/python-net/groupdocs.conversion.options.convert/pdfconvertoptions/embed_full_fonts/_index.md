## embed_full_fonts property

Properti ini menentukan apakah file font lengkap disematkan ke dalam PDF alih-alih subset.

Ketika diatur ke True, ukuran file output akan meningkat tetapi memastikan kompatibilitas yang lebih baik saat mengedit PDF yang dihasilkan. Hanya berlaku saat mengonversi dari dokumen WordProcessing.
