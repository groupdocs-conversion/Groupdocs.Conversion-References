## IPagedConvertOptions class

Mewakili opsi konversi yang memungkinkan pembatasan halaman dengan menentukan halaman mulai dan jumlah halaman.

Tipe IPagedConvertOptions menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | Tipe file yang diinginkan untuk mengonversi dokumen masukan. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | Nomor halaman untuk memulai konversi. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | Jumlah halaman yang akan dikonversi mulai dari `PageNumber`. |
