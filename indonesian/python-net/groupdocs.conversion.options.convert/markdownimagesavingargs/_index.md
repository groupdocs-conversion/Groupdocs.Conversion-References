## MarkdownImageSavingArgs class

Mewakili argumen yang diteruskan ke [`IMarkdownImageSavingCallback.image_saving`](/conversion/python-net/groupdocs.conversion.options.convert/imarkdownimagesavingcallback/image_saving/).

Tipe MarkdownImageSavingArgs menampilkan anggota-anggota berikut:

### Properti
| Properti | Deskripsi |
| :- | :- |
| [image_file_name](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_file_name/) | Nama file (atau id placeholder) yang disematkan sebagai URI gambar dalam output Markdown. Tetapkan untuk menulis ulang URI. |
| [image_stream](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/image_stream/) | Stream tujuan yang akan ditulisi byte gambar oleh konverter setelah callback ini mengembalikan. |
| [keep_image_stream_open](/conversion/python-net/groupdocs.conversion.options.convert/markdownimagesavingargs/keep_image_stream_open/) | Properti ini menentukan apakah konverter mempertahankan stream gambar tetap terbuka setelah konversi. |
