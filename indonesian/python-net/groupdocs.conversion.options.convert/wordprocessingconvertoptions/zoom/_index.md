## zoom property

Tingkat zoom dalam persentase.

Default adalah 100. Zoom default didukung hingga Microsoft Word 2010. Mulai dari Microsoft Word 2013, zoom default tidak lagi diatur pada dokumen; sebaliknya tampaknya menggunakan faktor zoom dari dokumen terakhir yang dibuka.
