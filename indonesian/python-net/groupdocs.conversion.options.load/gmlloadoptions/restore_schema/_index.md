## restore_schema property

Properti menentukan apakah konversi diizinkan mengurai atribut dalam file GML ketika skema XML tidak ada atau tidak dapat dimuat.

Jika disetel ke True, pembaca konversi tidak memerlukan keberadaan skema XML. Nilai default adalah False.
