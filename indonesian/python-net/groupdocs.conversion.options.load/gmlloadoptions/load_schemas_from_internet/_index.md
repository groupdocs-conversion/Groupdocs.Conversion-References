## load_schemas_from_internet property

Properti menentukan apakah konversi diizinkan memuat skema XML dari Internet.

Jika disetel ke False, skema dengan URI absolut yang tidak dimulai dengan 'file://' tidak akan dimuat. Default adalah False.
