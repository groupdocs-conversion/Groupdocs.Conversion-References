## schema_location property

schema_location adalah daftar pasangan URI yang dipisahkan spasi, di mana URI pertama dalam setiap pasangan adalah URI namespace dan URI kedua adalah jalur ke skema XML namespace tersebut.

Jika disetel ke None, Conversion akan mencoba membaca atribut schemaLocation dari elemen akar dokumen. Nilai default adalah None.
