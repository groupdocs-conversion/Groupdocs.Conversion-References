## PdfConvertOptions.EmbedFullFonts property

Ketika diatur ke true, file font lengkap disematkan ke dalam PDF alih-alih subset. Ini meningkatkan ukuran file output tetapi memastikan kompatibilitas yang lebih baik saat mengedit PDF yang dihasilkan. Hanya berlaku saat mengonversi dari dokumen WordProcessing.
