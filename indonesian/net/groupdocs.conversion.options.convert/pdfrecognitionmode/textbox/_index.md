## PdfRecognitionMode.Textbox field

Mode ini cepat dan baik untuk mempertahankan tampilan asli file PDF secara maksimal, tetapi kemampuan mengedit dokumen yang dihasilkan dapat terbatas. Setiap blok teks yang dikelompokkan secara visual dalam file PDF asli dikonversi menjadi kotak teks dalam dokumen hasil. Ini menghasilkan kemiripan maksimal antara dokumen output dan file PDF asli. Dokumen output akan terlihat bagus, tetapi akan sepenuhnya terdiri dari kotak teks dan dapat membuat penyuntingan lebih lanjut dokumen di Microsoft Word menjadi cukup sulit. Ini adalah mode default.

```csharp
public static readonly PdfRecognitionMode Textbox;
```
