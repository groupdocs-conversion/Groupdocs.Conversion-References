## WebConvertOptions.SlideShow property

Hanya berlaku untuk mengonversi presentasi ke [`Html`](../../../groupdocs.conversion.filetypes/webfiletype/html) atau [`Htm`](../../../groupdocs.conversion.filetypes/webfiletype/htm), dan diabaikan untuk konversi lainnya. Menentukan apakah presentasi menjadi slideshow HTML interaktif dengan transisi slide dan animasi bentuk, alih-alih halaman HTML statis default. Defaultnya false.

```csharp
public bool SlideShow { get; set; }
```

### Catatan

Hasilnya adalah satu file HTML dengan gaya, skrip, gambar, font, dan media yang disisipkan. Dua pustaka JavaScript yang menggerakkan slideshow dimuat dari CDN, sehingga halaman memerlukan koneksi internet untuk animasi dan navigasi.
