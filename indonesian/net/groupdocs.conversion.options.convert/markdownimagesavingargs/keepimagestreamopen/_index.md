## MarkdownImageSavingArgs.KeepImageStreamOpen property

Jika false (default), konverter menutup [`ImageStream`](../imagestream) setelah menulis — sesuai kebiasaan untuk pengganti FileStream yang harus dibuang ke disk. Atur ke true untuk menjaga aliran tetap terbuka setelah konversi selesai (biasanya untuk MemoryStream yang ingin Anda baca sendiri); pemanggil kemudian bertanggung jawab atas pembuangan.

```csharp
public bool KeepImageStreamOpen { get; set; }
```
