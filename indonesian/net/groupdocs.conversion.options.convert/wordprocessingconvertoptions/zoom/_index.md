## WordProcessingConvertOptions.Zoom property

Menentukan tingkat zoom dalam persentase. Default adalah 100. Zoom default didukung hingga Microsoft Word 2010. Mulai dari Microsoft Word 2013, zoom default tidak lagi diatur ke dokumen, melainkan tampaknya menggunakan faktor zoom dari dokumen terakhir yang dibuka.
