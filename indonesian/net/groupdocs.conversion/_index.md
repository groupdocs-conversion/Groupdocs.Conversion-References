Namespace menyediakan kelas untuk mengonversi dokumen ke semua format file populer dengan cara yang sederhana dan intuitif.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ConversionEvents](./conversionevents) | Mengumpulkan penangan peristiwa siklus hidup konversi. Berikan sebuah instance ke konstruktor [`Converter`](../groupdocs.conversion/converter) parameter `events` atau ke metode fluent `WithEvents`. Lebih disarankan menggunakan ini dibandingkan properti penangan individual [`ConverterSettings`](../groupdocs.conversion/convertersettings), yang sudah usang. |
| [ConvertContext](./convertcontext) | Mendefinisikan konteks konversi. |
| [ConvertedContext](./convertedcontext) | Mendefinisikan konteks konversi. |
| [ConvertedPageContext](./convertedpagecontext) | Mendefinisikan konteks halaman konversi. |
| [Converter](./converter) | Mewakili kelas utama yang mengontrol proses konversi dokumen. |
| [ConverterSettings](./convertersettings) | Mendefinisikan pengaturan untuk menyesuaikan perilaku [`Converter`](../groupdocs.conversion/converter). |
| [FluentConverter](./fluentconverter) | Kelas untuk pengaturan konversi secara fluent. |
| [License](./license) | Menyediakan metode untuk melisensikan komponen. Pelajari lebih lanjut tentang lisensi [di sini](https://purchase.groupdocs.com/faqs/licensing). |
| [LoadContext](./loadcontext) | Mendefinisikan konteks pemuatan. |
| [Metered](./metered) | Menyediakan metode untuk menerapkan lisensi [Metered](https://purchase.groupdocs.com/faqs/licensing/metered). |
| [SaveContext](./savecontext) | Mendefinisikan konteks penyimpanan. |
| [SavePageContext](./savepagecontext) | Mendefinisikan konteks halaman penyimpanan. |
