## ThreeDFileType.Ase field

File dengan ekstensi .ase adalah format file Autodesk ASCII Scene Export yang merupakan representasi ASCII dari sebuah adegan, berisi informasi 2D atau 3D saat mengekspor data adegan menggunakan Autodesk. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/ase).
