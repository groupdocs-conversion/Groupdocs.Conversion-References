## ThreeDFileType.Fbx field

FBX, FilmBox, adalah format file 3D populer yang awalnya dikembangkan oleh Kaydara untuk MotionBuilder. Format ini diakuisisi oleh Autodesk Inc pada tahun 2006 dan kini menjadi salah satu format pertukaran 3D utama yang digunakan oleh banyak alat 3D. FBX tersedia dalam format file biner maupun ASCII. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/fbx).
