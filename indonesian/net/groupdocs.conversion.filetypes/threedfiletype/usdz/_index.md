## ThreeDFileType.Usdz field

File dengan ekstensi .usdz adalah arsip ZIP yang tidak terkompresi dan tidak terenkripsi untuk format file USD (Universal Scene Description) yang berisi dan menjadi proxy untuk file dari format lain (seperti tekstur, dan animasi) yang disematkan dalam arsip dan menjalankannya secara langsung dengan runtime USD tanpa perlu mengekstrak. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/usdz).
