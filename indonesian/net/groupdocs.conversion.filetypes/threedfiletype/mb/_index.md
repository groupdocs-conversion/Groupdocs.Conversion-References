## ThreeDFileType.Mb field

File dengan ekstensi .mb adalah file proyek biner yang dibuat dengan aplikasi Autodesk Maya. Tidak seperti format file MA, yang berbentuk format file ASCII, file MB disimpan dalam format file biner. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/mb).
