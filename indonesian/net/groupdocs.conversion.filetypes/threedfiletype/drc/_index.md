## ThreeDFileType.Drc field

File dengan ekstensi .drc adalah format file 3D terkompresi yang dibuat dengan pustaka Google Draco. Google menyediakan Draco sebagai pustaka sumber terbuka untuk mengompresi dan mendekompresi mesh geometrik 3D serta awan titik, dan meningkatkan penyimpanan serta transmisi grafis 3D. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/drc).
