## ThreeDFileType.Usd field

File dengan ekstensi .usd adalah format file Universal Scene Description yang mengkodekan data untuk tujuan pertukaran dan augmentasi data antar aplikasi pembuatan konten digital. Dikembangkan oleh Pixar, USD menyediakan kemampuan untuk menukar aset elementer (seperti model) atau animasi. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/usd).
