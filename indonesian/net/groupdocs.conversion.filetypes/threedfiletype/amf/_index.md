## ThreeDFileType.Amf field

Sebuah file AMF terdiri dari pedoman untuk deskripsi objek agar dapat digunakan oleh proses Manufaktur Aditif. File ini berisi tag XML pembuka dan diakhiri dengan sebuah elemen. Ini didahului oleh baris deklarasi XML yang menentukan versi XML dan pengkodean file. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/amf).
