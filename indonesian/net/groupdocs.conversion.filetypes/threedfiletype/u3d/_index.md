## ThreeDFileType.U3d field

U3D (Universal 3D) adalah format file terkompresi dan struktur data untuk grafis komputer 3D. Ia berisi informasi model 3D seperti mesh segitiga, pencahayaan, shading, data gerakan, garis, dan titik dengan warna serta struktur. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/u3d).
