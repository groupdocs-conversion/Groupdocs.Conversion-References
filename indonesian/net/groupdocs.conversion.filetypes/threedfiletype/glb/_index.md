## ThreeDFileType.Glb field

GLB adalah representasi format file biner dari model 3D yang disimpan dalam GL Transmission Format (glTF). Format biner ini menyimpan aset glTF (JSON, .bin, dan gambar) dalam sebuah blob biner. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/glb).
