## ThreeDFileType.ThreeDS field

File dengan ekstensi .3ds merupakan format file mesh 3D Sudio (DOS) yang digunakan oleh Autodesk 3D Studio. Autodesk 3D Studio telah berada di pasar format file 3D sejak tahun 1990-an dan kini telah berkembang menjadi 3D Studio MAX untuk bekerja dengan pemodelan 3D, animasi, dan rendering. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/3d/3ds).

public static readonly ThreeDFileType ThreeDS;
