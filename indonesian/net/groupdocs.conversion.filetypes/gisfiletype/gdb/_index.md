## GisFileType.Gdb field

Geodatabase file ESRI (FileGDB) adalah kumpulan file dalam sebuah folder di disk yang menyimpan data geospasial terkait seperti dataset fitur, kelas fitur, dan tabel terkait. Ia memerlukan beberapa file lain yang disimpan bersamaan dengan file .gdb di direktori yang sama agar dapat berfungsi. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/database/gdb/).

public static readonly GisFileType Gdb;
