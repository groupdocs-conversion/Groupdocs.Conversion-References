## GisFileType.GeoJson field

GeoJSON adalah format berbasis JSON yang dirancang untuk merepresentasikan fitur geografis beserta atribut non-spasialnya. Format ini mendefinisikan berbagai objek JSON (JavaScript Object Notation) dan cara penggabungannya. Format JSON menyajikan informasi kolektif tentang fitur geografis, ekstensi spasial, dan propertinya. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/gis/geojson/).

public static readonly GisFileType GeoJson;
