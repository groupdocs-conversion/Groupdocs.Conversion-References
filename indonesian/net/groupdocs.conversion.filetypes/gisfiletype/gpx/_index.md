## GisFileType.Gpx field

File dengan ekstensi GPX mewakili format GPS Exchange untuk pertukaran data GPS antara aplikasi dan layanan web di internet. Ini adalah format file XML ringan yang berisi data GPS seperti waypoint, rute, dan trek yang dapat diimpor dan dibaca oleh banyak program. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/gis/gpx/).
