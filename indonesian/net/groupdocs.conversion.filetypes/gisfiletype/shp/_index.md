## GisFileType.Shp field

SHP adalah ekstensi file untuk salah satu tipe file utama yang digunakan untuk representasi ESRI Shapefile. Ia mewakili informasi Geospasial dalam bentuk data vektor yang akan digunakan oleh aplikasi Geographic Information Systems (GIS). Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/gis/shp/).
