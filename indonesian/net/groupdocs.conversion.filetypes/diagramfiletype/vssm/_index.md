## DiagramFileType.Vssm field

File dengan ekstensi .VSSM adalah file Stensil Microsoft Visio yang mendukung makro. File VSSM saat dibuka memungkinkan menjalankan makro untuk mencapai pemformatan dan penempatan bentuk yang diinginkan dalam diagram. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/vssm).
