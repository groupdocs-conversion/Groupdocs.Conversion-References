## DiagramFileType.Vstm field

File dengan ekstensi VSTM adalah file templat yang dibuat dengan Microsoft Visio yang mendukung makro. Tidak seperti file VSDX, file yang dibuat dari templat VSTM dapat menjalankan makro yang dikembangkan dalam kode Visual Basic for Applications (VBA). Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/vstm).
