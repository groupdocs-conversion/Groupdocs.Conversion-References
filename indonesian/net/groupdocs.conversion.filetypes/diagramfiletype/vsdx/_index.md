## DiagramFileType.Vsdx field

File dengan ekstensi .VSDX mewakili format file Microsoft Visio yang diperkenalkan sejak Microsoft Office 2013 ke atas. Format ini dikembangkan untuk menggantikan format file biner, .VSD, yang didukung oleh versi Microsoft Visio sebelumnya. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/vsdx).
