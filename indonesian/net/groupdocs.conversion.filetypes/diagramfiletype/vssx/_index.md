## DiagramFileType.Vssx field

File dengan ekstensi .VSSX adalah stensil gambar yang dibuat dengan Microsoft Visio 2013 ke atas. Format file VSSX dapat dibuka dengan Visio 2013 ke atas. File Visio dikenal untuk representasi berbagai elemen gambar seperti kumpulan bentuk, penghubung, diagram alur, tata letak jaringan, diagram UML. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/vssx).
