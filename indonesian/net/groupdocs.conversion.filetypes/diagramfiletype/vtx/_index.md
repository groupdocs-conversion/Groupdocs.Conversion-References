## DiagramFileType.Vtx field

File dengan ekstensi VTX adalah templat gambar Microsoft Visio yang disimpan ke disk dalam format file XML. Templat ini bertujuan menyediakan file dengan pengaturan dasar yang dapat digunakan untuk membuat banyak file Visio dengan pengaturan yang sama. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/vtx).
