## DiagramFileType.Vst field

File dengan ekstensi VST adalah file gambar vektor yang dibuat dengan Microsoft Visio dan berfungsi sebagai templat untuk membuat file lebih lanjut. File templat ini berformat file biner dan berisi tata letak serta pengaturan default yang digunakan untuk membuat gambar Visio baru. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/vst).
