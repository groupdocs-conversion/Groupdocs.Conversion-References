## FinanceFileType.IXbrl field

Di dalam iXBRL, konten XBRL dibungkus dalam format file xHTML yang menggunakan tag XML. Seperti XBRL, merupakan elemen akar dari file iXBRL. Format XHTML merepresentasikan isinya sebagai kumpulan berbagai jenis dokumen dan modul. Semua file dalam XHTML didasarkan pada format file XML dan mematuhi standar dokumen XML. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/finance/ixbrl/).
