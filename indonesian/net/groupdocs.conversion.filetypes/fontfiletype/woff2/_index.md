## FontFileType.Woff2 field

File dengan ekstensi .woff adalah file font web yang berbasis pada Web Open Font Format (WOFF). Ia memiliki wadah terkompresi khusus format yang berbasis pada jenis font TrueType (.TTF) atau OpenType (.OTT).
