## FontFileType.Type1 field

Font Type 1 adalah teknologi Adobe yang sudah usang dan sebelumnya banyak digunakan dalam perangkat lunak penerbitan berbasis desktop serta printer yang dapat menggunakan PostScript. Meskipun font Type 1 tidak didukung di banyak platform modern, peramban web, dan sistem operasi seluler, namun masih didukung di beberapa sistem operasi. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/font/type1/).
