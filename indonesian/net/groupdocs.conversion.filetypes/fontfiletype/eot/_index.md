## FontFileType.Eot field

File dengan ekstensi .eot adalah font OpenType yang disematkan dalam sebuah dokumen. Ini biasanya digunakan dalam file web seperti halaman Web. Font ini dibuat oleh Microsoft dan didukung oleh Produk Microsoft termasuk presentasi PowerPoint .pps. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/font/eot/).
