## SpreadsheetFileType.Dif field

DIF merupakan singkatan dari Data Interchange Format yang digunakan untuk mengimpor/mengekspor data spreadsheet antar aplikasi yang berbeda. Ini termasuk Microsoft Excel, OpenOffice Calc, StarCalc, dan banyak lainnya. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/spreadsheet/dif).
