## SpreadsheetFileType.Sxc field

Format file SXC (Sun XML Calc) termasuk dalam suite perkantoran yang disebut OpenOffice.org. Format ini umumnya menangani kebutuhan spreadsheet pengguna karena merupakan format file spreadsheet berbasis XML. Format SXC mendukung rumus, fungsi, makro, dan diagram bersama DataPilot. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/spreadsheet/sxc).
