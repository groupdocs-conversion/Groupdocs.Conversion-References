## SpreadsheetFileType.Numbers field

File dengan ekstensi .numbers diklasifikasikan sebagai tipe file spreadsheet, itulah mengapa mereka mirip dengan file .xlsx; tetapi file Numbers dibuat dengan menggunakan perangkat lunak spreadsheet Apple iWork Numbers.
