## SpreadsheetFileType.Xltm field

Ekstensi file XLTM mewakili file yang dihasilkan oleh Microsoft Excel sebagai file templat yang mendukung makro. File XLTM mirip dengan XLTX dalam struktur kecuali yang terakhir tidak mendukung pembuatan file templat dengan makro.
