## VideoFileType.Mp4 field

MP4 (singkatan dari MPEG-4 Part 14) adalah format file yang berdasarkan ISO/IEC 14496-12:2004 dan didasarkan pada QuickTime File Format, namun secara formal menentukan dukungan untuk Initial Object Descriptors (IOD) dan fitur MPEG lainnya. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/video/mp4/).
