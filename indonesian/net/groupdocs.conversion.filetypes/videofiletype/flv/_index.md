## VideoFileType.Flv field

FLV (Flash Video) adalah format file kontainer dengan ekstensi .flv. FLV digunakan untuk menyampaikan konten audio/video melalui internet dengan menggunakan Adobe Flash Player atau Adobe Air. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/video/flv/).
