## VideoFileType.Mov field

MOV atau format file QuickTime adalah kontainer multimedia yang dikembangkan oleh Apple: berisi satu atau lebih trek, masing-masing trek menyimpan jenis data tertentu seperti Video, Audio, teks, dll. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/video/mov/).
