## ImageFileType.Psb field

Adobe Photoshop menyimpan file dalam dua format. File berukuran 30.000 × 30.000 piksel disimpan dengan ekstensi PSD dan file yang lebih besar hingga 300.000 × 300.000 piksel disimpan dengan ekstensi PSB yang dikenal sebagai “Photoshop Big”. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/image/psb).
