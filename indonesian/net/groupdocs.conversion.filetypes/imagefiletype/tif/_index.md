## ImageFileType.Tif field

TIF, Tagged Image File Format, mewakili gambar raster yang dimaksud untuk penggunaan pada berbagai perangkat yang mematuhi standar format file ini. Format ini mampu menggambarkan data gambar bilevel, grayscale, palet-warna, dan warna penuh dalam beberapa ruang warna. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/image/tiff).
