## ImageFileType.Wmz field

File WMZ sebenarnya adalah versi terkompresi dari file Microsoft WMF. Hal ini memungkinkan distribusi file secara online menjadi lebih mudah. Ketika file EWMFMF dikompresi menggunakan algoritma kompresi .GZIP, maka diberikan ekstensi file .wmz.
