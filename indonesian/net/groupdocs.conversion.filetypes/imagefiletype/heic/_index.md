## ImageFileType.Heic field

File HEIC adalah format file High-Efficiency Container Image yang dapat menyimpan beberapa gambar sebagai koleksi dalam satu file. Format ini diadopsi oleh Apple sebagai varian HEIF pada peluncuran iOS 11. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/image/heic/).
