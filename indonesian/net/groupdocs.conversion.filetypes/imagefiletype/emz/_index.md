## ImageFileType.Emz field

File EMZ sebenarnya adalah versi terkompresi dari file Microsoft EMF. Hal ini memungkinkan distribusi file secara online menjadi lebih mudah. Ketika file EMF dikompresi menggunakan algoritma kompresi .GZIP, maka diberikan ekstensi file .emz.
