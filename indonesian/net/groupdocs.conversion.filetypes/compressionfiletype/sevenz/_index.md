## CompressionFileType.SevenZ field

7z adalah format arsip untuk mengompresi file dan folder dengan rasio kompresi tinggi. Format ini berbasis arsitektur Open Source yang memungkinkan penggunaan berbagai algoritma kompresi dan enkripsi.
