## CompressionFileType.Uue field

Arsip uuencoded adalah file atau kumpulan file yang telah dienkode menggunakan skema pengkodean Unix-to-Unix (uuencode). Metode pengkodean ini mengubah data biner menjadi format teks, sehingga lebih mudah mengirim file melalui saluran yang hanya mendukung teks, seperti email.
