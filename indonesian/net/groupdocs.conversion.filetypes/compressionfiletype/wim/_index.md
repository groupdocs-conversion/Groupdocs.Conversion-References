## CompressionFileType.Wim field

File dengan ekstensi .wim adalah arsip Windows Imaging Format, sebuah gambar disk berbasis file yang digunakan Microsoft untuk menyebarkan Windows. Sebuah arsip tunggal menyimpan satu atau lebih image dan menyimpan setiap file hanya sekali, terlepas dari berapa banyak image yang merujuknya. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/disc-and-media/wim/).
