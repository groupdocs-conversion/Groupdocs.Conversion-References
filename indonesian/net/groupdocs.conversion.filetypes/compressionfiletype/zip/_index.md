## CompressionFileType.Zip field

File dengan ekstensi .zip adalah arsip yang dapat menyimpan satu atau lebih file atau direktori. Arsip dapat diberi kompresi pada file yang termasuk untuk mengurangi ukuran file ZIP. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/compression/zip/).
