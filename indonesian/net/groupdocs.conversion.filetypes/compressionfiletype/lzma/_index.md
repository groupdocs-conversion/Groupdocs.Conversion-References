## CompressionFileType.Lzma field

File dengan ekstensi .lzma adalah file arsip terkompresi yang dibuat menggunakan metode kompresi LZMA (Lempel-Ziv-Markov chain Algorithm). File ini biasanya ditemukan/ digunakan pada sistem operasi Unix dan mirip dengan algoritma kompresi lainnya seperti ZIP untuk meminimalkan ukuran file. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/compression/lzma/).
