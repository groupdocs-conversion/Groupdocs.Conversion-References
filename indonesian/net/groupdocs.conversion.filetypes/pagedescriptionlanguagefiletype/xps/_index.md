## PageDescriptionLanguageFileType.Xps field

File XPS mewakili file tata letak halaman yang berbasis pada XML Paper Specifications yang dibuat oleh Microsoft. Format ini dikembangkan oleh Microsoft sebagai pengganti format file EMF dan mirip dengan format file PDF, tetapi menggunakan XML dalam tata letak, tampilan, dan informasi pencetakan dokumen. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/page-description-language/xps).
