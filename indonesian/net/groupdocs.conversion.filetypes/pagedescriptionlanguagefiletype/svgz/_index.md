## PageDescriptionLanguageFileType.Svgz field

File SVGZ sebenarnya adalah versi terkompresi dari file SVG. Ini memungkinkan distribusi file secara online menjadi lebih mudah. Ketika file SVG dikompresi menggunakan algoritma kompresi .GZIP, maka diberikan ekstensi file .svgz.
