## PageDescriptionLanguageFileType.Oxps field

Format file OXPS dikenal sebagai Open XML Paper Specification. Ini adalah bahasa deskripsi halaman dan format dokumen. Microsoft adalah pengembang format ini. Format file OXPS sangat mirip dengan file PDF. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/page-description-language/oxps).
