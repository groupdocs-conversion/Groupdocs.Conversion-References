## EBookFileType.Epub field

Ekstensi EPUB adalah format file e-book yang menyediakan format publikasi digital standar bagi penerbit dan konsumen. Format ini sudah begitu umum sehingga didukung oleh banyak e-reader dan aplikasi perangkat lunak. Pelajari lebih lanjut tentang format file ini [di sini](https://wiki.fileformat.com/ebook/epub).
