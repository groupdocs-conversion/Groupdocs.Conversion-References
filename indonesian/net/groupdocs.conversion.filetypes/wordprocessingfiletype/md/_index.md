## WordProcessingFileType.Md field

File teks yang dibuat dengan dialek bahasa Markdown disimpan dengan ekstensi file .MD atau .MARKDOWN. File MD disimpan dalam format teks biasa yang menggunakan bahasa Markdown yang juga mencakup simbol teks inline, mendefinisikan cara teks dapat diformat seperti indentasi, pemformatan tabel, font, dan header. Pelajari lebih lanjut tentang format file ini [here](https://wiki.fileformat.com/word-processing/md).
