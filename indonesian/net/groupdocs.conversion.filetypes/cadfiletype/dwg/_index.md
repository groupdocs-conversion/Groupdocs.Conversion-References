## CadFileType.Dwg field

File dengan ekstensi DWG mewakili file biner proprietari yang digunakan untuk menyimpan data desain 2D dan 3D. Seperti DXF, yang merupakan file ASCII, DWG mewakili format file biner untuk gambar CAD (Computer Aided Design). Pelajari lebih lanjut tentang format file ini [here](https://wiki.fileformat.com/cad/dwg).
