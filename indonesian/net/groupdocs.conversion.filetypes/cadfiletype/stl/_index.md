## CadFileType.Stl field

STL, singkatan dari stereolithrography, adalah format file yang dapat dipertukarkan yang mewakili geometri permukaan tiga dimensi. Format file ini digunakan dalam beberapa bidang seperti prototyping cepat, pencetakan 3D, dan manufaktur berbantuan komputer. Pelajari lebih lanjut tentang format file ini [here](https://wiki.fileformat.com/cad/stl).
