## GmlLoadOptions.LoadSchemasFromInternet property

Menentukan apakah Conversion diizinkan memuat skema XML dari Internet. Jika disetel ke false, skema dengan URI absolut yang tidak dimulai dengan ‘file://’ tidak akan dimuat. Nilai default adalah false.

public bool LoadSchemasFromInternet { get; set; }
