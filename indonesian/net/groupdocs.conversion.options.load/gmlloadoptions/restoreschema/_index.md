## GmlLoadOptions.RestoreSchema property

Menentukan apakah Conversion diizinkan mengurai atribut dalam file Gml yang skema XML-nya hilang atau tidak dapat dimuat. Jika disetel ke true, pembaca Conversion tidak memerlukan keberadaan Skema XML. Nilai default adalah false.

public bool RestoreSchema { get; set; }
