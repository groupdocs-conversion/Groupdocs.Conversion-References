## GmlLoadOptions.SchemaLocation property

Daftar pasangan URI yang dipisahkan spasi. URI pertama dalam setiap pasangan adalah URI dari namespace, URI kedua adalah Path ke skema XML dari namespace. Jika disetel ke null, Conversion akan mencoba membaca schemaLocation dari elemen root dokumen. Nilai default adalah null
