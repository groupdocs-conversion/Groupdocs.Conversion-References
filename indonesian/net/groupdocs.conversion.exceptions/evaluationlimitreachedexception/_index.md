## EvaluationLimitReachedException class

Pengecualian GroupDocs dilempar ketika kuota konversi evaluasi untuk proses saat ini telah habis.

```csharp
public sealed class EvaluationLimitReachedException : GroupDocsConversionException
```

### Catatan

Hanya dilempar ketika tidak ada lisensi. Menerapkan lisensi menghapus batasan, sehingga proses berlisensi tidak pernah melihat pengecualian ini, berapa pun jumlah dokumen yang dikonversinya.
