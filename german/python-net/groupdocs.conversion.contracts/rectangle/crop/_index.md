## crop {#crop_left-crop_top-crop_right-crop_bottom}

Erstellt eine beschnittene Version des aktuellen Rechtecks, indem angegebene Ränder entfernt werden.

```python
def crop(self, crop_left, crop_top, crop_right, crop_bottom):
    ...
```

| Parameter | Typ | Beschreibung |
| :- | :- | :- |
| crop_left | `int` | Die Anzahl der Pixel, die von der linken Seite entfernt werden sollen. |
| crop_top | `int` | Die Anzahl der Pixel, die von der oberen Seite entfernt werden sollen. |
| crop_right | `int` | Die Anzahl der Pixel, die von der rechten Seite entfernt werden sollen. |
| crop_bottom | `int` | Die Anzahl der Pixel, die von der unteren Seite entfernt werden sollen. |

**Returns:** Rectangle: A new cropped rectangle.
