## TargetConversion class

Stellt eine mögliche Zielkonvertierung dar und gibt an, ob sie primär oder sekundär ist.

Der TargetConversion-Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [convert_options](/conversion/python-net/groupdocs.conversion.contracts/targetconversion/convert_options/) | Die vordefinierten Konvertierungsoptionen, die verwendet werden können, um in den aktuellen Typ zu konvertieren. |
| [format](/conversion/python-net/groupdocs.conversion.contracts/targetconversion/format/) | Das Zielformat des Dokuments. |
| [is_primary](/conversion/python-net/groupdocs.conversion.contracts/targetconversion/is_primary/) | Die Konvertierung ist primär. |
