## IDocumentsContainerLoadOptions class

Stellt Ladeoptionen für einen Dokumenten-Container dar.

Der IDocumentsContainerLoadOptions-Typ stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [convert_owned](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owned/) | Die Option, zu steuern, ob die im Dokumenten‑Container enthaltenen Dokumente konvertiert werden müssen. |
| [convert_owner](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/convert_owner/) | Die Option, zu steuern, ob der Dokumentencontainer selbst konvertiert werden muss. |
| [depth](/conversion/python-net/groupdocs.conversion.contracts/idocumentscontainerloadoptions/depth/) | Die Option, zu steuern, wie viele Ebenen tief die Konvertierung durchgeführt werden soll. |
