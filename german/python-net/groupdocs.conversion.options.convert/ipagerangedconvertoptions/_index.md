## IPageRangedConvertOptions class

Stellt Konvertierungsoptionen dar, die die Konvertierung einer bestimmten Seitenliste unterstützen.

Der Typ IPageRangedConvertOptions stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/format/) | Der gewünschte Dateityp, in den das Eingabedokument konvertiert werden soll. |
| [pages](/conversion/python-net/groupdocs.conversion.options.convert/ipagerangedconvertoptions/pages/) | Die Liste der Seitenindizes, die konvertiert werden sollen. Sollte angegeben werden, um bestimmte Seiten zu konvertieren. |
