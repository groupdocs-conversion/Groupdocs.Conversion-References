## embed_full_fonts property

Die Eigenschaft bestimmt, ob die vollständige Schriftdatei in das PDF eingebettet wird anstatt eines Teilsets.

Wenn auf True gesetzt, erhöht sich die Größe der Ausgabedatei, gewährleistet jedoch eine bessere Kompatibilität beim Bearbeiten des resultierenden PDFs. Gilt nur beim Konvertieren von WordProcessing-Dokumenten.
