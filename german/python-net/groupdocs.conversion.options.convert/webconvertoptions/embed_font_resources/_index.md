## embed_font_resources property

Das Flag, das angibt, ob Schriftressourcen in das Haupt‑HTML eingebettet werden sollen. Standard ist False.

Wenn `FixedLayout` auf `True` gesetzt ist, werden Schriftartressourcen immer eingebettet.
