## IPagedConvertOptions class

Stellt Konvertierungsoptionen dar, die die Seitenbegrenzung ermöglichen, indem Startseite und Seitenanzahl angegeben werden.

Der Typ IPagedConvertOptions stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | Der gewünschte Dateityp, in den das Eingabedokument konvertiert werden soll. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | Die Seitenzahl, ab der die Konvertierung beginnen soll. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | Die Anzahl der Seiten, die ab `PageNumber` konvertiert werden sollen. |
