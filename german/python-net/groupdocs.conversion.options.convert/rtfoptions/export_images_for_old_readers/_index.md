## export_images_for_old_readers property

Das Flag, das angibt, ob Schlüsselwörter für alte Leser in die RTF-Ausgabe geschrieben werden.

Dies kann die Größe des RTF-Dokuments erheblich beeinflussen. Standard ist False.
