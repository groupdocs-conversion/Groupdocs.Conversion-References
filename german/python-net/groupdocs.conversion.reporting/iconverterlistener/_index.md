## IConverterListener class

Definiert die Methoden, die zum Überwachen des Konverters verwendet werden.

Mehr erfahren.

- More about monitoring conversion progress: https://docs.groupdocs.com/display/conversionnet/Listening

Der IConverterListener-Typ stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [completed](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/completed/) | Aufgerufen, wenn die Konvertierung abgeschlossen ist. |
| [progress](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress/#current) | Wird jedes Mal aufgerufen, wenn sich der Konvertierungsfortschritt ändert. |
| [progress_byte](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/progress_byte/) |  |
| [started](/conversion/python-net/groupdocs.conversion.reporting/iconverterlistener/started/) | Aufgerufen, sobald die eigentliche Konvertierung beginnt. |
