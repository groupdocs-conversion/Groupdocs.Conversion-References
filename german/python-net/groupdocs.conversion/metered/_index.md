## Metered class

Verwaltet die nutzungsabhängige (Pay-per-Use) Lizenzierung.

Metered-Lizenzen werden nach tatsächlichem Verbrauch abgerechnet (typischerweise Seiten oder
verarbeitete Dokumente). Setzen Sie das public/private-Schlüsselpaar einmal bei
Anwendungsstart; der Wrapper meldet die Nutzung zurück an die GroupDocs
Lizenzserver im Hintergrund.

Der Typ Metered stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [get_consumption_credit](/conversion/python-net/groupdocs.conversion/metered/get_consumption_credit/) | Gibt das verbleibende Metered-Guthaben für den aktuellen Schlüssel zurück. |
| [get_consumption_quantity](/conversion/python-net/groupdocs.conversion/metered/get_consumption_quantity/) | Gibt die bisher verbrauchte gesamte Metered-Menge zurück. |
| [set_metered_key](/conversion/python-net/groupdocs.conversion/metered/set_metered_key/#public_key-private_key) | Aktivieren Sie die Metered-Abrechnung mit dem angegebenen public/private-Schlüsselpaar. |
