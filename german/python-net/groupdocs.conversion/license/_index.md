## License class

Verwaltet die Lizenzierung von GroupDocs.Conversion.

Lizenzierte Builds schalten den vollen Funktionsumfang des Wrappers frei bei
Laufzeit. Nicht lizenzierte Builds laufen im Evaluierungsmodus mit derselben API
Oberfläche, jedoch mit Beschränkungen bei Ausgabegröße und wassergezeichnetem Inhalt.

Der Lizenztyp stellt die folgenden Mitglieder bereit:

### Methoden
| Methode | Beschreibung |
| :- | :- |
| [set_license](/conversion/python-net/groupdocs.conversion/license/set_license/#license_source) | Wenden Sie eine Lizenz auf den aktuellen Prozess an. |
