## all_columns_in_one_page_per_sheet property

Die Eigenschaft bestimmt, ob der gesamte Spalteninhalt eines Blatts im Ergebnis auf einer einzigen Seite dargestellt wird.

Wenn auf Wahr gesetzt, wird die Breite der Papiergröße in den Seiteneinstellungen ignoriert, während andere Seiteneinstellungen wirksam bleiben.
