## preserve_document_structure property

Das Flag, das angibt, ob die Dokumentstruktur beim Konvertieren in PDF erhalten bleiben soll (Standard ist False).

Beachten Sie, dass das Exportieren der Dokumentstruktur den Speicherverbrauch erheblich erhöht, insbesondere bei großen Dokumenten.
