## IResourceLoadingOptions class

Stellt einen Satz von Optionen dar, um zu steuern, wie externe Ressourcen geladen werden.

Der Typ IResourceLoadingOptions stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [skip_external_resources](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/skip_external_resources/) | Die Eigenschaft gibt an, ob externe Ressourcen geladen werden. |
| [whitelisted_resources](/conversion/python-net/groupdocs.conversion.options.load/iresourceloadingoptions/whitelisted_resources/) | Die externen Ressourcen, die immer geladen werden. |
