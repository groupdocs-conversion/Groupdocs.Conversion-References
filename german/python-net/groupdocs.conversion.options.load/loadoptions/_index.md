## LoadOptions class

Stellt abstrakte Dokument-Ladeoptionen dar.

LoadOptions-Klassen geben den Typ des zu ladenden Dokuments an und enthalten optionale Parameter, wie `password`. Sie werden in zwei Gruppen eingeteilt: Optionen für eine Formatfamilie und Optionen für einen bestimmten Dateityp.
