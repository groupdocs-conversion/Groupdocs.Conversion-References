## restore_schema property

Die Eigenschaft bestimmt, ob die Konvertierung das Parsen von Attributen in einer GML‑Datei erlauben darf, wenn das XML‑Schema fehlt oder nicht geladen werden kann.

Wenn auf True gesetzt, erfordert der Konvertierungsleser nicht das Vorhandensein eines XML-Schemas. Der Standardwert ist False.
