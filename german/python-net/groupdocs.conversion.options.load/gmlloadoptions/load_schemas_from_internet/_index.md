## load_schemas_from_internet property

Die Eigenschaft bestimmt, ob die Konvertierung das Laden von XML‑Schemata aus dem Internet erlauben darf.

Wenn auf False gesetzt, werden Schemas mit absoluten URIs, die nicht mit 'file://' beginnen, nicht geladen. Der Standardwert ist False.
