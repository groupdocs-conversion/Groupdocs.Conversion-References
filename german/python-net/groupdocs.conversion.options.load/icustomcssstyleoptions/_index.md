## ICustomCssStyleOptions class

Stellt Optionen für benutzerdefiniertes CSS-Styling während der Dokumentkonvertierung dar.

Der Typ ICustomCssStyleOptions stellt die folgenden Mitglieder bereit:

### Eigenschaften
| Eigenschaft | Beschreibung |
| :- | :- |
| [custom_css_style](/conversion/python-net/groupdocs.conversion.options.load/icustomcssstyleoptions/custom_css_style/) | Der benutzerdefinierte CSS-Stil, der während der Konvertierung auf das Dokument angewendet wird und in das `<head>`‑Tag des Dokuments eingefügt wird, um die Darstellung anzupassen. |
