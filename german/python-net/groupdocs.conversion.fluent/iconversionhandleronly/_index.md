## IConversionHandlerOnly class

Stellt eine fluent API bereit, um ausschließlich Konvertierungs‑Handler festzulegen.

Erbt [`IConversionHandlersStage`](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlersstage/) für `Convert`/`Compress`; die gestaffelten `OnConversion*` Überladungen werden über das Schlüsselwort `new` beibehalten, um die bestehenden Rückgabetypen und die Rückwärtskompatibilität zu erhalten.

Der Typ IConversionHandlerOnly stellt die folgenden Mitglieder bereit:
