## IConversionByPageHandlerSetup class

Stellt eine fluent API bereit, um Seitenkonvertierungs‑Handler festzulegen.

Ermöglicht das Setzen von `OnConversionCompleted` und/oder `OnConversionFailed` in beliebiger Reihenfolge, höchstens einmal jeweils, oder das Überspringen beider.

Der Typ IConversionByPageHandlerSetup stellt die folgenden Mitglieder bereit:

| [compress_compression_convert_options](/conversion/python-net/groupdocs.conversion.fluent/iconversionbypagehandlersetup/compress_compression_convert_options/) |  |
