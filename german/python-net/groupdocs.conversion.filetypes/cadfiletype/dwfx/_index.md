## DWFX field

DWFX‑Datei ist eine 2D‑ oder 3D‑Zeichnung, die mit Autodesk‑CAD‑Software erstellt wurde. Sie wird im DWFx‑Format gespeichert, das einem .DWF‑Dateiformat ähnelt, jedoch mit Microsofts XML Paper Specification (XPS) formatiert ist.
