## AMF field

Eine AMF‑Datei enthält Richtlinien zur Objektbeschreibung, damit sie von Additive‑Manufacturing‑Prozessen verwendet werden kann. Sie enthält ein öffnendes XML‑Tag und endet mit einem Element. Vorher steht eine XML‑Deklarationszeile, die die XML‑Version und die Kodierung der Datei angibt. Erfahren Sie hier mehr über dieses Dateiformat.
