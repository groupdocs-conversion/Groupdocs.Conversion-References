## GLB field

GLB ist das binäre Dateiformat für 3D‑Modelle, das im GL Transmission Format (glTF) gespeichert wird. Dieses binäre Format speichert das glTF‑Asset (JSON, .bin und Bilder) in einem Binärblob. Erfahren Sie mehr über dieses Dateiformat hier.
