## PLY field

PLY, Polygon File Format, ist ein 3D‑Dateiformat, das grafische Objekte speichert, die als Sammlung von Polygonen beschrieben werden. Der Zweck dieses Dateiformats war es, einen einfachen und leicht zu handhabenden Dateityp zu schaffen, der allgemein genug ist, um für eine breite Palette von Modellen nützlich zu sein. Erfahren Sie hier mehr über dieses Dateiformat.
