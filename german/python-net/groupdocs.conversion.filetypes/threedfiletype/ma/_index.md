## MA field

Eine Datei mit der Erweiterung .ma ist eine 3D‑Projektdatei, die mit der Autodesk Maya‑Anwendung erstellt wurde. Sie enthält eine umfangreiche Liste von Textbefehlen, um Informationen über die Datei zu spezifizieren. Erfahren Sie mehr über dieses Dateiformat hier.
