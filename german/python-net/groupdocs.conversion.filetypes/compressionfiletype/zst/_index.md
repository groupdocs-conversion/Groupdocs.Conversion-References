## ZST field

Eine ZST‑Datei ist eine komprimierte Datei, die mit dem Zstandard‑(zstd‑)Kompressionsalgorithmus erzeugt wird. Sie wird durch verlustfreie Kompression des Algorithmus erstellt. Erfahren Sie hier mehr über dieses Dateiformat.
