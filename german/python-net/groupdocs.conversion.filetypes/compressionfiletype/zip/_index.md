## ZIP field

Eine Datei mit der Erweiterung .zip ist ein Archiv, das eine oder mehrere Dateien oder Verzeichnisse enthalten kann. Auf das Archiv kann eine Komprimierung der enthaltenen Dateien angewendet werden, um die ZIP-Dateigröße zu reduzieren. Erfahren Sie hier mehr über dieses Dateiformat.
