## NSF field

Eine Datei mit der Erweiterung .nsf (Notes Storage Facility) ist ein Datenbankdateiformat, das von der IBM Notes‑Software verwendet wird, die zuvor als Lotus Notes bekannt war. Sie definiert das Schema zum Speichern verschiedener Arten von Objekten wie E‑Mails, Terminen, Dokumenten, Formularen und Ansichten. Erfahren Sie hier mehr über dieses Dateiformat.
