## SQL field

Eine Datei mit der Erweiterung .sql ist eine Structured Query Language (SQL)‑Datei, die Code enthält, um mit relationalen Datenbanken zu arbeiten. Sie wird verwendet, um SQL‑Anweisungen für CRUD‑Operationen (Create, Read, Update und Delete) auf Datenbanken zu schreiben. Erfahren Sie hier mehr über dieses Dateiformat.
