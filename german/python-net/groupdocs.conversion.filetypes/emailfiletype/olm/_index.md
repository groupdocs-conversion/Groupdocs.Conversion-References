## OLM field

Eine Datei mit der Erweiterung .olm ist eine Microsoft‑Outlook‑Datei für das Mac‑Betriebssystem. Eine OLM‑Datei speichert E‑Mail‑Nachrichten, Journale, Kalenderdaten und andere Anwendungsdaten. Sie ist ähnlich zu PST‑Dateien, die von Outlook unter Windows verwendet werden. OLM‑Dateien, die von Outlook für Mac erstellt wurden, können jedoch nicht in Outlook für Windows geöffnet werden. Erfahren Sie hier mehr über dieses Dateiformat.
