## SHP field

SHP ist die Dateierweiterung für einen der primären Dateitypen, die zur Darstellung von ESRI Shapefile verwendet werden. Sie stellt geodatenbasierte Informationen in Form von Vektordaten dar, die von Geographic Information Systems (GIS)-Anwendungen genutzt werden. Weitere Informationen zu diesem Dateiformat finden Sie hier.
