## KML field

KML (Keyhole Markup Language) enthält geodatenbasierte Informationen in XML‑Notation. Als KML gespeicherte Dateien können in Geographic Information System (GIS)-Anwendungen geöffnet werden, sofern diese sie unterstützen. Viele Anwendungen haben begonnen, das KML‑Dateiformat zu unterstützen, nachdem es zum internationalen Standard erklärt wurde. KML verwendet eine tagbasierte Struktur mit verschachtelten Elementen und Attributen. Weitere Informationen zu diesem Dateiformat finden Sie hier.
