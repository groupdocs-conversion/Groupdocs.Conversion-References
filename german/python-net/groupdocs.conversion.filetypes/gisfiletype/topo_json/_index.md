## TOPO_JSON field

TopoJSON ist eine Erweiterung von GeoJSON, die Topologie kodiert. Anstatt Geometrien einzeln darzustellen, werden Geometrien in TopoJSON-Dateien aus gemeinsamen Liniensegmenten, sogenannten Bögen, zusammengesetzt.
