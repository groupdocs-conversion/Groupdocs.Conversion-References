## GDB field

Die ESRI-Dateigeodatenbank (FileGDB) ist eine Sammlung von Dateien in einem Ordner auf der Festplatte, die zusammengehörige Geodaten wie Feature-Datasets, Feature-Klassen und zugehörige Tabellen enthalten. Damit sie funktioniert, müssen bestimmte weitere Dateien zusammen mit der .gdb‑Datei im selben Verzeichnis aufbewahrt werden. Weitere Informationen zu diesem Dateiformat finden Sie hier.
