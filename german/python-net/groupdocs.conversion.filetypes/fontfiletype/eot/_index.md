## EOT field

Eine Datei mit der Erweiterung .eot ist eine OpenType‑Schrift, die in ein Dokument eingebettet ist. Diese werden hauptsächlich in Webdateien wie einer Webseite verwendet. Sie wurde von Microsoft erstellt und wird von Microsoft‑Produkten, einschließlich PowerPoint‑Präsentationen (.pps), unterstützt. Erfahren Sie mehr über dieses Dateiformat hier.
