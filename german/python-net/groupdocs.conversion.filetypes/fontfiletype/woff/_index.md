## WOFF field

Eine Datei mit der Erweiterung .woff ist eine Web‑Schriftdatei, die auf dem Web Open Font Format (WOFF) basiert. Sie besitzt einen formatspezifischen komprimierten Container, der entweder auf TrueType (.TTF) oder OpenType (.OTT) Schriftarten basiert. Erfahren Sie mehr über dieses Dateiformat hier.
