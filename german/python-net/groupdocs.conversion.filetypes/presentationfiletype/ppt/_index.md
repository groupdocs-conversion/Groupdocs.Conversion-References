## PPT field

Eine Datei mit der Erweiterung PPT stellt eine PowerPoint‑Datei dar, die aus einer Sammlung von Folien für die Anzeige als Diashow besteht. Sie gibt das binäre Dateiformat an, das von Microsoft PowerPoint 97‑2003 verwendet wird. Erfahren Sie hier mehr über dieses Dateiformat.
