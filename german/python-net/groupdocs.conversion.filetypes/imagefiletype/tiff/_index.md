## TIFF field

TIFF, Tagged Image File Format, stellt Rasterbilder dar, die für die Verwendung auf einer Vielzahl von Geräten gedacht sind, die diesem Dateiformatstandard entsprechen. Es ist in der Lage, bilevel‑, Graustufen‑, Paletten‑ und Vollfarbbilddaten in mehreren Farbräumen zu beschreiben. Erfahren Sie mehr über dieses Dateiformat hier.
