## HEIC field

Eine HEIC‑Datei ist ein High‑Efficiency‑Container‑Image‑Dateiformat, das mehrere Bilder als Sammlung in einer einzigen Datei speichern kann. Das Format wurde von Apple als Variante des HEIF mit der Einführung von iOS 11 übernommen. Erfahren Sie hier mehr über dieses Dateiformat.
