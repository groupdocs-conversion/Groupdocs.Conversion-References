## SXC field

Das Dateiformat SXC (Sun XML Calc) gehört zu einer Office‑Suite namens OpenOffice.org. Dieses Format deckt im Allgemeinen die Tabellenkalkulationsbedürfnisse der Benutzer ab, da es ein XML‑basiertes Tabellenkalkulationsdateiformat ist. Das SXC‑Format unterstützt Formeln, Funktionen, Makros und Diagramme sowie DataPilot. Erfahren Sie hier mehr über dieses Dateiformat.
