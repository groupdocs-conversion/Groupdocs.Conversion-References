## OTS field

Eine Datei mit der Erweiterung .ots ist eine OpenDocument Spreadsheet‑Vorlagendatei, die mit der im Apache OpenOffice enthaltenen Calc‑Anwendung erstellt wird. Die Calc‑Software ist vergleichbar mit Excel, das in Microsoft Office verfügbar ist. Weitere Informationen zu diesem Dateiformat finden Sie hier.
