## XLTX field

Die XLTX‑Datei steht für Microsoft‑Excel‑Vorlagen, die auf den Office‑OpenXML‑Dateiformatspezifikationen basieren. Sie wird verwendet, um eine Standardvorlagendatei zu erstellen, die zur Erzeugung von XLSX‑Dateien genutzt werden kann, die dieselben Einstellungen wie in der XLTX‑Datei aufweisen. Weitere Informationen zu diesem Dateiformat finden Sie hier.
