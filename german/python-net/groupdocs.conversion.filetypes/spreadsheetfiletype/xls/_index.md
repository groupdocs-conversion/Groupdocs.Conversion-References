## XLS field

XLS steht für das Excel Binary File Format. Solche Dateien können von Microsoft Excel sowie anderen ähnlichen Tabellenkalkulationsprogrammen wie OpenOffice Calc oder Apple Numbers erstellt werden. Weitere Informationen zu diesem Dateiformat finden Sie hier.
