## ODS field

Dateien mit der Erweiterung ODS stehen für das OpenDocument Spreadsheet Document‑Format, das vom Benutzer bearbeitet werden kann. Daten werden in der ODF‑Datei in Zeilen und Spalten gespeichert. Weitere Informationen zu diesem Dateiformat finden Sie hier.
