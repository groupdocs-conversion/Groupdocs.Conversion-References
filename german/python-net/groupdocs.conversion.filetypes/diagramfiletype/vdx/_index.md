## VDX field

Alle in Microsoft Visio erstellten Zeichnungen oder Diagramme, die im XML‑Format gespeichert werden, haben die Erweiterung .VDX. Eine Visio‑Zeichnungs‑XML‑Datei wird in der Visio‑Software erstellt, die von Microsoft entwickelt wurde. Erfahren Sie hier mehr über dieses Dateiformat.
