## PUB field

Eine PUB‑Datei ist ein Microsoft Publisher-Dokumentdateiformat. Sie wird verwendet, um verschiedene Arten von Layout‑Dokumenten zu erstellen, wie Newsletter, Flyer, Broschüren, Postkarten usw. PUB‑Dateien können Text, Raster‑ und Vektorbilder enthalten. Erfahren Sie hier mehr über dieses Dateiformat.
