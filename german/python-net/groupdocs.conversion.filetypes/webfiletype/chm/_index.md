## CHM field

Das CHM-Dateiformat stellt eine Microsoft HTML-Hilfedatei dar, die aus einer Sammlung von HTML‑Seiten besteht. Es bietet einen Index für den schnellen Zugriff auf die Themen und die Navigation zu verschiedenen Teilen des Hilfedokuments. Erfahren Sie hier mehr über dieses Dateiformat.
