## MHTML field

Dateien mit der MHTML-Erweiterung stellen ein Webseitensicherungsformat dar, das von verschiedenen Anwendungen erstellt werden kann. Das Format wird als Archivformat bezeichnet, weil es den Web‑HTML‑Code und zugehörige Ressourcen in einer einzigen Datei speichert. Erfahren Sie hier mehr über dieses Dateiformat.
