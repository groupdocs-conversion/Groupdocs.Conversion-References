### Mp3 {#Mp3}
```
public static final AudioFileType Mp3
```


Dateien mit der Erweiterung .mp3 sind digital codierte Dateiformate für Audiodateien, die formell auf MPEG‑1 Audio Layer III oder MPEG‑2 Audio Layer III basieren. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/mp3/).


### Aac {#Aac}
```
public static final AudioFileType Aac
```


AAC (Advanced Audio Coding) bezieht sich auf einen digitalen Audio‑Codierungsstandard, der Audiodateien basierend auf verlustbehafteter Audiokompression darstellt. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/aac/).


### Aiff {#Aiff}
```
public static final AudioFileType Aiff
```


Das AIFF (Audio Interchange File Format) ist ein unkomprimiertes Audio-Dateiformat, das 1998 von Apple entwickelt wurde, basiert jedoch auf EA IFF 85. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/aiff/).


### Flac {#Flac}
```
public static final AudioFileType Flac
```


FLAC(Free Lossless Audio Codec) ist ein verlustfreies Kompressions‑Audio‑Codierungsformat, das von der Xiph.Org Foundation entwickelt wurde. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/flac/).


### M4a {#M4a}
```
public static final AudioFileType M4a
```


Das M4A-Dateiformat ist eine Audiodatei, die mit dem AAC (Advanced Audio Coding) erstellt wurde, das als verlustbehaftete Kompression bekannt ist. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/m4a/).


### Wma {#Wma}
```
public static final AudioFileType Wma
```


Eine Datei mit der Erweiterung .wma stellt eine Audiodatei dar, die im Advanced Systems Format (ASF) gespeichert ist. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/wma/).


### Ac3 {#Ac3}
```
public static final AudioFileType Ac3
```


Eine Datei mit der Erweiterung .ac3 ist eine Audio Codec 3‑Datei, die von Dolby Laboratories eingeführt wurde. Es ist ein Audioformat, das bis zu sechs Audiokanäle unterstützen kann. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/ac3/).


### Ogg {#Ogg}
```
public static final AudioFileType Ogg
```


OGG ist eine Ogg Vorbis komprimierte Audiodatei, die mit der Erweiterung .ogg gespeichert wird. OGG-Dateien werden zum Speichern von Audiodaten verwendet und können außerdem Künstler‑ und Titelinformationen sowie Metadaten enthalten. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/ogg/).


### Wav {#Wav}
```
public static final AudioFileType Wav
```


WAV, bekannt für WAVE (Waveform Audio File Format), ist ein Teil der Resource Interchange File Format (RIFF)-Spezifikation von Microsoft zum Speichern digitaler Audiodateien. Erfahren Sie mehr über dieses Dateiformat [hier](../https://docs.fileformat.com/audio/ogg/).
