### Tiff {#Tiff}
```
public static final ImageFileType Tiff
```


TIFF, Tagged Image File Format, stellt Rasterbilder dar, die für die Verwendung auf einer Vielzahl von Geräten gedacht sind, die diesem Dateiformatstandard entsprechen. Es kann bilevel, Graustufen-, Palettenfarb- und Vollfarbbilddaten in mehreren Farbräumen beschreiben.
Erfahren Sie mehr über dieses Dateiformat [hier](../https://wiki.fileformat.com/image/tiff).

### Png {#Png}

PNG, Portable Network Graphics, bezeichnet ein Rasterbilddateiformat, das verlustfreie Kompression verwendet. Dieses Dateiformat wurde als Ersatz des Graphics Interchange Format (GIF) erstellt und hat keine urheberrechtlichen Einschränkungen.
Erfahren Sie mehr über dieses Dateiformat [hier](../https://wiki.fileformat.com/image/png).


### Gif {#Gif}
```

```


Ein GIF oder Graphics Interchange Format ist ein stark komprimiertes Bild. Für jedes Bild erlaubt GIF typischerweise bis zu 8 Bit pro Pixel und bis zu 256 Farben im Bild.
Erfahren Sie mehr über dieses Dateiformat [hier](../https://wiki.fileformat.com/image/gif).
