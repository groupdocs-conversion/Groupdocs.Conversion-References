Der Namespace GroupDocs.Conversion.Contracts bietet Mitglieder zum Instanziieren und Freigeben von Ausgabedokumenten, zur Verwaltung von Schriftartersetzungen usw.

| Klasse | Beschreibung |
| --- | --- |

| [Enumeration](../com.groupdocs.conversion.contracts/enumeration) | Generische Aufzählungsklasse. |
| [FontSubstitute](../com.groupdocs.conversion.contracts/fontsubstitute) | Beschreibt den Ersatz für fehlende Schriftart. |
| [PossibleConversions](../com.groupdocs.conversion.contracts/possibleconversions) | Stellt eine Zuordnung dar, welche Konvertierungspaare für ein bestimmtes Quelldateiformat unterstützt werden. |
| [TargetConversion](../com.groupdocs.conversion.contracts/targetconversion) | Stellt mögliche Zielkonvertierung dar und ein Flag, ob es primär oder sekundär ist. |
