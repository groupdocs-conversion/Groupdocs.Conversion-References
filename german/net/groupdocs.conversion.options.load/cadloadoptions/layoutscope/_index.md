## CadLoadOptions.LayoutScope property

Liest oder setzt, welche Zeichenbereiche konvertiert werden. Standard ist [`Both`](../../cadlayoutscope/both), das die Konvertierung nicht einschränkt. Es wird ignoriert, wenn [`LayoutNames`](../layoutnames) angegeben ist, weil explizite Layoutnamen immer Vorrang haben. Ein `null`-Wert wird als [`Both`](../../cadlayoutscope/both) behandelt.

```csharp
public CadLayoutScope LayoutScope { get; set; }
```

### Hinweise

Ein Umfang, der keine der von einer Zeichnung angebotenen Blätter auswählt, lässt die Konvertierung mit einer [`InvalidLoadOptionsException`](../../../groupdocs.conversion.exceptions/invalidloadoptionsexception) fehlschlagen, die den Umfang und die vorhandenen Blätter nennt, anstatt die vom Umfang ausgeschlossenen Bereiche zu rendern. Eine Zeichnung, die überhaupt kein Blatt anbietet, bleibt unbeeinflusst und wird weiterhin als eine Einheit konvertiert. Nicht berücksichtigt beim Konvertieren zu PDF/UA-1, aus dem Grund, der bei [`LayoutNames`](../layoutnames) angegeben ist.
