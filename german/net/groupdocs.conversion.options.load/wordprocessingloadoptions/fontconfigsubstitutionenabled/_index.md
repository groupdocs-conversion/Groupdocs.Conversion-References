## WordProcessingLoadOptions.FontConfigSubstitutionEnabled property

Ersetzt fehlende Schriften automatisch basierend auf FontConfig im System. Standard: false.

```csharp
public bool FontConfigSubstitutionEnabled { get; set; }
```

### Hinweise

**Note:** The order of substitution is as follows:

1) Fehlende Schriftarten automatisch basierend auf dem Schriftartnamen ersetzen (falls aktiviert).

2) Fehlende Schriftarten automatisch anhand von FontConfig ersetzen (falls aktiviert).

3) Fehlende Schriftarten anhand von FontSubstitutes ersetzen (falls festgelegt).

4) Fehlende Schriftarten automatisch anhand von FontInfo ersetzen (falls aktiviert).

5) Fehlende Schriftarten anhand von DefaultFont ersetzen (falls festgelegt).
