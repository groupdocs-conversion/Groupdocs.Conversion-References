## ConversionEvents.OnFontSubstituted property

Wird ausgelöst, wenn eine im Quell‑Dokument referenzierte Schriftart nicht verfügbar ist und ersetzt wird (entweder durch eine kundenseitig bereitgestellte [`FontSubstitute`](../../../groupdocs.conversion.contracts/fontsubstitute)-Regel, durch die konfigurierte Standardschriftart oder durch das interne Fallback der Konvertierungspipeline).

```csharp
public Action<FontSubstitutionContext> OnFontSubstituted { get; set; }
```

### Hinweise

Das Ereignis wird pro `(SourceFileName, OriginalFontName)` innerhalb eines einzelnen `Converter.Convert(...)`‑Aufrufs dedupliziert — Abonnenten erhalten höchstens eine Benachrichtigung pro fehlender Schriftart pro Quelldokument. Es wird synchron im Konvertierungsthread ausgelöst. Nicht bei Bildkonvertierungen ausgelöst.

Bei Präsentationsdokumenten wird die Schriftart‑Substitution nur unter Windows erkannt, da die Engine sie über plattformspezifisches Schriftarten‑Matching auflöst, das auf anderen Betriebssystemen nicht verfügbar ist.
