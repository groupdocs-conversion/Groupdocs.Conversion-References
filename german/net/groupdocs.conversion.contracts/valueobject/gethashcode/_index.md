## ValueObject.GetHashCode method

```csharp
public override int GetHashCode()
```

### Rückgabewert

Ein Hashcode für das aktuelle Objekt.

### Hinweise

Array-, Listen- und Dictionary-Komponenten werden anhand ihres Inhalts gehasht, was dem Vergleichsverhalten der Gleichheit entspricht, sodass zwei Objekte, die gleich sind, auch denselben Hashwert haben und als Dictionary‑Schlüssel oder Set‑Elemente verwendet werden können. Dies gilt NICHT für eine Komponente, die ein anderes IEnumerable ist: Eine solche Komponente wird nach Referenz gehasht, und eine, die als lazy‑Iterator bereitgestellt wird, liefert bei jedem Zugriff einen anderen Wert, sodass ein Objekt, das sie trägt, überhaupt nicht als Schlüssel verwendet werden kann. Verschachtelte Sammlungen werden ebenfalls nach Referenz verglichen und gehasht, nicht rekursiv. Eine weitere Konsequenz ist, dass das Mutieren einer von einem Wertobjekt exponierten Sammlung – z. B. das Hinzufügen zu einer Seitenliste oder das Schreiben in ein Layout‑Namens‑Array – den Hash dieses Objekts ändert, sodass eine bereits im Hash‑Container gespeicherte Instanz unerreichbar wird. Betrachte ein Wertobjekt als unveränderlich, sobald es als Schlüssel verwendet wurde.
