## EvaluationLimitReachedException class

GroupDocs-Ausnahme, die ausgelöst wird, wenn das Bewertungskonvertierungs‑Kontingent für den aktuellen Prozess aufgebraucht ist.

```csharp
public sealed class EvaluationLimitReachedException : GroupDocsConversionException
```

### Hinweise

Wird nur ohne Lizenz ausgelöst. Das Anwenden einer Lizenz setzt das Kontingent zurück, sodass ein lizenzierter Prozess diese Ausnahme nie sieht, egal wie viele Dokumente er konvertiert.
