## IConversionHandlersStage interface

Flach strukturierte Stufe für Konvertierungshandler. Ermöglicht das Setzen von `OnConversionCompleted` oder `OnConversionFailed` in beliebiger Reihenfolge und beliebig oft, bevor zu `Convert` / `Compress` übergegangen wird. Ereignisse sollten in der frühen Phase über [`WithEvents`](../iconversionsettings/withevents) registriert werden, nicht in dieser Stufe.

```csharp
public interface IConversionHandlersStage : IConversionConvertOrCompress
```
