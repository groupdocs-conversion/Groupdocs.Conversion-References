## EmailFileType.Olm field

Eine Datei mit der Erweiterung .olm ist eine Microsoft‑Outlook‑Datei für das macOS. Eine OLM‑Datei speichert E‑Mail‑Nachrichten, Journale, Kalenderdaten und andere Arten von Anwendungsdaten. Diese sind ähnlich zu PST‑Dateien, die von Outlook unter Windows verwendet werden. Allerdings können OLM‑Dateien, die von Outlook für Mac erstellt wurden, nicht in Outlook für Windows geöffnet werden. Erfahren Sie mehr über dieses Dateiformat [hier](https://wiki.fileformat.com/email/olm).
