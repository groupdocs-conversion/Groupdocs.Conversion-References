## ImageFileType.Jfif field

JFIF (JPEG File Interchange Format (JFIF)) ist ein Bilddateiformat, das die .jfif-Erweiterung verwendet. JFIF baut auf JIF (JPEG Interchange Format) auf, indem es die Komplexität reduziert und dessen Einschränkungen löst.
