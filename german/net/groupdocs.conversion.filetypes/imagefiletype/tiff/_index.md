## ImageFileType.Tiff field

TIFF, Tagged Image File Format, steht für Rasterbilder, die für die Verwendung auf einer Vielzahl von Geräten gedacht sind, die diesem Dateiformatstandard entsprechen. Es kann Bilevel-, Graustufen-, Paletten‑ und Vollfarbbilddaten in mehreren Farbräumen beschreiben. Erfahren Sie mehr über dieses Dateiformat [hier](https://wiki.fileformat.com/image/tiff).
