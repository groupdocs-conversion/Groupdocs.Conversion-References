## ImageFileType.Heic field

Eine HEIC-Datei ist ein High-Efficiency Container Image-Dateiformat, das mehrere Bilder als Sammlung in einer einzigen Datei speichern kann. Das Format wurde von Apple als Variante des HEIF mit dem Start von iOS 11 übernommen. Erfahren Sie mehr über dieses Dateiformat [hier](https://docs.fileformat.com/image/heic/).
