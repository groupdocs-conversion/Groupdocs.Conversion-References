## DiagramFileType.Vsdx field

Dateien mit der .VSDX-Erweiterung repräsentieren das Microsoft Visio-Dateiformat, das ab Microsoft Office 2013 eingeführt wurde. Es wurde entwickelt, um das binäre Dateiformat .VSD zu ersetzen, das von früheren Versionen von Microsoft Visio unterstützt wird. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://wiki.fileformat.com/image/vsdx).
