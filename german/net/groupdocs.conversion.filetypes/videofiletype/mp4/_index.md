## VideoFileType.Mp4 field

MP4 (Kurzform für MPEG‑4 Part 14) ist ein Dateiformat, das auf ISO/IEC 14496‑12:2004 basiert und auf dem QuickTime File Format aufbaut, jedoch formell die Unterstützung von Initial Object Descriptors (IOD) und anderen MPEG‑Funktionen spezifiziert. Erfahren Sie mehr über dieses Dateiformat [hier](https://docs.fileformat.com/video/mp4/).
