## FontFileType.Woff field

Eine Datei mit der Erweiterung .woff ist eine Web‑Schriftdatei, die auf dem Web Open Font Format (WOFF) basiert. Sie enthält einen format­spezifischen komprimierten Container, der entweder auf TrueType‑(.TTF) oder OpenType‑(.OTT) Schriftarten beruht. Erfahren Sie mehr über dieses Dateiformat [hier](https://docs.fileformat.com/font/woff/).
