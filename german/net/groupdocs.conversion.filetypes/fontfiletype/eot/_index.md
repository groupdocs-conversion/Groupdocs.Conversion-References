## FontFileType.Eot field

Eine Datei mit der Erweiterung .eot ist eine OpenType‑Schrift, die in ein Dokument eingebettet ist. Diese werden hauptsächlich in Web‑Dateien wie einer Webseite verwendet. Sie wurde von Microsoft erstellt und wird von Microsoft‑Produkten, einschließlich PowerPoint‑Präsentationen im .pps‑Format, unterstützt.
