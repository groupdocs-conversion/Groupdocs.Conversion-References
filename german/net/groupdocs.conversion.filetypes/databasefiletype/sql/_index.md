## DatabaseFileType.Sql field

Eine Datei mit der Erweiterung .sql ist eine Structured Query Language (SQL)-Datei, die Code enthält, um mit relationalen Datenbanken zu arbeiten. Sie wird verwendet, um SQL-Anweisungen für CRUD‑Operationen (Erstellen, Lesen, Aktualisieren und Löschen) auf Datenbanken zu schreiben. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://docs.fileformat.com/database/sql).
