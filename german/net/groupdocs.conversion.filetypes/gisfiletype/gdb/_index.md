## GisFileType.Gdb field

Die ESRI-Dateigeodatenbank (FileGDB) ist eine Sammlung von Dateien in einem Ordner auf der Festplatte, die zusammengehörige geodatenbezogene Daten wie Feature-Datensätze, Feature-Klassen und zugehörige Tabellen enthalten. Sie erfordert, dass bestimmte weitere Dateien neben der .gdb-Datei im selben Verzeichnis aufbewahrt werden, damit sie funktioniert. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://docs.fileformat.com/database/gdb/).
