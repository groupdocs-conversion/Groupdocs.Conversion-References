## CompressionFileType.Cab field

Eine Datei mit der Erweiterung .cab gehört zu einer Windows-Cabinet-Datei, die zur Kategorie der Systemdateien zählt. Es ist eine Datei, die im Archivdateiformat in den Versionen von Microsoft Windows gespeichert wird, die komprimierte Datenalgorithmen wie LZX, Quantum und ZIP unterstützen. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://docs.fileformat.com/system/cab/).
