## PageDescriptionLanguageFileType.Svgz field

Eine SVGZ-Datei ist tatsächlich eine komprimierte Version einer SVG-Datei. Dies ermöglicht eine einfachere Verteilung der Datei online. Wenn eine SVG-Datei mit dem .GZIP-Kompressionsalgorithmus komprimiert wird, erhält sie die Dateierweiterung .svgz.
