## ProjectManagementFileType class

Definiert Projektdateiformate, die von Projektmanagement-Software wie Microsoft Project, Primavera P6 usw. erstellt werden. Eine Projektdatei ist eine Sammlung von Aufgaben, Ressourcen und deren Zeitplanung, um ein messbares Ergebnis in Form eines Produkts oder einer Dienstleistung zu erzielen. Projektmanagement-Dokumente. Enthält die folgenden Dateitypen: [`Mpp`](./mpp), [`Mpt`](./mpt), [`Mpx`](./mpx). Erfahren Sie mehr über Projektmanagement-Formate [hier](https://wiki.fileformat.com/project-management).
