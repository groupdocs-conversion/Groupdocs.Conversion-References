## IPagedConvertOptions class

Representerar konverteringsalternativ som tillåter begränsning av sidor genom att ange startsid och antal sidor.

Typen IPagedConvertOptions visar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [format](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/format/) | Den önskade filtypen som inmatningsdokumentet ska konverteras till. |
| [page_number](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/page_number/) | Sidnumret att börja konverteringen från. |
| [pages_count](/conversion/python-net/groupdocs.conversion.options.convert/ipagedconvertoptions/pages_count/) | Antalet sidor att konvertera med start från `PageNumber`. |
