## Metered class

Hanterar mätbaserad (betala per användning) licensiering.

Metered-licenser faktureras baserat på faktisk förbrukning (vanligtvis sidor eller
dokument som bearbetas). Ställ in det offentliga/privata nyckelparet en gång vid
applikationsstart; omslaget rapporterar användning tillbaka till GroupDocs
licensserver i bakgrunden.

Metered-typen exponerar följande medlemmar:

### Metoder
| Metod | Beskrivning |
| :- | :- |
| [get_consumption_credit](/conversion/python-net/groupdocs.conversion/metered/get_consumption_credit/) | Returnera den återstående meterade krediten för den aktuella nyckeln. |
| [get_consumption_quantity](/conversion/python-net/groupdocs.conversion/metered/get_consumption_quantity/) | Returnera den totala meterade mängden som har förbrukats hittills. |
| [set_metered_key](/conversion/python-net/groupdocs.conversion/metered/set_metered_key/#public_key-private_key) | Aktivera meterad fakturering med det angivna offentliga/privata nyckelparet. |
