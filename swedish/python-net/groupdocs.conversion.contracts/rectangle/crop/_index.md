## crop {#crop_left-crop_top-crop_right-crop_bottom}

Skapar en beskuren version av den aktuella rektangeln genom att ta bort angivna marginaler.

```python
def crop(self, crop_left, crop_top, crop_right, crop_bottom):
    ...
```

| Parameter | Typ | Beskrivning |
| :- | :- | :- |
| crop_left | `int` | Antalet pixlar som ska tas bort från vänstra sidan. |
| crop_top | `int` | Antalet pixlar som ska tas bort från övre sidan. |
| crop_right | `int` | Antalet pixlar att ta bort från högra sidan. |
| crop_bottom | `int` | Antalet pixlar att ta bort från nedre sidan. |

**Returns:** Rectangle: A new cropped rectangle.
