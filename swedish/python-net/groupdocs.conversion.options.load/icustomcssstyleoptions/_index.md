## ICustomCssStyleOptions class

Representerar alternativ för anpassad CSS‑styling under dokumentkonvertering.

ICustomCssStyleOptions-typen visar följande medlemmar:

### Egenskaper
| Egenskap | Beskrivning |
| :- | :- |
| [custom_css_style](/conversion/python-net/groupdocs.conversion.options.load/icustomcssstyleoptions/custom_css_style/) | Den anpassade CSS-stilen som ska tillämpas på dokumentet under konvertering, vilken kommer att infogas i dokumentets `<head>`-tagg för att anpassa rendering. |
