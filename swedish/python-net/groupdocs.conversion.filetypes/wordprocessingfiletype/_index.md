## WordProcessingFileType class

Klassen WordProcessingFileType definierar filformat för ordbehandling, som täcker enkla text- och riktextvarianter.

Vanliga textfiler innehåller oformaterad text utan några teckensnitt eller sidinställningar tillämpade. Rich‑text‑filer stödjer formateringsalternativ såsom teckensnittstyper, stilar (fet, kursiv, understruken), sidmarginaler, rubriker, punktlistor, nummer och andra funktioner.

### Exempel

```python
from groupdocs.conversion import Converter
from groupdocs.conversion.options.convert import WordProcessingConvertOptions
from groupdocs.conversion.filetypes import WordProcessingFileType

def specify_output_format():
    # Instansiera Converter med inmatningsdokumentet
    with Converter("./business-plan.docx") as converter:
        # Definiera konverteringsalternativ; standardutdataformat är DOCX
        word_convert_options = WordProcessingConvertOptions()
        # Ändra utdataformatet inom formatfamiljen från DOCX till TXT
        word_convert_options.format = WordProcessingFileType.Txt

        # Konvertera inmatningsdokumentet till TXT
        converter.convert("./business-plan.txt", word_convert_options)

if __name__ == "__main__":
    specify_output_format()
```
