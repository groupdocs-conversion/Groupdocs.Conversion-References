## PLY field

PLY, Polygon File Format, representerar ett 3D‑filformat som lagrar grafiska objekt beskrivna som en samling polygoner. Syftet med detta filformat var att skapa en enkel och lättfil som är tillräckligt allmän för att vara användbar för ett brett spektrum av modeller. Läs mer om detta filformat här.
