## GML field

GML står för Geography Markup Language som är baserad på XML-specifikationer utvecklade av Open Geospatial Consortium (OGC). Formatet används för att lagra geografiska datafunktioner för utbyte mellan olika filformat. Det fungerar som ett modelleringsspråk för geografiska system samt ett öppet utbytesformat för geografiska transaktioner på internet. Läs mer om detta filformat här.
