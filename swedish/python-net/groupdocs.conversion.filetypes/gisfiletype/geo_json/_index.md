## GEO_JSON field

GeoJSON är ett JSON-baserat format utformat för att representera geografiska funktioner med deras icke-spatiala attribut. Detta format definierar olika JSON (JavaScript Object Notation)-objekt och deras sammanslagningsmetod. JSON-formatet representerar en samlad information om de geografiska funktionerna, deras rumsliga utbredning och egenskaper. Läs mer om detta filformat här.
