## XLTM field

XLTM‑filändelsen representerar filer som genereras av Microsoft Excel som makroaktiverade mallfiler. XLTM‑filer liknar XLTX i struktur förutom att den senare inte stödjer att skapa mallfiler med makron. Läs mer om detta filformat här.
