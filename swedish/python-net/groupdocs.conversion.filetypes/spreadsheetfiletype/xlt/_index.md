## XLT field

Filer med .XLT‑extension är mallfiler skapade med Microsoft Excel, ett kalkylprogram som ingår i Microsoft Office‑sviten. Microsoft Office 97‑2003 stödde att skapa nya XLT‑filer samt att öppna dem. Läs mer om detta filformat här.
