## SQL field

En fil med .sql‑extension är en Structured Query Language (SQL)‑fil som innehåller kod för att arbeta med relationsdatabaser. Den används för att skriva SQL‑satser för CRUD‑operationer (Create, Read, Update, Delete) på databaser. Läs mer om detta filformat här.
