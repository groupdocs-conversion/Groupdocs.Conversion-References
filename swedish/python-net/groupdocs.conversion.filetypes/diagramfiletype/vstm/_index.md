## VSTM field

Filer med VSTM‑tillägg är mallfiler skapade med Microsoft Visio som stödjer makron. Till skillnad från VSDX‑filer kan filer som skapats från VSTM‑mallar köra makron som utvecklats i Visual Basic for Applications (VBA)-kod. Läs mer om detta filformat här.
