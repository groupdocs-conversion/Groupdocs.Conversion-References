## PPTX field

Filer med PPTX‑tillägget är presentationsfiler som skapats med det populära Microsoft PowerPoint‑programmet. Till skillnad från den tidigare versionen av presentationsfilformatet PPT, som var binärt, är PPTX‑formatet baserat på Microsoft PowerPoints öppna XML‑presentationsfilformat.
