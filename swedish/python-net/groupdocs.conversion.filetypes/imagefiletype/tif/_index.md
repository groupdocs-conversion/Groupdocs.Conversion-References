## TIF field

TIF, Tagged Image File Format, representerar rasterbilder som är avsedda för användning på en mängd olika enheter som följer denna filformatstandard. Det kan beskriva tvånivå-, gråskala-, palettfärg- och fullfärgsbilddata i flera färgrymder. Läs mer om detta filformat här.
