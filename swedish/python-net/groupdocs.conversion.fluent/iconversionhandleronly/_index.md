## IConversionHandlerOnly class

Tillhandahåller ett flytande gränssnitt för att endast ställa in konverteringshanterare.

Ärver [`IConversionHandlersStage`](/conversion/python-net/groupdocs.conversion.fluent/iconversionhandlersstage/) för `Convert`/`Compress`; de stage‑ade `OnConversion*`‑överladdningarna behålls via nyckelordet `new` för att bevara de befintliga returtyperna och bakåtkompatibiliteten.

Typen IConversionHandlerOnly visar följande medlemmar:
