Namnrymden tillhandahåller klasser för att konvertera dokument till alla populära filformat på ett enkelt och intuitivt sätt.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ConversionEvents](./conversionevents) | Samlar konverteringslivscykelns händelsehanterare. Skicka en instans till [`Converter`](../groupdocs.conversion/converter) konstruktorns `events`-parameter eller till den flytande `WithEvents`-metoden. Föredra detta framför de enskilda [`ConverterSettings`](../groupdocs.conversion/convertersettings) egenskaperna för hanterare, som är föråldrade. |
| [ConvertContext](./convertcontext) | Definierar konverteringskontext. |
| [ConvertedContext](./convertedcontext) | Definierar konverteringskontext. |
| [ConvertedPageContext](./convertedpagecontext) | Definierar kontext för konverteringssida. |
| [Converter](./converter) | Representerar huvudklassen som styr dokumentkonverteringsprocessen. |
| [ConverterSettings](./convertersettings) | Definierar inställningar för att anpassa [`Converter`](../groupdocs.conversion/converter)-beteendet. |
| [FluentConverter](./fluentconverter) | Klass för flytande konverteringsinställning. |
| [License](./license) | Tillhandahåller metoder för att licensiera komponenten. Läs mer om licensiering [här](https://purchase.groupdocs.com/faqs/licensing). |
| [LoadContext](./loadcontext) | Definierar laddningskontext. |
| [Metered](./metered) | Tillhandahåller metoder för att tillämpa [Metered](https://purchase.groupdocs.com/faqs/licensing/metered)-licens. |
| [SaveContext](./savecontext) | Definierar sparningskontext. |
| [SavePageContext](./savepagecontext) | Definierar kontext för sparningssida. |
