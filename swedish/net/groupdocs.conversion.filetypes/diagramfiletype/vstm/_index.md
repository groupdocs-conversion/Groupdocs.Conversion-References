## DiagramFileType.Vstm field

Filer med VSTM‑extension är mallfiler som skapats med Microsoft Visio och som stöder makron. Till skillnad från VSDX‑filer kan filer som skapats från VSTM‑mallar köra makron som utvecklats i Visual Basic for Applications (VBA)-kod. Läs mer om detta filformat [här](https://wiki.fileformat.com/image/vstm).
