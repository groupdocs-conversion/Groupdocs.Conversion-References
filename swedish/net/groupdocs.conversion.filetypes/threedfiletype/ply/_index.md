## ThreeDFileType.Ply field

PLY, Polygon File Format, representerar ett 3D‑filformat som lagrar grafiska objekt beskrivna som en samling polygoner. Syftet med detta filformat var att skapa en enkel och lätt filtyp som är tillräckligt generell för att vara användbar för ett brett spektrum av modeller. Läs mer om detta filformat [här](https://docs.fileformat.com/3d/ply).
