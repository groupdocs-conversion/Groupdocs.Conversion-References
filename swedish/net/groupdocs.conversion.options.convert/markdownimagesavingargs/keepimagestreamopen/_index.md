## MarkdownImageSavingArgs.KeepImageStreamOpen property

När falskt (standard) stänger konverteraren [`ImageStream`](../imagestream) efter skrivning — idiomatiskt för FileStream‑ersättningar som bör skrivas till disk. Sätt till true för att hålla strömmen öppen efter att konverteringen är klar (typiskt för en MemoryStream som du avser att läsa själv); anroparen ansvarar då för borttagning.

public bool KeepImageStreamOpen { get; set; }
