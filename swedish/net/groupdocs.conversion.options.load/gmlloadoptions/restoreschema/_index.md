## GmlLoadOptions.RestoreSchema property

Bestämmer om Conversion får tolka attribut i en Gml‑fil där ett XML‑schema saknas eller inte kan läsas in. Om den är satt till true kräver inte Conversion‑läsaren närvaron av ett XML‑schema. Standardvärdet är false.

public bool RestoreSchema { get; set; }
